# 汇报与设计 Kit

独立的一目，服务PM/FDE的发现、定义、决策、对齐、交付、评估及复盘材料。

使用流程：`source → claim/evidence → artifact grammar → audience adaptation → visual/writing grammar → renderer → review`。

先说明读者、他们需要做的决定和已有上下文，再选memo、pre-read、deck或HTML。页面围绕一个论点；可视化由比较、趋势、分布、关系或流程问题决定。反AI套话是内容与证据约束，不是添加装饰。
