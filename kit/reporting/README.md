# 汇报与设计

用于发现、定义、决策、对齐、交付、评估及复盘材料。

1. 填写 [Reporting brief](../../templates/reporting/README.md)：读者、需要的决定、上下文与材料类型。
2. 按 [材料路由与使用契约](grammar.md) 组织主张、证据、叙事与呈现。
3. 从 [结构化提炼与本地设计材料](../../vault/distilled/reporting/README.md) 选择样例；原件及离线依赖状态见 [快照](../../vault/snapshots/README.md)。
4. 按 [材料与呈现验收](../verification/README.md) 检查引用、图表、决策请求及导出结果。

产物：可独立阅读、证据可追溯且决策请求明确的材料。

查证与重访：[逐源登记](../../vault/provenance/reporting/README.md)；分类理由：[材料分类提炼](../../vault/distilled/reporting/material-classification.md)。
