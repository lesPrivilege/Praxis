# Reporting · 材料目的与组织决定

先决定材料要让谁理解什么、比较什么或采取什么动作，再选择表达模式。

1. 填写 [Reporting brief](../../templates/reporting/README.md)：读者、期待、阶段、证据、张力与 Ask。
2. 读 [组织动作与文体选择](grammar.md)，形成主张、替代方案和所需决定。
3. 到 [Write](../write/README.md)选择成文、空间编排或时间叙事；视觉与交互取舍按需进入 [Design](../design/README.md)。
4. 交付按 [内容验收](../write/shared/verification.md)与 [分层验收](../verification/README.md)分别检查材料和业务接收。

产物：事实可追溯、论证自足且下一动作明确的材料。开放题答卷另用 [Prose / Genres](../write/prose/genres/assessment-answer.md)，不是所有汇报的默认文体。
