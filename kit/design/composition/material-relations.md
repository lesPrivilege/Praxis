# 材料关系 · 制作约束作为图形语法

本页是跨材料的普通参考：把可证实的制作约束转成可操作的软件关系时，保留原材料的单位、连接和使用情境。它不提供预设皮肤，也不把不同文化和工艺说成同一件事。来源卡保留各自用语与边界；本页的设计转换是本 Kit 的推演。

## ASA-G-ANDEAN-WOVEN-GARMENTS · 经、纬与服饰的约束

### 语境、术语与归属边界

古代安第斯纺织是跨多地区、时期和结构的材料实践，不是单一风格。此条只以 Met 对安第斯织物结构的一般综述和两件确切对象记录为依据：一件晚期 Chimú tapestry-woven shirt；一件早期 Nasca 的 Poncho or Tunic，被馆方登记为 discontinuous warp and weft。Met 公报将古代衣物放回穿着、身体动作和社会传递的语境，同时承认特定图像意义难以从现存材料恢复。它没有提供当代织作者词汇或全面传统史，因此本文保留英文来源术语，不自行造一个看似普适的本地术语。

- [ASA-M-01：Met, *Weaving Abstraction in Ancient and Modern Art*](../../../vault/provenance/art-software-atlas/material/cards/asa-m-01-weaving-abstraction-ancient-and-modern.md) · Embracing the Grid
- [ASA-M-02：Chimú Shirt, object 1979.206.588](../../../vault/provenance/art-software-atlas/material/cards/asa-m-02-met-chimu-shirt.md) · object description / artwork details
- [ASA-M-03：Nasca Poncho or Tunic, accession 34.1579](../../../vault/provenance/art-software-atlas/material/cards/asa-m-03-brooklyn-nasca-poncho.md) · object label / key information

**出处事实。** Met 综述描述 backstrap loom 由织者倾身调节经线张力；其 tapestry weave 文字说明是纬线密集覆盖经线。Nasca 物件记录的 discontinuous warp and weft 则指经、纬线都会随色区与织作时段而改变，不应与连续经纬布面混为一类。衣物可能被穿着，也可能在历史上改制。两件对象的记录可支持具体媒材与馆方描述；不能支撑每一个人物或符号的确定释义。上述对象文字确已读取，但图像未能实际打开；下文不把形态观察伪装成看图结论。

**感知和传意目标。** 用材料结构说明图案如何依赖织造关系，而非把布当作任意的矩形像素画布。服饰视图可需考虑穿着时的整体、局部、背面和开口；若内容语境关乎人物、身份或社会传意，织物既是图像载体也是有重量、边缘、接缝并随身体动作变化的物。

### 可操作构件与不变量

1. **定义 loom / cloth 框架。** 经线与纬线各有自己的纱线身份、路径、颜色、材料、张力或密度说明；明确由哪一方向遮盖哪一方向。平面视觉格点不能替代上下穿插关系。
2. **区分连续布面与色区接续。** 连续布面可按纬线逐道记录穿越的经线；不同色区之间的经线或纬线是否连续，应作为拓扑数据，而非从颜色差异猜测。只有掌握接续方式时才表现 interlock、转折、回程和留出的开口。
3. **将衣物几何建成后续构造。** 面片、边缘、衣领、袖窿、缝线和穿戴方向有自己的可查关系；不可将裁剪后的服饰剪影当成单纯蒙版，因为作品可能原为面板后改制，或由多幅织片缝制。
4. **图样的构成方向要随织造网格变化。** 不同区域的密度、纬线回程、缝接或开缝可能造成局部视觉转折；不要先画一张不受约束的图再把“经纬纹理”作为滤镜叠上去。
5. **将身体与观看状态设为明确的视图。** 展平图、穿着图和背面图是不同投影。需要运动时另建姿态或折叠假设；未核实的内容标为示意，不填补为传统事实。

### 两种实现方式

- **SVG：线段 / path 与显式织物拓扑。** 为纱线存路径与 over/under 交叉数据，生成纱线中心线或放大细节图；用局部 clip path 限制边界，面板与缝线保留独立语义。优点是交叉顺序和单线走向容易检查，缩放适合出版；缺点是大批细密线条的 DOM 体量较大，普通 SVG stroke 视觉并不会自动体现压扁、毛羽、厚薄和张力。
- **Canvas：逐道沉积的局部栅格。** 按纬线 pass 顺序画入，再依交叉表遮盖经线；离散色区可维护单独的纱线段和左右连接状态。优点是逐行织造解释和高密度模拟灵活；缺点是绘制缓冲通常不携带“这段属于哪根纱线”的语义，需保留外部 graph / provenance 才能编辑或高保真输出。

若交互的任务是读懂色区连接，使用纱线图和穿插顺序；若任务只是比较服饰版面，可用更轻的二维区域图，但旁边说明所省略的结构。一个可编辑像素图或 SVG 条纹只能在其声明的范围内使用，不能据其外观就称作织物模拟。

### 建构夹具

可为离散织造流程建立小型构造测试：生成 6 根经线和 4 道纬线，给经线分配可识别颜色；每道纬线逐根穿过全部经线，在相邻格点交替记录覆盖关系。第二步在一组相邻列中插入色区分界，要求系统只能在显式登记的方式下处理连续跨色纬线、区域内往返或共享边连接。改变列宽和纱线密度后，检查已登记的穿插拓扑仍保持不变。该夹具只测试软件的数据模型和连通性，不声称重建这两件古代作品或特定传统技法。

Nasca 物件可作为未来的复杂测试目标：其馆方描述要求系统允许经纬在色区间都发生变化；在未看到结构图前，不断言如何实作内部交界或产生哪种结边。

### 失败边界与反例

- 将所有面表示为无限连续的经纬栅格，会抹去 Nasca 来源描述的离散经纬拓扑。
- 将 tapestry weave 仅做成图像滤镜，可能忽略纬线遮住经线这一结构事实。
- 只展示二维展开稿，便声称已经解释穿着动作或身份意义。
- 把馆方对整体安第斯 textile 的社会用途说明套给每个具体图案，或把馆藏对象当成所有安第斯社区的代表。
- 以现代极简抽象风格套色代替史料不明的图像解释。

### 后续相邻研究

补读有图版的具体构造分析与当代安第斯织作者材料；核对当地术语、织机差异、接经和接纬规则、色区边界、纱线整理与作品如何从织机转成衣物。对当前对象，先获取可放大图像，确认前后片、织片与边缘，再选技术性复原夹具。所有现代设计转译都标为当代实验。

## ASA-G-ISLAMIC-GEOMETRIC-SURFACES · 几何纹样与建构方法

### 语境、术语与归属边界

Islamic geometric patterns 是跨区域、时代、载体和工艺的馆方综述标签；具体图案并没有一个由此自动推出的生成方法。某一研究提出历史上部分 girih 纹带可由带线多边形（girih tiles）镶接而成，同时也承认 straightedge / compass 的连续线法等替代解释。V&A 的拼贴、折叠和印章练习是今天面向儿童的馆教活动，不是工艺史档案。此处将历史对象描述、来源中的研究假说与本 Kit 的软件设计推演分开。

- [ASA-M-04：Met, *Geometric Patterns in Islamic Art*](../../../vault/provenance/art-software-atlas/material/cards/asa-m-04-met-geometric-patterns-islamic-art.md) · 分类、应用媒介和综述限制
- [ASA-M-05：Tile 1972.88, Bukhara / Samarqand](../../../vault/provenance/art-software-atlas/material/cards/asa-m-05-met-entrelacs-octagon-tile.md) · stonepaste 刻纹施釉单件
- [ASA-M-06：V&A 教育活动页](../../../vault/provenance/art-software-atlas/material/cards/asa-m-06-v-and-a-tile-activity.md) · 当代教学转译
- [ASA-M-07：Lu & Steinhardt, “Decagonal and Quasi-Crystalline Tilings...”](../../../vault/provenance/art-software-atlas/material/cards/asa-m-07-science-girih-tilings.md) · 研究模型和限制

**出处事实。** Met 综述讨论圆、多边形、星形等重复单位及其组合，并指出复杂图样可能跨越多种分类；建筑与器物皆见几何纹饰。具体 Met tile 的馆方文字将其描述为一片可能出自陵墓檐带的石质陶土砖，刻纹、绿松石 / 深紫釉、两处八边形主形和半八边形交织带。Lu 与 Steinhardt 的文章摘要及可读讨论提出 girih tiles 的历史解释，同时引用有图网格的备择做法，并限制了他们关于历史工匠是否理解现代准晶概念的断言。论文全文与补充材料未完整核查。V&A 折纸、剪贴和印章步骤仅作为教育活动记录。

此处没有目视具体瓷砖、手稿或建筑纹带；视觉关系只按馆方文字登记。不要从 Islamic 标签直接推导反人物规则、宗教含义或历史制作流程。Met 综述本身指出几何纹样可与人物表现共存；单件和研究者复原模型也不足以代表跨地域方法。

### 感知和传意目标

将纹样当作铺在某个有边界、有接缝、有厚度载体上的关系系统：重复关系、交错顺序、留白、尺度和区域终止可成为可操作变量。可让读者看见建构过程或几何关系；不必通过“东方神秘数学”一类文化刻板意象赋予其含义。对象纹样的意义由原语境和有依据的解释说明，不由程序生成规则自行决定。

### 可操作构件与不变量

1. **声明建构模型。** 选择并标注连续网格线构形、中心射线 / 角度分割、或候选多边形 tiles 等模型。除非有对象证据，不能把一种模型写为来源作品的既定历史步骤。
2. **先声明基元和连接契约。** 对多边形 tile 写入边 ID、邻接边、旋转 / 镜像许可、内嵌纹带端口和可组成邻居；每条边的条带必须能与相邻单位无缝连接或以可解释方式终止。
3. **分开骨架和载体 / 施工层。** 几何中心线、路径交错序、底色、切缝、刻纹或釉色层各自建模。线条跨越边界的连续性不自动证明砖块怎么切，也不说明釉色如何制作。
4. **处理平铺与裁切边缘。** 在无限平面生成后，以明确的视口 / 构件边界裁切；继续显示边缘或邻件提示，区别图形截断与历史图案本身结束。
5. **解释尺度和对称是选项而非主题默认。** 旋转、反射、平移或比例变化必须来自模型或实际对象证据；不要为了把纹样强行填进不合比例的矩形而扭曲边角。

### 两种实现方式

- **SVG：解析式线稿 / polygon adjacency graph。** 以精确顶点和半边拓扑表达基元，把共享边只建一次；纹带以中心线、显式交叉序和图层表示；对整体作 pattern 平铺或单独 clipPath 到墙面 / tile。优点是小规模构造可读、容易挑出断线与端口冲突；缺点是曲面、真实雕刻深度、窑变釉面或复杂多层交错需要额外表示，不能仅凭 path 冒充实物。
- **Canvas：按单元和图层栅格化。** 先生成 adjacency / hidden-grid 数据，再按背景、底色、槽线、装饰带、交叉遮挡顺序绘制；图案若需交互，可缓存 tile 的多尺度缓冲区。优点是适合密集纹带和局部缩放；缺点是光栅缩放、碰撞选取和路径身份需额外语义图，否则细节只是一张不可解释的位图。

两法都需维护模型 provenance 与真实作品标注的分离。SVG / Canvas 是实现选择，不是 Islamic 几何的历史属性。若产物任务只需讲重复关系，可提供可切换的草稿网格；当页面介绍特定工艺时，除非来源支持，勿让隐藏网格动画看起来像历史重演。

### 建构夹具

为单个长方视口设一个显式八边形底单元，并用相邻半八边形端口连接其中心线纹带；逐边检查邻接后的带线方向、共享边是否恰好落一次、交叉的上 / 下次序是否一致，裁切后保留可追踪的边缘端口。用 Tile 1972.88 的文字记录创建“观察待核对”的测试标签：模型只能标注描述中的八边形、八角星、花形与半八边形交织关系，不能声称所建即历史原型。之后以实际图像替换文字推测，验证比例、边界与颜色层。

若实现 girih tile 的方法实验，单独创建两套可替换生成器：tile adjacency 与连续隐藏网格；输入同一局部区域后比较可解释性、错误累积、边缘闭合和编辑成本。二者是现代的软件实验，不能声称完全复原作者方法；结果需连同研究论文假说与其争议一起标示。

### 失败边界与反例

- 把全世界、多世纪作品强行降成统一十角星 tile 套件。
- 把数学上能拼成周期 / 非周期图样当成历史匠人意图、知识范围或宗教思想的证据。
- 将 V&A 儿童拼贴练习描述成中世纪工匠步骤。
- 仅以一件 tile 证明一个完整墙面使用同一周期、同一网格或同一配色。
- 用无限平铺图隐藏真实墙面接缝、砖片边缘、场地裁切和工艺误差。
- 将简单生成的星纹当成可取代原件视觉核对或文化归属解释的 look。

### 后续相邻研究

获取清晰图像并核对对象图版、原址空间和邻接构件；补读 girih 论文全文及支持材料、Topkapi Scroll 原图、手稿研究和替代直尺 / 三角板构造论证；再查不同地域的砖、木、石、灰泥与彩绘工艺以及当地制作词汇。以至少两个具体建筑或手稿比较方法差异，不要把复原后的图解当作原始施工记录。
