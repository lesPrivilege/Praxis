# Composition · 空间与编码

内容关系已经确定后，从需要解决的视觉问题进入。

- 层级、阅读顺序、主次与宽窄重排：读 [空间编排](layout.md)。
- 数量、状态、变化与关系如何可视化：读 [图形编码](encoding.md)。
- 窄屏要保留对象比较：先读 [按属性维持比较](../references/curated/comparison-continuity.md)。
- 注释要跨宽窄保持局部关系：先读 [注释保持邻接](../references/curated/note-adjacency.md)。
- 需求用风格名表达（如“Swiss 味”）：先读 [视觉语言参考](../references/languages.md)，把名字换成一两条关系再回本页。
- 其他编排方法与历史样张：进入 [普通编排参考](../references/composition.md)；优先卡片的验收范围不是通用实现通过。

输出是能够被实际内容检验的布局或图形，不是一套强制主题。标题、description、图注、来源等内容职责在 [Write / Publish](../../write/publish/README.md)维护。
