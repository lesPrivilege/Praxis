# Motion · 运动与时间表现

先区分两类任务：

- 界面状态、定位与反馈需要运动：读 [运动判断](grammar.md)，保持可中断与真实状态一致。
- 文稿要成为视频或动态解释：先在 [Write / Motion](../../write/motion/README.md)确定分镜语义，再读本分支选择视觉运动。

本分支负责表现方式，渲染器接口留在具体项目。时长、曲线、镜头、材质与动态排印按任务选择。界面动效参考见 [C16–C21](../references/composition.md)。
