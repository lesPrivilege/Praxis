# 视觉语言与风格名参考

任务里出现风格名（“做一点 Swiss 味”“往 Bauhaus 方向”），或者想探索某种视觉语言时读本页。读后能把一个名字换成一两条可以在真实内容上检验的构成关系，再回 [Composition](../composition/README.md) 施工。问题只是间距、表单、状态或可访问性时不必读。

本页是 [构成关系与问题地图](../foundations/relations.md)的一种取用方式：名字只是找到关系的线索。没有合适的名字时直接从问题地图起步。

八个条目都是 `distilled / reference`，取用优先级 normal；证据状态逐条不同，见末列。它们不是主题包：不附带字体、配色、圆角或动效的默认值。

## 名字怎么用

1. 先确定读者要完成什么，取舍有争议时回 [设计判断](../foundations/grammar.md)。
2. 从条目里取一两条关系，在真实内容上排一版。
3. 按问题地图的 [检验方法](../foundations/relations.md#怎样检验一条关系)做对照：只换字体和颜色的一版、加长的一版、收窄的一版。
4. 在项目 index 记条目 ID、借的是哪条关系、自己定的参数和一处失配。

“可以试的关系”来自对原作的文字描述，转到界面上是推断，不是来源的主张。历史来源能证明原作做了什么，不能证明今天的页面该怎么做。

每条的完整解释在 [包内条目](../../../vault/snapshots/local/design-grammar-atlas-20261002/profiles/index.md)，逐来源的重访结果在 [来源卡](../../../vault/provenance/design-grammar-atlas-20261002/cards/README.md)。重访读的是文字；原作图像本仓库只看过 H01 页内的一张 Hofmann 海报，其余都没有看过。要把某件原作当视觉参照，或要用它的图片、字体、采样，先打开原件并另查许可。

八个名字不在同一层：有学校，有具体团体，有回溯性的大类，也有网络时代的后设标签，彼此可以重叠。它们来自一次研究的检索起点，偏重西方和互联网视觉文化；没有合适条目时退回任务和关系，不硬凑流派。
