# 设计

跨项目可复用的设计知识：外部成熟做法的选用结论、已经裁决过的取舍，以及可以直接参考的产出。它从各项目的施工记录中裁出通用部分，本身不是项目规范。各项目保留自己的 index 与 grammar；项目需要设计支持时从这里取用，裁决和消费记录写回项目自己的 index，只有能跨项目复用的结论才回流到这里。

| 层 | 位置 | 内容 |
|---|---|---|
| 1 | 本页 | 按任务分两支的原则与选型结论 |
| 2 | [参考索引](references.md) | 每条外部参考的状态、取用内容、消费位置和证据位置 |
| 3 | [vault](../../vault/README.md) 中的快照、来源目录与项目记录 | 原件、读取范围、核对日期 |

逐层按需展开：先在本页找到相关条目，需要依据时进入参考索引，需要原文时再进入 vault。每条结论后的编号对应参考索引中的依据。

## 内容与数据可视化编排

适用于长文、答卷、报告和说明页。

**论证先于版式。** 页面层级是问题—答案树的投影：每题、每节先问后答，理由、证据和条件依次跟上。标题承载命题，不只是主题名。编号和分隔线只表示真实的层级。（C07、P01）

**按论证关系选择表达方式。** 条件用分支图，比较用共同尺度的对照，数量用同尺度的图并附精确值，状态用状态图，变更用结构 diff，连续推导用正文。不为每个节点都配图。（C07、C06）

**图文分工。** 正文负责推导，图承担关系；比较的前提紧挨着图；图不复述正文，图注写明主张。（C04、C06）

**线图语法。**
- 实线表示已发生或已确定，虚线表示候选或尚未发生，线宽表示当前状态。
- 一张图只在需要人决定处用一种强调色。
- 宽版与窄版共用同一个图注。
- 去掉颜色后，状态也要能读出来；高对比度模式下改用系统前景色与背景色。

（C01、C02、C03、U04）

**数据。** 数量图从零起算；直接标注，不用只靠颜色的图例；每张图配精确值；假设和构造数据标明身份；没有数据就不画曲线；刻度不按比例时写明。（C05、C22）

**排印。**
- 层级靠字号与字重，不靠颜色和框线；字号只用几档具名的尺寸。
- 衬线只用于顶层标题。
- 中文正文每行约 40 字；中英文之间自动留空；标题在标点处换行。
- 表格按基线对齐，数字右对齐，首列作行标题。

（C04、C22、C25、U05）

**导航与位置。**
- 宽屏用章节标签，窄屏用原生折叠菜单；关闭 JS 时全文依次可读。
- 翻页条显示当前章节、当前小节和本章阅读进度。
- 小节少时不用吸附侧栏。

（C08、C09、C13、C14、C15、C20）

**动效。**
- 只在状态变化处使用：换页、数值重算、菜单展开；时长不超过 240ms，缓出。
- 键盘操作不加动画。
- 开启减弱动效时只保留淡入。
- 不做滚动时逐段淡入。

（C16、C19、C21）

**色彩。** 浅色冷调，一种强调色；不用暖色、渐变、玻璃拟态或装饰纹理；颜色不单独承载状态。（C22、C23、C25）

**交付。**
- 单文件、离线可读、没有外部请求。
- A4 打印每章另起一页，带页码。
- 375px 宽度下没有横向溢出。
- 图中文字不超出所在的框，用脚本检查。

（P01）

## 产品软件界面

适用于工作台、控件与交互状态。组件候选与验收矩阵见 [kit/ui](../ui/README.md)。

- **命中区与缩放**：命中区 24px 为下限，触控与高后果操作 44px；200% 缩放与调整文字间距后仍可读，不固定高度裁切。（U01、C17）
- **标签页**：标签页标识对象、版本与范围；关闭和切换只是视图动作，不等于取消、删除或批准。（U02）
- **表面层级**：分组靠留白、对齐和字阶；卡片只给独立对象，不嵌套卡片；提示框不承载必要信息，也没有只能悬停才看到的信息。（U04、C22）
- **状态**：
  - 录入、启用、已用、已加载分别标示；
  - 请求发出后结果未知，单独作为一个状态；
  - 没有真实进度，不画百分比或预计完成时间。

  （U03、U06、U07）
- **字阶**：正文不动，界面文字降一档。（U05）

CW 的设计入口是 `engineering/design/README.md`、`sources.md`、`decisions.md` 和 `scout/README.md`。它的记录状态标注严格，但决定台账停在 2026-09-08；取用前对照当前提交复核。

## 增量

1. **发现**：explorer 召回或检索到新做法，先按[入账规范](../../docs/governance/intake.md)登记到 vault，附原始地址、读取日期和读取范围。
2. **候选**：在参考索引加一行，状态为 `candidate`，写明打算取用什么。
3. **裁决**：在具体任务中使用后，改为 `accepted`、`rejected` 或 `deferred`，写明理由和消费位置。状态词沿用[状态词表](../../docs/governance/status-vocabulary.md)。
4. **回流**：结论能跨项目复用时，才写进本页；只对一个项目成立的，留在该项目的 index。

同一来源只保留一个登记位置，其他地方链接过去。上游能力覆盖了某条做法时，把该条改为 `superseded`，写明替代位置，不直接删除。

## 项目取用

其他项目取用本页时，在自己的 index 中记录 Praxis 提交、用到的条目和参考编号（如 C08、U04），以及本项目的裁决。本页更新后，项目按自己的节奏复核，不自动跟随。
