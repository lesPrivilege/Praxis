# Foundations · 设计判断

有多种视觉方案、担心个人样式被写成普遍规则时，读 [判断契约](grammar.md)。输出是与任务相关的取舍依据和检验范围。

视觉诉求还说不清是哪类问题，或手头没有合适的参考、样张时，读 [构成关系与问题地图](relations.md)：十五个构成问题、各自要保住的语义和检验一条关系的方法。形状、图像、材质、色彩分工、中文与双向文字这些还没有专门分支的问题，也从那里起步。

要在同一张图或同一页里区分已经定了的、还没定的和等人决定的内容，读 [成立程度与归属的标记](standing.md)。一句话要挂在别的东西上（证据对主张、条件对几个字、判断对某个版本），读 [精确指向](anchoring.md)。两页各给一套“只用文字、一张图、几张图连起来”的三级做法。

确定具体操作后转 [Composition](../composition/README.md)、[Interaction](../interaction/README.md)或 [Motion](../motion/README.md)。按需读，不把每份材料都变成完整设计研究。
