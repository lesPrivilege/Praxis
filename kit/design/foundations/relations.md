# 构成关系与问题地图

Design 的可复用单位是一条构成关系：谁相对谁怎样组织，为了让读者辨认什么。风格名、样张、原子、组件都是这条关系在某份内容上的一次取用。读本页可以把一个模糊的视觉诉求换成一两个能检验的问题，再去对应分支施工；没有合适的条目或样张时，本页仍然够用。

本页给问题和要保住的语义，不给参数。字体、色值、圆角、时长由具体任务决定。

## 一条关系要说清什么

- 目的：读者要辨认、比较或完成什么。
- 关系：哪两个元素、层级或状态之间，怎样组织或变化。
- 范围：对哪类内容和媒介有意义，哪里不适用。
- 自由处：哪些可以随任务改。
- 反证：出现什么结果就说明它不成立。

粒度用一个问题检查：只改这一项，能否说出预期会看到什么、可能在哪里失败。“做一个 8 像素圆角”太小，没有目的；“做一整套温暖品牌界面”太大，无法归因；“角部处理怎样区分可操作层与静态层”可以检验。几个量共同构成一项关系时可以一起改，但要说明它们怎样耦合。

## 十五个问题

先找到当前卡住的那一个，再沿“相关”看一两个邻居。不必通读，也不是检查表。

| 问题 | 可以调的 | 换什么都要保住的 | 相关 | 本地规则 |
|---|---|---|---|---|
| G01 构图：先看什么，哪些内容是一组 | 优先级映射、对齐参照、主从面积、分栏与例外位置 | 标题归属、叙事与步骤顺序；重排后的程序化读序仍合理 | G07、G11、G12 | [空间编排](../composition/layout.md) |
| G02 字体：层级和声音怎样可读 | 字体角色、字号比例、字重、行长、行距、数字样式、后备字体 | 字符不缺失；层级不只靠外观；数字和标签不被截断；文字能放大 | G07、G12、G13 | 无专门规则；见 [界面参考](../references/interface.md)与 [编排参考](../references/composition.md)的字阶条目 |
| G03 色彩：颜色承载身份、层级还是数据 | 角色分配、明度与色度跨度、强调色面积、表面与内容配对、明暗映射 | 信息不只靠色相；同一状态或数据含义不随换肤改变；文字与图形的对比 | G06、G09、G10 | 部分：[图形编码](../composition/encoding.md)、[状态与可达性](../interaction/states.md) |
| G04 形状：外形怎样表达可点、分组与包含 | 轮廓家族、角曲率、内外角关系、描边与填充、可见尺寸与命中区 | 动作与对象身份；内容安全区；命中区不等于可见轮廓 | G02、G07、G09 | 无 |
| G05 图像：在解释、证明、导航还是营造气氛 | 图像角色、裁切锚点、景别、占比、序列、图注位置 | 证据不被裁切误导；信息图有等效内容；装饰图不制造朗读噪音 | G01、G03、G11 | 无；内容职责见 [展项](../../write/publish/exhibits.md) |
| G06 材质：怎样表达前后层、边界与临时覆盖 | 不透明度、模糊、纹理、描边、阴影、遮罩 | 层级、文字可辨、控件边界；去掉透明和阴影后结构还在 | G03、G08、G09 | 无 |
| G07 密度与节奏：一屏放多少，哪里停顿 | 每组项数、组内与组间距离之比、重复节拍、辅助信息显隐 | 分组与比较关系；标签完整；重要信息不因紧凑而藏起 | G02、G04、G10 | 部分：[空间编排](../composition/layout.md)的容量检查 |
| G08 运动：变化说明了什么因果、位置或状态 | 目的、起止状态、路径、时长、缓动、幅度、同时运动的数量、降级方式 | 最终状态与对象对应；结果不只出现在短动画里；停止或降级后任务仍能完成 | G06、G09、G10 | [运动判断](../motion/grammar.md) |
| G09 交互状态：人怎样知道能做什么、正在发生什么 | 状态图、触发条件、多通道表达、反馈持久性、焦点迁移、恢复路径 | 各状态含义不混淆；名称、角色、值与实际行为一致 | G03、G04、G08 | [状态与可达性](../interaction/states.md) |
| G10 图表：读者比较哪种量，编码是否忠实 | 数据任务、编码、尺度与基线、排序、分组、标签、类别/顺序/发散色义 | 原始值、单位、分母、时间范围、缺失与零、类别身份、参考点 | G02、G03、G12 | [图形编码](../composition/encoding.md) |
| G11 编辑：内容以什么顺序、长度和语气被理解 | 结论、证据、行动的先后；标题粒度；段落长度；列表或叙述；注的位置 | 事实、限定条件、来源；删短不能删掉关键的不确定性 | G01、G05、G10 | [Publish 编排](../../write/publish/composition.md) |
| G12 适配：媒介和空间变了，哪些关系要重构 | 内容压力触发的断点、行列转置、换行与截断、信息优先级、输入能力 | 核心任务、读序、标签与数据语义；不靠隐藏必要内容换整齐 | G01、G02、G10 | [空间编排](../composition/layout.md)、两张 [优先参考](../references/curated/README.md) |
| G13 中文排版：字种、地区与横竖排怎样影响段落 | 地区与字形、标点位置与挤压、禁则策略、中西文与数字混排、标题断行 | 文本与数值单位、标点配对、语言标识；简繁不等同地区 | G02、G07、G12 | 只有一句：[Publish 编排](../../write/publish/composition.md)；断行与字重的观察见 A01 |
| G14 双向文字：内容怎样既正确存储又正确呈现 | 基础方向、内嵌片段的方向与隔离、逻辑起止边、需要镜像的图标 | 字符存储顺序、数字与产品名、成对标点、读序；不整串反转，不镜像一切 | G01、G09、G10 | 无 |
| G15 空间与声音：深度和声音是否帮助定位、因果或情境 | 参照框架、深度与遮挡、声源锚定、反馈频率与音量 | 重要提示有替代通道；可静音；动作与声源对应 | G05、G06、G08 | 部分：[时间叙事](../../write/motion/narrative.md)的音画分工 |

“本地规则”为“无”或“部分”的九项，本页给出的问题和要保住的语义就是当前全部指引。更细的候选笔记、可做的原子比较和逐条来源在 [提炼与裁决](../../../vault/distilled/design-grammar-atlas-20261002/README.md)，按需回查。

## 约束强度

三种强度按 [体例契约](../../../docs/architecture/documentation.md)区分：

- “换什么都要保住的”一栏是内容与语义的边界，换表现方式不得破坏。
- 外部标准的数值门槛（对比度、目标尺寸、重排、减少运动）只在项目明确采用某个标准、版本和级别后成为规则，例外跟着条款走。本页不替项目采用任何标准。
- “可以调的”一栏全是风格取舍，由任务决定。

某个设计系统的默认值不是普遍规则；一次样张里好看的数值也不是。

## 怎样检验一条关系

1. 内容固定，只改关系。用真实内容，或标明是合成的夹具；不删难排的文字，不换更好看的图。
2. 加一版只换字体和颜色的对照。两版先读到的东西相同，差别就不来自关系。
3. 把内容加长、把宽度收窄各看一次，记下最先失效的地方。失效处常常不在关系本身。
4. 需要说“可复用”时，换一种媒介或另一份内容再做一次。固定的是解释和目的，不是像素。
5. 少做。先挑最有区分度的一对；新增一个样张的理由是消除一个具体的不确定，不是填满矩阵。
6. 分开记：自动检查能证明文字完整、没有溢出；先读到什么、好不好看要人看图判断；读者效果要找读者。

记录写进项目 index 或样张说明：借了哪条关系、自己定了什么、保住了什么、一处失配。

## 取用方式

这些是同一套判断的入口，按手头的线索选一个：

| 手头有什么 | 去哪里 | 得到什么 |
|---|---|---|
| 一个风格名 | [视觉语言参考](../references/languages.md) | 名字对应的范围和可以试的关系（VL01–VL08） |
| 一个编排难题 | [Composition](../composition/README.md)、[优先参考](../references/curated/README.md) | 规则、已验收的结构方法和样张家族 |
| 想看一条关系落到内容上的样子 | [A01 阅读关系样张](../../../vault/distilled/design-grammar-atlas-20261002/a01-reading-relations/README.md)、[编排实验](../../../vault/distilled/layout-specimens-20260927/README.md) | 同内容多关系的对照与失配记录 |
| 准备自己打样 | 包内 [打样提案与夹具](../../../vault/snapshots/local/design-grammar-atlas-20261002/briefs/atomic-task-proposals.md) | A01–A04 四个问题和 F1–F3 三组合成内容，只作参考 |

条目、样张和原子可以增删改名；问题地图和检验方法不依赖其中任何一个。
