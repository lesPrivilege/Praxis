# Motion · 时间叙事

将既有论证转成有时间顺序的视听表达。先读 [叙事与分镜交接](narrative.md)，确定每段时间承载的认知任务，再去 [Design / Motion](../../design/motion/README.md)选择运动与表现。

有旁白或屏幕文字的片子同时要用到 Prose：旁白按 [口播旁白体例](../prose/genres/narration.md)撰写，屏幕上的结构文字按 [成文原理](../prose/grammar.md)第 5 条撰写，两者的审阅见叙事页的“旁白与屏幕文字的审阅”一节。

交付：可与原稿核对的分镜/时间线、字幕或屏幕文字、来源配套、实际观看记录，以及 [4:3 与 3:4 原生封面](narrative.md#多平台封面)。封面画幅与成片画幅独立。证据身份沿用 [Shared](../shared/evidence.md)。运行实现见下列项目。
