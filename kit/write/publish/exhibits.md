# 展项与说明

输入为有来源的证据、关系或合成示例；输出为读者能独立理解并回查的图、表或引用片段。

图、表、引文或示例作为主展项（exhibit）时，按需要交代以下职责，不要求每项都成为独立文本块：

| 成分 | 读者需要得到什么 |
|---|---|
| 标题 | 这部分回答的问题或支持的判断 |
| Description / 引介 | 正在看什么、比较范围、必要前提和阅读口径 |
| 图表或内容主体 | 实际承载数量、关系、引文或示例的证据 |
| Annotation / 图内标注 | 关键差异、例外、方向或局部解释 |
| Caption / 图注 | 使主展项可独立理解的必要结论或限定 |
| Source / 来源 | 产生证据的来源身份、时间与精确定位；对外交付只链接可披露的来源或经检查的公开证据索引 |
| Method note / 方法说明 | 计算、抽样、转换与未覆盖范围中会影响判断的条件 |

来源跟随所支持的主张或展项，完整登记留项目内部 index；对外索引是经过披露检查的投影，不能直接暴露原 Chat、本地路径、身份映射或其他内部登记。具体按 [证据与来源](../shared/evidence.md)处理。图注、引介与正文各自承担信息，不重复同一句总结。引文保留原意和定位，假设示例与真实观测分开。对于采用正文/index 分离的答卷，遵循 [回答体例](../prose/genres/assessment-answer.md)：正文保留影响推理的条件，登记字段集中在适用的 index，不机械添加这些标签。

Markdown、HTML、PDF、Slides 和视频是不同投影。同一主张的证据身份、限定条件与引用关系应在转换后保留；导航、页序、字幕、音频和时间节奏按实际媒介验收。HTML 可使用语义标题、列表与表格表达相应关系，不能只凭 CSS 外观赋予内容身份。

这些职责是本仓库对讨论材料的消费裁决，见 [ADR-015](../../../docs/decisions/015-kit-editorial-contract.md)。完整内容原子注册表、canonical specimen 与 renderer schema 尚未建立；由后续实际交付产生样本和失败证据，再决定是否需要独立维护。
