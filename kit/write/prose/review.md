# 成文审阅

用于改写、审校以及逐条裁决他人的修改。输入是原稿、不可损失的信息与审阅意见；产物是成文和可解释的修改记录。

## 执行次序

1. 列出不可损失项：任务所需的事实、数字、单位、条件、限定词、证据身份、术语及推理关系。
2. 按问题和对象之间的关系组织内容；每个问题有实际回答，必要条件在判断或行动之前可见，不规定回答句数或叙事次序。
3. 成文。
4. 逐段检查信息作用与连贯：删后是否损害理解或任务完成，下一句为何接得上，必要复杂度和重复是否保留。
5. 通篇检查句式是否重复：对照否定（“不是……而是……”）、短句收尾、自问自答、数目预告（“有两件事”“分三步”）和对称排比，各出现了几次。内容需要这个区分、停顿或数目的地方保留；只因顺手而重复的，按语境改成别的说法。换的是句式；术语不换，同一概念仍用同一个词。
6. 单独检查结构位置：把标题、表头、行标题、标签、图注、一句话答案和画面上的短文字按位置类别列在一起看。同类是否并列，是否凝练成短语，有没有口语、直译搭配或从正文截来的句子；同一句话在几处出现时是否逐字一致，缩略时限定词是否还在。表格、图表、页面和视频画面的结构文字多，这一步交给没有参与撰写的审阅者，做法见 [结构文字的独立审阅](#结构文字的独立审阅)。
7. 对照第1步，确认不可损失项都没有改变。

## 审阅与裁决

审阅的目标是让成文更接近人类作者写出的中文。他人的审阅意见逐条裁决，不整包采纳。先核对准确性、信息作用、术语和适用范围，再判断修改是否改善连贯与读者理解。客观错误照改；让文字更接近人类作者、又不损失信息的改法采纳；在书面语体里把书面语压成口语、引入翻译腔、删去必要条件或证据身份、混淆概念的改动退回。每条标明采纳、改写后采纳或退回，并写一句依据。依据要指出具体问题，例如句式重复、直译搭配、口语进入结构位置；只说“更像人写的”不够。审阅者个人的用字偏好与语言、文体要求分开。

## 成文的独立冷读

成文写完，交给没有参与撰写、不带撰写上下文的审阅者读一遍。撰写者对自己写的句子有成见，念不出别扭的地方。

| 项 | 做法 |
|---|---|
| 交给审阅者的 | 成稿；审阅目标和委托方对上一稿的原话；适用的规则页 |
| 问题类别 | 句式重复、直译搭配与模型惯用的搭配、预告和表态、语体跳动、指代不清、不连贯、没有信息的句子。每条意见落到一类 |
| 不能动的 | 不可损失项；故意写成的段落和引文列为不审；分段、长度等交付约束 |
| 产出 | 意见表（位置、原文、类别、建议）；各类句式出现的位置；整体观察；“不必改、容易被误伤”的清单 |

主笔逐条裁决。建议里带着对事实的推断时，回到来源核对后再采纳。“不必改”的清单保护的是内容本身的对照、提问和必要重复，裁决别的意见时一并参考。口播的做法另见 [口播旁白体例](genres/narration.md)。

## 结构文字的独立审阅

撰写者带着正文的语感，容易把正文或旁白里的句子直接搬进标签。结构文字多的材料，由没有参与撰写、不带撰写上下文的审阅者只读审一遍。

| 项 | 做法 |
|---|---|
| 范围 | 只审结构位置，正文不在其内。把全部结构文字连同所在位置交给审阅者；清单从成品里抽（渲染后的页面、成片），不从草稿里抄 |
| 要找的问题 | 口语进入结构位置、直译搭配、同类位置形式不一、从正文截来的句子、同一句话在几处写法不一、语体跳动、公文腔、名词化 |
| 约束 | 含义、数字、限定词和证据标签不变；同列或同类并列；标签长度以原位置放得下为限；不为求变化而换同义词 |
| 产出 | 一张表：位置、原文、问题、建议，按严重程度排序；逐组的并列性检查；同一概念的不同叫法；“不必改、容易被误伤”的清单 |

主笔逐条裁决后落地，再检查改后的文字在版面里放得下。这套做法来自 2026-09-23 答卷的结构文字审阅，记录见 [答卷验收](../../../vault/distilled/ai-capability-assessment/rendered/verification.md)；2026-10-05 在一条知识片的画面文字上又用了一次，加了后三项产出。

## 交付

以最终成文为主要交付。改写、审校或裁决意见需要解释改动时，附简短记录：位置、原文、改后、理由；用户只要成稿或 diff 时按指定形式交付。

## 验收

- 不可损失项逐一核对，都没有改变。
- 术语含义与适用范围一致，语体符合任务。
- 结构位置没有口语和直译搭配，没有从正文截来的句子；同类位置形式并列。
- 同一种句式没有因顺手而通篇重复。
- 段落之间能看出关系；导航、情境、必要重复和条件未因缩短而丢失，无作用的旁白与客套已删去。

空格、标点和链接等机械问题按 [格式检查](format.md)处理。信息作用、逻辑、语体和连贯需要结合上下文判断，不用禁词表、固定句数或正则匹配代替审阅；检索只用来定位，例如找出某种句式出现在哪些位置。

## 来源

- 撰写凡例：沿用其中的第一性原理，即每个成分都承重、不对读者施力、对象作主语、证据分级。具体词汇、文言单字和音律规则不沿用，它们是个人语言习惯，难以稳定复刻。
- 能力测试答卷（2026-09-23 至 24）的撰写与两轮审阅：系统内部对象泄漏进正文、结构位置的语体、英文直译的搭配、独立审阅的裁决方法。记录见[答卷验收](../../../vault/distilled/ai-capability-assessment/rendered/verification.md)。

## 常见偏差

以下例子来自技术答卷和一条知识片画面文字的历史审阅，说明当时的取舍，不是替换词表。口播旁白的例子在 [口播旁白体例](genres/narration.md)。其他任务的口语、第一人称或不同搭配未必有错，仍按用途与上下文判断。

| 偏差 | 例 | 改为 |
|---|---|---|
| 内部结构直译成句子 | 首先形成的是这次事项的交付记录 | 律师交付这份合同，完成的是客户A的委托 |
| 口语进入结构位置 | 表头“该改的地方” | 修改位置 |
| 同一句式反复出现 | 全篇多处“不代表……” | 按语境换开：不等于、是另一回事 |
| 从正文截来的标签 | 面板标题“写在这一组上面的那句话” | 每组的概括句 |
| 口语的类目 | 图表类目“没用起来的 / 用起来的” | 首月未启用 / 首月已启用 |
| 同级标题不并列 | 凑三点 / 为切而切 / 最隐蔽的一种 / 有时不该先说结论 | 凑三点 / 为切而切 / 先定结论 / 埋没要点 / 不分场合 |
| 一个分句拆成两个标签 | “读者”“时间少”分列两侧 | 读者时间少 |
| 标签写成问句 | 空位上的“标题？”；“往哪儿放？” | 无标题；无处可放 |
| 同一句话几处写法不一 | 塔上“首月辅导能提高启用率”，缩略图上“辅导提高启用率” | 缩略也留着“能” |
| 悬空的指代 | 章首眉题“这个顺序” | 结论在前 |
| 同一列形式不一 | 要证明什么 / 比较方法 / 足以支持什么判断 | 待证明的结论 / 比较方法 / 可以支持的判断 |
| 英文直译的搭配 | 约束在送到模型之前就丢了 | 约束在送达模型之前已经缺失 |
| 翻译腔 | 模型需要知道两件事 | 最终要交付什么、上一步做到了哪里，这两点都要留在上下文里 |
| 口语情态与正反问 | 还得查清；输入是不是一样 | 还要查清；输入是否一致 |
| 公文腔 | 须予以阻断 | 直接阻断 |
| 证据身份丢失 | 演算里省下的33元 | 假设演算里省下的33元 |
| 限定词丢失 | 自动错误是少了 | 自动错误可能少了 |
