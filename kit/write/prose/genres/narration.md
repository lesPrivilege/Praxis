# 口播旁白体例

用于由人或合成语音读出、听的人只听一遍的文字：视频旁白、讲解词、播客稿。先守 [成文原理](../grammar.md)；本页只写口播与书面成文不同的地方。画面上的文字不归本页，按成文原理第 5 条和 [叙事与分镜交接](../../motion/narrative.md)处理。

## 为耳朵写

听的人不能回读，也看不到标点。

- **指代**：指代词紧跟它所指的东西。中间隔了别的名词，就把名词再说一遍。“委员会认定……不亚于那块泡沫；但它也在报告里……”，这个“它”会被听成泡沫，改成“但报告也……”。
- **主干**：一句话的主干先出来。“先说结论的理由，常见的解释是……”，开头会被听成“先说／结论的理由”，改成“为什么结论要先说，常见的解释是……”。
- **读音**：多音字、同音词、数字、英文缩写和外文短语，念出来有歧义的先换说法，例如“这句话得是一个判断”改成“这句话必须是一个判断”。换不了的列进读音清单。
- **叫法**：同一个东西只用一个叫法。一条因果链上的同一环节前后换词（先说“上线难不难”，再说“上线顺不顺”），听的人会当成两件事。

## 语体

口播用口语。书面的连接词和被动式不落在口语句里：则、而、可见、取决于、由……接着、被告知。“读的时候则从塔尖往下读”改成“读的时候反过来，从塔尖往下读”。

名词作主语的判断句读起来像译文：“她在公司里的名声是会改报告”“开头的任务是把读者带到问题面前”。让人或事作主语：“她在公司里是出了名的会改报告”“开头要做的，是把读者带到问题面前”。这是成文原理第 2 条在口播里的用法。

## 句式

下面几种句式在口播里重复起来，比在纸面上更显眼。通篇数一遍，只在内容需要的地方留下。

| 句式 | 留下的条件 | 例 |
|---|---|---|
| 对照否定 | 区分本身是论点、引语或证据边界 | 留：“开头那个实验给的是主题，不是结论。”改：“这是在整理文件，不是在整理想法”改成“等于只把文件理了一遍” |
| 短句收尾 | 这一句带着新内容 | 改：“一共九页。结论在第八页。”改成“报告一共九页，结论写在第八页。” |
| 自问自答 | 提问是内容的一部分：方法靠提问推进，或读者真会这样问 | 留：“它们合在一起说明什么？”改：“可怎样才算理清楚？她去图书馆……”改成“为了知道怎样才算理清楚，她去图书馆……” |
| 数目预告 | 听的人要先知道有几项才跟得上 | 改：“横向只有两种关系。归纳：……”改成“一种是归纳：……另一种是演绎……” |
| 预告与表态 | 这句导航带着证据身份或任务 | 留：“拿一家虚构的公司，来看这座塔是怎么搭起来的。”改：“要说实话：……”，直接说后面的话 |
| 悬念后揭晓 | 全篇一两处，句式不重样 | “有人……她叫……”与“那个形状……是一座金字塔”句式相同，改掉一处 |

句式换开时术语不换。

## 念到书面句子时

旁白引一句写在画面上的话，例如一句判断、一个标题、一段引文，用它的书面形式，并与画面逐字一致。解说它的话才用口语。

近似的说法不超出画面上的数。7.8 折对 7.9 折说“几乎一样”，不说“一样”。

## 审阅与交付

旁白写完交给没有参与撰写的人冷读，做法见 [成文的独立冷读](../review.md#成文的独立冷读)，问题类别加上听感一类。故意写成的段落在任务书里列为不审，例如实验材料、角色说的话和引文。

交付文稿时附两样：

- 改稿前后的句式统计，用同一种数法。
- 读音清单：没有人听过的多音字、数字、缩写和外文。制作方听不了声音时写明，不称读音已核对。
