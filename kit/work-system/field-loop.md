# 现场闭环

现场工作把 [共同工作语法](../grammar/work.md) 接到 [现场治理](field-governance.md)，不替代后者的价值、资产双账本和净减负口径。

1. **发现**：记录问题、受影响的人、当前基线和未知。
2. **选择**：比较非 AI 替代方案、风险、授权、接收者与停止条件。
3. **介入**：限定对象、动作、版本、人工检查和可恢复边界。
4. **验证与试点**：分别检查文档、知识、材料、系统行为、业务影响和运营条件；试点必须有可比基线。
5. **移交**：交付版本、允许用途、未决项、失败处理、支持方式、责任人和下一观察点。
6. **运营、扩展或退出**：依据真实使用和可比证据扩展；若收益、责任或条件不成立，停止推荐并保留必要历史。

普及材料和真实任务可以并行：前者帮助理解，后者证明质量、减负和采用。演示成功、技术可行、实际采用、净减负和经营改善仍是不同判断。
