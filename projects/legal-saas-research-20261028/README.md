## 证据状态

- `observed_public_page`：公开网页可读内容；不是登录后实测
- `observed_recording`：官方录屏或 webinar 的可定位画面/讲解
- `verified_interaction`：亲自操作公开产品所得；本轮仅在确有交互与截图时使用
- `vendor_claim`：厂商陈述，未作独立验证
- `inferred`：由多个已标注事实推断
- `unknown`：证据不足或登录墙内不可访问

本研究主会话没有云端交互式浏览器工具；另一个独立云端 worker 已采集并逐图核验 42 项公开页面、官方文档嵌入图、官方视频帧与官方营销产品图。其观察记录见 `05-evidence/visual_observation_ledger.md`。这不构成登录产品实测。图像 ZIP version 1 已获用户批准并保存为独立 Library 文件；当前执行环境在旧版 ZIP 的 Library 材料化和一次带网络权限的有界重试后仍 `download failed`，且按父任务指示未再尝试，因此无法本地复核图像字节或并入文本 ZIP。报告只使用 worker 的已核验观察，并保留这个证据传输边界。
