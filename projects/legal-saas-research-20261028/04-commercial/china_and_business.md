# 中国法律科技代表与跨产品商业 / 服务模式

采集日期：2026-10-28（UTC）  
证据范围：公开官网、官方帮助中心、官方产品/计费页；未登录、未注册、未联系销售、未上传文件。  
方法：Exa 5 个工作流、18 次搜索，`sources_reviewed = 180`；180 个结果行去重为 158 个唯一结果 URL。以下只保留与研究任务有关的高信号来源。  
证据状态：`observed_public_page` 指公开网页可读内容，不等于亲自操作产品；厂商的安全、效果、数据规模和客户数字均标为 `vendor_claim`。

## 结论先行

中国法律科技的商业形态不能用“按席位 SaaS”一项概括。公开证据至少出现四种可独立计量的货架：

1. 电子签约采用“版本订阅 + 签署用量 + API/集成许可 + 可选模块/出证”的组合。法大大公开页把订阅版本、签署用量和大量增购项分开；“免费版”被官方帮助页明确标为“非售卖”，不能据此写成免费产品。[CN-FDD-01][CN-FDD-02]
2. 法律内容正在被拆成可供 agent 调用的 MCP/API。北大法宝公开 MCP、CLI、统一鉴权与引用校验/原文链接工具，但公开定价页本轮抓取时仅显示加载骨架，价格仍为未知。[CN-PKU-01][CN-PKU-02]
3. 通义法睿把合同审查、法律研究和按量 API 分成不同收费单元：合同审查既有月/年版本额度，也有 4 元/页的后付费；研究、法规检索、案例检索分别按次数计费。[CN-TY-01]
4. “AI + 律师”平台同时销售软件能力、数据/API 和法律专业服务。得理把 AI 基础解答、律师匹配/协同办案、律所管理和开放平台并列；这些不是同一种交付，不应合并成一个 SaaS 价格。[CN-DL-01][CN-DL-03]

对 Agent 产品建设最有启发的，不是照搬界面，而是把商业计量与业务对象对齐：席位控制“谁能工作”，用量控制“处理多少合同/调用多少检索”，内容授权控制“能否引用和再利用”，实施服务控制“把规则、模板和集成配置到什么程度”，法律专业服务则另有执业主体与责任边界。

### 未进入深描的理由

- 契约锁、上上签的公开流程证据较好，但与法大大同属电子签约域；本节把它们用于验证部署与版本分层的差异，避免三个相近对象挤占深描名额。
- Alpha 与 MeFlow 有丰富产品/案例材料，但公开定价不充分；可由主报告的 matter/CLM 工作者承接功能深描。
- 威科先行、法信的内容质量与授权边界值得保留；本轮未取得足以支持页面级深描的帮助/录屏证据。
- 通义法睿计费证据很强，但产品公开页面的具体状态转移仍不足；此处只把计费单位作为可靠商业证据。

## 深描 A：法大大——版本、用量与增购对象分离

### 用户、购买者与业务对象

公开价格页直接按企业规模与系统复杂度划分购买者：基础版面向小型初创，专业版面向中小企业，卓越版面向有内部系统并需要 API 的企业，旗舰版面向多主体集团。[CN-FDD-01]

可见业务对象包括：个人身份、企业身份、成员/关联企业、合同/签署任务、模板、印章、审批模板/审批单据、相对方、归档与履约任务、集成应用、订单/权益/发票、日志和出证服务。这里的“对象存在”来自公开价格/帮助页的功能表，不代表登录后页面已实测。[CN-FDD-01][CN-FDD-02]

### 公开证据支持的状态与动作

| 流程段 | 输入对象 | 动作 | 可见结果 / 下一状态 | 异常、回退或权限 |

### 商业拆账

| 层 | 公开证据 | Agent 建设含义 |
|---|---|---|
| 软件订阅 | 四个企业版本；帮助页另列“免费版（非售卖）” | 版本是功能与治理边界，不应把未售卖层写成免费套餐 |
| 用量 | 签署任务/份数和批量上限；帮助页明确旧新版为“订阅版本 + 签署用量” | 用量账户要与版本权益分开建模，避免用户有版本却无可用份数 |
| 增购 | API 许可、审批模板、相对方风险、智能比对、归档履约、第三方集成、用户数、私有化存储、出证 | 每个增购对象应有独立 entitlement、配额与到期状态 |
| 部署与运维 | 混合云按模块按年订阅；标准模块页面声称最快一周；文件留私有环境，客户运营中心含监控告警 | 部署交付不是普通席位开通；要记录环境、版本、运维责任和升级窗口 |
| 专业/证据服务 | 在线出证、公证存证证明等按需或订阅 | 出证是独立服务结果，不等同于 SaaS 日志本身即具法律证明力 |

安全、合规、不可篡改等表述均是厂商声明；本轮未审阅认证证书原件，也未做技术验证。

### 关键未知

- 价格页的抓取结果在不同入口出现“联系商务经理”与官网首页局部可见金额的差异；本节不汇总为统一现价，待浏览器按地区/身份实拍。
- 登录后导航、列表/详情/编辑器布局、审批拒绝/撤回的具体状态机未验证。
- “智能审查”功能表存在，但风险→依据→候选文本→接受/拒绝流程没有公开证据；不能推断存在三类不同“接受”动作。

## 深描 B：北大法宝 MCP——法律内容成为可调用能力

### 用户与产品面

北大法宝传统产品同时服务法院、检察院、政府、律所、企业与高校；公开 MCP 页面把新的购买/使用对象扩展到需要法律数据能力的 AI 客户端、agent 和开发者。[CN-PKU-01][CN-PKU-03]

公开 MCP 页不是普通聊天界面说明，而是把内容能力拆成工具：法规语义/关键词、案例语义/关键词、法条关键词、法规名称与条款识别、案号识别、引用校验、文档超链。鉴权使用同一 Token；MCP 让模型选择工具，CLI 直接返回结构化 JSON。[CN-PKU-01]

### 可证实的调用链

| 阶段 | 业务对象 | 动作 | 输出 / 状态 | 边界 |
|---|---|---|---|---|
| 接入 | 应用、Token、MCP server/CLI | 注册账号、在控制台取 Token、配置 server 或安装 CLI | 应用进入可鉴权状态 | 控制台页面与 Token 生命周期未实测 |
| 研究 | 自然语言问题或固定命令 | 模型经 MCP 选择法规/案例工具，或 CLI 直接调用 | 法规、案例或法条级结构化结果 | MCP 路径有 Schema/LLM 上下文消耗；CLI 页面宣称不经 LLM、Token“零消耗” [CN-PKU-01] |
| 核验 | 文本中的法规/条款引用 | 调用 citation validator / recognition；页面另列 doc-link 工具 | 核验结果与超链结果的精确返回字段待工具 schema 证实 | 准确率、失败返回、版本选择、字段组合与时效性规则未验证 |
| 交付 | 已有文档 | 调用 doc-link / 超链工具 | 在文档中指向原文的链接 | 授权范围、批量上限、输出再分发条款未公开核实 |

### 商业与服务边界

- **内容订阅 / 数据许可**：传统 V6 产品含法规、案例、期刊、律所实务、英文译本等库，并提供企业、律所、法院检察等解决方案；公开产品页还列翻译、数据外包/处理、培训、平台定制等服务。[CN-PKU-03]
- **API/MCP 软件能力**：MCP 与 CLI 采用统一鉴权，面向对话与脚本两类调用方式。[CN-PKU-01]
- **价格**：`/pricing` 路由本轮公开抓取仅返回加载骨架和留资入口，金额与计费单位记为 `unknown`，不能写成免费。[CN-PKU-02]
- **内容授权**：公开 MCP 页面说明可接入，但未在本轮取得可支撑再分发、缓存、模型训练或批量导出的许可条款；Agent 产品落地前必须单独审阅合同/许可。

### Agent 机制参考

`observed`：把“研究→来源核验→原文定位”拆成不同工具，而不是让同一个生成模型同时回答与自证。  
`inferred`：引用校验和超链工具允许把生成物中的引用实体变成稳定对象，Agent 可记录 `citation_candidate → canonical_citation → source_url` 的状态变化。  
`proposed`：实现时为每个引用保留查询参数、内容版本、时效性、命中原文、核验结果和人工采用状态；未核验的候选引用不得进入“可用文书”状态。  
代价与反例：内容许可和时效性判定比 API 接通更难；能返回链接不等于引用在具体案情中适用。

## 深描 C：得理——软件、用量、数据能力与律师服务并存

### 产品与服务对象

官网按律师、企业、个人、律所四类入口组织产品：律师版做检索、文书、合同与获客；企业版将合同审查/合规问答与真人律师协同并列；个人版把 AI 基础解答和复杂事项转律师并列；得理律助则覆盖案源、案件/项目、知识、文档与智能体。[CN-DL-01][CN-DL-03]

这是一种“软件 + 市场/转介 + 法律专业服务”复合模式。报告必须保留责任边界：AI 输出是软件结果；律师匹配、委托和办案是另一项专业服务，不能把两者都写成“AI SaaS 已完成法律服务”。

### 公开页面支持的对象与动作

| 工作面 | 对象 | 动作 | 结果 / 下一状态 | 证据缺口 |
|---|---|---|---|---|
| 得理法搜 | 查询、案例/法规、裁判文书、检索报告 | 关键词/语义/长文本检索，提取要点与时间轴，生成报告 | 检索结果、摘要、类案报告 | 引用定位和错误恢复未实测 [CN-DL-02] |
| 智能合同 | 合同、风险条款、版本 | 生成、审查、比对；律师版含一定次数，可加购 | 风险标注/修改建议/比对结果 | 接受风险、接受候选文本、批准规则三类动作均未在公开页证实 [CN-DL-01][CN-DL-02] |
| 律助项目/案件 | 客户、项目、任务、时间、文档、审批 | 协作、项目跟踪、任务分发、时间与审批管理 | 项目状态、任务与文档协作 | 列表/详情/权限/审计未实测 [CN-DL-03] |
| AI→律师 | 个人或企业法律问题、复杂事项 | AI 先答；超出能力边界时匹配/转接律师 | 律师跟进或办案 | 委托成立、冲突检查、费用、责任与交付验收未公开说明 [CN-DL-01] |
| 开放平台 | API key、余额、调用请求 | 充值、生成 key、调用 API/Skills/MCP | 结构化法律数据或模型结果、资源消耗 | 单项费率与 SLA 本轮未完整取得 [CN-DL-04][CN-DL-05] |

### 商业拆账

- **律助 SaaS**：个人版、团队版、机构版按账号与起购数量区分。公开页显示“75/”“83/”但抓取文本缺失时间单位，不据此写“每月”；团队 3 个账号起购、机构 10 个账号起购可直接确认。[CN-DL-03]
- **法搜内容/AI 订阅**：个人版公开为 68 元/月、58 元连续包月、488 元/年、888 元/两年、1288 元/三年（页面同时展示划线价/限时标签，复查时需截图日期）。一个账户限一人。[CN-DL-02]
- **合同用量**：律师版权益公开列包月 20 次、包年 300 次、两年 600 次、三年 1000 次；用完可自助加量，余额在会员到期后暂停、续费后恢复。[CN-DL-02]
- **数据/API**：开放平台称按实际调用量付费、最低充值 100 元；API key 与资源消耗独立管理。[CN-DL-04]
- **法律专业服务**：企业/个人复杂事项可转资深/对口律师；这是专业服务/转介，不应计入 SaaS 自动化完成率。[CN-DL-01]

### 共同模式

1. **价格页不是单一标价表**：企业级法律软件常把功能层、用量、集成、实施和支持组合报价；“未公开金额”应写 `quote_based` 或 `not_found`，不是 `free`。
2. **实施也是产品的一部分，但不是软件功能**：Juro 的 Legal Engineers、Ironclad 的 SOW/partner、法大大的混合云运营中心都产生单独责任、里程碑和成本。
3. **安全声明需要双层记录**：先记录厂商承诺，再单独保存证书/审计/合同原件的独立核验状态；官网一句“数据不出域”不能替代数据流和子处理者清单。
4. **内容型产品多一层许可**：数据库/MCP 的可调用性与内容再分发、缓存、训练权限不是同一件事；必须把 `access_entitlement` 与 `content_usage_right` 分开。

## 可迁移的 Agent 商业对象与事件

以下为建设建议，不是对任一厂商内部实现的复原。

| proposed 对象 | 关键事件 | 权限 / 人审 | 实现代价与反例 |
|---|---|---|---|
| `plan_entitlement` | grant、upgrade、expire、suspend | 组织管理员可看，变更需计费系统确认 | 不要只存 plan name；同一 plan 可有地区/合同差异 |
| `usage_wallet` | reserve、consume、release、top_up | 批量任务先预占，失败后释放；财务/管理员审计 | 合同按“份/页/次”计费不可共用一个整数余额 |
| `addon_entitlement` | purchase、activate、quota_change | API/SSO/审批/私有存储各自授权 | 把 add-on 塞进 boolean 会丢失数量、期限与范围 |
| `content_license` | accept_terms、scope_change、revoke | 法务批准许可；agent 执行时校验使用范围 | 能检索不等于能缓存、再分发或训练 |
| `implementation_project` | kickoff、template_ready、integration_ready、go_live、acceptance | 客户项目负责人/厂商实施双边确认 | “账号已开通”不等于流程、模板与权限已验收 |
| `professional_service_matter` | conflict_check、engagement、assign_lawyer、deliver、close | 必须由合格专业人员承担；与 AI 输出分开 | 自动转介若未完成冲突检查/委托，不得写“律师已接案” |
| `vendor_assurance` | claimed、document_received、verified、expired | 安全/法务审阅证书和合同 | 官网承诺过期或适用范围不同，不能永久缓存为已验证 |
