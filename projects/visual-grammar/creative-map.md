# 表现与技术组合地图

这是给 Opus 的探索起点，不是技术白名单或效果准入表。可组合多条路径，也可引入更合适的成熟实现。外部入口的读取与运行状态见 [来源索引](sources.md)，具体API以选定版本为准。

| 想探索的表现 | 可以组合的技术方向 | 可借鉴的已有材料 | 可留下的经验 |
|---|---|---|---|
| 字体成为动作、形变与图形结构 | SVG/DOM、Canvas、GSAP、Remotion、字体轮廓 | 动态排印、对象持续变形、字幕与节奏样例 | 同语义的不同grammar、字形可读性、形变失败 |
| UI成为空间和叙事舞台 | React、SVG、WebGL、Three.js、camera framing | Courtwork状态与Attention对象、camera lab | 状态如何映射镜头、交互与成片如何共用源 |
| 跨尺度漫游、拆解与空间隐喻 | Three.js、GLSL/WebGPU、procedural geometry | CPU→原子continuous zoom、Schema/Praxis关系材料 | 尺度衔接、空间关系、材质与镜头组织 |
| 代码物理、信息流和模拟 | Canvas、GPU compute、physics、shader | 水模拟仓库、黑洞lab、token/graph概念 | seed、时间推进、交互输入、科学事实与创作隐喻区别 |
| 声音决定视觉时间 | Web Audio、Python音频分析、forced alignment、beat/energy事件 | 技术栈截图、音频工具官方入口 | audio-derived/authored/inferred事件、同步与字幕 |
| 混合媒体与生成式资产 | 程序scene与图像、纹理、音频、视频资产混合 | 任意许可明确且可召回的素材 | provenance、合成层、风格统一、资产替换 |
| 可执行作品到多种交付 | Remotion、headless browser、FFmpeg、交互式网页 | 按帧composition与导出官方文档 | scene与视频复用、运行配置、可复现范围 |
| 一份输入生成系列作品 | JSON/Markdown/audio→story→timeline→scene | Schema结构、已有作品、模板与renderer | 输入协议、变体、失败诊断、自动与手作的协作 |

可主动尝试夸张镜头、密集粒子、强烈光影、复杂morph、音画共振或超现实组合，不要求Astra预先批准风格。将解释性陈述与艺术隐喻分开标注，便于理解作品及复用经验。技术探索本身也可以成为工单的目的。
