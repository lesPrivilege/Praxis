# 变体 storage-from-behind

由 `node build.mjs storage-from-behind` 从 [storage-from-behind.json](../storage-from-behind.json) 生成，不手改。镜头替换：“落盘”一章改从存储层的另一侧看，事件、文字和时间线不动。

预期：请求的状态、标签文字和运行记录与主片逐刻相同，只有看到的范围变了。

打开 [index.html](index.html) 运行；代码与主片共用，只有 `data.js` 不同。检查结果见 [验收回执](../../acceptance.md)。返回 [变体说明](../README.md)。
