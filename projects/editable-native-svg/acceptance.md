# 验收任务与反例

当前所有绘制、渲染、编辑器往返、读屏、Motion、Flash 和受众验收均未运行。本页定义将来做什么，不填写预设的“通过”。静态文档/登记检查的实际结果另见 [本轮回执](../../docs/verification/editable-native-svg-20261004.md)。

## 制作方的正常与失败输入

[fixtures.json](fixtures.json)含 F01–F06 六份合成内容及可核对的预期；它们是制作方输入，不是 Flash 的陌生任务。复制 fixture 需保留版本与合成标记，修改内容生成新版本。需求登记的压力数量只是试验起点；实际容量由结果说明。

| 检查 | 实际操作 | 应观察的结果 / 失败反例 |
|---|---|---|
| A01 语义编辑 | 更换对象 ID 与标签、增加/删除节点、重新绑定一条关系 | 所有端点、图例和说明一致更新；手修几十个 path 才能换对象则失败 |
| A02 文字/几何分离 | 把中文标签增长 4 倍，加入 English、数字和多行说明 | 文字仍可选/编辑，几何随边界重排；转轮廓或删除限定以求整齐则失败 |
| A03 准确作用范围 | F06 的条件在宽/窄/长标签三态中改 target | 只限定 claim-A；只圈条件盒却误指 A/B 是已知反例，不以零溢出判通过 |
| A04 多实例引用 | 同款 10 个实例、异款 2 件及一次移除/重插 | 所有 ID/URL/href/ARIA/CSS 局部绑定，移除一个不改变别件渐变、箭头或文本说明 |
| A05 容器与缩放 | 320/375/768/1440 容器、200% 文字放大、窄侧栏、固定帧、打印 | 保留核心比较/范围/来源，标签可达、marker/filter 不被裁切；全图缩小到不可读失败。以上是项目测试点，不宣称通用断点 |
| A06 量与口径 | F03 改值、分母、domain、排序并插入负值/缺失 | 6 与 0 可复算，missing 与 not-applicable 不转为 0；多面板尺度可查；没有依据的总分拒用 |
| A07 版本绑定 | F01 上传 material v2，matter 保持 v8；再变 matter 与 reading | old reading 仍绑 material v1 §4，新材料保持未读/待判断；依赖单一事项版本检测而自动重接旧说明失败 |
| A08 状态与事件 | F02 的 pending/reject/replay，加非法转移或冲突 | 候选与人判断分开、拒绝仍留历史、重放不重复生效；连线运动不能授权提交 |
| A09 组合和职责 | R27 或 R28 放入同一完整项目，去重标题/来源/图例 | 去重不丢口径、条件与来源；注释槽位与外壳不抢占，跨件线连接语义端点 |
| A10 文本替代 | 非视觉读取名称、关系、步骤或数据表；有交互则键盘操作 | 核心任务可完成，名称和状态正确；一个超长 desc 不能替代可导航结构。自动可访问树检查与真实读屏分开记 |
| A11 安全/许可 | 静态检查 SVG 与源码/资源清单；注入字面 `<script>` 标签文本 | 标签显示为文本；无 active content/远端引用/实体；借用许可证和实际版本明确。许可未定资产不得标可复用 |
| A12 编辑器往返 | 对所声称支持的实际编辑器保存→关闭→打开→再导出 | 文字、分组、语义映射、ID 和引用保持；未用编辑器测试就不写其名称/兼容通过 |
| A13 时间与静态等效 | F04/已选时间作品，暂停、静音、反向和乱序 seek、reduced-motion | 时间偏移与区间正确，业务时间与播放时间分开，静态和动态终态同义。关键帧只能验局部，完整播放才评价节奏 |
| A14 拒用与替代 | 无流量却请求 Sankey、无统计方法却请求 CI、长文要求整页 SVG | 明确缺口与正文/表格/示意替代；强行补拟真量、图式或全路径页面失败 |

制作方为实际采用的需求执行相应检查，未采用/不适用须说明。自动数值/ID/安全探针、几何检查、作者看图、独立看图和读者效果五类结果分开，不用一份“43 项通过”代替用途与覆盖。若失败可保留为反例资产，入口清楚标失败，不能混在可用件中。

## Flash / Agent 的陌生消费任务

SVG-05 由消费测试组织者在绘制完成后提供全新内容。组织者不把下列候选映射、fixtures、答案或路径放进消费方上下文。消费方只得到自然任务、输入和可读写 Praxis checkout；记录其实际模型，未运行就保持未执行。以下是组织者准备任务的规格，不能原样连同整包给消费方。

1. **发现并调整关系**：给一份从未用于绘制的合成设备检修说明，包含三个 actor、两条条件分支、一次移交尚未接收。只要求交一张可编辑关系图和等效步骤，不给资产名；看是否找到合适件、保留责任与条件，并能替换长标签和端点。
2. **选择并组合比较**：给新造的采购方案数据，含四个对象、不同单位的两个指标、真实零、缺失和一项有条件建议。要求窄侧栏与宽屏均可比较，提供修改输入和完整预览；看是否共享正确尺度、拒绝无依据总分，以及将建议条件与局部说明组合。
3. **独立版本与证据**：给从未见过的质检批次，报告附件修订但批次状态版本未变，旧解释基于原附件，机器提出复核、人尚未决定。要求解释风险的可编辑图和来源列表；检验旧解释是否仍指旧版本、四种内容身份是否分开。
4. **拒用任务**：只给三段访谈，没有计数、空间或因果依据，却请求数量流图。成功可以是拒绝该图型并交正文或有明确假设的关系说明；未取用任何 SVG 不算自动失败。

组织者提供具体新文本与数值，保存版本、合成标记和预期不变量；不读取或复制真实客户资料。任务说明避免“先读某文件、使用某 ID”等指路，根目录正常指引仍保留。可以串行独立运行，不要求消融、双盲或所谓 Flash 一定胜任；制作方看到失败后修订的内容不能继续作为留出。

消费回执至少记录任务/模型/基线、实际发现路径、选择或拒用及理由、调整范围、组合输出、核对结果、读到的无关材料、人工补点次数、已知时间/调用成本及未知费用、失败与下一责任。若找到了却未改成功，或改成功但语义误导，分别报告。若要声称参考优先级或规则产生增益，按仓库现有默认另补适用的对照；这不阻塞本轮探索，也不把日常消费强制变成研究实验。
