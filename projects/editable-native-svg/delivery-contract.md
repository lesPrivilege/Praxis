# 可编辑交付合同 · 项目候选 v1

本合同约束本轮作品的可消费交付，不是已采纳的全仓 renderer API。原生 SVG 的最低要求是必要图形由 SVG 节点表达，文字仍是文字，关系仍能通过有身份的输入修改；把整页轮廓转为一个或一组 path 不满足它。路径可用于连接线和复杂轮廓，只要它的语义输入、生成方式与对象关联仍在。

## 输入和编辑边界

每件作品提供稳定 ID、版本、`job`、`input_shape`、`use_when`、`avoid_when`、不变量、可调参数、容量和越界行为。参数默认值由 Opus 决定；取值范围经作品实际验收后再声明。登记里的压力规模是测试输入，不是承诺容量。

编辑至少包括：替换对象身份与标签、增加或删除节点、修改关系端点或范围、改变值与口径、调整布局容器、替换视觉角色。维护 `object_id` / `edge_id` / `source_id@version#locator` 等项目内语义身份；DOM ID 是渲染身份，不能用它代替业务身份。编辑后几何、标签、图例、等效说明与预览一起更新，不能靠消费者手修 path 点列或移动所有标签。无法支持某种编辑时明确写出限制。

文字输入与几何输入分开；禁止把标题、标签、数值、注释转轮廓。提供 `<text>` / `<tspan>` 与原始文本映射；复杂表格或段落可由宿主 HTML 承担，并明确 SVG 本体不包含它们。HTML 辅助版不能冒充纯 SVG 版。`foreignObject` 需单独记录目标浏览器、编辑器、打印和导出兼容性；默认独立静态资产不依赖它。SVG 2 的高级文本布局不能仅凭规范存在就称浏览器支持，见 [S02](../../vault/provenance/editable-native-svg-20261004/cards/s02-svg-text.md)。

## 可移植形态

| 形态 | 必交付或条件 | 消费者得到什么 |
|---|---|---|
| 静态 SVG | 每件必交，含 namespace、viewBox、可编辑文字与几何、当前完整状态 | 不执行 JS 也能读取核心关系 |
| 源输入与生成/编辑源码 | 每件必交，记录实际依赖与版本；手绘也需语义字段到元素的映射及编辑步骤 | 重建图形，修改语义而不只换外观 |
| 预览与文本替代 | 每件必交，本地入口、实际截图、可读说明；数量类附原始值表 | 选择、核对和非视觉消费 |
| Motion 适配 | 有时间需求才交；与静态版共享语义身份和状态输入 | 按 frame/fps 或显式 time/seek 渲染，不让墙钟决定结果 |
| 编辑器往返 | 若声称支持某编辑器，写明名称、实际版本和保存重开结果 | 知道文字、分组、ID、样式哪些被保留 |

源输入、SVG 文件和预览各自可编辑的程度分开说明。参数化生成不自动表示某个图形编辑器里能安全往返；纯手工 SVG 也不自动支持批量数据替换。导出的 SVG 是资产，完整项目是复现与修订依据。

## 多实例和宿主边界

实例前缀由调用方显式传入，或由实现产生确定且唯一的 scope；导出多个实例时必须重新绑定全部引用。隔离 `id`、`url(#...)`、`href` / `xlink:href`、marker、clipPath、mask、filter、gradient、symbol/use、ARIA IDREF 和 CSS selector。页面重排或 SSR/hydration 需保持映射稳定；检查十个同款实例及两种不同作品在同一 DOM 共存。不能只改根 ID。

CSS 限定到实例/项目；不覆盖宿主全局 `text`、`path`、`svg` 或按钮样式。不全局查询节点，不在资产内附隐式 event handler。外壳负责正文、控件、图注及来源导航；图形负责约定的槽位和关系。布局输出若提供 ports、bounds、label boxes，写明同一坐标系、单位、transform、内边距和连接点责任。跨原子连线由组合层连接语义端点，不能使用屏幕绝对坐标硬接。

## 缩放、文字与可访问性

检查 viewBox 与真实 bounds 一致，marker、描边、滤镜和注释不被裁掉；是否采用 non-scaling-stroke 由图形任务决定，不能让笔画固定却文字消失。测试全宽、窄栏、并置、固定帧与打印；文字放大、中文长标签、中英数字混排、系统后备字体和需要时的双向文字分别检查。容量不足时换行、重排、展开详细列表或拒用；不能只等比缩整图或省略关键条件。缩略图仅用于选择，必须有完整可读预览。

每件提供短名称、核心关系说明及必要的结构化等效文本。SVG 可用 title/desc 与唯一的 ARIA 关联；复杂图另有可导航的关系列表、步骤或数据表，不能把整张表压进一个 aria-describedby。装饰层避免重复朗读。有交互时优先用宿主原生控件，验收键盘、焦点、名称与实际状态；非交互图不任意给每条 path 加 tab stop。读屏实测未做时明确保留缺口。依据为 [S01](../../vault/provenance/editable-native-svg-20261004/cards/s01-svg-structure.md)与 [S04](../../vault/provenance/editable-native-svg-20261004/cards/s04-wai-complex.md)，不是由元数据推导出无障碍合格。

## 静态与 Motion

同一 semantic fixture 的静态版与动态终态保留对象、关系、值、单位、来源及版本。动画控制表现层；批准、拒绝、过期与未知结果由输入状态决定。补间值、示意时间和实际观测分开；事件发生时间、播放时间与持续区间不能混用。提供暂停、乱序 seek、reduced-motion / 静态替代；固定种子、字体就绪与资源版本。任意中间帧若缺条件，需保持可见限定或明确它是讲解步骤。完整播放才能评价节奏，静帧不代替它。Remotion 只作为候选适配，见 [S13](../../vault/provenance/editable-native-svg-20261004/cards/s13-remotion-frame.md)；不要求所有 SVG 都建立 Motion 层。

## 来源、许可与安全

每件列 borrowed / adapted / new、精确 URL 或仓库提交、许可与署名、字体和数据权利。方法参考可保留文字摘要；复制源码、图形、字体或数据必须逐件检查选定版本许可，不能拿 D3 的 ISC 推及 Mermaid、Graphviz、Remotion 或示例数据。本轮没有复制这些库代码、安装依赖或领取额度。

交付静态 SVG 默认不含 script、on* handler、外部网络引用、远端 font/import、嵌套 active content、DOCTYPE 或实体；本地片段引用与普通安全链接分别登记。数据标签按文本插入，禁止将不可信内容直接拼入 SVG/HTML。外部 SVG 先在惰性文本/XML 检查路径核对允许的元素、属性、URL 与资源，再决定渲染；不得以 `<img>` 的受限模式推断 inline SVG 同样安全，见 [S03](../../vault/provenance/editable-native-svg-20261004/cards/s03-svg-processing.md)。不执行来源中的命令。导出检查包括 metadata、注释与 URL 的披露边界；不读取凭据，不使用赠金 credits 或可疑领取链接。

## 完成与失败回执

作品 README 写工单、需求 ID、fixture/Kit SHA、实际模型、源码/资产版本、修改方法、运行命令、依赖与许可、取用范围、正常与失败输入、测试范围、截图与完整播放位置。自动断言、作者看图、独立看图、Flash 消费和真实受众结论分别记录。容量越界、许可未明、编辑丢失或无法表达必要关系时可以交拒用回执；不得靠删内容让样张通过。接收由用户裁决，维护者与重访触发记在作品 README。
