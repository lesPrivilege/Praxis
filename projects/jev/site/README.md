# 网页

[index.html](index.html)：Jev 专章的单文件网页，离线可读，不依赖外部字体或脚本，可打印 A4，375 px 窄屏可读。由底稿改编，改编范围见 [底稿 README](../draft/README.md#与网页的关系)。

## 构成

| 文件 | 内容 |
|---|---|
| [src/page.html](src/page.html) | 页面正文与样式；图的位置写作 `{{FIG:名称}}`，来源行写作 `<p class="src" data-src="ID 列表"></p>` |
| [src/data.json](src/data.json) | 六张图的数据，每组带它依据的主张 ID |
| [build.py](build.py) | 画图、按登记填出来源行与来源列表，未知 ID 时停止 |

```bash
python3 projects/jev/site/build.py
```

## 设计取舍

- 底色、墨色与字阶取自 Kit 的 [marks tokens](../../../dsh-praxis/kit/design/marks/tokens.css)。用户要的是必要的强调，不要五彩斑斓，所以只用两种强调色，其余保持墨色与灰：
  - **蓝**：本专章的主体与当前位置。当前章节、章标题上方的短线、阅读进度线、判断流程里决策模型做判断的三步、Jev 的条形，以及温度缩放后的校准误差。
  - **琥珀**：风险，以及会改变判断的条件。关键数字里的 22.2%、Knowviq 图中 Jev 隐藏好答案的那一点、Jev 多放行 9.1 个百分点的注释，以及“改变判断的条件”框。
  - SAG2 消融图只用一个色相由浅到深，表示逐步加上的环节；生态图的点一律为墨色，实心与空心区分是否开放权重。蓝与琥珀这一对已用 `validate_palette.js` 校验，色觉缺陷与正常视觉都能分辨；琥珀对白底不足 3:1，凡是用到它的地方都有文字。
- 读者正文不放维护信息与引导旁白（用户 2026-10-25）：修订触发移到 [底稿 README](../draft/README.md#重访触发)；去掉“见二”式交叉引用、步骤条下的读法句与“每一步下方是……”一类说明。[排列与刻度](../../../dsh-praxis/kit/design/foundations/placement.md)第 2 条要求图里写一句读法，本页按用户裁决不写：步骤条只有编号与通线，不按比例排，读者不会把间距读成时长。
- 结构文字按位置撰写：图的引介只交代看的是什么、定义读图所需的术语，图注承载限定或结论；标题、表头、图例、关键数字说明各自成句。2026-10-25 从渲染后的页面抽出全部结构文字，交给未参与撰写的审阅者按 Kit [结构文字的独立审阅](../../../dsh-praxis/kit/writing/review.md#结构文字的独立审阅)审了一遍，45 条意见逐条裁决。
- 不用文字框左侧的竖条或短线做强调（用户 2026-10-23 的要求）；层次靠编排承担：
  - 结论是一张对齐的判断表：编号、判断、依据三栏；改变判断的条件写成“如果出现 / 改写”的两栏表。
  - 一次调用画成“请求 → Jev → 响应”三栏；Jev 的要点写成左标签右内容的事实表。
  - 私有化五步、阈值选法、到演示为止的实施顺序画成横向步骤条：一条通线串起编号，图下写明“从左到右是先后；间距不表示时长”（[排列与刻度](../../../dsh-praxis/kit/design/foundations/placement.md)的默认排法）；实施顺序里“完成的标志”用 subgrid 横向对齐。窄屏改为纵向，不画通线。
  - 自报成绩与微调收益改为表格；行内容的去向写成“发往 TypeSafe / 留在平台或本地”两栏对照。
  - 关键数字条去掉格间竖线，只留上下两条横线。
- 运动只用在两处状态变化：SAG2 消融逐步加上一个环节，一个问题依次经过六步判断。都可以手动步进；后者可以播放，可以随时暂停。`prefers-reduced-motion` 时去掉过渡；没有脚本时全部内容可见；打印时全部展开。
- 生态图是按路线分组的点图，横轴为对数参数量；实心与空心区分是否开放权重，规模未公布的放在右侧单列，不估值。
- 版式：正文、图与表共用一条左边线，正文行宽 680 px，图与表 760 px。视口不小于 1120 px 时章节列表固定在左侧并标出当前章；更窄时章节列表横排在标题下。窄屏下图保留 620 px 宽，横向滚动，表格同样可横向滚动，正文不横向溢出。
- 页面只链接公开 URL，不暴露原 Chat 与本地路径。

## 取用的 Design 参考

2026-10-23 按 [Design 参考路由](../../../dsh-praxis/kit/design/references/README.md)逐项对照后取用：

| ID | 参考 | 本页怎样用 |
|---|---|---|
| C07 | show-me、visual-explainer 等的“第一屏显出判断” | 标题下五个关键数字，各链到对应章；风险数字用琥珀 |
| C13、C14 | GOV.UK contents list、ONS table of contents | 章节列表标出当前所在；九个条目，宽屏才吸附 |
| C20 | 阅读进度线 | 页顶 3 px 蓝色进度线 |
| C22 | Vercel design：具名字号档位、基线表格、数字右对齐 | 字号改为七个具名档位；表格以横线分行、数值列右对齐 |
| C03、C12 | 宽窄两版图；拒绝“横向滚动是唯一路径” | 五张 SVG 图各附一个可展开的数据表，窄屏不必只靠横向滚动读图 |
| C16 | WCAG 2.3.3 | 步进与播放可停，减弱动效时去掉过渡 |
| C25 | anti-ai-slop-kit 反模式 | 自查：无渐变、无玻璃拟态、无模板化大标题 |

没有取用：C21 记录的奶油色纸底、首字下沉、引文拉出与滚动淡入（与浅色冷调和“运动只表达状态变化”不符）；[注释保持邻接](../../../dsh-praxis/kit/design/references/curated/note-adjacency.md)（REF-COMP-002）的边注做法，本页可作边注的是来源行，长度多在两三行以上，放进 1440 px 下约 216 px 的右侧空白会碰撞；[按属性维持比较](../../../dsh-praxis/kit/design/references/curated/comparison-continuity.md)（REF-COMP-001）留待窄屏比较成为主要任务时再用，目前以数据表兜底。
