# Fixture

两份 fixture 都是合成数据，各自对应一个场景。后端启动时检查它们是否自洽，有重复编号、悬空引用或状态与记录不符就列出全部问题并拒绝启动。日期写成相对后端启动日的偏移，所以期限不会随时间过期。“他人并发修改”和两种响应丢失各只发生一次，重启后端后恢复。
