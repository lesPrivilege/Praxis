# 分镜施工约定

每一集是一张 1920×1080 的网页舞台，每一帧只由时间 `t` 决定，渲染器逐帧调用 `Film.seek(t)` 再截图。配音先生成，画面跟着配音的时间走。单集和合集用的是同一份 `scenes.js`：时间线换了，场景按段号和词重新落位。改自 [金字塔片第五版的约定](../../../demos/knowledge-film-001-pyramid-cut5/film/AUTHORING.md)，增加了单集与合集同源、主张与素材登记两部分。

## 文件与所有权

| 文件 | 作用 | 谁能改 |
|---|---|---|
| `episodes/<集>/script.json` | 旁白分段：`id`、`role`（intro / body / outro）、`text`、`gap` | 主会话 |
| `episodes/<集>/scenes.js`、`scenes.css` | 这一集的画面；CSS 类名带本集前缀（`iu-…`） | 这一集的负责人 |
| `episodes/<集>/motif.py` | 封面上的图形 | 这一集的负责人 |
| `film/engine.js`、`kit.js`、`series.js`、`film.css` | 引擎、工具、系列卡片与书单图、设计变量 | 主会话 |
| `research/claims.jsonl`、`assets.jsonl`、`sources.json` | 主张、素材与来源登记 | 主会话；施工者需要新主张或新图时，在交接里提出 |
| `assembly/timelines/*` | 由 `build/assemble.py` 生成的时间线 | 生成物，不手改 |

## 时间

```js
Series.unit('iu', ({ T, tl, has, u, chrome, standalone }) => {
  T('iu.b3')              // 这一段开始
  T('iu.b3', '安全帽')    // 旁白说到“安全帽”的时刻
  T('iu.b3', '安全帽', 1) // 第二次出现
  T('iu.b3', 'end')       // 这一段的声音结束
  T('iu.b3', 1.2)         // 这一段开始后 1.2 秒
  u.bodyStart, u.bodyEnd  // 本集正文的起止
});
```

锚词只用汉字词；数字、英文在配音里切分不同，不拿来当锚。不写死秒数，也不假设某段有多长。动作通常比锚词早 0.1–0.2 秒起步，落点压在词上。

## 单集与合集

- 正文（`role: body`）的场景无条件注册；它们在单集和合集里都出现。
- 单集引入和收尾（`intro`、`outro`）只在单集里有，场景要先判断：`if (has('iu.i1')) …`。
- 正文场景不能依赖引入段的时间或画面：合集里正文前面是章节卡，不是引入。
- 第一场正文从 `u.bodyStart` 前 0.2 秒左右开始，淡入盖住标题卡或章节卡。最后一场一直放到 `u.bodyEnd + Series.HOLD`，自己不淡出：后开始的场景画在上面，单集的收尾、合集的下一张章节卡和片尾都在正文结束时淡入盖住它，两部分之间不露空纸。系列标识、标题卡、章节卡、片尾和单集收尾（`Series.outro(id)`）由 `film/series.js` 统一生成，不在本集里画。
- 单集引入由 `Series` 画：书单图先高亮上一集，念到“这一集”或“最后一集”时换到本集，读物名出现在图下。引入超过十几秒、需要更多节拍时，集里用 `ctx.intro`（合集里为 `null`）拿到书单图与读物名，在 `if (intro)` 里加自己的场景；压暗这些元素用写明起止值的 `tl.fromTo`，因为启动时引入场景还隐藏着，`autoAlpha` 会把 0 记成起点。

## 证据与素材

- 画面上的引文一律用 `K.quote(parent, 'iu.hh-stop', x, y, w)`：英文原话取自 `research/claims.jsonl` 的 `quote_en`，中文取 `quote_zh`。出处由左下角的出处行写，引文卡里不再重复；卡片的来源和此刻的出处行不同时，才传 `locator: true`（取 `screen_locator`）或一段文字。不在场景里手写英文引文；在别处显示账本英文时用 `K.curly`，把来源里的直引号排成弯引号，字句不变。
- 出处行用 `K.source(root, '文字', from, to, ['iu.hh-stop'])`，必须带主张 ID。舞台会拒绝没有登记或没有审过的主张。
- 外部图片一律用 `K.figure(parent, 'asset-id', x, y, w, h)`；权利状态是 `unknown`、`blocked` 的，舞台拒绝启动。署名按登记自动加在图上。
- 本系列自己的推论，在画面上用虚线框或虚线连线，并写明“本系列的读法”；来源说过的关系用实线，来源说过的失败（没有送到、被拒绝）用红色实线。没读到、没找到、无法确定的东西用灰色实线或灰字，不用虚线。虚线全片只有这一种含义。
- 合成的教学例子本系列不用；画面上的例子都来自来源。

## 场景写法

```js
Film.scene('iu-hardhat', T('iu.b1') - 0.2, T('iu.b5', 'end') + 0.4, ({ root }) => {
  root.classList.add('paper');
  chrome(root, '一顶安全帽');
  ...
});
```

1. **初始状态在搭建时设定，动画只用 `tl.to()`**，或用 `K.show`、`K.rise`、`K.draw`。不用 `from()`、CSS transition / animation、`setTimeout`、`Date`、`Math.random()`（随机数用 `K.rng(seed)`）。例外是压暗与恢复一个已经出现过的元素：启动时引擎先渲染到片尾再倒回，`autoAlpha` 和 `opacity` 的补间会把 0 记成起点，这时用写明起止值的 `tl.fromTo(…, { immediateRender: false })`。
2. 每帧计算用 `Film.onFrame(t => …)`，必须是 `t` 的纯函数。
3. 量尺寸用 `offsetWidth` / `offsetLeft`。位置用舞台像素：`K.box(parent, cls, x, y, w, h, html)`。
4. 同一元素的同一属性，补间不要在时间上重叠。
5. 场景只在 `[from, to)` 内可见；相邻场景可以重叠零点几秒做转场。
6. 不在帧时间里量位置（`getBoundingClientRect`）：镜头的缩放会算进去。搭建时用 `offsetLeft` / `offsetTop`。

## 镜头

每场的内容在启动后移进一层，由 `film/camera.js` 取景；颗粒、暗角、章节标、出处行和角标留在场景上不动。镜头每 0.2 秒看一次可见内容，在章节标与出处行之间的安全区（x 150–1770，y 150–930）里取景：内容小就居中放大，最多 1.3 倍；放不下或贴边出血就按原版面。镜头提前 1 秒、回看 0.5 秒，新内容进场时画面已经在让位，淡出的内容不被裁掉；路径平滑，另有缓慢推近和转场时的小幅推拉。

- 场景自己管视野（滚动的长链、精确的构图），设 `root.dataset.cam = 'drift'`，只保留推近与推拉；`'off'` 完全不动。
- 不该影响取景的装饰，加 `data-cam="ignore"`；要钉在画面上不随镜头动的直接子元素，加 `data-cam="fixed"`。
- 一拍的东西逐个进场时，自动取景会每来一件就重新取一次。两种办法先把这一拍的构图定下：`K.frame(root, x0, y0, x1, y1, from, to, { zoom })` 让镜头在这段时间对准一块区域；或者放一个不画任何东西、标 `data-cam="frame"` 的框，它显示的时候算进取景。
- `K.focus(el, from, to, { zoom, pad })` 让镜头在这段时间推近一个元素，用在全集几处要紧的节拍，先给观众看清周围。目标在 1 倍下放不进安全区时，推近被忽略，控制台给出警告。
- `K.focus` 与 `K.frame` 在 `'frame'` 和 `'drift'` 两种场景里都有效；时段重叠时先登记的生效；每段提前 0.4 秒开始拉，平滑再提前约 1 秒，所以镜头在 `from` 之前 1 到 1.4 秒就开始动：前一拍还没淡出时，`from` 放在它淡出之后，否则正在淡出的内容会被推着走。
- 取景量的是元素的盒子，不是文字本身：一个 1520 宽的块级文字框，哪怕只有一行短字，也按整宽算。要居中取景的文字框不写宽度，让它贴着文字。
- 单集引入在念到本集时由镜头轻推全图；集里重排了引入画面的，设 `intro.lean = false`。
- `K.lit(spans, at)` 是短语的强调：变蓝，下面画一道细线。引文和正文里的短语用它；方框和边框仍用颜色补间。
- `K.figure` 的图片在场景期间缓慢推进 5%；不要时传 `{ drift: false }`。

## 设计

- **调子**：编辑设计，冷白纸面（`.paper`）为常态。颜色只有墨色、灰阶和一个蓝色；蓝色只给此刻的重点。红色只给断裂与失败（例如没送到的消息）。不用渐变装饰、阴影卡片、表情符号。
- **字**：标题和引文用衬线，说明用无衬线，数字用 `.t-num`。字级 `.t-hero 148 / .t-display 92 / .t-title 64 / .t-lead 46 / .t-body 34 / .t-small 26`。画面上要读的字不小于 30px；出处行、图片署名例外（24px、20px）。
- **版面**：四周留 80px 以上；左上角 (80,64) 是章节标，左下角是出处行，别压住。一屏只讲一件事；主体要够大，至少占画面宽度六成。
- **运动**：只表示变化——出现、归位、连接、替换、镜头移动。同一个对象在变换前后保持是同一个元素。进场 `expo.out` / `power3.out` 0.5–1.0 秒；大位移 `power2.inOut` 1.2–2 秒；成组错开 0.04–0.12 秒。一段旁白超过 4 秒时，中间要有与语义对应的推进。不做无意义的漂浮。
- **屏幕文字**：是旁白的骨架，不是字幕。章名、标签、图注按 [成文原理](../../../dsh-praxis/kit/writing/principles.md)第 5 条单独撰写：凝练的名词或动宾短语，同类并列，不从旁白里截句子，不写问句。引用的书名、人名和英文原词照原样。

## 自查

```bash
python3 build/frames.py ep01 iu.b1 iu.b1+2 iu.b2+1 --name iu-a --out /tmp/prl-review
python3 build/frames.py ep01 --range 30 60 --step 2 --name iu-b --out /tmp/prl-review
```

输出带时间和段号的拼图，用 Read 看。每段旁白至少看开头、中间、结尾三帧，转场处按 0.2 秒一帧看。检查：字有没有溢出、重叠、被裁；最小字号；该出现时出现、该消失时消失；控制台报错（脚本会打出来）。全集做完后按 3 秒一帧过一遍，再在合集里看本集正文是否照样成立（`frames.py compilation …`）。
