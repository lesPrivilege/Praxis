# 05 没有送到的情报

Lawrence Wright 的 The Looming Tower。书的正文只有出版方节选可读，而且不涉及情报机构，这一集用作者本人在《纽约客》的报道、9/11 委员会报告、CIA 监察长摘要和一场纪念馆对谈，讲同一段历史：一本护照的复印件、一个签证，怎样没有从 CIA 送到 FBI。几种解释分开标出处，再讲委员会说的病根和“需要知道”的制度。最后与 Qureshi 讲的数据权限做法对照，标为本系列的读法。单集 6:31；正文在合集里是第六章。
