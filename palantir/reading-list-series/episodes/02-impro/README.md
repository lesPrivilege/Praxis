# 02 地位是一种做法

Keith Johnstone 的 Impro。正文只读到 Routledge 2012 年重印本在谷歌图书上的出版方预览，大多在讲地位的那一章，所以这一集主要讲地位：地位是正在做的一件事，高低两句潜台词，头不动，练习时只比搭档高一点或低一点；再讲自发性一章里的接受与阻挡，以及作者自己的保留和 2007 年对“接受所有提议”的改口。最后是 Qureshi 往外用、Mabrey 往里用的两种读法，本系列的推论用虚线标出。单集 5:16；正文在合集里是第三章。
