## 阅读顺序建议

先读两篇背景文章和 Dalio 的原则材料，建立问题语境；随后优先补齐 *Impro* 与 *Interviewing Users*，再读 GTD；最后以 *The Looming Tower* 做案例提炼。这个顺序只是研究工作安排，不表达来源权威等级，也不把可取得性当作证据强度。
