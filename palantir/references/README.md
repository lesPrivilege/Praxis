## 阅读顺序建议

先读两篇背景文章和 Dalio 的 2011 PDF，这三份全文在手，问题语境可以一次建立。随后按片段范围读 *Interviewing Users* 第 1 章，并对照作者公开的六份实践 PDF 看提问、现场记录与综合的实际写法；再读 GTD 官方节选。*The Looming Tower* 目前只有一段节选，做案例提炼之前要先补齐正文；*Impro* 连节选都没有，暂不具备阅读条件。

这个顺序只是研究工作安排，不表达来源权威等级，也不把可取得性当作证据强度。
