# 网页

[index.html](index.html)：Jev 专章的单文件网页，离线可读，不依赖外部字体或脚本，可打印 A4，375 px 窄屏可读。由底稿改编，改编范围见 [底稿 README](../draft/README.md#与网页的关系)。

## 构成

| 文件 | 内容 |
|---|---|
| [src/page.html](src/page.html) | 页面正文与样式；图的位置写作 `{{FIG:名称}}`，来源行写作 `<p class="src" data-src="ID 列表"></p>` |
| [src/data.json](src/data.json) | 六张图的数据，每组带它依据的主张 ID |
| [build.py](build.py) | 画图、按登记填出来源行与来源列表，未知 ID 时停止 |

```bash
python3 jev/site/build.py
```

## 设计取舍

- 底色、墨色与字阶取自 Kit 的 [marks tokens](../../dsh-praxis/kit/design/marks/tokens.css)。2026-10-23 应用户反馈（单色扁平）加入五种色相：蓝、青绿、琥珀、紫、品红，取自 dataviz 参考调色板，相邻顺序经 `validate_palette.js` 校验（色觉缺陷与正常视觉的分辨下限都通过；青绿、琥珀、品红对白底不足 3:1，图中一律有文字标签）。文字用各色相的深一级。
- 每种颜色都有图例或就近标签说明，含义按图局部定义：生态图与校准图按实现路线（encoder 青绿、LLM backbone 蓝、logits 包装琥珀、先快后想紫、结构化抽取品红、架构未公开灰）；判断流程与 SAG2 按判断者（决策模型蓝、检索青绿、权威数据与规则灰，后者用方形编号）；Jev 对 Astra 用蓝对琥珀；Knowviq 图只给 Jev 上蓝色。章节另有一套导航色，只用在章节列表的色块与章标题上方的短线，帮助长页面定位。“改变判断的条件”用紫色底框。
- 运动只用在两处状态变化：SAG2 消融逐步加上一个环节，一个问题依次经过六步判断。都可以手动步进；后者可以播放，可以随时暂停。`prefers-reduced-motion` 时去掉过渡；没有脚本时全部内容可见；打印时全部展开。
- 生态图是按路线分组的点图，横轴为对数参数量；实心与空心区分是否开放权重，规模未公布的放在右侧单列，不估值。
- 版式：正文、图与表共用一条左边线，正文行宽 680 px，图与表 760 px。视口不小于 1120 px 时章节列表固定在左侧并标出当前章；更窄时章节列表横排在标题下。窄屏下图保留 620 px 宽，横向滚动，表格同样可横向滚动，正文不横向溢出。
- 页面只链接公开 URL，不暴露原 Chat 与本地路径。
