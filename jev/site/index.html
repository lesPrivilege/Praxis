Jev 与 System One 决策模型

结论

Jev 读一段 state，回答一组带类型的问题（是否、选一个、打分），每个答案附概率，不生成文本。同样的请求格式五周内已有十几个开放或托管的实现，数据平台把它做成了 SQL 函数。在企业知识库里，它适合承担检索之后、回答之前的判断；权限、版本和生效时间仍由源系统决定。

  1. 接口固定，模型可换。Laya、Kev、Clef、Liquid 的托管 d1、GLiDE 直接沿用 Jev 的请求格式，Perplexity 与 OpenAI 推出了同类 API，Databricks 的 ai_decide 写明与之兼容。见二
  2. Jev 本身没有私有化途径。它只有托管 API，不接受客户数据微调，没有找到 VPC 或本地部署的官方方案；私有化走开放权重，从几亿参数的 Laya 到 27B 的 Kev 都有完整的训练与服务命令。见三
  3. 概率要先校准，阈值要按模型定。Knowviq 用自己产品的流量测了五个模型，可回答性 AUC 几乎相同；套同一个 0.75 阈值，Jev 隐藏了 22.2% 的好答案，其余模型 6–11%。见四
  4. 总体分数相近，错误可以不同。495 条陈述的核验中，Jev 与 GPT-6 Astra 的 balanced accuracy 没有显著差异，Jev 放行的不受支持陈述多 9 个百分点。见四
  5. 公开证据以自测为主，企业知识治理还没有公开评测。厂商与使用方自测居多，学术评测都不在企业知识库上做；点名的企业案例只有 TypeSafe 自己发布的一例；版本冲突、生效时间、撤权这类判断，公开数据覆盖最薄。见五

改变这些判断的条件

  • TypeSafe 提供私有部署或客户微调：第 2 条改写。
  • 出现在真实企业知识库上、按决策单元报告误拒与误放的独立评测：第 5 条改写。
  • 某个开放实现在中文判断任务上发布可复现的校准结果：私有化路线的比较要重做。

TypeSafe AI 于 2026-09-15 发布的第一个 System One model，只以托管 API 提供：输入每百万 token 0.042 美元，输出免费。

训练、评测与企业条款

训练方法称为 Reinforcement Learning for Calibrated Decisions（RLCD，以概率校准为目标的强化学习），目标是“带有诚实概率的答案”；架构、参数量和训练数据都没有公开。TypeSafe 不发布标准 benchmark 排行，自建的 Workflow evals 以 GPT-6 Astra 与 Claude Fable 5.1 的平均输出为参考答案，测的是与两家前沿模型的一致程度。

企业页列出 SOC 2 Type II、企业客户可向销售申请零数据保留、不用客户数据训练。模型页写明 Jev 不用客户数据做 fine-tune，所有账户用同一套权重；VPC 或本地部署没有找到官方方案。当前版本 jev-1.13.0（09-15），jev-1.14.0（10-14）为预览，加入了图像输入。

三 · 私有数据微调与部署

四 · 评测

已发表的评测反复给出同一个结论：总体指标相近的模型，在部署关心的那一种错误上可以差得很远。区分能力与阈值上的误拒、误放要分开测。

阈值的选法

Hamel Husain 与 Antaripa Saha 给出一个可以照做的流程：分层五折交叉验证；在 precision 与 recall 都不低于 80% 的阈值里选 F1 最高的，没有满足的就退回不加约束的 F1 最优并记下这一折；之后在 log-odds 上拟合 Platt scaling（用一条逻辑回归校正概率），所有模型用同一组折，画 reliability 图，报 Brier 分数（预测概率与实际结果之差的平方均值）。他们的数据只有 98 条 trace，门槛只用来引导选择。

来源：How To Use Decision Models for Evals

常见追问

有没有能在本地跑的中文模型？

Laya 多语言版（322M，mmBERT 底座，自报在 51 种语言中 48 种可用）和 Liquid d1-3B（16 种语言）是开放权重。另一条路是直接微调中文 encoder（bert-base-chinese、chinese-roberta-wwm-ext，或 1,800 多种语言的 mmBERT）。中文判断任务上的校准结果，没有找到。见三

微调需要多少数据和算力？

这里只记录各来源点名的硬件和自报结果：Laya 的 notebook 用两块 T4，Kev 的示例在 H100 上约 15 分钟。本专章不预设算力与成本。见三

哪个榜单可信？

几个榜单同名不同物，排名随版本变化，分数多为自报。先看单项评测的设置：比的是零样本还是微调后，阈值是否按模型定，标签从哪里来。见四

能不能让模型判断权限？

不应该。可查到的企业检索产品都在查询时按源系统同步的 ACL 判定权限，未知身份按拒绝处理。见五

Jev 的数据会留在哪里？

企业客户可向销售申请零数据保留，TypeSafe 不用客户数据训练；但调用本身要把 state 发到 TypeSafe 的托管服务。见一
