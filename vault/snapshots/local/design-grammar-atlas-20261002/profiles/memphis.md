# Memphis
ID 建议：memphis · 研究草案 0.1
description：当任务想研究几何、表面装饰与物件情感语义的关系时读取。

范围先指 1981 年公开亮相的米兰设计群体及作品；后来的“Memphis 图形风”需要另标为转译／复兴，不与原群体混为一谈。

**最小证据**：Memphis 官方历史把装饰层压板、材料反差、象征与情感意义置于功能之外的扩展，而非取消功能 [H04](../research/history-sources.md#h04)。NGV 的 Carlton（1981）明确兼有实用家具与独立雕塑的角色，记录几何结构与印花层压板 [H05](../research/history-sources.md#h05)；本轮看过完整正面图。

**软 prior／候选原语**：几何单元的角色反转、结构与花纹表面的对照、方向冲突中的整体平衡。Carlton 可研究斜向构件如何改变“架子”的读法，不复制其轮廓或花纹。

**边界／组合**：不能仅凭圆点、波浪和三角形就宣称代表全部Memphis；视觉活跃不等于随机，具体装饰选择仍由Opus决定。可把表面语义与 Swiss 信息秩序组合，需坦承是当代实验。历史／物件依据高，UI 效果未验证。Opus 可按作者和用途收窄，配色、密度与空间节奏均开放。
