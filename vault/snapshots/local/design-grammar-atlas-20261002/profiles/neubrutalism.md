# Neubrutalism
ID 建议：neubrutalism · 研究草案 0.1
description：当任务需要强轮廓、显性结构的当代 UI 表达，并要避免与建筑或早期 web brutalism 混淆时读取。

范围是当代 web／UI 风格称呼；Neobrutalism 可作检索别名。命名权与起点未确证，不宜画成必然的建筑→网页单线演化。

**最小证据**：2022 年 Malewicz 原文把高对比、硬阴影、明确轮廓与仍可读的常规布局结合，也明确允许线宽／圆角不一致 [H18](../research/history-sources.md#h18)。Gumroad 原发布可核验 2021-11-26 换品牌，但不证明它自称此流派 [H11](../research/history-sources.md#h11)。早期 web brutalism 的创作者访谈呈现更复杂的动机 [H12](../research/history-sources.md#h12)、[H17](../research/history-sources.md#h17)。

**软 prior／候选原语**：轮廓分组、硬偏移层、展示字与正文的强弱反差；只登记候选，不锁数值。本轮未能看 Medium 配图，不把其例图描述当独立视觉核验。

**边界／组合**：“原始”“故意错位”不授权破坏阅读、键盘操作或层级；高对比不等于可访问性。与 Memphis 可共享玩心，不据此外推直接血缘。术语记录中置信，UI 成效未测。Opus 决定是否、在哪里使用，完全可以局部采用或弃用。
