# Vaporwave
ID 建议：vaporwave · 研究草案 0.1
description：当任务需要媒介记忆、采样或虚构商业空间，而不只是粉紫怀旧滤镜时读取。

范围是约 2010 年前后兴起的网络音乐与视觉文化及其多种衍生；不是 1980 年代设计本身。

**最小证据**：AIGA 文章把旧广告、游戏、媒体痕迹的再语境化与视觉传播联系起来，并提供作者署名图像 [H14](../research/history-sources.md#h14)。本轮看过 Ramona Xavier 的 Floral Shoppe（2011）封面。她的 Bandcamp 访谈同时反对把个人创作永久装进流派框，说明其来源和意图比单一“反资本主义”口号复杂 [H13](../research/history-sources.md#h13)。

**软 prior／候选原语**：不同时代视觉片段的并置、熟悉商业符号的语境位移、媒介痕迹提示时间距离。封面可研究平面图像与虚拟空间的关系，不能由此规定每件作品必须雕像、棋盘和日文。

**边界／组合**：与 Y2K、Cassette Futurism 可交叉，但怀旧、设备、技术乐观主义是不同关系；不要使用无意义东亚文字充当纹理。文化轮廓中置信，作者具体作品高，UI 应用是推断。Opus 自由选择原语；任何现成封面、采样和字体另查授权。
