# Swiss / International
ID 建议：swiss-international · 研究草案 0.1
description：当任务需要校正“瑞士风格”的信息组织、网格或字体假设时读取。

范围主要是战后平面、海报、出版与公共传播；Swiss Style / International Typographic Style 保持同一检索入口。不是所有瑞士设计，也不是建筑 International Style。

**最小证据**：瑞士国家图书馆把约 1950–1970 的实践连到网格、无衬线、清晰层级与摄影 [H01](../research/history-sources.md#h01)。Poster House 强调每次从传播问题重新构网格，并记录 Zürich 与 Basel 的差别；Helvetica 必选论不成立 [H02](../research/history-sources.md#h02)。

**软 prior／候选原语**：共同对齐轴、模块比例、文字与图像的视觉权重、信息层级与留白关系。可从 Hofmann 的 Stadt Theater Basel 节目更新区，研究“稳定框架容纳可变内容”；这是馆方文本给出的待试线索，本轮未看该海报图。

**边界／组合**：不能据此禁止所有颜色、插画或破格。可与其他入口的材料、图像语汇组合；与 Bauhaus 有历史连接，不应并为同一外观。证据对历史关系较强，对 UI 转译仅是低至中置信提案。Opus 自行选择、修改或弃用原语及参照，不锁字体、列数或参数。
