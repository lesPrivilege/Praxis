# Y2K
ID 建议：y2k · 研究草案 0.1
description：当任务需要千禧年前后技术未来感，并需区分原时期与后来的复兴时读取。

这里指围绕世纪之交技术文化的回溯性 aesthetic，不涵盖全部 1990／2000 年代，更不等于当代所有 Y2K 时尚。

**最小证据**：CARI 自述 2013–2014 开始整理相关视觉现象，2014 图集使用约 1996–2003 的探索范围；随后还区分 Neo-Y2K [H09](../research/history-sources.md#h09)。其 Y2K 简介提到渐变、圆润电子产品等，但断代与释名文字有问题，只作词汇线索 [H08](../research/history-sources.md#h08)。1998 iMac 馆藏提供可独立核验的当时物件，本轮看过图 [H16](../research/history-sources.md#h16)。

**软 prior／候选原语**：外壳与内部可见性的关系、圆润体量、表面光泽与信息平面的反差。iMac 可作单件对照，不推导全套界面玻璃化。

**边界／组合**：应区分原时期作品、复兴作品与当下解释；可与数字材质或 Vaporwave 组合，但前者技术乐观想象与后者媒介再语境化不能自动等同。命名／时期边界中低置信，物件年代高。Opus 可另找更贴任务的原作，不固定银色、荧光色、圆角或动效。
