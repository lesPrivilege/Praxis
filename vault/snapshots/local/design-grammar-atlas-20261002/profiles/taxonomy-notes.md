# 分类边界的校订意见
研究草案 0.1 · 2026-10-02 · 仅供 Opus 取舍

## 建议保留多对多关系
不要强迫八个入口占同一种分类层级。可把下列维度当检索辅助，而非强制 schema：
- 历史学校／群体／运动：Bauhaus、Memphis；Swiss/International 是相关设计实践与传播谱系；Art Deco 是回溯性概括，内部很杂
- 文化 aesthetic／网络场景：Y2K、Cassette Futurism、Vaporwave；作品生产时期与标签流行时期应分开
- 当代 UI／web 风格称呼：Neubrutalism；不能直接继承建筑 Brutalism 的全部主张
- 技术／材质／媒介条件：凸面显示器、印刷工艺、层压板、漆、半透明外壳等，可横跨多个入口
- 个人作者语言：Hofmann、Sottsass、Eileen Gray、Ramona Xavier 等的具体作品；一位作者不能代表整个入口，也不能被某标签永久圈定

## 原语登记到什么颗粒度
建议登记“可被组合且能说清作用的关系”，如“信息对齐到共同轴”“重复单元打断一次”“表面材质与物件结构形成反差”“用旧媒介痕迹提示时间距离”。不登记一整套默认 palette/radius/motion，也不把时代名翻译成样式开关。

任何从纸面、家具、音像到 UI 的转译，都标为**待试推断**：历史文本说明原作做了什么，不证明现代交互应该怎么做。可组合不等于有历史继承关系；共享几何、鲜色、网格或怀旧也不等于同类。

## 需要优先修正的误读
1. Swiss 与 International Typographic Style 保留同入口，内部差异用参照和上下文表达
2. Bauhaus 不等于红黄蓝几何；Memphis 不等于随机撒点；Art Deco 不等于黑金放射纹
3. Y2K 不是整个 2000 年代；Vaporwave 不是 1980 年代本身；Cassette Futurism 不是有确证纲领的 1970 年代运动
4. Neubrutalism 的粗边与硬阴影是可观察选择，不是强制全组件规则；高对比也不自动保证可访问性
