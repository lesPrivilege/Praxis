# Cassette Futurism
ID 建议：cassette-futurism · 研究草案 0.1
description：当任务想借用有实体控件的复古未来设备语言，并需要核实来源时读取。

这是后设文化 aesthetic／技术想象标签，不是已确证的历史设计运动。CARI 用 1970–1980 年代笨重、棱角化科幻与硬件描述它，但页面没有命名者、确切起点或完整时期证据 [H10](../research/history-sources.md#h10)。

**最小证据**：Sony 原档案确认 TPS-L2（1979），并展示后来运动型、透明、豆形等多种路线 [H15](../research/history-sources.md#h15)。本轮看过 TPS-L2 正面静帧：实体体量、磁带观察窗与机壳分区可核验；这证明硬件物件，不证明它当时属于“Cassette Futurism”。

**软 prior／候选原语**：控件／读数／外壳的功能分区、可见状态窗、媒介载体带来的体量感。CRT、扫描线或仪表可另找原作，暂不假定是必需特征。

**边界／组合**：磁带年代也有圆润、鲜色、小型设备；不能把所有旧电子产品并成军用工业面板。可与 Y2K 比较同一厂商的外壳变化，或与 Vaporwave 比较“设备想象”和“记忆采样”。名称溯源低置信、物件信息高。Opus 可不用此标签，只取对任务有用的关系。
