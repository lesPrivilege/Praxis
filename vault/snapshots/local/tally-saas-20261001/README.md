# 清算 SaaS 正文初稿 v1

从组织约束到软件机制，再到 Agent 的逐项审计。

本版包含六部 23 章连贯正文、前言、8 幅原创机制图、7 个显示公式及完整证据账本。23 章合计约 50,794 个汉字，计数不含英文词、数字和标点；这不是提纲扩写包。研究与资料核查截至 2026 年 9 月 30 日。

## 阅读与编辑

- `SaaS_Book_Manuscript_v1_zh.pdf`：76 页，已逐页目检，适合连续阅读与批注的排版阅读版
- `index.html`：带章节目录和来源索引的离线阅读版；解压后直接用支持 MathML 的现代浏览器打开
- `manuscript.md`：整合 Markdown 正文，可在支持 LaTeX 数学的编辑器中继续修改
- `chapters/`：前言与 23 个独立章节，是分章编辑入口
- `assets/`：8 幅可编辑 SVG 机制图，以及排版需要的数学资源（若存在）
- `equations.tex` 与 `equation-manifest.json`：7 个显示公式的可编辑 LaTeX 片段、章节映射及边界说明
- `figure-manifest.json`：图号、用途、图源性质与相关依据
- `evidence/evidence_ledger.json` 与 `.csv`：70 项来源的读取状态、支持范围与不能证明的内容
- `evidence/style-sources.json`：本次核读的中文技术写作指南与采用范围
- `QA_REPORT.md`：内容、来源和格式检查范围，以及尚未完成的验证

HTML 不加载外部脚本、字体或数学服务。阅读正文和查看包内图无需联网；点击文献来源链接才会访问外部网站。HTML 采用本地系统的中文字体，因此不同电脑的换行可能略有差异。

## 修改后重建

修改 `chapters/` 后，已有 PDF 和 HTML 不会自动变化。Markdown 是继续写作的可编辑源，LaTeX 片段也是源文件，不是完整 TeX 成书工程。

如本机已安装 Python 3 和 Pandoc，可运行：

```bash
python build/build_book.py --output rebuilt
```

脚本从分章源重建离线 HTML、整合 Markdown 及其资源，输出到 `rebuilt/`。它不会重新生成 PDF。图文件的编号和使用位置由 `figure-manifest.json` 维护；大幅改动图号或文件名后须同步修改正文及清单。

## 证据与使用边界

所有 P2P 数值和异常轨迹都是合成测试输入。正式验收 8 件、采购 10 件、本期可批准 800、剩余 200 的设定保持一致；800 来自验收与合同条件，内部预算、银行现金、采购承诺及应付义务分别表达。

本版没有运行 A/B/C 实验，没有测得 Agent 成本、可靠性或替代比例。实验协议、指标和空结果模板用于下一轮验证。库存、案件、探索与连续控制已经用于模型开发，不能再作为未见留出样本。

原 70 项证据中，64 项核读相关正文段落，6 项只核读摘要或概览；不声称通读所有长篇论文和标准。规范说明定义，工程文档说明机制，不能据此推断部署效果。正文的条件化判断与研究缺口仍然保留。

中文技术文档风格参考阮一峰的社区指南，不等同于强制国家标准，也不声称逐条满足所有建议。这是可继续修订的正文初稿，不是完成实证和出版流程的终稿。
