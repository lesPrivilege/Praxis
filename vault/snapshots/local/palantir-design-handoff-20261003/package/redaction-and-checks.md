# 脱敏与检查

## 最少必要披露

保留原报告Palantir窄范围方法卡与Design brief的承重语义、公开来源作者/标题/精确链接、项目候选状态和全部合成标注。通用专业概念与判断关系未因脱敏被删空。

排除类别：用户真实姓名、邮箱、账号和身份映射；个人本机路径、私人仓库URL、Chat/会话定位；原报告全文和无关章节；其他项目源码、工程状态及样张；Git元数据、历史、hooks和远端认证；密钥、凭据和环境资料；完整书稿/PDF、原图/网页全文；依赖、缓存和下载工具。仅列类别，不复述敏感原文。

源路径只在本地说明中以仓库相对定位记载，并清楚映射到包内位置。案例只有虚构订单甲/乙、虚构角色与演练记录；原报告身份与哈希用于版本复核，不包含签名下载链接或账户身份。
