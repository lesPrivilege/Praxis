# mangent · harness 规格

版本:v0.1(2026-07-03)
性质:活文件。组件随验证结果增删;版本号在结构性修订时递增。

## 1. 定义域

mangent:在承认 base model 不可选择、生命 context 已大部分输入的前提下,通过工程方法对剩余可操作空间做系统性优化的实践。

判据是计算的,不是道德的。区别于 self-help:不诉诸意志力、格言激励或对命运的抗议。意志力是稀缺资源,只保留给最高优先级工作;其余一切由外部系统在低能量时段自行运转。

终极目标:harness 变薄。补偿 base model 不足的组件,在对应行为内化为 weights 后应当拆除,否则转为摩擦。不折旧的只有 loop engineering 本身——设计、观测、修正循环的元能力。

## 2. 分层结构

- **刚性层**:离散、可编码、执行成本低的规则。时间戳、事件戳、工具链配置。直接写死。
- **柔性层**:不可直接下指令的目标(生化信号、注意力状态)。只能做环境设计——调整目标变量涌现的背景条件,类似塑造 reward landscape 而非指定输出。
- **开放层**:显式不管辖。留 margin,允许 token 浪费在看似无关的事上。系统满载即丧失适应能力;噪声中有一部分是当时未识别的信号。

## 3. 组件清单

### 3.1 已固定(刚性层,不动)

- 22:45 熄灯,抛弃光源,不看流媒体
- 褪黑素作为 fallback:至迟 23:00 未入睡则复用
- 戒断午睡,白天工作拉满
- 早起,晨间集中数学时段(纸笔,逐步推演)
- 步行通勤作为 context 中性恢复,不填充媒体

### 3.2 验证中(每次只动一个变量,观测数日,保留或回滚)

| 组件 | 层 | 假设 | 观测判据 |
|------|----|------|----------|
| 社媒代偿 | 柔性 | 注意力漂移流入社媒是能力不足,需低认知负荷活动接住;魔方/散步是候选。启动成本必须低于社媒(魔方放桌面,不放抽屉) | 疲劳窗口内社媒进入次数 |
| 睡前 context dump | 刚性 | 睡前言语/推理反刍无法消除,但可给出口:写下几行即释放 working memory | 入睡前反刍主观强度 |
| 学习硬截止前移 | 刚性 | 认知惯性直冲睡眠窗口;22:15 截止,留 30 分钟降速区间做低刺激活动 | 22:45 后自然入睡成功率 |
| 褪黑素低剂量 | 柔性 | 0.3–0.5mg 更接近生理节律,早醒副作用小于常见 3mg | 早醒/半夜醒频次 |

### 3.3 已识别、暂不立项

- 颈椎:白天适当活动即可缓解,优先级次于睡眠系统
- 居家 routine 稳定性:难于外出 routine,待睡眠闭环收敛后再动

## 4. 运行规则

1. **白天不做精细 harness**。白天是 goal 驱动的长 loop,自然调用工具;goal-driven 推理本身即最好的 context 管理。只锚定时间戳/事件戳,其余随整体自然完成。
2. **唯一需要 harness 介入的点:专注→漂移的转折点**。这是边界管理,不是全程管理。转折有前兆(任务卡住、间歇未被有意识用掉、疲劳过阈)。干预是最小的:起身、换物理位置、拿魔方、喝水。物理准备优先于决心。
3. **单变量验证**。先固定能固定的,每次只动一个变量,观测,再决定保留或回滚。
4. **定期审计变薄条件**。已内化的组件从 3.1 移出并删除,不保留仪式性规则。

## 5. 核心判准

**白天的 context 质量是入睡的上游,不是反之。** 一天在高质量推理与实践中度过,晚间大脑自然收敛,疲劳是生理性的、干净的;垃圾 session 产生的疲劳身体累而大脑不收敛。因此睡眠问题的主战场在白天,不在床上。

系统的耦合结构:入睡困难 → 褪黑素 → 早醒 → 睡眠不足 → 白天认知下降 → 注意力漂移 → 社媒 → 睡前大脑活跃 → 入睡困难。单点优化会在下游反弹;所有验证中组件都是对这个闭环不同节点的切入,判据统一回到闭环是否收敛。
