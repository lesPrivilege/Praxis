# 反 AI Slop 检测清单

> 上线前打印或贴 PR。任一项「是」= 需解释或修改。  
> 严重度：🔴 必改 · 🟡 强烈建议 · 🟢 情境判断

---

## A. 颜色

| # | 检查项 | 级 |
|---|--------|----|
| A1 | 是否存在紫/靛/violet 渐变作为主品牌色而无品牌理由？ | 🔴 |
| A2 | 标题或 CTA 是否使用 `background-clip: text` 渐变字？ | 🔴 |
| A3 | Dark 模式是否默认霓虹 glow / cyan-on-black？ | 🔴 |
| A4 | 背景是否「无理由 cream/beige 品味默认」？ | 🟡 |
| A5 | 正文与背景对比是否 < WCAG AA（4.5:1）？ | 🔴 |
| A6 | 灰字是否直接压在彩色底上？ | 🔴 |
| A7 | 强调色是否超过 2 个且用途不清？ | 🟡 |

## B. 字体

| # | 检查项 | 级 |
|---|--------|----|
| B1 | 全站是否只有 Inter / Roboto / Open Sans / Geist / Space Grotesk？ | 🔴 |
| B2 | 是否跟风 Instrument Serif 斜体大标题（AI startup hero）？ | 🟡 |
| B3 | 标题与正文字号比是否 < 1.25？ | 🔴 |
| B4 | 长句是否用 display 字号占满首屏？ | 🟡 |
| B5 | 正文是否 all-caps 或 letter-spacing > 0.05em？ | 🔴 |
| B6 | 是否加载了 ≥3 个无关 Google Fonts 家族？ | 🟡 |

## C. 布局与组件

| # | 检查项 | 级 |
|---|--------|----|
| C1 | 是否 Hero + 三等分 icon 卡片？ | 🔴 |
| C2 | 是否 cards nested in cards？ | 🔴 |
| C3 | 是否 rounded card + 一侧粗色条（side-tab）？ | 🔴 |
| C4 | 小卡片 border-radius 是否 ≥ 20px？ | 🟡 |
| C5 | 是否同时 hairline border + 大面积 soft shadow？ | 🟡 |
| C6 | 是否每节都有 `01 / 02 / 03` 或 uppercase kicker？ | 🔴 |
| C7 | 全局 gap/padding 是否单一数值无节奏？ | 🟡 |
| C8 | 正文行长是否 > 80ch？ | 🔴 |
| C9 | Icon 容器是否大于文案本身？ | 🟡 |

## D. 动效

| # | 检查项 | 级 |
|---|--------|----|
| D1 | Dialog/卡片是否 bounce/elastic？ | 🔴 |
| D2 | 是否 animate width/height/padding/margin？ | 🔴 |
| D3 | 图片是否默认 hover scale/rotate？ | 🟡 |
| D4 | 是否到处 micro-interaction 无一处主叙事动效？ | 🟡 |
| D5 | `prefers-reduced-motion` 是否被尊重？ | 🔴 |

## E. 文案

| # | 检查项 | 级 |
|---|--------|----|
| E1 | 是否出现 Supercharge / Empower / World-class / Next-gen？ | 🔴 |
| E2 | em-dash（—）是否在一段内 ≥3 次？ | 🟡 |
| E3 | 是否「Not X. Y.」式反驳金句堆砌？ | 🟡 |
| E4 | 身份是否标签云（AI \| Web3 \| Full Stack \| Ninja）？ | 🔴 |
| E5 | 项目描述是否无问题→方法→结果？ | 🟡 |
| E6 | 是否有 lorem / placeholder 人名？ | 🔴 |

## F. 功能与 a11y

| # | 检查项 | 级 |
|---|--------|----|
| F1 | 表单是否无错误态/必填提示？ | 🔴 |
| F2 | 键盘 Tab 是否可见焦点？ | 🔴 |
| F3 | 标题层级是否跳级（h1→h3）？ | 🔴 |
| F4 | img 是否空 src / 无 alt？ | 🔴 |
| F5 | 是否仅用颜色传达状态？ | 🟡 |
| F6 | 移动端首屏是否需横滑才能读完？ | 🔴 |

## G. 个人站特有

| # | 检查项 | 级 |
|---|--------|----|
| G1 | 首页能否在 10 秒内回答「这人是谁、在做什么」？ | 🔴 |
| G2 | 项目是否链到可验证产物（repo/产品/文章）？ | 🔴 |
| G3 | 是否整站 fork 某开源站未改 creds？ | 🔴 |
| G4 | 是否为动效牺牲 LCP（大 hero 视频/WebGL）？ | 🟡 |
| G5 | 联系方式是否真实可达？ | 🔴 |

---

## 快速评分

- 🔴 任一项未处理 → 不合并  
- 🟡 ≤2 可接受（需注释理由）  
- 全绿 → 可进入视觉 polish

# 若已装 impeccable
