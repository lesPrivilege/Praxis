## 30 秒结论

1. AI slop = 无约束时的训练分布采样（紫渐变 / Inter / 三卡片 / 玻璃 / cream+衬线…）
2. 品味首先是 **禁止清单**，不是更炫的模板
3. 2026 工具三件套：**Taste**（生成 ban）· **Pro Max**（行业系统）· **Impeccable**（检测门禁）
4. 动手：`05/12` 规则 → `05/10` prompt → 生成 → `05/09` 清单 + `impeccable detect`
