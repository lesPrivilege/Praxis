## D. 如何「按图索骥」读一个站（15 分钟协议）

对任一目标站：

1. **关掉自己的品味偏见**，只记录事实  
2. **字**：几套字族？字号阶？正文 measure？  
3. **色**：主/次/强调/背景？强调用在何处？  
4. **空**：区块间距 vs 卡片内间距  
5. **动**：入场？hover？scroll？有无 bounce？  
6. **文**：第一句是什么？能否删掉 50% 装饰词？  
7. **链**：项目是否指向真实产物？  
8. **源**：View Source / GitHub / CSS 变量名  
9. **写 3 条「我要偷」+ 3 条「我绝不做」**

## E. 反面教材类型（社区常见，勿学）

1. **Purple SaaS 克隆**：Inter + indigo 渐变 + 三 feature 卡  
2. **Awwwards 空壳**：全屏 WebGL，加载 8 秒，无真实项目  
3. **Fork Brittany 不改色**：被识别为「又一个 portfolio template」  
4. **AI 一键站**：Lyria 背景音乐 + 通用 bento，无个人事实  
5. **标签云身份**：`AI | Full Stack | Blockchain | 3D | Ninja`

## F. 快速对照表

| 维度 | Slop 默认 | 标杆站做法 |
|------|-----------|------------|
| 首页第一屏 | 大标题 + CTA | 一段人话 或 一句原则 |
| 项目 | 3 张一样的卡 | 不等权列表 / 深度 case |
| 色 | 紫渐变 | 1 主色 + 1 强调 或 近单色 |
| 字 | Inter only | 有配对或自定义 display |
| 动效 | 到处 fade | 一次编排 或 内容内交互 |
| 证明 | 「Passionate developer」 | 链接到 Docs / OSS / 产品 |
