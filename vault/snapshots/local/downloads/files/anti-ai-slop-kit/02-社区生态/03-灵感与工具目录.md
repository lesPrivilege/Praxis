## 6. 每周品味训练（30 min）

| 日 | 任务 |
|----|------|
| 一 | 打开 1 个标杆站，只研究字体阶 |
| 二 | 同一站，只研究间距 |
| 三 | View Source / GitHub 找 tokens |
| 四 | 读 1 篇 Josh/Rauno/Paco 写作 |
| 五 | 用 checklist 审计自己的 WIP |
| 六 | 从电影/摄影抽 5 色，换掉默认 accent |
| 日 | 休息或只读长文站（jvns/gwern） |

## 7. 工具栈建议（实现层）

| 层 | 推荐 | 原因 |
|----|------|------|
| 框架 | Astro 或 Next | 内容站 Astro 更轻；交互站 Next |
| 样式 | CSS variables + 少量 utility | 纯 Tailwind 易被 AI 写成紫 |
| 动效 | CSS first；需要时 Motion | 少依赖 |
| 主题 | next-themes 模式 | 无闪烁 |
| 部署 | 任意静态/Vercel | 与审美无关 |
| 检测 | Impeccable + 人工 checklist | 双保险 |
