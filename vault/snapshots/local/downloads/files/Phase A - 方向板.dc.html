1a 素白 排印即界面 — 一頁素紙，層級只靠字。

「素白」把界面收縮到排印本身：整頁只有一種底色，卡片容器全部退場，層級交給字重、字號、留白與髮絲線。數字以大號輕重量呈現；藍墨色只出現在可以按的東西上——顏色即可供性。它拒絕的是「容器堆疊」：圓角卡片、陰影、色塊統統刪去，也拒絕把溫暖感外包給米色底。十年論證：這個方向的全部風格特徵只剩「排得好」，而排印標準不隨潮流折舊——iA Writer 十餘年未變樣。風險同樣寫明：對執行精度要求最高，錯 2px 就會顯得窮而不是素。
動效檔位：quick 120 / gentle 240 沿用；擬新增 ~420ms 慢檔（翻卡）——Phase B 以 token 提案。陰影 token 保留名，值退為透明（僅 overlay 用 lg）。

第三章 · 图灵机与可计算性

1930 年代，图灵在研究可计算性问题时提出了通用机模型。这一构想将「计算」从具体装置中抽象出来，也为后续存储程序计算机的体系结构提供了理论基础。

与此同时，冯·诺依曼在普林斯顿整理 EDVAC 报告草案，把「存储程序」的思想系统化。这一设计后来被工程界反复验证，最终奠定了现代计算机的通用体系结构。

这段历史提示我们：许多重大变革最初都源于纯粹的理论构想而非工程实践的直接需求——通用机模型本是数理逻辑领域的抽象产物，却在工程界手中转化为现代计算机体系结构的基石。

Reader · 沉浸（L2） 方向立場：閱讀也用無襯線（如 iA Writer），17/1.95；高亮 = accent-soft 底色，不加下劃線。頂部進度為唯一常駐 chrome。
1b 玄墨 墨為體，硃為印 — 一本可以日日翻開的書。

「玄墨」把 Mnemos 當一本嚴肅的書來造：宋體承擔正文與中文 chrome，紙面灰度收斂到近乎無色的暖白（chroma 0.005，現行 0.012 的一半以下），墨色加深拉開對比。硃砂只以「鈐印」的劑量出現——待復習數、一枚方章、選中態。直角與 2-4px 圓角、極輕的單層陰影，是印刷品的物理感。它拒絕現行的「暖米底＋赭石＋mono 標籤」模板味，也拒絕把書卷氣做成仿古裝飾——無紋理、無假紙張、無界畫。十年論證：宋體＋硃砂＋留白的搭配在印刷史上已穩定數百年，不屬於任何一個 app 潮流週期；折舊的是裝飾，不是排印傳統本身。
動效檔位：quick 120 / gentle 240 沿用；擬新增 ~480ms 翻卡慢檔（紙感翻面）——Phase B 以 token 提案。暗色改暖墨（hue 75），不用現行藍灰 250。
