版式模式

两种注意力组织假设共用同一套视觉 token 与控件；切换只改版面，不改行为含义。

输入与换行

  • Enter 发送；中文输入法组合过程中的 Enter 只用于确认候选词，不会发送。
  • Shift+Enter 换行。运行中仍可编辑下一条消息，草稿会保留并标明未发送。
  • 运行中发送即「排队为下一轮」：入队后可修改或撤回，运行自然结束时自动发送；停止或断线时退回草稿，不会发送。本版没有实时插话（steer）。
  • 每条请求可「回到此处之前」：确认后移除其后的记录、活动与产物，原文回到输入框；演示原型没有版本库，移除不可取回。
  • 切换工作时各自的草稿与滚动位置分别保存。

快捷键

按键作用范围
Enter输入框内发送
Shift + Enter输入框内换行
Esc关闭浮层或辅助面，焦点回到触发处
⌘ / Ctrl + K全局：聚焦工作筛选
⌘ / Ctrl + .运行中：请求停止
⌘ / Ctrl + [全局：收起或展开左栏
⌘ / Ctrl + ]全局：收起或展开右栏
⌘ / Ctrl + \全局：右栏在卡片列与预览面之间切换

数据位置
