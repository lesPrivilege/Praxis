# 企业汇报图式库

按页面要回答的问题选择图式。主文是业务判断与证据，图表、流程和容器为内容服务。

| 文件 | 责任 |
|---|---|
| [绘制规范](绘制规范.md) | 层级、容器、线条、颜色与验收的唯一规则源 |
| [图式目录](图式目录.md) | 阅读任务、必需字段与适用图式 |
| [视觉记号](视觉记号.md) | 数量、状态、关系和强调的表达方式 |
| [图式样张](图式样张.html) | 九种骨架；支持灰盒、层级、缩略与打印检查 |

先确定本页判断和业务字段，再选择一张主图。Diagram 表达结构，Chart 比较数量，Table 承担查数，Card 承载独立工作对象。数量图共用坐标与单位；角色、系统和状态关系靠位置、边界与连接表达。

应用实例：[LNG 八页定本](../LNG合同全周期合成案例/README.md)。来源及研究快照统一在[来源索引](../../来源索引.md)。Agent 读取顺序见[消费接口](AGENTS.md)。
