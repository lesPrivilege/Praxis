# 视觉记号与数据表达

内部规则，正式标准来源见来源与裁决。此文件是视觉变量语义的唯一维护源。

| 变量 | 默认含义 | 边界 |
|---|---|---|
| 位置 | 阅读顺序、层级、依赖 | 空间距离不自动等于时间或数量 |
| 面积 | 页面注意力分配 | 只有明确量化编码时才表示业务数量 |
| 长度 | 数量大小或时间跨度 | 必须有单位、尺度与基准；占位长度不能当数据 |
| 连接线 | 关联或依赖 | 映射/引用没有方向时不用箭头 |
| 箭头 | 明确的流转或交接方向 | 标明传递的对象或动作，不装饰 |
| 虚线 | 单一图内选定的特定语义 | 不同时表示预测、待审与例外；须图例和文字状态 |
| 边框 | 独立记录或明确范围 | 不等于系统实际已治理 |
| 阴影 | 可独立讨论的工作对象 | 内部约定，非标准或权限证明 |
| 深蓝 / 灰 | 主结构 / 次级语境 | 不自动编码批准/实测 |
| Amber / Red | 关注或异常 / 严重异常 | 无已定义状态不随意着色 |

时间样张使用计划空心圆、实际实心菱形、预测空心菱形并保留状态标签，这是本库选择，不称为ISO记号。定量样张比较从零起算；系统映射默认无箭头，受控动作才体现方向。

## 数据表达检查

1. 比较图在相同单位、期间、分母与统计口径下比较。条形图以零为长度基准；截断坐标必须明确标识，不能夸大差异。
2. 时间图采用真实间距；里程碑等距布局需明确只是顺序。计划、预测、实际和目标保留文字状态与更新时间，不仅靠颜色区分。
3. 同一图组比较同一量时共用尺度。若尺度不同，要分开图组并直接标注，不能让等长图形暗示相同数量。
4. 结构比较优先横条，连续时间优先按从左到右展开；在业务语义更清楚时可例外。数量构成与能力范围不能使用同一统计含义。
5. 颜色稀缺。全库默认主结构蓝灰、风险amber、critical红；数据系列需要自己的图例，不把蓝色自动解释为已批准或实测。
6. 表格用于查数，图表用于观察模式；允许一页主图加小表，不强迫二选一。保留信息密度，以结构和对齐降低查找成本。
7. 标题先确定内容是否支持判断。已有差异与证据时写判断；范围介绍和对象定义使用准确主题。Slide Sorter检查论述顺序，不要求每页使用同一种句式。

这些为本库实施规则。来源对应与采用范围单列于来源与裁决，不宣称完整实现任何标准。
