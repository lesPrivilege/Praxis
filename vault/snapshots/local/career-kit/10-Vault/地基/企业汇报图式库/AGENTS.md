# 企业汇报图式库 · 消费接口

采用渐进读取，不默认装载全部案例和来源。

1. 首读README.md，确认产物是企业汇报而非产品UI。
2. 按业务问题在图式目录.md选择一到两个候选，再读绘制规范.md对应规则。
3. 图式样张.html用于浏览几何、容器与L1–L4；不要把占位文案和形状尺寸当业务数据。
4. 只有涉及外部归因、IBCS/ISO规则或存在争议时，查../../来源索引.md及其快照。
5. 需要真实应用才进入LNG案例；不要复制整个案例目录作为新项目依赖。

最终裁决顺序：用户目标与已有事实 → 阅读任务 → 结构与证据 → 图式 → 容器与视觉。外部建议不自动覆盖用户裁决。命名、百分比面积和阴影语义为内部约定，不能包装成ISO标准。

维护单一源：通用规则改绘制规范；图式输入/失败条件改图式目录；行业业务映射留在案例。每次加入新图式，应有结构样张并记录验证状态；不为了库完整而造业务数据或搭新框架。
