# AgentScope: English AgentScope 2.0.10dev

> ## Agent Instructions
> For AgentScope Python, use https://docs.agentscope.io/stable/en/index for new projects. For existing projects, check the installed agentscope version and use matching versioned documentation.
> The /latest/ alias points to development documentation. Use it only with the matching development source. Do not mix AgentScope 1.x and 2.x APIs.
> State the AgentScope version when providing installation commands or code examples. ReMe uses its own continuously updated /reme/latest/ documentation.

### Building Blocks

- [Message & Event](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/message-and-event.md): The core data abstractions for agent communication and streaming
- [Plan](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/plan.md): Give agents a structured task list to plan, track, and coordinate complex work
- [Standard Operating Procedure](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/sop.md): Break a multi-step task into milestones that agents complete in a fixed order, each one checked before the next begins.
- [Middleware](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/middleware.md): Intercept and extend agent behavior at key lifecycle points
- [RAG](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/rag.md): Build retrieval-augmented generation (RAG) capabilities for agents.
- [Long-Term Memory](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/long-term-memory.md): Cross-session long-term memory implemented with agent middleware
- [Console](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/console.md): Quickly test and verify agent behavior in the terminal
- [A2A Protocol](https://docs.agentscope.io/en/versions/2.0.10dev/building-blocks/a2a.md): Connect to a remote agent behind the A2A protocol and talk to it.
