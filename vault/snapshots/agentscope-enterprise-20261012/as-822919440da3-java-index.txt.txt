# AgentScope Java

## v2

### Home

- [AgentScope Java v2](https://java.agentscope.io/v2/en/intro.md): Build your own Agent application with the AgentScope Harness SDK, or use managed Agent services through AgentScope Service with platform-managed runtimes.

### Harness

#### Quick Start

- [What's AgentScope 2.0?](https://java.agentscope.io/v2/en/docs/index.md): Build agents that keep working with Harness, then connect them to business applications, execution environments, and service APIs.
- [Quickstart](https://java.agentscope.io/v2/en/docs/quickstart.md): Start with replies, live output and conversation history; add background tasks and recovery when needed.

#### Building Blocks

- [Agent](https://java.agentscope.io/v2/en/docs/building-blocks/agent.md): Learn how to define and configure agents in AgentScope Java 2.0
- [Message & Event](https://java.agentscope.io/v2/en/docs/building-blocks/message-and-event.md): The core data abstractions for agent communication and streaming
- [Middleware](https://java.agentscope.io/v2/en/docs/building-blocks/middleware.md): Intercept and extend agent behavior at key lifecycle points
- [Model](https://java.agentscope.io/v2/en/docs/building-blocks/model.md): Configure and connect LLM model providers in AgentScope Java
- [Permission System](https://java.agentscope.io/v2/en/docs/building-blocks/permission-system.md): Fine-grained control over which tools your agents can execute and when
- [Tool](https://java.agentscope.io/v2/en/docs/building-blocks/tool.md): Define, register, and manage the capabilities an agent can call
- [Context & AgentState](https://java.agentscope.io/v2/en/docs/building-blocks/context.md): Stateless agent engine, AgentState lifecycle, state persistence, and RuntimeContext

#### Harness

- [Harness Architecture](https://java.agentscope.io/v2/en/docs/harness/architecture.md): What HarnessAgent is, how to choose an invocation style, combine capabilities and persist conversation state
- [Context management](https://java.agentscope.io/v2/en/docs/harness/context.md): Follow the reasoning loop to assemble useful model input, keep task state visible, and manage long conversations
- [Workspace](https://java.agentscope.io/v2/en/docs/harness/workspace.md): Source of truth for agent definition and evolution: directory layout, workspace-vs-API parity, native multi-tenant isolation, filesystem modes, and deep dive on key contents
- [Session operations, events and recovery](https://java.agentscope.io/v2/en/docs/harness/session-log.md): Build background conversations, restore the UI, handle user input and continue interrupted tasks with AgentSession.
- [Memory](https://java.agentscope.io/v2/en/docs/harness/memory.md): Two-layer long-term memory, conversation compaction, large tool-result offloading; prompts and trigger policy are customizable
- [Filesystem](https://java.agentscope.io/v2/en/docs/harness/filesystem.md): Three deployment modes: local + shell / shared store / sandbox; IsolationScope dimensions; multi-user isolation; how skills and tools behave in each mode
- [Sandbox](https://java.agentscope.io/v2/en/docs/harness/sandbox.md): Isolated execution + cross-call recovery + multi-replica deployment
- [Subagent](https://java.agentscope.io/v2/en/docs/harness/subagent.md): Declare subagents, sync/background calls, auto push-back, remote subagents, streaming forwarding
- [Skill](https://java.agentscope.io/v2/en/docs/harness/skill.md): Four-layer skill composition, skill marketplaces, the self-learning loop
- [Plan Mode](https://java.agentscope.io/v2/en/docs/harness/plan-mode.md): Think before acting: a read-only phase that writes a plan file and requires HITL approval before executing
- [Channel](https://java.agentscope.io/v2/en/docs/harness/channel.md): Route messages, manage sessions, and stream events through Channel

### Service

#### Getting started

- [What is AgentScope Service?](https://java.agentscope.io/v2/en/service/index.md): Deploy your own Agent service platform, use managed Agents built on HarnessAgent, and expand into application integration and multi-agent collaboration.
- [Deploy AgentScope Service](https://java.agentscope.io/v2/en/service/quickstart.md): Start AgentScope Service with Docker Compose, sign in to the console, and run your first Agent.
- [Run your first Managed Agent](https://java.agentscope.io/v2/en/service/create-managed-agent.md): Use curl to create a Managed Agent, start a session, submit work, and inspect the result.
- [Visual Console](https://java.agentscope.io/v2/en/service/console/index.md): Configure Agents, run Sessions, and manage work visually, sharing platform resources and execution records with the API.

#### Delegate work and interact

- [Integrate applications with the Session API](https://java.agentscope.io/v2/en/service/service-api.md): Delegate tasks to an Agent through the Session API, follow progress, and participate during execution.
- [Sessions, tasks, and budgets](https://java.agentscope.io/v2/en/service/session-event-log.md): Add requirements, answer pending actions, cancel or resume submitted work, and manage usage and budgets.
- [SSE and event replay](https://java.agentscope.io/v2/en/service/sse-events.md): Observe tasks with snapshots and SSE, recover progress after disconnection, and receive backend Webhook notifications.
- [Files and artifacts](https://java.agentscope.io/v2/en/service/files.md): Give an Agent files as task input, then retrieve, download, and verify the actual deliverables.
- [Example: a resumable chat application](https://java.agentscope.io/v2/en/service/agent-api-chat.md): Connect a Managed Agent to a chat page through the Session API, including progress, refresh recovery, and human interaction.

#### Configure Agents and resources

- [Configure Agents and models](https://java.agentscope.io/v2/en/service/managed-agent-configuration.md): Create and update Agent definitions, associate tools and MCP connections with an Agent, and select models and Session resources.
- [Tools, MCP, and permissions](https://java.agentscope.io/v2/en/service/tools.md): Declare built-in tools and MCP connections in an Agent definition, save the configuration, and use it through a Session with authentication and permissions.
- [Workspaces, Skills, and subagents](https://java.agentscope.io/v2/en/service/workspaces.md): Create shared capability definitions, publish a Workspace revision, bind it to an Agent, and verify it in a new Session.
- [Environments: execution locations](https://java.agentscope.io/v2/en/service/environments.md): Prepare a tool execution backend, select it through Agent defaults or Session creation, and verify where tools run.
- [Memory: shared knowledge](https://java.agentscope.io/v2/en/service/memory.md): Create a knowledge Store, bind it to a Managed Agent or Session, and verify read-only access and document updates.
- [Vault: credentials for tools](https://java.agentscope.io/v2/en/service/vault.md): Store tool credentials, attach Vaults through Agent defaults or Session creation, and verify MCP authentication and rotation.
