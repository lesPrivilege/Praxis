#### Get Started

- [Concepts](https://docs.agentscope.io/en/reme/latest/concepts.md): The principles and trade-offs behind ReMe's file-native agent memory.

#### Integration

- [Overview](https://docs.agentscope.io/en/reme/latest/integration/overview.md): Choose how an application or agent should run and use ReMe.
- [Deployment](https://docs.agentscope.io/en/reme/latest/integration/deployment.md): Run ReMe as a shared service and choose MCP, CLI, or HTTP as the access boundary.
- [Python SDK](https://docs.agentscope.io/en/reme/latest/integration/python-sdk.md): Run ReMe in the host Python process and manage its lifecycle directly.
- [Agent Integrations](https://docs.agentscope.io/en/reme/latest/integration/plugins.md): Connect supported agents to ReMe through maintained in-process Python, tool, Skill, and plugin integrations.
