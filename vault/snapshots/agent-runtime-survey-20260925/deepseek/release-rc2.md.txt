English release-note excerpt:

New features
- Manage reminders and view their run history after enabling scheduled tasks. Tasks survive app restarts and can repeat as often as once a minute.
- New Desktop onboarding introduces available credit and helps users choose intended use and work-detail display; interrupted onboarding can be resumed.
- View, search, customize, and reset keyboard shortcuts on Web and Desktop, with current bindings shown in the sidebar.
- Use newly enabled tools in an ongoing conversation without starting a new one.
- When Auto review denies an operation, users can decide whether to proceed in conversations that allow manual approval. Review failures are reported separately.
- Tasks continue in the background when the Desktop window is closed. Quitting the app warns users about the impact on tasks.

Changes
- Enable Auto review from the Plugins page; Inspector is no longer included by default and must be installed separately.
- Account-funded and API Key tasks have separate model entries; signing out confirms and stops account tasks, and expired sign-in prompts for sign-in.
- Coding Tools controls trajectory, code changes, and mode selection for new tasks; the separate mode switch is removed.
- Time context defaults to ten-minute updates when enabled; Scheduled tasks and time context are disabled by default on Web and Desktop.
