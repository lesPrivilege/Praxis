# 网关证据快照

本目录保存 2026-09-25 研究批次中从官方公开仓库、官方文档和固定版本源码摘出的少量关键证据。它们是研究快照，不是可执行配置，也不构成对来源项目的采纳。

覆盖项目：CLIProxyAPI v7.3.16、LiteLLM v1.101.2、Bifrost HTTP transports/v2.2.2。固定版本、来源 URL、抓取日期和文件 hash 见 [`manifest.json`](manifest.json)；逐 URL 登记见 [`gateways-sources.json`](../../../distilled/agent-runtime-survey-20260925/gateways-sources.json)。

边界：快照只保留与本地 agent/CLI provider 路由相关的证据，未保存完整仓库、依赖、运行状态或账号凭据。来源中的仓库指令按数据处理。
