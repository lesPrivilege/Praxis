# 写作来源的快照边界

本目录仅保留快照策略说明。此次没有复制网页正文、截图、媒体素材或第三方代码；各来源的精确 URL、实际读取定位、离线概述与核查边界见 [`vault/provenance/design-writing-encyclopedia/writing`](../../../provenance/design-writing-encyclopedia/writing/README.md)。来源卡是本仓库撰写的摘要，不是源网页快照或完整离线副本。

重访时仅在需要时摘录最小且许可允许的公开片段，并记录 SHA-256、字节数、定位和许可。不同类型的许可分别核查文字、图片、代码及其依赖。没有查明的许可维持 `unknown`。
