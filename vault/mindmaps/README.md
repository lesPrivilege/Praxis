# 思维导图

跨任务查找可用于 XMind 等工具的 Markdown 原稿。知识正文由所属主题维护，此处只登记入口、用途和验证状态。组织裁决见 [ADR-012](../../docs/decisions/012-platform-grammar-mindmaps.md)。

| 任务 | 纲目原稿 | 带自然语言解释的原稿 | 状态 |
|---|---|---|---|
| 平台产品 grammar 扫盲 | [先读词表](../distilled/platform-product/outline.md) | [再展开解释与案例](../distilled/platform-product/annotated.md) | 研究说明；XMind 实机导入待验证 |

先导入纲目版建立全景，再用注解版展开不熟悉的分支。来源、口径与覆盖边界在 [主题入口](../distilled/platform-product/README.md)，不塞进每一个导图节点。

新增任务登记主题原稿的相对路径；无明确归属的临时草稿可先留此处并注明状态，确定主题后迁移。二进制导出只有在实际生成时登记对应原稿版本和验证工具版本，不作为正文权威副本。

所有标记为 Xmind-compatible 的原稿遵循 [xmind-md/0.1](../../docs/governance/xmind-markdown-profile.md)。用户提供的基线为 Xmind Desktop 26.05.01107；静态检查及实际导入分别记录。
