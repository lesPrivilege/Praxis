建议直接放进全局 ~/.codex/AGENTS.md

ChatGPT session ingestion

When a ChatGPT conversation, session, transcript, or substantial discussion is attached to or otherwise available in the current workspace, treat it as source material that may need to be made durable and discoverable in the repository.

Codex's default role for this material is ingestion, provenance, and knowledge maintenance, not implementation unless implementation is explicitly requested.

Goal

Convert useful ChatGPT discussion and exploration into repository artifacts that future agents can discover and consume progressively without needing the original conversation.

Preserve the distinction between:

- source / event record — what was actually discussed or observed;
- durable project state — decisions, hypotheses, constraints, references, unresolved questions, and reusable findings;
- model context — the smallest index or artifact a later worker needs to read for its task.

Do not collapse these layers into one large summary.

Default behavior

When relevant session context is available:

1. Read the available conversation as a whole before deciding what is durable.
2. Identify material relevant to the current workspace: decisions, design directions, constraints, rejected alternatives, external references, unresolved questions, implementation implications, and reusable research.
3. Use Astra as the adjudicator of what belongs in durable project state.
4. When claims, products, libraries, papers, implementations, community practices, or other external references should be recoverable or verified, delegate focused provenance work to Luna explorer(s) when useful.
   - Prefer primary/original sources where available.
   - Record enough provenance for a later agent to recover the source and understand why it matters.
   - Do not turn every statement in the conversation into a research task.
5. Write or update compact repository artifacts using the project's existing documentation conventions.
6. Maintain a thin discovery/index layer so later workers can find the relevant artifact before reading raw material.
7. Preserve unresolved or weakly supported claims as such rather than silently converting them into facts.
8. Make ingestion incremental and idempotent: update existing artifacts when the same session or topic has already been consumed instead of creating duplicates.
9. Finish the ingestion itself without requiring the user to repeatedly prompt each intermediate step.

Progressive disclosure

Prefer artifacts that allow a later worker to move approximately:

"index → topic/session artifact → specific provenance/reference → raw source"

rather than loading an entire session or research corpus by default.

A useful durable artifact normally contains only what is needed to recover the work:

- what changed or was learned;
- decisions and their rationale;
- important hypotheses or rejected alternatives;
- implications for the workspace;
- unresolved questions;
- pointers to external sources and deeper/raw material.

Do not preserve conversational filler, repeated reasoning, or wording merely because it appeared in the chat.

External exploration

Luna is well suited to parallel, bounded provenance and exploration work. Astra remains responsible for synthesis and final inclusion decisions.

Use multiple explorers when independent references or alternatives can be investigated separately. Do not impose a fixed sub-agent topology when a simpler approach is sufficient.

Scope and access

Do not assume access to ChatGPT conversations that are not actually present in the current task context. If only part of a session is available, ingest what is available and make the coverage limitation explicit rather than reconstructing missing turns.

Do not begin product or code implementation merely because the discussion contains implementation ideas. The default deliverable is a durable, source-traceable artifact that later workers can consume.这基本就能消掉你现在大部分的手动 loop。
