# WCAG 2.2 SC 2.5.8 Target Size (Minimum)

来源：[原始页面](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) · 状态：`partial`

用途：ACCESSIBILITY / TARGET_SIZE / CW / SE

## 摘要

本地外部索引报告 WCAG 2.2 AA 目标尺寸 24 CSS px 及 spacing/equivalent 等例外，并把 44px 保留为 coarse/touch 或高后果控件的 CW 选择；不把 44px 说成通用 WCAG 要求。
