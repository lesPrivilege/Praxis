## 摘要

Catalog combines provider model lists and pricing/capability data; wildcard and explicit allowlists have different semantics, with empty list deny-all.

Catalog availability and provider list refresh behavior were not live-tested. 本批外部证据保存为研究摘录/归纳，未保存完整原始源码；未实跑验证。
