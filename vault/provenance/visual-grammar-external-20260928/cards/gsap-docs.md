## 读到什么

GSAP 官方 docs 将 core 描述为跨浏览器动画基础，列出 Tween、Timeline、CSS/attribute/array values、eases、staggers、keyframes、snapping、modifiers、ticker 与 `matchMedia()`；Drag、Scroll、SVG、UI、Text、Morphing 等能力有单独入口或插件。

## 可消费内容

可把 GSAP 作为 DOM/SVG/UI motion 的实现候选，尤其适合 staged reveal、UI morph、continuous zoom 的 easing、stagger、drag/scroll interaction。它是可选实现，不替代场景语义或 render contract。

## 边界

首页/文档入口不是性能基准、许可证裁决或当前浏览器验收；本批未安装、未运行 timeline/plugin、未验证 React/Three.js 集成。
