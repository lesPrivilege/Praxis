# Web Audio API

- source ID: `web-audio-api-mdn`
- URL: <https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API>
- accessed: 2026-09-28 (Asia/Singapore)
- status: `verified`; snapshot: `summary-only`

## 读到什么

MDN 将 Web Audio API 描述为以 audio context 和节点路由图控制音源、效果、可视化与空间声像的 Web 音频系统。页面标记为 widely available，但指出部分能力支持程度可能不同；模块化节点可组合复杂的动态效果。

## 可消费内容

可用于程序化音色、audio-aware visual、节拍/能量可视化与 3D positional audio 的入口检索。它与 Skillry 的 mechanical keyboard/Web Audio 标签以及源/时间分析层有直接关系。

## 边界

MDN 不是音画同步或跨浏览器延迟的实测；本批没有创建 AudioContext、验证 autoplay policy、采样率、音频时钟、录制输出或 headless 支持。

## 重访

做 procedural sound、beat/energy extraction、音频可视化或跨浏览器 render 时重访接口、兼容性与 Web Audio specification，并以实际音频样片验收。
