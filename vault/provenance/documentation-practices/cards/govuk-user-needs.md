# Learning about users and their needs

来源：[原始页面](https://www.gov.uk/service-manual/user-research/start-by-learning-user-needs) · 状态：`verified`

用途：GRAMMAR / DOCUMENTATION

## 摘要

GOV.UK 把入口和服务设计锚定在真实使用者的任务与结果，要求研究贯穿阶段、覆盖支持角色，并保留从稳定用户需要到具体工作项的追溯。对 Praxis 的直接启发是：README 的任务行应来自实际消费者问题，文档修订应有使用断点或反馈证据，而不是只凭维护者判断增加旁白。

## 证据与使用边界

这是公共服务研究方法，不是企业 Kit 的合规要求；用户需要字段、观察频率和证据强度需要 Astra 按 Praxis 场景裁决。 本次未保存 GOV.UK 页面快照；页面带有更新日期和反馈表单，但本批未取得其后台反馈或使用数据。

## 何时重访

README 的任务路由没有对应读者、触发条件或真实产物。 修订只凭作者意见，没有使用走读、反馈、搜索或支持问题证据。 需要把维护者、接收者、运营者等非直接读者纳入消费研究。 GOV.UK 页面更新用户研究、用户需要或追溯指导。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
