# Page content types

来源：[原始页面](https://kubernetes.io/docs/contribute/style/page-content-types/) · 状态：`verified`

用途：GRAMMAR / DOCUMENTATION

## 摘要

Kubernetes 把内容类型落实为可重复的页面骨架，而非只在风格指南中讲原则：概念页有背景与下一步，任务页有前置、步骤和必要的最少解释，教程承载更大目标，参考页承载稳定描述。它还为读者提供下一步和反馈入口。

## 证据与使用边界

只借鉴结构和链接关系；不复制 Kubernetes/Hugo shortcode、目录名、五项 next 上限或其产品内容组织。 本次未保存 Kubernetes 页面快照或其站点资产；页面实际显示多语言、版本与反馈结构，但本批未验证其生成系统或分析配置。

## 何时重访

某个 README 既要教新人、指导操作、定义字段又要解释取舍，读者无法判断页面用途。 场景或契约页面缺少前置、完成条件、下一步或反馈路径。 需要设计 README 模板或检查页类型一致性。 Kubernetes 变更页面类型骨架、版本策略或维护流程。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
