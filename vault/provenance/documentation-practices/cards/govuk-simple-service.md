# 4. Make the service simple to use

来源：[原始页面](https://www.gov.uk/service-manual/service-standard/point-4-make-the-service-simple-to-use) · 状态：`verified`

用途：GRAMMAR / DOCUMENTATION

## 摘要

该页把‘易用’表达为可检查的行为：用户少求助即可完成目标，团队频繁测试实际交互，且检查完整服务链。这支持把 README 当作使用入口来测，而不是把可读性理解为再增加解释段落。

## 证据与使用边界

仅借鉴‘以用户完成任务为验收’的结构；不把 GOV.UK Service Standard 宣称为 Praxis 的企业合规或服务等级。 本次未保存页面快照，也未取得 GOV.UK 服务实际使用数据；‘简单’在本批只作为结构候选，未作量化结论。

## 何时重访

消费者能读懂页面但无法完成入口承诺的任务。 一次任务需要在多个入口间猜测下一步或重复提供上下文。 新增文档影响上下游接收、支持或退出，而验收只看链接存在。 GOV.UK 更新该服务标准点的成功、测试或可靠运营要求。
