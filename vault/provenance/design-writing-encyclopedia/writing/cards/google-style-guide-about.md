# DWW-001 · Google developer documentation style guide — About this guide

来源：[原始页面](https://developers.google.com/style) · 状态：`verified` · 实际阅读页面总则的可见文字。

## 内容摘要

Google 将这份指南定位为面向软件开发者和其它技术从业者的技术文档编辑指南。它提出一种清晰的引用顺序：项目特定风格先于通用指南，第三方工具书在其后；具体领域及读者需要可使作者偏离指南，偏离后文内保持一致。它明确把自己的内容称为 guidance，并未声称每条都是规则。

## 定位与支持的判断

- Page Summary 与首段，页面可见行 50–58：读者范围与指南用途。
- Editorial resources / Reference hierarchy，行 61–77：项目指南、Google 指南与第三方参考的先后。
- Break the rules，行 89–98：指南不是绝对规则，为清晰度和读者需要可偏离，偏离时保持一致。

支持 [DWW-001-C1–C2](../catalog.json)。这是页面文字的陈述，不表示 Google 已批准本 Kit 的解释，也不证明哪种写法对 Praxis 用户更有效。

## 可复用判断与边界

适合在发生风格冲突时，先检查产品/项目语境及读者，而非直接套另一组织的编辑表。其范围是英文技术文档中的指南层级；不能据此确定本地化中文写法、产品法务要求、或任何特定主张是否被证据支持。页面声明正文按默认条款采用 CC BY 4.0，示例代码另为 Apache 2.0；本卡不摘录源文。
