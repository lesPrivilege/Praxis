# DWW-003 · Microsoft Style Guide — Global communications

来源：[原始页面](https://learn.microsoft.com/en-us/style-guide/global-communications/) · 状态：`partial`。

## 内容摘要

该页可见部分提醒，内容会被不同国家的读者阅读，也可能继续转成其它语言。它区分 translation（语言转换）与 localization（适配到地区语言、文化与政治期待及要求），并指出本地化由熟悉当地语言文化的人完成。

## 定位与支持的判断

- “Global communications”，页面可见行 31–37：多语读者、翻译和本地化的定义与目的。
- 页面出现授权提示，正文范围仅限公开可见部分；具体读者建议及其下级内容未核查。

支持 [DWW-003-C1–C2](../catalog.json)。

## 可复用判断与边界

这组区分帮助团队避免把逐词翻译当成完成了地区化。它只支持区分工作的目标，并未说明任一地区的具体法律要求、标准格式、内容政策或术语。不应据此将原文源语言视为唯一拥有者；关键主张应能在各语言版本追溯并由当地相关人员复核。页面许可未核查。
