# Hairline · Make your own figure

原件：[skill 页面](https://hairline.lucasmarkes.com/skill)。页面标称 Hairline skill 可在 MIT 条款下使用。

## 摘要

生成流程把一次图形工作划分为选择概念、仅绘图形、自动按项目规则检查、浏览器目视复核、交付规则与未查项目、随后按使用反馈调整。示例直接展示对象被误读的反例：轨道几乎不可见，火车就成了松散方块；修订目标不是“变精致”，而是让它一眼看得出是铁路。天气示例也记录“云像一堆圆柱”的辨形问题。这种修复以语义识别为边界，装饰精度仍由产品用途决定。

## 定位与证据

网页 `How it works` 1–5 步、`What it draws` 下 sales funnel / rate limiter / git branches / weather 示例（文本阅读位置约行 33–78）。作者的流程描述与反例足以支持“先定对象动作和读数，再检查形体是否表达比喻”的操作；没有执行页面所称检查脚本或浏览器观察。静态呈现证据在单独查看的 [DWV-06](hairline-hero-gif.md)。

## 边界和许可

该项目面向小型产品 UI 中可响应指针的等距线图，适合简单机制或状态隐喻，不自动适合机械剖面、精密数据图或多层真实对象。skill 自述的浏览器检查只是其流程，不代表此批已经测试。品牌标志作为例子出现；即使代码/skill 标为 MIT，标志本身仍属各自权利人。
