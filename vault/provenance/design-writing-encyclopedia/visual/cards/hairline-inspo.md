# Hairline · How Hairline was made

原件：[How Hairline was made](https://hairline.lucasmarkes.com/inspo)。

## 摘要

作者把最初参考限定为一种“感觉”，先找出可观察的行为再拟定自己的图形：交互响应有明确时序、指针距离衰减和逐帧结构；首稿后用滑块比较数字、讨论何种曲线能表达关系。地形柱阵的默认地面太平，就让静止画面本身也有形；卡片波纹和分层窗口分别要能讲清它在产品里承担的工作。可复用的方法是把含糊的感觉转成参数和可否决规则，再用具体例子反驳或修正。

## 证据定位

读取网页 §§01–04：`A feeling, not a look`、`The brief`、`What came back` 和 `Pushback`，文本位置约行 25–93。它写出一组具体参数与作者如何审稿；页面嵌图在没有用于验证最终画面的细节。项目 README 另链接有静态 hero GIF；该文件已单独查看，见 [DWV-06](hairline-hero-gif.md)。

用于设计判断时，把 reference 当作建立可检验问题的线索，不当作要照搬的主题皮肤。小图是否说清对象和状态要在具体尺寸看；参数可调不是效果证据，作者的“calm”等感受仍是个体判断。

## 边界

此卡仅复述作者对制作过程的自述；参数范围、手感和识别效果没有独立测试。没有运行任何 JS、打开交互图或验证访问性。
