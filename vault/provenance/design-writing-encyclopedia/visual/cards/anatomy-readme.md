# Anatomy · project README

原件：[GitHub README](https://github.com/wheresryan22/anatomy) · 项目声称为 MIT 授权。

## 摘要

Anatomy 将技术概念转成带结构和运行关系的真实机器隐喻。README 描述由许多实体、阴影化部件组成的等距对象，图卡附标签和读数，部件可在指针/键盘操作下分开；它还把线条无法表达的火焰、水、光、蒸汽等放到 SVG 图层前后之间的 WebGL 效果中。其根本取向是让一个可检查的物理模型同时驱动图形和读数，而不是单纯给流程加装饰性图标。

## 证据定位与证据状态

读取 README 的 About、Gallery、What it makes 文字（网页阅读位置 §§ About / What it makes，web 文本提取行 224–262）；README 链接的 firing still 另有独立卡 [DWV-02](anatomy-firing-still.md)。文字支持“作者如何定义方法”，图片支持“这一件静态图如何呈现”。README 说明其截图是通过项目自带 capture / drive 脚本捕获并将 HTML 示例提交，但没有执行或操作示例。

只取其判断顺序：概念机制确实需要读者辨认多个实体部件和动作时，才尝试构成性的对象比喻；同一个状态模型要支持绘图、动作与数值读数；放大检查连接处是否自洽。不要只因题目技术，就把抽象对象硬改造成机器。这个操作转到内容解释任务上属于本 Kit 推断，并非来源保证学习效果。

## 限制

作者自述、链接图和静态仍图不能证明发动机物理正确、操作行为可访问、渲染性能稳定、或图形让读者更易理解。README 链接的 [技能入口](anatomy-skill-landing.md)在直访失败；不能把该页当作核验来源。逐资产再发布需分别核实许可、署名和素材内的第三方权利；本 Kit 不保存图像。
