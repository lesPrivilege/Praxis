# ColorBrewer · Color scheme types

原件：[完整色标类型说明](https://colorbrewer2.org/learnmore/schemes_full.html)。

## 摘要与定位

文本将制图色标分为三种数据工作：sequential 对有序低到高的量，视觉上强调明度阶差；diverging 把有意义的中值与两端做对照，要求中心断点与数据含义有关；qualitative 表示 nominal/categorical 类别，不代表数量大小。它还提供两项变体：paired schemes 用相同 hue 的明暗搭配表示概念相关、但未排序的类；accent 对少数重要类加突出色，同时提醒检查是否强调错对象。

这是从数据结构反推色标语义的实用提问方式。迁移到一般统计图时，可问“有无顺序”“零/基线是否有意义”“色相会不会暗示等级”。应用到非地图要重新核对背景、面积、类数、阅读情境与黑白打印表现。
