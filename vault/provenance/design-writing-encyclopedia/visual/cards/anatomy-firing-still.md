# Anatomy · Raptor 2 firing still

原件：[直接图像 URL](https://raw.githubusercontent.com/wheresryan22/anatomy/main/.github/assets/raptor-engine-firing.webp)，由 Anatomy README 链接。

## 原创观察（不是图像快照）

将远端 still 下载到临时目录并实际查看完整 900×900 画面。发动机可见为近乎白色的填充体积，表面有轻量明暗和细边线；管线、接头和支架分别可辨，发动机悬在测试架内，底板带刻度和圆形测试盘。喷嘴下的喷焰是柔红色渐层效果，与机械部件本体的浅色表面不同。对这个例子，称它“透明线框”会误述实际外观：虽然轮廓线细而轻，它有清楚填充面和结构遮挡。

这是对单个静态图片的视觉观察，不代表该方法各作品都同样，也不证明图中实体尺寸、工程关系或火焰模拟正确。图注中作者描述 hover 后会拆成 assemblies；没有操作 HTML、悬停或键盘。

## 消费判断

遇到解释需要看清前后装配、表面和连接时，可先用实心填充体加可控轮廓；透明材质或额外光效放到确实需要它们表达的次级层。图本身已经有高密度细节，过度降低线对比或缩得过小会让机械信息连成杂讯，宜保留更大画面和少量重点标签。这个转译是本 Kit 的设计推断。
