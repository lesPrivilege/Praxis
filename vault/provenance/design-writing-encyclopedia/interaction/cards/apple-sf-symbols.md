# DWI-005 · Apple HIG: SF Symbols

来源：[Apple Developer HIG: SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols) · 状态：partial（官方 HIG URL 可打开，但正文读取器仅返回标题；另见 DWI-008 官方目录页全文）

## 这份来源是什么

Apple HIG 的 SF Symbols 使用页面，是实际 UI 使用细节的官方入口。页面搜索摘录提示使用前理解条款，并提示不能在 app icons、logos 或其他 trademark-related use 中使用符号或与之混淆的图像。直开该 HIG URL 仅返回标题/元数据；这条警示来自官方搜索摘要，而非可通读的页面正文。不能据它断言其他具体使用场景一定允许或禁止，也不能据此替代当前 SF Symbols 许可文本。

## 支持的判断

- 官方目录页 DWI-008 支持字重、尺度、文字对齐、阅读方向与各类符号动画/渲染为相关设计变量；不应把这些平台能力当成通用 icon library 的功能或跨平台授权。
- 当前可读的警示摘要要求在具体使用前查条款，并禁止某些 app icon、logo 与商标用途；符号自身及相似图像边界需结合 Apple license 条文逐项确认。

定位：[Apple HIG SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols) 搜索摘要及其用法入口。有关条款的细节未能直读 HIG 正文；[DWI-008 官方 SF Symbols 页](apple-sf-symbols-overview.md) 展示目录能力，但未给出许可证条文。没有打开 SF Symbols app、下载/使用图样，也没有逐个核查限制符号。

## 用途、边界与重访

作为 Apple 系统内 icon 语义/规范的回查入口；产品视觉参照能力见 DWI-008。它不能作为 Web 跨平台许可依据，也不意味着全部符号都能商用、复制或重绘。需实际选用素材时先看当期授权条款，并核对该符号的标记和用途。

重访触发：导入具体符号、制作跨平台产品、或 Apple 条款/工具版本变化时。关联语法：[controls.md](../../../../../dsh-praxis/kit/design/interaction/controls.md)（`DWG-I-CONTROLS`）。
