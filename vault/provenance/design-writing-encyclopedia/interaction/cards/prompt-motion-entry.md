# DWI-006 · Prompt Motion public entry example

来源：[Claude self-intro motion graphic entry](https://www.prompt-motion.com/1littlecoder-9fef89) · 状态：partial；仅为待核对的发现线索

## 这份来源是什么

Prompt Motion 的单条公开目录项，页面搜索摘录显示一条由作者提供的提示词，包含时长意图、创意方向，并链接作者来源。它是用户作品/提示词的聚合入口，不是运动设计研究、规范、播放器或作品托管质量保证。未进入或播放任何视频。

## 可以支持什么

只能支持“此 URL 可发现一个被整理的 prompt 条目，并标示作品描述/作者线索”的判断。它不能证明：生成输出长什么样、实际秒数、帧间运动是否平滑、文字是否正确、音画是否同步、减少动态行为如何，或该 prompt 能复现同一输出。

定位：[单条 entry](https://www.prompt-motion.com/1littlecoder-9fef89) 搜索结果描述的 Prompt / Model / Posted 信息；单独项目页与成品的身份、作者和媒体访问条件仍须核实。

## 用途、边界与重访

仅作为按题材发现动态设计候选的目录。若后续把具体作品纳入视觉观察，记录成品页面、媒介是否实际播放、所见的时长/环境和观察者可见特征；提示词与生成结果分开描述。不能把首页或静态目录描述当成“prompt motion 作品已验证”。

重访触发：实际需要观察某个作品并可访问其媒体时。关联语法：[motion choreography](../../../../../dsh-praxis/kit/design/motion/choreography.md)。

许可状态：提示词与媒体版权/嵌入/复制状态未查明；此处没有复制原句或媒体。证据形态：目录项文本搜索摘要，不含视频观看或源码执行，partial。
