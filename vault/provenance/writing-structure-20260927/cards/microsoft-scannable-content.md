# Scannable content — Microsoft Style Guide

来源：[原始页面](https://learn.microsoft.com/en-us/style-guide/scannable-content/) · 状态：`verified` · 访问：2026-09-27

用途：GRAMMAR / WRITING / SCANNABILITY / HEADING / LIST / TABLE / PARAGRAPH / NAVIGATION

## 是什么

Microsoft 将 heading、list、table、paragraph 视为帮助读者扫描的离散内容组件：长文应短而清楚，重要关键词放在 heading、table entry 和 paragraph 开头，类似信息保持平行结构；长文需要内部导航，段落保持短小。证据见页面第 31–40、45–59、60–75 行。

## 取用

当 README、Kit 或长报告需要整体检查扫描性时，先把内容拆为可识别的结构组件，再检查首屏信息、内部导航、关键词位置和重复结构。可以把它作为跨 heading/list/table/paragraph 的总览检查，与 Google 各专题页的语义 HTML 建议配合使用。

## 限制

页面正文前带有“access requires authorization”提示；本批只登记实际可读的上述行，不声称已核查隐藏或受限内容。三到七行是经验范围，受字体、宽度、设备和语言影响，不能直接成为 Praxis 的硬阈值；页面没有本仓库导航或使用效果数据。

## 何时重访

需要跨 heading/list/table/paragraph 做整体扫描性判断、长文缺少目录或回到顶部路径、目标页面需要本地化或响应式排版、授权状态变化或 Microsoft Style Guide 更新时重读原页面。
