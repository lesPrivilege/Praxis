# Lozana Rossenova · ArtBase Redesign Data Models

稳定 ID：`ASA-R-02`。来源：[原页](https://sites.rhizome.org/artbase-re-design/data-models.html)。

模型把作品、变体、参与者、文本、事件和保全活动分开：同一作品可经不同主体干预形成多种实例。它特别保留协作者与环境依赖，提醒目录不能只存标题、作者和截图。

读取定位：Artwork record model; Variant record model; Actor records model; Preservation metadata modeling。

证据范围：这是作者提出并解释的模型，不能把提案每一部分说成 ArtBase 的现有功能；本批没有复现其 PROV 案例。
