# Agent Design Resources Ecosystem

This stream records public project and protocol sources for design systems and design artifacts exposed to coding agents. It separates discovery candidates from the selected research exemplar, vendor descriptions from inspected contracts, and source claims from Praxis translations.

- [URL catalog](catalog.json) preserves each read URL.
- [Source cards](cards/README.md) record reading locations, claims, limits, and rights notes.
- [Entity map](entities.json) relates the projects, implementation substrates, and examples.
- [Research history](CHANGELOG.md) records this intake and boundaries.
- [Agent design resources](../../../../dsh-praxis/kit/design/references/agent-design-resources.md) translates two inspected contracts into task-level reference grammar.

The label “Open Design” is ambiguous. This stream does not infer which candidate the user intended. It uses the `nexu-io/open-design` project for the core technical exemplar because its public repository documents machine-readable design-system packages, skill/template separation, and integration boundaries. `opendesigner.io` is separately recorded as a candidate and its claims are not attributed to that repository.

## 证据与复用边界

本流仅有文档文本读取，没有安装、集成运行或视觉审阅。厂商说明与协议要求分别归于原作者，不作为实现验证。来源用途标签、证据形态与逐项权利维护在 [catalog](catalog.json)，卡片保留具体主张、定位和会影响取用的限制；获取与检查过程见 [研究记录](CHANGELOG.md)。文档或仓库许可不延伸至第三方字体、图像、品牌、组件、设计文件及服务权限。
