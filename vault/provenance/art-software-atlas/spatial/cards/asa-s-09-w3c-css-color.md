W3C CSS Color Module Level 4 说明 CSS 可在多种色彩空间指定颜色、插值並进行 gamut mapping。它为 DOM/CSS 原型提供色彩编码能力和边界说明；屏幕上的 CSS 光色是显示系统发出的像素，不能据此说房间中的墙受到了同等照明，或不同设备间出现同一知觉。

**边界。** 读取的版本标为 Candidate Recommendation Draft，是工作中的标准文本，不能用来主张所有浏览器都实现了所有特性。本轮未作浏览器测试；color-space 值也不等于现场亮度、适应状态或光谱。重访时检查当前规范和实现矩阵。
