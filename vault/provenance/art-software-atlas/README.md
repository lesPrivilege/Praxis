# 艺术、设计与软件语法 · 来源书目

从一项实践的原始语境找到可试的操作，再选择软件实现。这里是有边界的参考书样本：来源、作品、发现集合、实现工具与本仓库推导的语法分别有身份；相互关联不表示文化等价、效果已证或许可互通。

| 想了解的来源 | 从这里进入 | 能得到什么 |
|---|---|---|
| 编织、构造与材料约束 | [材料实践](material/README.md) | 具体作品、原有术语与构造关系 |
| 图形计数、排印与阅读方向 | [编辑与信息](editorial/README.md) | 作者的方法与不能通约的语言约束 |
| 光、空间与材料表面 | [空间材料](spatial/README.md) | 作品记录、呈现条件与屏幕转译边界 |
| 乐谱、时间与规则生成 | [时间与计算](temporal/README.md) | 指令、演出、算法和实例的不同角色 |
| 交互库、实验目录与数字艺术档案 | [发现与组件](discovery/README.md) | 从集合回到单件及实现契约的方法 |
| Open Design 候选与面向 agent 的设计资源 | [设计资源生态](ecosystem/README.md) | 名称歧义、供应方分类、集成与权限边界 |

只想解决设计问题时读 [操作入口](../../../kit/design/references/art-software-atlas.md)，不必通读书目。查字段与结构取舍读 [架构](architecture.md)；组合查询读 [索引](index.json)、[书目表](bibliography.csv) 与 [模式](schema.json)；规划下一轮读 [研究流地图](streams.md)。既有 [Design / Write 书目](../design-writing-encyclopedia/README.md)保持原位。

来源摘要支持离线初筛，外部原件与运行依赖没有整体快照。日期、访问活动、版本与失败见各分支 CHANGELOG 及 [交付记录](../../../docs/verification/art-software-atlas-20261011/README.md)。所有语法为 normal / reference；最终选择由消费设计师依据任务、受众与约束裁决。
