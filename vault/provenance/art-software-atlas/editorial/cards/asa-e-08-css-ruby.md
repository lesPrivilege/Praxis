# ASA-E-08 · CSS Ruby Annotation Layout Module

**来源原题名：** CSS Ruby Annotation Layout Module Level 1

**准确 URL：** https://www.w3.org/TR/css-ruby-1/

CSS 模块将 ruby 描述为附着在 base text 上的一小段注记，常用于东亚文档中的发音提示或简短释义。文档区分 group-ruby 与逐字关联，并讨论注记与正文的配对、换行和位置；这些概念可帮助软件保留注记和正文之间的语义关系。

**阅读位置：**摘要；第 1.1 节“What is ruby?”及示例；文档状态。

**支持的主张：** `ASA-E-08-E08-C1` — ruby 的定义与常见用途；`ASA-E-08-E08-C2` — 注记关联可采用组注或逐字关联；`ASA-E-08-E08-C3` — 文档状态为 Working Draft，而非稳定建议。
