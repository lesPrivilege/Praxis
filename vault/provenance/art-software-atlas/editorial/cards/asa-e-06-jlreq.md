# ASA-E-06 · Requirements for Japanese Text Layout

**来源原题名：** Requirements for Japanese Text Layout

**准确 URL：** https://www.w3.org/TR/jlreq/

W3C Japanese Layout Task Force 编写的文档描述日文排版需求，主要依据 JIS X 4051，也涵盖其外的部分事项。文档明确说其目标是说明问题和需求，而非提出完整的实现方案。章节涉及纵排与横排、页面规格、标点、行首/行尾禁则、ruby、标题、注释、插图、表格和页序。

**阅读位置：**摘要与状态；第 1.1–1.3 节；目录中第 2.3、3.1.7–3.1.9、4.3.5 节（ruby）；实现夹具时另参考“basic principles”和页面章节。

**支持的主张：** `ASA-E-06-E06-C1` — 文档的目的及其与 JIS X 4051 的关系；`ASA-E-06-E06-C2` — 文档称先厘清问题与需求，不直接提出完整实现；`ASA-E-06-E06-C3` — 文档列出的排版领域。

**限制：** 这是 Working Group Note，不是 W3C Recommendation；文档本身指出它可能被更新或取代。其需求描述的是一般日文排版，并承认有多种书写方向，不要求所有出版物都使用纵排。此卡记录对 W3C 托管报告文字的阅读；另两张仓库托管图示分别登记为 [ASA-E-11](asa-e-11-jlreq-vertical-comma-figure.md) 和 [ASA-E-12](asa-e-12-jlreq-horizontal-mixed-script-figure.md)。
