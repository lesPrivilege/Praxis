# ASA-E-07 · CSS Writing Modes Level 4

**来源原题名：** CSS Writing Modes Level 4

**准确 URL：** https://www.w3.org/TR/css-writing-modes-4/

CSS 模块将行内方向、块级流向和字形方向区分为书写模式的不同部分。文档列出 Latin、Arabic、Mongolian 和 Han-based 书写系统的常见方向，也指出杂志和报纸可在同一页混用横排与纵排。它是实现规范，不是完整的编辑设计指南。

**阅读位置：**摘要；第 1 节“Introduction to Writing Modes”；`writing-mode`、`direction` 与 `text-orientation` 的定义。

**支持的主张：** `ASA-E-07-E07-C1` — CSS writing mode 行为的三个组成部分；`ASA-E-07-E07-C2` — 文档列出的常见书写方向及单页混排可能性。

**限制：** 本次读取的版本标为 Candidate Recommendation；实际建构时应核对当前技术报告。规范文字不能证明某个浏览器与字体组合的支持情况。本卡仅记录文字阅读。
