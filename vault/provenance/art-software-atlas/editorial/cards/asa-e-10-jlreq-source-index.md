# ASA-E-10 · JLReq 源码索引

**来源原题名：** Requirements for Japanese Text Layout - 日本語組版処理の要件（日本語版）

**准确 URL：** https://raw.githubusercontent.com/w3c/jlreq/gh-pages/index.html

这是 W3C Japanese Layout Requirements 报告的公开源 HTML。`fig2_11` 附近的源码将其标为纵排中读点特殊处理的范例，并说明右列汉数字与读点采用紧排（solid setting）。`fig2_1` 则标为使用逗号与句点的横排日文文本范例。源码中的 figure caption 与 alt 说明可追溯到独立图片文件。

**阅读位置：**`fig2_11` 附近的源码（纵排数字与读点）；`fig2_1` 附近的源码（横排逗号与句点）；figure markup 指向 `images/img2_11.png` 和 `images/img2_1.png`。

**支持的主张：** `ASA-E-10-E10-C1` — 报告源码说明右侧纵排数字/读点行采用 solid setting；`ASA-E-10-E10-C2` — 源码将横排样例标为逗号和句点约定；`ASA-E-10-E10-C3` — 源码为两图提供身份、alt 与文件地址。

**限制：** 源码说明报告希望图示表达什么，不能证明浏览器实现或日文排版的普遍用法。此 raw repository file 与 W3C 托管的渲染报告是不同 URL 身份。
