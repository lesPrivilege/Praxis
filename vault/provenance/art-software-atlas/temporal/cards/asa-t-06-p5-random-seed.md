# ASA-T-06 · p5.js：`randomSeed()`

原始 URL：[p5.js Reference](https://p5js.org/reference/p5/randomSeed/)

## 来源摘要

p5.js 官方 API 参考说 `randomSeed()` 设置 `random()` 和 `randomGaussian()` 的种子；默认运行时会变化，固定常量参数可让这两个函数在每次 sketch 启动时给出同样的结果。

## 可支持与边界

支持该参考文档明示的重复运行行为；不支持浏览器间兼容保证、其他随机函数或模拟随机数质量判断，也没有执行示例。它是实现选项之一，不是视觉风格方法。
