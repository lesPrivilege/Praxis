# ASA-T-04 · V&A：Molnar 的 “machine imaginaire”

原始 URL：[V&A Blog](https://www.vam.ac.uk/blog/museum-life/vera-molnar-machine-imaginaire-the-dance-of-hands-and-machine-thinking)

## 来源摘要

V&A 博物馆文章把 Molnar 的 “machine imaginaire” 解释为手工与数学算法之间共享的视觉语言，描述她在获得计算机之前用网格、规则和自我设定约束探索图形组合。文章也强调即使由机器/绘图仪执行，作品仍保留创作者的判断和辨识度。这是博物馆作者的策展性解读，而不是 Molnar 对每件作品的逐项说明。

## 可支持与边界

可支持文章所述的手工算法过程、约束和作者性作为一种来源观点。文中部分措辞属于作者的个人感受，不能当成普遍心理规律；也不意味着任何伪随机输出都承载作者意图。

## 阅读位置与用途

“machine imaginaire” 与 manual algorithmic practice 的前两段、关于 authorship 的段落。供 [rule systems](../../../../../kit/design/motion/rule-systems.md)；[CHANGELOG](../CHANGELOG.md)。
