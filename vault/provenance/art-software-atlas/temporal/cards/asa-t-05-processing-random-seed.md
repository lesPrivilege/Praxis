# ASA-T-05 · Processing：`randomSeed()`

原始 URL：[Processing Reference](https://processing.org/reference/randomSeed_.html)

## 来源摘要

Processing 官方参考说明 `randomSeed(seed)` 设置 `random()` 的种子。默认调用每次运行会产生不同的伪随机结果；固定常量种子可让程序每次运行返回同样的伪随机序列。页面示例用它绘制一排按随机值控制灰度的线条。

## 可支持与边界

只支持该 Processing API 页面写明的可重复伪随机行为与示例；不支持统计随机质量、跨语言/版本逐比特一致性、加密随机、每次都不同的作品效果或用户意图判断。属于官方文档自述，需在实际项目使用具体版本时复核。
