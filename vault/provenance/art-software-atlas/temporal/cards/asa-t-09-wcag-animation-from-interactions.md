# ASA-T-09 · W3C：WCAG 2.2 SC 2.3.3 Understanding

原始 URL：[Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 来源摘要

W3C 对 WCAG 2.2 成功准则 2.3.3 的理解文件说明：由交互触发、非必要的动画应允许关闭，必要于功能或信息的动画除外；并将交互触发动画与 2.2.2 自动启动的 Pause, Stop, Hide 区分。文中列举 `prefers-reduced-motion` CSS 媒体查询、JavaScript 查询和用户偏好控制等技术。

## 可支持与边界

这是 WCAG 2.3.3 的 explanatory document 与标准解释，不代替规范文本、完整适用性判断或产品合规审查。该条与 auto-start 内容的标准范围不同；受众、平台和目标符合级别需单独判断。没有检查任何实现。
