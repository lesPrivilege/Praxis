# Temporal stream research record

## Initial bounded research

- Scope: graphic/event scores, Vera Molnar’s rule-based and intentionally perturbed drawing practice, timing documentation for Tone.js and SuperCollider, reproducible pseudo-random seeds, and WCAG interaction-triggered animation.
- Selection: ten distinct public URLs from museum/editorial scholarship and primary library/documentation sources. No matching canonical URLs were found in the existing `vault/provenance` catalog scan.
- Search: Exa Search result slots requested: 45 (three broad angle queries of 10, one targeted Molnar query of 10, and one primary-source PDF discovery query of 5); read URLs total ten. The W3C page was fetched directly after selecting the criterion for scope, not found in an additional Exa search. Search result slots are not claims verified.
- Consumed: Getty Research Institute object record for Earle Brown, *December 1952*; Getty introduction to *The Scores Project*; Earle Brown’s official music foundation preface PDF for *Folio and Four Systems*; Morgan Library record for Vera Molnar, *Interruptions*; V&A contextual essay on Molnar’s “machine imaginaire”; official Processing and p5.js `randomSeed()` references; Tone.js Transport docs; SuperCollider server timing guide; W3C WCAG 2.2 Understanding 2.3.3.
- Evidence: all ten URLs read as text. Visual inspection follow-up: direct GET of the Getty score image `https://www.getty.edu/publications/scores/_assets/images/figures/posters/sequences--301-001.jpg` and thumbnail `https://www.getty.edu/publications/scores/_assets/images/figures/thumbnails/r2014200_980039_b170_f1_033_th.jpg` returned HTTP 403; direct GET of the Morgan image `https://www.themorgan.org/sites/default/files/images/collection/drawings/405692v_0001.jpg` returned HTTP 403; headless browser navigation to the Getty object page returned `net::ERR_TUNNEL_CONNECTION_FAILED`. The Getty book PDF screenshot request `https://www.getty.edu/publications/scores/_assets/downloads/the-scores-project.pdf` (page 25) timed out in the screenshot tool with a 400 timeout response (remote HTTP status unknown); the artist-foundation preface PDF screenshot call returned an image marker but no image payload for inspection, and direct GET returned HTTP 403. An alternate Getty figure repository was reported in handoff as private and limited to publication use; it was not accessed. Therefore no visual artifact was actually inspected. No audio was listened to, no demonstration was executed, and no code was run.
- Limits: the museum and institutional texts support the named work descriptions and historical framing only within their stated scope. The framework docs support documented API/timing behavior, not an auditory quality judgment, synchronization guarantee in a concrete running system, browser/device behavior, or accessibility conformance of an implementation. The Molnar human intention/agency framing is treated as source-authored interpretation, not as a universal property of generative art.
- Open follow-up: inspect an accessible authorized image of a specific score and a specific Molnar drawing; optionally run paired visual/audio scheduling examples in a documented environment and audition the sound before making perceptual claims.
