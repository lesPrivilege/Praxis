# ASA-M-05 · Tile Decorated with Entrelacs Pattern Based on Octagons

来源：[The Metropolitan Museum of Art object record](https://www.metmuseum.org/art/collection/search/452379) · 状态：verified（仅限馆方对象说明）

用途：单件建筑构件、材料和纹样的连接案例。派生参考见 [Material relations](../../../../../kit/design/composition/material-relations.md)。

## 摘要与定位

馆方将此物登记为14世纪后半、今乌兹别克斯坦的布哈拉或撒马尔罕所制，石质陶土（stonepaste），刻纹并施绿松石与深紫釉。它可能原属 Buyan Quli Khan 陵墓的檐带。对象描述建议一种阅读顺序：看两处深色大八边形，内部各包含八角星与四瓣花饰；再看贯穿其中的绿松石交织，称它由两边开放的半八边形构成。馆方称这一复杂纹样不易被单一几何解释完全规整。

- 对象描述：推定建筑用途、地区、材料、颜色、图形构成及解释保留。支持 ASA-M-05-C1。
- Artwork Details：年代、产地、材质、装饰方法、编号。支持 ASA-M-05-C2。
- 图像 URL 可由对象页打开，但本轮下载返回 HTTP 403；未目视作品。

对软件设计有用的证据不是把它约化成一个重复图标，而是单片构件、底釉、刻纹、开放边和主纹彼此关联；这些线索来自馆方文字，不能代替对图版和相邻构件的观察。

## 限制与重访

原属陵墓是馆方推定；单件残片记录不能证明完整墙面或其全部重复单位。馆方关于难以规整的文字是对作品阅读的解释，并非历史制作方法证据。无本地快照。

如需讨论纹带重复范围、几何路径或釉陶工艺，应取得物件清晰图像及原建筑 / 同类构件资料，并另查技术来源。
