# WPS 365 open platform

来源：[原始页面](https://open.wps.cn/documents/app-integration-dev/guide/overview) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

WPS 官方开放平台称有上千 OpenAPI，覆盖通讯录、云文档、消息、会议、日历等，并称部分接口适配 MCP。

## 证据与使用边界

能力、权限和租户审核决定实际可用性；产品宣传数字需按版本复查。

## 何时重访

WPS tenant、API 版本或 MCP 能力变化时复查。
