# Google Workspace CLI (gws)

来源：[原始页面](https://github.com/googleworkspace/cli/blob/main/README.md) · 状态：`partial`

用途：GRAMMAR / BUILD

## 摘要

仓库自称统一 Drive/Gmail/Calendar 等 API 的 structured JSON CLI，支持 schema introspection、dry-run、分页和 skills；明确声明非 Google 官方支持产品、v1.0 前活跃开发。

## 证据与使用边界

不能把社区仓库当 Google 官方产品；命令/API、权限和 breaking changes 需锁版本。

## 何时重访

将 gws 用于企业账号或关键路径前复查仓库版本/授权。
