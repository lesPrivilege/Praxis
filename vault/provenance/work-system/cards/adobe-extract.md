# Adobe PDF Extract API

来源：[原始页面](https://developer.adobe.com/document-services/docs/overview/pdf-extract-api/) · 状态：`verified`

## 摘要

Adobe API 可对 native/scanned PDF 输出结构化 JSON 或 Markdown，识别文本、表格和图形。
