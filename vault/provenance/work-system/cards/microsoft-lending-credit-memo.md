# Banking - Modernize lending processes

来源：[原始页面](https://enablement.microsoft.com/en-us/scenario-library/financial-services/speed-credit-memo-generation/) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Microsoft 官方金融服务场景展示从客户财务/项目材料与贷款申请抽取信息，计算财务比率并评估信用评级，再生成贷款评估摘要和 draft credit memo，供信用分析师与合规人员进一步讨论。

## 证据与使用边界

页面明确是 Copilot 场景示例，最终流程、内控、法域合规和人工决策责任需由机构自行验证；不应把 draft memo 当成自动授信。
