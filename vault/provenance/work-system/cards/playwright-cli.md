# Playwright CLI for coding agents

来源：[原始页面](https://playwright.dev/docs/getting-started-cli) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Playwright 官方将 playwright-cli 定位为 coding agents 的低 token、skill-based CLI，并与 MCP 的持久探索场景区分。

## 证据与使用边界

需要 Node 20+；浏览器登录、站点权限和反自动化策略仍可能阻塞。
