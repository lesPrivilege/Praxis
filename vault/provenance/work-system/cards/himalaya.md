# Himalaya email CLI

来源：[原始页面](https://github.com/pimalaya/himalaya) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

项目 README 列出 IMAP/SMTP/JMAP、Gmail REST、Microsoft Graph、多账户和 --json；还描述 OAuth token broker 与 secret command。

## 证据与使用边界

项目是第三方 CLI；OAuth v2 不内置 flow，凭证、版本和 provider 行为需治理。

## 何时重访

迁移邮件 provider、凭证方式或发送权限时复查。
