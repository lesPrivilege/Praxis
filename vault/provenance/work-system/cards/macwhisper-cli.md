# MacWhisper CLI

来源：[原始页面](https://docs.macwhisper.com/article/57-macwhisper-command-line-tool) · 状态：`verified`

用途：GRAMMAR / FIELD_PRACTICE

## 摘要

支持页说明 CLI 通过本地 socket 与运行中的 MacWhisper app 通信，并可批量输出 transcript。

## 证据与使用边界

CLI 依赖 app 正在运行和本地配置；不能推导无头服务稳定性。

## 何时重访

CLI 版本、运行方式或批量转录 SLA 变化时复查。

引用映射与核查日期见 [catalog](../catalog.json)。本卡为登记结果的阅读投影；补充找到的来源不代表恢复原Chat隐藏引用。
