# n8n execution history/retry

来源：[原始页面](https://docs.n8n.io/workflows/executions/all-executions/) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

官方文档支持查看 execution、按状态筛选，并以原 workflow 或当前保存 workflow 重试失败执行。

## 证据与使用边界

删除 workflow 会删除其 execution history；custom data 的套餐可用性有限。

## 何时重访

审计、保留期、重试幂等或套餐变化时复查。

引用映射与核查日期见 [catalog](../catalog.json)。本卡为登记结果的阅读投影；补充找到的来源不代表恢复原Chat隐藏引用。
