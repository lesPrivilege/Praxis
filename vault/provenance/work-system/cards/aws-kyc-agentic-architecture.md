# Modernizing KYC with AWS serverless solutions and agentic AI for financial services

来源：[原始页面](https://aws.amazon.com/blogs/architecture/modernizing-kyc-with-aws-serverless-solutions-and-agentic-ai-for-financial-services/) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

AWS 架构博客把 KYC 参考流程拆为身份验证、文档分析、欺诈检测、合规与风险、客户体验等子任务，并以置信度示例路由自动批准、补充验证或人工审查。

## 证据与使用边界

这是 AWS 参考架构；文中的置信度阈值和 Agent 划分是示例，不是 KYC/AML 法定阈值或通用合规结论。
