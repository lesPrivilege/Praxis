# CLI for Microsoft 365 MCP server

来源：[原始页面](https://github.com/pnp/cli-microsoft365/blob/main/docs/docs/user-guide/using-cli-mcp-server.mdx) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

MCP server 是 CLI for Microsoft 365 的 wrapper，将自然语言转成 CLI 命令/链；复用 CLI 登录上下文。

## 证据与使用边界

不是 Microsoft 官方 MCP；自然语言 wrapper 仍需命令审阅和 tenant policy。

## 何时重访
