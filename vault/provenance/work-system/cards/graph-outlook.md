# Outlook mail API overview

来源：[原始页面](https://learn.microsoft.com/en-us/graph/outlook-mail-concept-overview) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Microsoft Graph Outlook mail API 支持云端主邮箱和共享邮箱等邮件/日历/联系人数据。

## 证据与使用边界

不支持 in-place archive mailbox；权限、版本和租户配置需逐项核实。
