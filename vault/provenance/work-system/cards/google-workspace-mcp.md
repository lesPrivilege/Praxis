# Google Workspace Remote MCP servers

来源：[原始页面](https://developers.google.com/workspace/guides/configure-mcp-servers) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Google 官方文档列出 Gmail/Drive/Docs/Sheets/Slides/Calendar/Chat 等 remote MCP endpoint，并使用 OAuth 2.0。

## 证据与使用边界

工具覆盖、账号类型和租户政策会变；MCP 连接不等于写操作授权。

## 何时重访
