# 腾讯云 ADP 前沿部署工程师（FDE）认证指南与生态伙伴

来源：[原始页面](https://adp.tencent.com/zh/blog/adp-fde-certification-guide) · 状态：`verified`

用途：GRAMMAR / FIELD_PRACTICE / SCALE

## 摘要

腾讯云官方指南将企业级智能体 FDE 能力拆为需求分析、方案设计、应用搭建、交付实施和安全合规，并说明真实客户需要适应业务流程、接入企业数据/系统并持续运行的应用。

## 证据与使用边界

这是腾讯云 ADP 的认证与产品方法视角，不是大陆所有 FDE 岗位的统一职业标准；认证范围和页面表述会变化。

## 何时重访

认证大纲、ADP 产品能力或 FDE 角色范围更新时复查。
