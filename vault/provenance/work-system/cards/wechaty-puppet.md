# Wechaty Puppet

来源：[原始页面](https://wechaty.js.org/docs/specs/puppet) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Wechaty 文档说明 Puppet 是控制 IM 协议的抽象层，列出 Web/iPad/iOS 等 provider，并保存 session secret。

## 证据与使用边界

社区/协议适配存在 provider 生命周期和合规风险；不是个人微信官方通用 API。

## 何时重访

个人微信是否进入关键路径、provider 状态或企业合规要求变化时复查。

引用映射与核查日期见 [catalog](../catalog.json)。本卡为登记结果的阅读投影；补充找到的来源不代表恢复原Chat隐藏引用。
