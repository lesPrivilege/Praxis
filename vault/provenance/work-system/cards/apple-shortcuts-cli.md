# Run Shortcuts from command line

来源：[原始页面](https://support.apple.com/en-gb/guide/shortcuts-mac/-apd455c82f02/mac) · 状态：`verified`

用途：GRAMMAR / FIELD_PRACTICE

## 摘要

Apple 支持 shortcuts run/list/view，支持文件输入、stdout/文件输出和退出码；建议避免弹窗/输入以便命令行自动化。

## 证据与使用边界

需要 macOS Shortcuts 权限；特定 App Intent 仍需按机器与版本测试。
