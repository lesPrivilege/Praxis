# Pandoc User's Guide

来源：[原始页面](https://pandoc.org/MANUAL.html) · 状态：`verified`

用途：GRAMMAR / FIELD_PRACTICE

## 摘要

Pandoc 是通用文档转换器，reader 解析为 AST，writer 输出多种格式；文档同时说明复杂布局/表格可能有损。

## 证据与使用边界

转换不是保真渲染；复杂 Office、PDF 和版式需逐项 QA。

## 何时重访

文档格式、AST filter 或交付保真要求变化时复查。

引用映射与核查日期见 [catalog](../catalog.json)。本卡为登记结果的阅读投影；补充找到的来源不代表恢复原Chat隐藏引用。
