# @deepseek-ai/dsh-home-paths

来源：[原始页面](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/util/home-paths/README.md) · 状态：`verified`

用途：GRAMMAR / SCALE

## 摘要

官方 home-paths 说明 Harness home 的优先级是显式配置、$DSH_HOME、最后 ~/.dsh；并提供从同一根目录推导 settings/cache 等子路径的 helper。

## 证据与使用边界

该库只证明 home 的解析规则；把两个 home 作为 Praxis 与 coding 的隔离策略是本 Kit 的工程推论，仍需按实际凭据、浏览器 profile、端口和桌面打包验证。

## 何时重访
