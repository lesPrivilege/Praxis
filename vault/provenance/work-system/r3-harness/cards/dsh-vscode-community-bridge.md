# DeepSeek Harness WebUI for VS Code discussion

来源：[原始页面](https://github.com/deepseek-ai/deepseek-harness/discussions/915) · 状态：`partial`

用途：BUILD / GRAMMAR

## 摘要

官方仓库的 Show Your Plugins 讨论记录一个非官方 VS Code 扩展：把 DSH WebUI 映射到 IDE 原生扩展页/面板，并提供服务启动、状态和日志操作。

## 证据与使用边界

讨论支持的是社区扩展存在与其作者自述；没有证明它通过官方 client-plugin seam 注入 profile，也没有官方维护或兼容承诺。

## 何时重访

要采用 VS Code bridge、依赖多 webview 或宣称官方 seam 兼容时复查扩展仓库和当前 DSH client API。
