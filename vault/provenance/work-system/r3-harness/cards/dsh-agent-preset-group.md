# packages/preset group

来源：[原始页面](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/preset/README.md) · 状态：`verified`

用途：GRAMMAR / SCALE

## 摘要

preset group 将 agent preset 定义为含一个 agent.cordis.yml 的目录；每个 session 可拥有自己的 tools、prompt sections 和 skills 组合，agent-presets 管 roster/discovery/mount，单进程可同时运行不同 composition 的 agents。

## 证据与使用边界

该页说明 Harness 的 composition grammar，不是对任意社区 preset 的审核，也不把 model routing 归入 preset。

## 何时重访

新增 preset 类型、用户目录、继承或 session composition 规则时复查。

引用映射与核查日期见 [catalog](../catalog.json)。本卡为登记结果的阅读投影；补充找到的来源不代表恢复原Chat隐藏引用。
