# Home Manager introduction

来源：[原始页面](https://nix-community.github.io/home-manager/introduction.html) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

Home Manager 官方手册将其描述为基于 Nix、可复现管理用户 home 目录的工具，覆盖程序、配置文件、环境变量和任意文件，并强调跨主机一致性。

## 证据与使用边界

这是 Home Manager/Nix 生态的能力说明，不代表适合所有企业 Fresh Mac；版本锁定、MDM 冲突、学习成本和运维责任需另评估。
