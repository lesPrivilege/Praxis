# Apple Platform Security: Keychain access control

来源：[原始页面](https://help.apple.com/pdf/security/en_US/apple-platform-security-guide.pdf) · 状态：`verified`

用途：GRAMMAR / GOVERNANCE

## 摘要

Apple Platform Security 官方指南把 Keychain 描述为保存用户名、密码、数字身份、加密密钥和 secure notes 的安全存储，并讨论 Keychain access control。

## 证据与使用边界

平台安全指南是系统能力说明，不是 Praxis credential lifecycle 或第三方 secret manager 的部署规范。

## 何时重访

Apple 平台安全指南、Keychain access control 或企业设备安全基线变化时复查。
