# W3C Time Ontology in OWL

来源：[原始页面](https://www.w3.org/TR/owl-time/) · 状态：`partial`

用途：GRAMMAR / REFERENCE

## 摘要

W3C Candidate Recommendation Draft，2022-11-15，不是正式的 Recommendation。Instant 是没有延展的时间实体，Interval 是有延展的；before 的定义是前一个的结束早于后一个的开始，对时刻是基本关系，对区间是导出的；时长另由 Duration 表达。时间参照系可以是序数式的，即一列有名字的区间，不一定等长。Time Zone 说明当地时间相对 UTC 的偏移。页面里没有找到关于结束未知的区间的说法。本仓库取用“先后和时长是两个问题”“时刻与区间分开”。
