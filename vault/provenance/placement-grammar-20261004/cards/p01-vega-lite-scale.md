# Vega-Lite 文档：Scale

来源：[原始页面](https://vega.github.io/vega-lite/docs/scale.html) · 状态：`partial`

用途：GRAMMAR / REFERENCE

## 摘要

Vega-Lite 的在线文档，页面上没有版本号、日期和许可声明。尺度分三类：连续的（linear、time、utc 等，把连续的定义域映到连续的范围）、离散的（ordinal、band、point）和把连续值分档的。band 和 point 接受离散的定义域，映到像素这样的连续范围；band 把范围分成均匀的带。本仓库取用“只有先后”与“先后加时长”是两类尺度这一分法；文档没有说离散尺度不表示大小，那一句是本仓库的推断。
