# Markdown to Mind Map

来源：[原始页面](https://xmind.com/user-guide/markdown-to-mind-map) · 状态：`verified`

用途：GRAMMAR / DOCUMENTATION / XMind_IMPORT

## 摘要

Xmind 官方用户指南说明可从 File → Import → Markdown 导入 .md；标题层级映射为节点层级，第一行文本或标题成为中心主题，并支持粘贴 Markdown 文本。

## 证据与使用边界

官方指南用于核对导入能力；具体输出遵循用户提供的 xmind-md/0.1。单一 H1、短标题、列表解释，不依赖表格、代码围栏或 HTML。未执行本机 Xmind 实测，不能把文档核查视作导入验收。

## 何时重访

Xmind 修改 Markdown 导入入口、标题映射、最大层级或纯文本粘贴规则；Xmind 导入实测出现 H1、H2、H3、H4 结构丢失；仓库新增 md/xmind profile。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
