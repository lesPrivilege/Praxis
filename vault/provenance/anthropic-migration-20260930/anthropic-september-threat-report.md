## Source-level finding

Anthropic describes proxy networks/transfer stations as part of illicit, industrial-scale access campaigns using fake accounts, stolen identities/payment methods, or stolen API keys to circumvent geographic and related controls; some third-party routers also retained and resold user transcripts. It also reports account-level metadata/content as campaign attribution signals. This concerns adversarial bulk abuse and user-data exposure through untrusted intermediaries. It does not establish that ordinary device migration, a changed home/work IP, or a legitimate corporate proxy triggers enforcement.

## Limits
