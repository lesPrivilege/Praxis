# Before you recycle, sell, or gift your Xbox or Windows PC

- URL: https://support.microsoft.com/en-us/accounts-billing/security/before-you-recycle-sell-or-gift-your-xbox-or-windows-pc
- Retrieved: 2026-09-30
- Publisher: Microsoft Support (official first-party documentation)
- Evidence state: verified-online-no-page-snapshot
- Locator: “Reset a Windows device” and “Remove a device from your Microsoft account”.

## Source-level finding

Microsoft says back up needed data, reset Windows through System > Recovery > Reset PC, then remove the reset device from the personal Microsoft account; unlinking is a separate optional Store device-limit action.

## Limits

This is the consumer account/consumer Windows reset flow. Organization-owned or enrolled hardware needs the organization’s IT process before reset/disposal.
