## Source-level finding

Claude Code requires internet access and location in an Anthropic-supported country. Supported authentication choices include Claude.ai with Pro/Max, Anthropic Console, and enterprise cloud providers. Anthropic says Claude Code securely stores credentials and directs readers to Credential Management. For a normal device move, reinstall from the official source, authenticate through the intended account/provider, and check the credential-management steps for the currently installed version.

## Limits

This page does not provide a per-device remote revoke procedure; Claude account token revocation is documented separately. Installation commands and supported OS versions may change.
