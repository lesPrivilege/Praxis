# JevBench README

来源：[原始页面](https://github.com/fstandhartinger/jevbench/blob/main/README.md) · 状态：`partial`

用途：GRAMMAR / SCALE / SOURCE

## 摘要

JevBench v1.3.0 将 chance-corrected Intelligence、Calibration、Speed、Cost 以几何平均组合，基于 534 decisions；Cost 明确是每 1,000 个 decision，不是 token。README 还把 classifier.dev Fast 标为 Jev 底层服务的 honorable mention，不与 Jev 自身重复排名。

## 证据与使用边界

复合权重、延迟 ×2/+0.15s 调整和部分价格估算是 benchmark 作者规则/假设；534 decisions 不是所有业务任务，榜单不等于生产 SLA 或独立业务正确性。

## 何时重访

JevBench 版本、decision set、复合权重、价格/延迟口径或 classifier.dev 底层模型变化时；引用数字需锁定 tag/artifact。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
