# Jev is now available in LangSmith Evals

来源：[原始页面](https://www.langchain.com/blog/jev-is-now-available-in-langsmith-evals) · 状态：`partial`

用途：GRAMMAR / SCALE / SOURCE

## 摘要

LangSmith 公告说明 Jev 可作为 online evaluator，以 typed questions 生成 feedback keys；文中直接复用 S05 结果，并在当时的 LangSmith provider 配置说明中写出 TypeSafe 当前不提供 ZDR。

## 证据与使用边界

它不是第二次独立实验；ZDR 表述是该接入路径/公告时点的产品说明，和 TypeSafe enterprise ZDR 索引及 Vercel AI Gateway 的按请求 ZDR 选项不能拼成统一账户结论。

## 何时重访

LangSmith provider、TypeSafe 合同、ZDR 选项、在线 evaluator 数据流或 S05 实验版本变化时；分别核对通道与账户。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
