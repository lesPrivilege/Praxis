# What is OpenTelemetry

来源：[原始页面](https://opentelemetry.io/docs/what-is-opentelemetry/) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

OpenTelemetry 是厂商中立的观测性框架/工具包，不是后端；支持代码和零代码插桩。

## 证据与使用边界

不能据此选择 Collector、后端或保留期。

## 何时重访

落地 traces/metrics/logs 方案时复查。
