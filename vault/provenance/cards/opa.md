# Open Policy Agent

来源：[原始页面](https://www.openpolicyagent.org/docs) · 状态：`verified`

用途：GRAMMAR / BUILD

## 摘要

OPA 将策略作为代码并通过 API 外置决策，与应用执行解耦。

## 证据与使用边界

策略治理、发布、测试和故障回退仍需项目设计。
