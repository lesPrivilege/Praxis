# H03 · Bauhaus-Archiv：Preliminary Course, Workshops and Bauhaus Diploma

来源：[原始页面](https://www.bauhaus.de/en/discover/article/preliminary-course-workshops-and-bauhaus-diploma/) · 状态：`verified` · 重访：2026-10-02（ok）

用途：GRAMMAR / DESIGN-HISTORY / PROFILE

## 是什么

Bauhaus-Archiv 的培训体系说明，足以支持课程随时期和负责人变化、1927 年才有常设建筑课程。另有图注 Johannes Zabel 的 Balance study（Moholy-Nagy 预备课，约 1923）。页内还有 1919–1933 年表链接，以及摄影、纺织、广告系的名称。

页面所见：Bauhaus-Archiv / Museum für Gestaltung，2025-05-13

## 台账要点与本轮重访

- 有依据：课程／材料方法随时期和负责人变化。Itten/Muche 时期重色彩、形式、材料与放松练习；Moholy-Nagy/Albers 转向材料及其性能；Meyer 增加工程、心理学、商业；Mies 把学校变为建筑学校并取消必修预备课。
- 有依据：1927 常设建筑课程。明说 1927 年建筑成为常设课程，此前只是私人事务所里的个别项目。
- 有依据：Dessau 原型与后期建筑导向。Dessau 阶段强调住宅与住宅区的实践实验、模型与原型；Mies 时期建筑居首并有附属工坊。
- 有依据：（不支持项）学校等于三原色几何主题。文中没有这类断言。
