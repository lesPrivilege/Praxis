# H01 · Swiss National Library：The International style 1950–1970

来源：[原始页面](https://www.nb.admin.ch/en/the-international-style-1950-1970) · 状态：`verified` · 重访：2026-10-02，两次（ok）

用途：GRAMMAR / DESIGN-HISTORY / PROFILE

## 是什么

瑞士国家图书馆的专题页，确认三个名称指同一入口，并列出网格、无衬线、摄影、理性构图等特征；页末另有 Hofmann 与巴塞尔学派的人物说明。

页面所见：Swiss National Library

## 台账要点与本轮重访

- 有依据：International Style / International Typographic Style / Swiss Style 的同入口关系。正文直接说新兴的 International Style 也称 International Typographic Style 或 Swiss Style。
- 有依据：网格、无衬线、摄影与秩序的历史倾向。列出排版网格、无衬线字体、以（多为黑白）摄影代替插画，并强调理性构图、高度结构化。
- 有依据：（不支持项）Helvetica 必选。页面全文没有出现 Helvetica，与台账「不支持」一致。

与台账不符或需注意：台账记“未看图”，本仓库第二次重访看了页内的一张海报。

## 第二次重访

2026-10-02，Opus 5.5 主会话，应用内浏览器直接读页面文字。读了页面全文，并看了页内唯一一张图：Armin Hofmann 为巴塞尔工艺美术馆做的展览海报。海报由四行手工构成的黑色大字铺满纸面，右侧一小块展讯用衬线字、右对齐，行尾落在同一条竖线上，另有一条赭色横带，没有照片。页面自己列的特征里有“无衬线”和“以摄影代替插画”，这张配图两项都不符合。profile 里的“清晰层级”是转述，页面原话是结构严整、和谐、易读的构图。

## 限制

不能证明所有瑞士作品都同样，不能证明 Helvetica 必选，不能作 UI 规则。只看了页内一张海报，一张图不代表整个时期。
