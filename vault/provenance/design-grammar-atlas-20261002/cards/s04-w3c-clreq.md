# S04 · W3C 中文排版需求 CLReq

来源：[原始页面](https://www.w3.org/TR/clreq/) · 状态：`verified` · 重访：2026-10-02（ok）

用途：GRAMMAR / STANDARD / DESIGN-SYSTEM

## 是什么

中文排版需求的 W3C 草案说明，能支持地区差异、混排与禁则严格度分级。

页面所见：W3C Internationalization WG（Chinese Layout Task Force）；W3C Group Note Draft, 01 September 2026

## 台账要点与本轮重访

- 有依据：2026-09-01 Group Note Draft。页头及元数据均为该日期，并声明草案不被 W3C 或其成员背书。
- 有依据：地区不等于简繁。文中说明大陆、台湾、香港、澳门、新加坡、马来西亚等地各有规范化字形与排版规则。
- 有依据：横竖排、混排、标点位置/挤压。有横排竖排章节，西文在竖排中的处理，以及标点位置的地区差异。
- 有依据：行首行尾禁则、不可分单元。有行首行尾禁则章节与不可断开标记的规则。
- 有依据：禁则严格度可配置。原文列出四种严格度的断行规则：不处理、基本、GB 法、严格；并注明各地常见用法。

## 限制

不是强制标准；不能当作日韩排版依据；本次未核查文中所引国家标准全文。 本轮只读文字，没有看图。
