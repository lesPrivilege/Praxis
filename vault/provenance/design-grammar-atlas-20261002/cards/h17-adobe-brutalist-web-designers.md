# H17 · Adobe：Brutalist Web Designers Eschew Rules for UX Best Practices

来源：[原始页面](https://blog.adobe.com/en/publish/2016/12/01/brutalist-web-designers-eschew-rules-for-ux-best-practices) · 状态：`verified` · 重访：2026-10-02（ok）

用途：GRAMMAR / DESIGN-HISTORY / PROFILE

## 是什么

Adobe 的编辑采访，Deville 等人谈反同质化、极简、粗粝与艺术动机。

页面所见：Adobe Blog，署 The Adobe XD Team，2016-12-01

## 台账要点与本轮重访

- 有依据：不同创作者的反同质化。Deville 说 UX 设计本应不是一种风格，却已变成风格，使网站雷同。
- 有依据：极简、粗粝。Deville 谈设计师想去掉创意元素；并把「不漂亮」类比为朋克式的风格。
- 有依据：艺术动机。Ryan Pickard 说漂亮设计已见顶，出现反叛；Max Robinson 认为网页设计终究是艺术。
- 有依据：（不支持项）编辑开头「更难导航」。开头确有「更粗糙、更基础，同时更难导航」之语，为编辑口吻，台账已设为不采纳。

## 限制

平台有产品营销背景；不能证明用户成效；不能把「更难导航」当 UI 目标。 本轮只读文字，没有看图。
