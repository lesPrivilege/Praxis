# H05 · NGV：Carlton room divider

来源：[原始页面](https://www.ngv.vic.gov.au/essay/carlton-room-divider/) · 状态：`verified` · 重访：2026-10-02（ok）

用途：GRAMMAR / DESIGN-HISTORY / PROFILE

## 是什么

NGV 馆藏释读，足以支持 Carlton 兼具雕塑与实用角色，以及几何结构与印花层压板。

页面所见：National Gallery of Victoria；藏品号 D76.a-c-1985；版权署名 © erede Ettore Sottsass / Copyright Agency, 2024

## 台账要点与本轮重访

- 有依据：1981、设计／制造者、材料。1981，Ettore Sottsass 设计，Memphis, Milan 制造兼销售；材料为木、热固性层压板、金属、塑料。
- 有依据：雕塑性与实用性并存。文中说它被设计成像雕塑一样独立站立，同时是实用兼装饰的家具。
- 有依据：几何构件、斜向关系、印花层压板。方、长方、三角形被斜向构件赋予意外转折；Memphis 家具常用带印花的塑料层压板。

与台账不符或需注意：页面作者署名在抓取摘要中未显示 Amanda Dunsmore；此项未能核实，不当作不符。
