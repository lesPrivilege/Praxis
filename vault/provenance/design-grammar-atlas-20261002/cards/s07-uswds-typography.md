# S07 · USWDS：Typography

来源：[原始页面](https://designsystem.digital.gov/components/typography/) · 状态：`verified` · 重访：2026-10-02，两次（ok）

用途：GRAMMAR / STANDARD / DESIGN-SYSTEM

## 是什么

美国政府网页设计系统的排版指导，支持各排版变量互相牵制及标题归属等原则。

页面所见：U.S. Web Design System (GSA)；Exa 副本标 Published 2026-08-28；页面元数据 published/modified 2026-09-28；页面标注 Passed WCAG 2.1 AA

## 台账要点与本轮重访

- 有依据：字号、行长、行距、留白互相影响。页面分别给出正文至少 16px、行长约 45–90 字符、长文行高至少 1.5、段间留白。
- 有依据：标题靠近所属段落。标题上方留白不少于下方的 1.5 倍，以强化与后续内容的联系。
- 有依据：短标签与长文可采用不同目标。说明、脚注等可超出一般行长范围，界面元素行距较紧。
- 有依据：16px、45–90 字符、左对齐等并非所有语言媒介的硬规范。页面确有这些默认值，且面向英文政府网页，台账限定正确。
- 有依据：衬线更适于长文不升级为实验结论。页面仅称衬线字体多为易读性而设计，未引用实验。

与台账不符或需注意：台账日期 2026-08-28 与页面元数据 2026-09-28 不一致；Exa 副本仍为 08-28，疑为缓存时差，需主代理裁决采用哪一个。
