# Model Context Protocol — The 2026-07-28 Specification

来源：[原始页面](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · 状态：`verified`

用途：GRAMMAR / SCALE

## 摘要

MCP 官方 2026-07-28 发布说明将协议核心改为无会话/可路由，并为 tools/list 结果提供 ttlMs/cacheScope；工具变更通知迁移到客户端主动订阅的 subscriptions/listen，支持更可控的目录缓存和刷新。

## 证据与使用边界

这是协议发布说明，不证明每个 agent、MCP server 或 SDK 已实现/协商该版本；Chat 中引用的 2025-11-25 listChanged 语句需要按目标连接版本重新核对。

## 何时重访

MCP 协议/SDK 升级、版本协商、工具目录缓存或 subscriptions/listen 实际支持变化时。

来源身份、核查日期、支持主张与选型状态见 [catalog](../catalog.json)。
