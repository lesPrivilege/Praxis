# Anthropic — Steering thinking and cost

来源：[原始页面](https://platform.claude.com/docs/en/build-with-claude/thinking-steering-and-cost) · 状态：`verified`

用途：GRAMMAR / SCALE

## 摘要

Anthropic 文档说明 thinking/effort 可按请求和任务控制，长任务应观察推理、工具和上下文管理的总成本；本批将其作为节点预算与任务预算拆分的外部对照。

## 证据与使用边界

供应商 API 文档；不把单次 max_tokens、thinking 档位或其成本口径外推成完整 agent run 的预算上限。

## 何时重访

thinking、effort、context editing、prompt caching 或供应商计费文档变化时。
