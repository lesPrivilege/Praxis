# Palantir 入职书单系列的视频管线

原件：<palantir/reading-list-series/build/README.md>

## 是什么

旁白带领的系列片管线：单集与合集由同一份正文排出。按段合成配音并对回逐字时间，程序铺底混音，无头浏览器逐帧渲染，再做成片检查（静止、空白、字号、转写、响度，合集另查同源与接缝），出 4:3 与 3:4 原生封面。一集五步：assemble → mix → render → screen_text → check。

读取范围：读了 build/README 与系列 README；2026-10-19 用它产出六集与合集，没有为登记重跑。证据状态：partial。

## 边界

脚本绑定本系列的编排、主张与素材登记；需要 SEED_TTS_* 与 GEMINI_API_KEY 环境变量、经 uv 临时取用的 ffmpeg、Playwright Chromium 或本机 Chrome；成片与配音不入库。制作方没有按实际速度听过，无受众测试。

## 何时重访

下一次做旁白带领的系列片或合集，或 TTS 服务、浏览器渲染方式变化时
