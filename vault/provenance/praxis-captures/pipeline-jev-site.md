# Jev 专章网页构建器（数字与出处一一对上的单页）

原件：<jev/site/build.py>

## 是什么

单文件离线网页：图由 data.json 画出，每个数字只有一处来源；页面里的来源行按研究登记（来源与主张 ID）填出公开链接，未知 ID 停止构建；末尾生成全部引用来源的列表。可打印 A4，375 px 窄屏可读，样式取自 Kit 的 marks tokens。

读取范围：读了 build.py 的说明与 jev/site/README；2026-10-23/25 用它产出专章网页，没有为登记重跑。证据状态：partial。

## 边界

读取格式绑定 Jev 的 sources.json 与 claims.jsonl；图的种类写在脚本里，换题要改画图函数。

## 何时重访

下一次做一份数字与出处要一一回到研究登记的网页时
