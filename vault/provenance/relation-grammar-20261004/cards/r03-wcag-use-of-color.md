# Understanding WCAG 2.2 SC 1.4.1 Use of Color

来源：[原始页面](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) · 状态：`partial`

用途：GRAMMAR / REFERENCE

## 摘要

WAI 的说明文档，页面标注 2025-09-16 更新。成功准则的原句是颜色不作为传达信息、指示动作、提示响应或区分视觉元素的唯一视觉手段；说明里建议在颜色之外用形状或文字。本仓库没有声明采用 WCAG 的某个级别，这里只取“颜色之外另有文字或形状”作为做法依据。
