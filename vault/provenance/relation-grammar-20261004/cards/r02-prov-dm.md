# W3C PROV-DM: The PROV Data Model

来源：[原始页面](https://www.w3.org/TR/prov-dm/) · 状态：`partial`

用途：GRAMMAR / REFERENCE

## 摘要

W3C Recommendation，2013-04-30。Agent 是对活动、实体的存在或另一个 agent 的活动负有某种责任的东西，软件 agent 是运行中的软件；Attribution 把实体归给 agent；Revision 是结果为修订版的派生；Invalidation 是实体开始被销毁、停用或过期。本仓库取用“归属写的是谁负责”和“修订、失效是实体之间的关系”这两点。页面全文没有“rejected”“confidence”“certainty”这几个词，“提议、拒绝、待定”的词表不取自它。
