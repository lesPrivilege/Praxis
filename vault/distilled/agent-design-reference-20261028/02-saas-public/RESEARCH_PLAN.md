# SaaS 公共页面设计参照：选样与方法

采集日期：2026-10-28。范围为公开营销首页及定价界面，不涉及登录后的产品功能验证。

选择六组不同的视觉及商业关系：Linear（专业工具与克制排版）、Stripe（复杂产品体系与分层商业信息）、Notion（工作系统与亲和表达）、Vercel（技术基础设施与网格秩序）、Ramp（企业信任与结果导向）、Intercom（人工服务与 AI 服务并置）。每组至少首页与定价各一帧，再选一项能揭示密度变化或操作状态的画面。

取样以实际页面为准；候选的风格定位只是研究问题，不预设观察结论。截图须记录 URL、日期、视口及状态。价格作为页面信息架构研究对象，不作为购买建议；地域、周期、套餐和时间均不跨页拼接。

本文不复制品牌。提炼对象是信息关系、比例和阅读节奏，再通过跨领域映射形成新的组合。定义三层：observed 为截图或受支持 DOM 实际可见；inferred 为对其作用的解释；proposed 为可迁移的设计构造，不宣称属于原厂规则。
