# 工单二 · 三个陌生 brief 的冷读结果

状态：验证记录，2026-10-02。协议、内容与评阅由 Opus 5.5 主会话完成；九次冷读由 Sonnet 5.5 代理各跑一次。Luna 在本会话不可用。评阅者就是 Kit 和题目的作者，不是独立评阅。

## 结论

读过 Kit 的六次运行全部找到了需要的页面，也全部作出了预期的决定：迁移题取了贴合新内容的关系，拒用题拒绝了比例时间尺，补充题用了时间尺并把区间画成区间。

不读仓库的三次对照在版面结构上作出了同样的决定。看得见的差别只有一处：对照组把无衬线、黑白加一种红、十二栏网格列为“Swiss 味”带来的做法，读过 Kit 的两次没有。

所以这一轮能说的是：Kit 没有妨碍判断；它改变了风格名的处理方式，并让依据可以回查；在这三份内容上，它没有改变结构决定。这不等于 Kit 对结构决定没有用，只说明这三题在文字草图这一层分不出来。

## 做了什么

三份合成内容，都不在仓库里，结构各不相同。预期判断在代理开跑前写下并冻结。

| 题 | 需求 | 内容 | 检验什么 | 协议 |
|---|---|---|---|---|
| A 迁移 | 做一点 Swiss 味，别像海报；A4 公告加手机 | 工具库借用规则调整：五行“现在与之后”的成对取值，一条有期限的行动 | VL01 的关系换一份内容还取得出来吗 | [protocol.md](protocol.md) |
| B 拒用 | 照上次活动页，画按时长成比例的时间尺 | 新住户三步办理：约 10 分钟、1–3 个工作日、未知 | 点名的关系不适合内容时会不会拒用 | 同上 |
| C 补充 | 画按时长成比例的时间尺 | 签约到拿钥匙：约 1 天、3–10 天、1 天内 | 该用时会不会也不用；区间会不会画成定长 | [protocol-addendum.md](protocol-addendum.md) |

每题三次运行：两次从仓库根 `AGENTS.md` 起步，只读；一次对照，不得打开任何文件。任务书不点名材料，只要求报告打开的文件、做过的搜索、版面结构、引用的仓库原句、给需求方的回复和失效条件。九份原始报告在 [reports](reports/README.md)，检查脚本与结果在 [checks](checks/README.md)。

补充题是首轮评完之后加的。首轮的拒用题里对照组也拒用了，分不出 Kit 的作用，于是把边界挪到另一侧再测一次。

仓库冻结在 `3954ca0`。两份协议的 SHA-256 分别是 `4fe59320…98ec24f` 与 `457306dc…f2cbe4`，完整值见 [checks](checks/README.md)。

## 读过 Kit 之后不一样的地方

| 观察 | 出现在 | 怎么看 |
|---|---|---|
| 不把字体、颜色、列数归给风格名 | A-1、A-2；对照组相反 | 条目的“名字推不出的”一栏起了作用。这是本轮唯一能归给 Kit 的决定差别 |
| 每条做法给出仓库原句，并分开列出自己的通用知识 | 六次 | 依据可回查。候选样张被标成候选，没有当规则用 |
| 写明没有渲染、没有试印、没有找读者 | 六次 | 来自验证页的要求。对照组里只有 C-0 提了一句未试排 |
| 保持来稿顺序 | A-1、A-2、C-1 | 对照组把“你需要做的”和“合计”提到了前面，这更贴读者目标。C-2 引 G11 也挪了。问题地图把“读序”列在要保住的一栏，可能被读成来稿顺序不能动 |
| 把 A01 的“汉字字重到 600 为止”用到 A4、A5 印刷上 | A-1、A-2、B-1、B-2、C-2 | 这条观察是在浏览器里用系统字体测的。五次都注明它只有一件样张支持，仍然照用。这是局部观察越出了适用范围 |
| 第二版偷省文字 | C-1、C-2 | 与 Kit 无关，可能与读得多、报告长有关 |

向需求方提的问题两组都有，方向不同。读过 Kit 的几次盯的是数据会不会过期和口径（“排队 23 户”要不要标日期，5–12 天含不含退回重审）；对照组问的是彩打还是黑白、日历日还是工作日。

## 处置

- VL01 整行与问题地图的 G01、G11、G12 记为“在这份通知上支持了决定”，登记在 [视觉语言参考](../../../../kit/design/references/languages.md)的已有消费里。范围限于这一份内容和文字草图。
- A01 样张丙的边界两侧各测了一次，登记在 [A01 说明](../../design-grammar-atlas-20261002/a01-reading-relations/README.md)。
- A01 的字重观察补了一句适用范围。这是本轮唯一的修订。
- 保持来稿顺序这一项不改 Kit，留作下一次有针对性的检验。
- “实心加斜纹画区间”不登记为规则。
- 没有新增条目、参数或样张。

## 限制

- 一种模型，每个条件一到两次运行。差别只能当线索。
- 产出是文字结构草图，没有渲染，没有人看过成品。中文断行、字重、印刷这些在 A01 上最先失效的地方，这一轮碰不到。
- 评阅者是 Kit 和题目的作者。判据是先写的，但 T3 这样的判据写得宽。
- 三份内容都是合成的，都是住户通知一类，彼此不算远。
- A-2 读到了工单记录。
- 对照组的任务书少了“仓库里缺什么”一项，两组的报告格式不完全相同。

## 给下一包的输入

文字草图这一层已经到顶，三题都分不出差别。还没有碰的是渲染之后的事：中文断行、字重、印刷尺寸、窄屏折行。六次运行列出的缺口也集中在印刷与窄屏规格、中文排版这几处。工单三适合挑一件要真排出来、真打印的任务，内容用真实的。

可以继续追的两条线索：来稿顺序会不会被 Kit 读成不能动；A01 的单场景观察在别的媒介上会不会继续被照用。
