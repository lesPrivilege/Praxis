# 工单二协议：两个陌生 brief

冻结时间：2026-10-02，代理开跑之前。冻结后只追加“结果”文件，不改本页；本页的 SHA-256 记在 [README](README.md)。

## 要回答什么

问题地图和风格名条目能不能帮一个没参与编写的使用者，在没见过的内容上作出设计决定。分两问：

- 迁移：VL01 的关系换一份结构不同的内容，还取得出来吗，还是照搬旧样张？
- 拒用：需求方点名要一条在旧样张上成立的关系，而内容不适合时，使用者会不会拒用并说明？

路由（找到执行下一步所需的内容）与迁移（在新内容上产出满足 brief 的结果）分开记。

## 代理怎样设置

六个 Sonnet 5.5 代理，每个只跑一次，互不知道对方。Luna 在本会话不可用。

| 代号 | brief | 条件 |
|---|---|---|
| A-1、A-2 | A | 从仓库根 `AGENTS.md` 起步，只读；不得打开 `vault/snapshots` 与 `vault/archive` |
| A-0 | A | 对照：不得打开仓库里的任何文件，只凭自己的知识 |
| B-1、B-2 | B | 同 A-1 |
| B-0 | B | 对照：同 A-0 |

任务书不点名任何材料，不提“问题地图”“VL01”“工单”。只要求报告可观察的东西：按顺序打开的文件、做过的搜索、方案、方案引用的仓库原句、给需求方的回复、什么变化会让方案失效、仓库里缺什么。不问“在哪一步判断够了”。

对照组用来回答“没有 Kit 时会怎样决定”。每个条件只有一到两次运行，差别只能当线索。

## Brief A：迁移

需求方的话：

> 下面这份通知要贴在楼道公告栏（A4 竖版），也会发到住户群里用手机看。帮我排一版，做一点 Swiss 味，但别像海报。给我版面结构就行，不用写代码；宽版和手机版各给一个，所有文字都要放进去。

内容（合成）：

```
工具库借用规则调整
2026年12月1日起生效

冬季借用量上升，部分电动工具排队超过两周。为了让更多住户借到，借期、件数、续借和逾期处理从12月1日起调整。

项目｜现在｜12月1日起
手动工具借期｜14天｜14天（不变）
电动工具借期｜14天｜7天
同时可借件数｜6件｜4件，其中电动工具最多2件
续借｜不限次数｜1次；有人预约时不能续借
逾期｜每件每天2元｜不收费；逾期满7天暂停借用30天

已借出的工具：11月30日前借出的，按原借期归还。
你需要做的：手上超过4件的住户，请在12月14日前归还多出的部分。
例外：维修志愿者借用不受件数限制，凭志愿者编号登记。
咨询：周二、周四 18:30–20:30，一层服务台；toolroom@example.org
```

这份内容与 F1 的差别在结构：F1 是一场活动的四项事实加三个环节；这里是五行“现在与之后”的成对取值，外加一条有期限的行动、一条过渡规定和一条例外。

### 开跑前写下的预期

读者要完成的事：住户判断新规对自己有没有影响，以及要在哪一天之前做什么。

路由算成功：到达 `kit/design/references/languages.md` 的 VL01；到达 `kit/design/foundations/relations.md` 或 `kit/design/composition/layout.md`、`encoding.md` 之一；没有打开被禁止的目录。

迁移算成功，需同时满足：

| 编号 | 判据 |
|---|---|
| T1 | 说出的读者目标是“是否受影响、何时前做什么”一类，而不是呈现风格 |
| T2 | 取的关系贴着这份内容：成对取值按行、沿共同的轴对齐，便于逐行比较；或说明网格是从这份内容的比较结构来的。没有把 A01 的时间尺或 F1 的“时间、地点、内容、参加方式”四项结构搬过来 |
| T3 | 有期限的行动（12月14日前归还）和生效日在版面上排在前列或有明确的强调，没有被埋在表格之后的小字里 |
| T4 | 事实齐全：14天、7天、6件、4件、2件、1次、2元、30天、11月30日、12月14日、12月1日、周二、周四、18:30–20:30、toolroom@example.org、志愿者编号。不变的那一行没有被删，或仍看得出不变 |
| T5 | 没有把字体、颜色或列数说成 Swiss 的必要条件；自己选的参数标明是自己选的 |
| T6 | 说得出什么变化会让方案失效（例如取值变成长句、行不再可比、宽度放不下两列） |
| T7 | 手机版里每一行的“现在”和“之后”仍成对出现，没有拆成两个相隔很远的列表 |

判为没迁移：到了正确的文档，但方案是 A01 某个样张换字；或只给了字体、配色和大标题；或为了“像 Swiss”删改了事实。

对照组的预期：多半会把“无衬线、红黑、严格网格”写成 Swiss 的要求（首轮冷启动的断点就是这样）。如果对照组也满足 T1–T7，就说明这题分不出 Kit 的作用。

## Brief B：拒用

需求方的话：

> 这一页要放进入住手册（A5 竖版），也会放进小程序。上次活动页那条按时长成比例的时间尺效果很好，这次三步办理也照那样做：一条时间尺，三段，段长按各步要花的时间来。给我版面结构就行，不用写代码；所有文字都要放进去。

内容（合成）：

```
新住户三步办理

搬入后按顺序办完三步，才能使用门禁和车位。前一步没办完，后一步无法受理。

1 实名登记
一层服务台现场办理，约10分钟。
带身份证件、租赁合同或房产证明。

2 门禁录入
实名登记完成后在服务台提交，1–3个工作日生效。
生效前可凭临时通行单进出，临时单有效5天。

3 车位申请
门禁生效后可申请。目前排队23户，等待时间未知。
有空位时按登记顺序短信通知，收到通知后3天内确认。

办理时间：周一至周六 9:00–18:00
咨询：frontdesk@example.org
```

三步的“时间”分别是一个约数（10 分钟）、一个区间（1–3 个工作日）和一个未知。按比例画成三段，就要给未知定一个长度，还要把分钟和工作日放上同一条线。

### 开跑前写下的预期

读者要完成的事：新住户知道先办哪一步、每步带什么、要等多久，以及哪一步的等待说不准。

路由算成功：到达 `layout.md`（跨距和强调不能制造无依据的权重或确定性）或 `encoding.md`（数量比较需要共同尺度；缺失和零分开；没有数据时不补拟真的曲线），或 A01 样张说明里“时长成形限时长有差别的日程”的边界。

拒用算成功，需同时满足：

| 编号 | 判据 |
|---|---|
| R1 | 说出的读者目标包含顺序和等待的不确定 |
| R2 | 没有给出按时长成比例的三段时间尺。如果画了任何时间图形，未知没有被赋予长度，分钟与工作日没有不加说明地放在同一条线性尺上 |
| R3 | 给了合适的替代：按顺序排列的三步，前置条件看得见，等待用文字写出并保留“约”“1–3”“未知” |
| R4 | 事实齐全：约10分钟、1–3个工作日、5天、23户、未知、3天内、身份证件、租赁合同或房产证明、周一至周六、9:00–18:00、frontdesk@example.org，以及“前一步没办完，后一步无法受理” |
| R5 | 说得出什么情况下时间尺可以用（各步时长已知且可比） |
| R6 | 在给需求方的回复里明说没有照做以及原因；不是默默照做，也不是默默换掉 |

判为没通过：画了时间尺并给未知定了长度（等分三段、虚线长条都算），且没有指出问题；或照做但只加一句免责。等宽三步并标明“不按比例”的，不算时间尺，按 R3 处理。

对照组的预期：不确定。通用知识也可能发现“未知画不出来”。如果对照组同样拒用，这题只能说明 Kit 没有妨碍判断。

## 失败怎样归类

| 类别 | 判断 |
|---|---|
| 入口 | 没到达需要的页面 |
| 表述 | 到了，读了，但把页面的话理解成另一回事 |
| 适用边界 | 理解对了，用在不该用的内容上，或该拒用时照做 |
| 任务输入 | brief 本身缺信息，换谁都要追问 |

首轮结果原样保留。之后如果改了 Kit 再测，另记一轮，不覆盖。
