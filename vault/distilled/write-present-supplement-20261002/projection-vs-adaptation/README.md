# 投影与改编 · 同一份内容的两种处理

状态：specimen，2026-10-02，Opus 5.5 主会话制作并看图。打开 [index.html](index.html) 即可，本地单文件，不加载远端资源，不需要脚本。

这件样张给 [证据与来源](../../../../kit/write/shared/evidence.md)里“投影、改编与新增”那一段配一个对照。原稿是真实内容：[工单二回执](../../../../docs/verification/design-kit-wo2-20261002.md)的“结果”“这一轮支持什么，不支持什么”“失败与观察”三节，879 字（不计空白）。

| 处理 | 做了什么 | 能不能说内容没有变 |
|---|---|---|
| 投影 | 三节原样重排成一页，表格和列表照旧 | 能。脚本逐字比对，879 字完全相同 |
| 改编 | 改成五分钟现场汇报的五页，340 字，约为原稿的 39% | 不能。删了四处，压缩一处，挪了一处，新增一处，页面下方有变动表 |

页面后半是一张归属图：Reporting、Write、Design 各分支维护哪一类决定，四个任务各取用哪些分支，做到一半什么情况要回头。它画成一张任务对分支的表，没有画成流程，因为这些分支不是依次都要过的步骤。裁决见 [ADR-019](../../../../docs/decisions/019-expression-owners-and-entry-paths.md)。

## 两条可带走的观察

1. 改编里最容易被悄悄删掉的，是对结论不利的那一条。原稿的表格里有一格写着读过 Kit 的一组“小程序版没有把文字列全”，五页放不下，删掉之后第二页比原稿好看。变动表把它单列出来，并写明代价。
2. 压缩会带走限定。“支持”的三条在原稿里各带一个限定（一份成对取值的通知上；候选样张被标成候选），压成半句之后限定没有了。数字都还在，范围丢了。

两条都只有这一件样张支持，是场景内观察。

## 已检查与未检查

已检查：投影的文字与原稿逐字相同；改编里声称出自原稿的 21 个片段都在原稿里；1440 与 375 两种视口、禁用脚本下无横向滚动、越界或裁切；主会话看过六张截图，并按截图改过四处（变动表列宽、分组标签折行、窄屏路线表的重复标签、幻灯片表格首列折行）。

未检查：读者测试、读屏器、键盘、200% 缩放、实际打印、深色模式、其他系统的字体。五页幻灯片没有投出来讲过；五分钟讲不讲得完没有试。

投影那一页的表格在半页宽的栏里仍会把词拆到两行（例如“把字／体与颜色”）。这是 [A01](../../design-grammar-atlas-20261002/a01-reading-relations/README.md)记过的中文断行问题，这里没有解决。
