数量与关系

本家族帮助读者判断一个量“有多大、跟什么比、变了多少、可信到什么程度、处在什么状态或流程位置”。原子以必须同时在场才能判断的字段划界：值不带单位、时间范围和基准，就不是一个可判断的指标。

划分：Q01 单个指标、Q02 前后变化、Q03 与参考的差、Q04 分布、Q05 组成、Q06 区间与不确定性、Q07 时间事件、Q08 状态、Q09 流转与例外分支，本次新拆出 Q10 趋势序列（26 周序列与 Q02 的两点变化判断不同）。Q07–Q09 描述的是“关系”而非数量，保留在本家族是因为它们都依赖位置与编码，而不是命题语言；它们与“枚举与比较”的有序步骤有重叠，差别在于这里的顺序有刻度（时间或流程位置）。

与其它家族的边界：数量原子只负责让量可判断；数量说明什么（结论）属于文本与命题；数据来源、口径和方法说明属于证据与解释，这里只保留判断所必需的最短口径。

Q01 · atom · 数量与关系

指标及上下文 · Metric in context

读者判断“这个数算多还是少”。值、单位、时间范围、基准缺一项就无法判断，所以四者属于同一个原子。

输入、适用与失败
输入
必需：指标名、值、单位、时间范围或口径期；基准（目标、参考线、对照组）或明确写“未设基准”。可选：差值、样本量、口径链接。
适用
一个段落或一屏里只需要记住一个量；决定段的首个论据。
不适合
需要看形状（用 Q10）、需要看各部分（Q05）、只有值没有任何基准时不宜放大成“大数字”。
容量
单个指标 1 个值 + 1 个基准；簇状（Q01-d）以 5–6 个为限。
已见失败
只有大数字没有单位和期间；长金额在大字号下撑破窄屏；缺失值被写成 0 或空白。

Q01-a 指标块 baseline single · stack · linear

夜间到馆人次 · 河湾 + 东坡两馆合计

480人次/周

周均，2026-03-02 至 08-30，共 26 周目标 400 人次/周比目标多 80（+20%）

四个必需字段按“名 → 值 → 期间 → 基准与差”自上而下。值是最大字号，但单位紧贴在值后、同一行；期间与基准在下一行用细分隔，不需要再读一句话。成立条件：一个指标、一个基准。缺基准时第三行写“未设目标”，而不是删掉这一行。

Q01-b 句中标值 editorial single · inline · linear

试点 26 周里，两馆夜间平均每周到馆 480 人次，比目标 400 人次多 80——高出两成。

周均 = 26 周合计 12,480 人次 ÷ 26；2026-03-02 至 08-30。

值不再是独立块，而是嵌在命题里：读者按句子读到值、基准和差。衬线大字号把这句话当作段首 lead。让什么更可见：数与“多两成”这个判断的关系。何时成立：全段只有一个关键量；若一句里超过两个数，句子会变成数表，应改用 Q01-d。期间藏进脚注行，是本变体的代价。

Q02 · atom · 数量与关系

数值变化 · Change

读者判断“从哪里到哪里、变了多少、往哪个方向”：前值、后值、两端时点、方向与幅度（绝对与相对）。

输入、适用与失败
输入
必需：前值与后值（同单位同口径）、两端时点或状态、方向（增/减，用文字或符号，不只用颜色）。可选：绝对差、相对差、不可比说明。
适用
两点比较；方案相对现状的增减。
不适合
中间过程重要时（用 Q10）；两端口径不同（如开放晚数不同）时，不能直接相减。
容量
1–4 组变化；更多用表。
已见失败
只给百分比不给基数；比较不可比的两期；方向只靠红绿。

Q03 · atom · 数量与关系

基准差异 · Gap to reference

读者判断“离参考线多远、在哪一边”：值、参考值及其身份（目标？盈亏线？对照组？）、差的方向和大小。

输入、适用与失败
输入
必需：对象、值、参考值、参考的身份与单位、差（绝对或倍数）。可选：刻度范围、参考的来源。
适用
“低于盈亏线”“是日间的 3 倍”这类判断；多个对象各自对照自己的参考。
不适合
参考线本身不可信或未定义时；只有一个对象且差很小时（用 Q01 的上下文行即可）。
容量
1–6 行；每行可有不同单位，但不同单位的行不能共用一把刻度（Q03-d 用比例解决，但有代价）。
已见失败
截断轴放大差距；参考线只用颜色；把“未采集”画成零长度的条。

Q03-c 倍数作标题的分式 editorial single · offset · linear

3.1倍

¥116 夜间每次到馆成本

¥38 日间每次到馆成本

夜间每小时成本更高（¥1,860 对 ¥1,410），每小时来的人却更少，两者相乘成了三倍差距。

Q04 · atom · 数量与关系

分布 · Distribution

读者判断“集中在哪、散到哪、有多少说不清”：有序类别、各类占比、分母、缺失类别。

输入、适用与失败
输入
必需：类别（有序时保持顺序）、占比或计数、分母及口径（谁被统计）、缺失/未填写类。可选：累计占比、组距。
适用
年龄、时段、金额段等有序分组；3–8 组。
不适合
无序类别的份额（更像 Q05 组成）；组距不等却用面积编码。
容量
3–8 组 + 1 个缺失组；更多组用直方刻度或表。
已见失败
未填写混入有序类别或被丢弃；四舍五入后计数与总数对不上而不说明；不等组距的面积误导。

Q09 · atom · 数量与关系

流转与例外分支 · Flow & exception branch

读者判断“正常路径怎么走、在哪一步可能岔出去、岔出去之后回到哪里或在哪里终止”：主线步骤、分支触发条件、分支动作、汇合点或终点。

输入、适用与失败
输入
必需：有序主线步骤（可带时刻）、分支的触发条件、分支动作、回到主线的位置或明确的终止。可选：执行角色、实例（日志）、反馈。
适用

分支没有汇合点；分支与主线等重，读者分不清哪条是常态；把实例（某晚 23 人）当成规则。
