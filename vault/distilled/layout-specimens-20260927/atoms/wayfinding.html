定位与辅助阅读

这一家族不提供命题或数量，只帮读者回答四个问题：我在哪里；这一段管什么、不管什么；与它有关的东西在哪、要不要现在去看；还剩多少。每个原子都寄生在一段简短的 F0 宿主正文上（北岸区图书馆夜间开放试点评估，6 节 22 小节），宿主用浅灰文字排出，原子本身是墨色部分。

划分：W01 标识一个位置，W02 给出顺序中的前后与进度，W08 给出可跳转的全体；三者都是“位置”，但分别服务直读、续读与扫描跳转。W03 与 W05 都处理“他处的内容”：W03 把注释搬到被注内容旁边，W05 留在原处并指路。W04 声明范围，W06 管理可以不读的补充。W07 把一个局部放回总体。

与其他家族的边界：标题作为命题归文本家族，W01 只处理编号与层级；方法说明（怎么测的）归证据家族，W04 只处理“覆盖/不覆盖”；周序列的数值读取归数量家族，W07 只处理“局部在总体中的位置”。

W03 · atom · 定位与辅助阅读

邻接注释与边注 · Adjacent note

读者在读到某个说法的同一视线范围内拿到它的限定或出处，判断“这句话要打几折”，而不用翻到文末。

输入、适用与失败
输入
必需：被注锚点（词或句）、注释内容、两者的对应标记（编号或符号）。可选：注释类型（口径 / 来源 / 反例）。
适用
注释会改变对被注句的理解：口径、例外、反向意见。
不适合
注释量大于正文；注释本身是必须先读的前提（改用 W04 或正文限定）。
容量
边注每段 ≤ 2 条，超过即发生碰撞下移；每条 ≤ 80 字。
已见失败
尾注离正文过远、无回链；边注碰撞后与锚点错位；只在悬停时出现的注释。

W04 · atom · 定位与辅助阅读

范围说明 · Scope statement

读者在读结论前确认“这一节的数据覆盖哪些对象、哪段时间、哪些情况不在内”，避免把局部结论外推。

输入

适用

不适合

容量
