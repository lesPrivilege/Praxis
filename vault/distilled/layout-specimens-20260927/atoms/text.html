文本与命题

本家族帮助读者判断“这里在主张什么、主张到什么程度、要我做什么”。原子按命题的职责划分：标题给出主张，引介告诉读者看什么，要点、定义、条件、反例、结论、行动请求、未决问题分别承担一种不同的认识状态，正文段落是它们的承载体。

贯穿本页的问题是邻接：条件、反例、未决问题必须留在它们限定的命题旁边。同一种邻接关系在不同原子里分别用四种空间方式试验：内联（同句）、悬挂（紧随其下、缩进挂靠）、边注（主列＋旁栏）、并置（左右对等）。结论与行动请求的区别在 T07/T08 中只用语法、结构与位置表达，不依赖颜色。

边界：数字本身的编码（变化、基准差）属于“数量与关系”；引文、来源和 caption 属于“证据与解释”；章节编号和交叉引用属于“定位与辅助”。本页只在命题需要时引用它们。

T01 · atom · 文本与命题

命题标题 · Propositional heading

读者只扫标题就能知道本节的判断是什么，而不只是知道本节“关于什么”。

输入、适用与失败
输入
必需：一个可被证伪的主张（含主语、谓语、关键数量）。可选：话题标签（眉题）、转折或限定从句。
适用
报告、答卷、决定材料的节标题；读者可能只读标题。
不适合
纯导航性的目录节点、参考附录；主张尚未成立时（改用 T10 问题式标题）。
容量
单行 ≤ 28 字最稳；28–48 字需要按语义断行或拆出前提；超过 48 字应拆成“问题＋前提”。
已见失败
话题标签冒充标题；长标题省略号截断；转折后半句被挤到孤行。

T01-a 眉题＋命题 baseline stack · linear

到馆与成本

两馆夜间周均到馆 480 人次，超出目标 20%；每次到馆成本却是日间的 3 倍

话题降级为眉题，命题占据标题位。层级只靠字号与字重，数字不加色。成立：主张一句话说得完、两个分句都有数字支撑。分号保留了“好消息／代价”的并列结构。排印发现：单用 text-wrap: balance 时 Chrome 会把“目标”拆成“目｜标”；改为 word-break: keep-all＋在逗号、分号后放 <wbr>，换行只落在意群之间。数字两侧的空格仍是断点。

T01-b 转折分层 editorial stack · linear

§2 · 到馆与成本

夜里有人来：周均 480 人次，超出目标 20%

但每次到馆 ¥116，是日间 ¥38 的 3 倍

把一句含转折的命题拆成两层：主句用衬线大字，“但”字悬挂在左边距外，后半句降一级。让什么更可见：主张和它的代价分属两行，扫读时两者都不丢，且“但”的位置固定，读者会习惯在左边距找转折。何时成立：只有一个转折；有两个以上限定时改用 T05。

T01-c 话题入栏、命题入正文 spatial main-margin · scan

两馆夜间周均到馆 480 人次，超出目标 20%；每次到馆成本却是日间的 3 倍

话题标签和编号移入左栏，与命题首行基线对齐；左栏在全文中保持同一列，形成可扫的目录竖轴，右栏只放命题。成立：长文、多节、读者既要找位置又要读判断。窄于 520px 时左栏回到上方成为眉题（等同 T01-a）。与 wayfinding 家族的“章节标识”重叠，这里只保留标题职责。

T02 · atom · 文本与命题

引介 · Lead

进入一节时，读者知道接下来要看哪几样东西、为什么看、看完能回答什么问题。

输入、适用与失败
输入
必需：看什么（对象）、为何看（它回答的问题）。可选：阅读顺序、需要提前知道的例外或缺失。
适用
节首；材料多于两件、或读者需要提前知道例外时。
不适合
只有一段正文的小节；复述标题的引介。
容量
1–3 句，≤ 120 字。超过则改为分项路线（T02-c）。
已见失败
“本节将介绍……”式空引介；把结论提前写在引介里导致与 T07 重复。

T02-a 节首一段 baseline stack · linear

先看 26 周的到馆曲线，判断夜间需求是一时新鲜还是稳定存在；再看每次到馆成本，判断这份需求值不值得按现在的方式供给。

两句话、两个对象、各带一个“判断……”。字号比正文大一级，行长限 34em。成立：对象 ≤ 3，顺序即阅读顺序。

T02-b “看／因为”悬挂 editorial offset · linear

看26 周到馆曲线与每次到馆成本。

因为决定会要回答的是：夜间需求是否稳定，以及这份需求值不值得按现在的方式供给。

把引介的两个必需成分做成悬挂词，放在左边距外的衬线字里。让什么更可见：读者可以只读左边的“看”“因为”检查引介是否完整；缺“因为”一眼可见。何时成立：全篇每节都用同一结构；只有个别节使用会显得像装饰。窄舞台时悬挂词回到行内。

T02-c 阅读路线 graphic stack · drill

本节回答：夜间需求稳定吗？值得按现在的方式供给吗？

  1. 周到馆曲线看趋势是否在第 13 周后仍上升
  2. 每次到馆成本夜间 ¥116 对日间 ¥38，差在哪
  3. 东坡周二唯一持续低于参考线的时段

引介变成带编号的路线：问题在上，三站各有“看什么／为何看”两层，编号和粗连线表示顺序。成立：一节里有 3–5 个图表或证据块，读者需要知道它们的顺序和各自回答的子问题。链接在组合页里应指向真实锚点；此处指回自身。边界：与 wayfinding 的“阅读顺序”重叠——区别是这里每站必须带“为何看”。

T02-d 带例外预告的引介 stress S3 · S5 stack · exception

先看 26 周的到馆曲线，判断夜间需求是否稳定；再看每次到馆成本，判断它值不值得按现在的方式供给。

△读图前注意：第 14 周东坡停开 5 晚，曲线在该周下陷不是需求变化；北站没有采集夜间数据，下文所有北站数字都是推测，不是 0。

压力：引介必须提前交代两个例外（S5 第 14 周、S3 北站缺失），长度翻倍。处理是把例外拆成第二段，用三角记号＋“读图前注意”文字标签，与引介正文分开但不离开节首。暴露的问题：例外段比引介本身更长，读者注意力被抢走；超过两条例外时应转给 T05/T06，引介只写“本节有两处例外，见图注”。

T02-e 空引介 failed stack · linear

本节将对夜间开放试点的相关数据进行介绍和分析，主要包括到馆情况、成本情况等方面的内容。

失败原因：只列话题（“到馆情况、成本情况”），没有要判断的问题，也没有顺序理由；删掉它读者不损失任何判断，按原子划界规则它不是原子。

T03 · atom · 文本与命题

要点 · Key point

读者读完需要记住并带走的一个判断，在回看时能被重新找到。

输入、适用与失败
输入
必需：一句判断。可选：它所在段落的回链、支撑数字。
适用
一节里最多一个；读者会被追问“所以关键是什么”。
不适合
每段都有一个“要点”；尚未被证据支撑的判断（用 T10）。
容量
≤ 50 字一句。更长说明它其实是结论（T07）。
已见失败
等权高亮多条；要点与原段落脱钩后失去上下文。

T03-a 左线独立句 baseline stack · linear

试点期内两馆夜间合计到馆 12,480 人次。夜间读者中首次持证者占 22%，日间只有 9%。

要点夜间开放带来的不只是更多到馆，还有一批日间不来的新读者。

这一点在方案比较里常被忽略，因为它不直接体现在每次到馆成本上。

要点是正文流里的一句，左侧 3px 线＋“要点”文字标签，字重加一级。成立：要点紧跟支撑它的数字段落。标签是文字，打印成灰度也不丢。

T03-b 段首主题句 baseline inline · linear

夜间开放带来的不只是更多到馆，还有一批日间不来的新读者。试点期内两馆夜间合计到馆 12,480 人次，其中首次持证者占 22%，日间只有 9%。这一点在方案比较里常被忽略，因为它不直接体现在每次到馆成本上。

不单列，要点就是段落第一句，加粗。结构差异：a 是“证据→要点”，b 是“要点→证据”，阅读顺序相反。成立：扫读者只读段首时。缺点是回看时不如 a 好找。

T03-c 边栏要点带回链 spatial main-margin · revisit

试点期内两馆夜间合计到馆 12,480 人次，周均 480 人次。

¶夜间读者中首次持证者占 22%，日间只有 9%。这一点在方案比较里常被忽略，因为它不直接体现在每次到馆成本上。

要点 夜间开放带来一批日间不来的新读者。 见 ¶ 首次持证 22% 对 9%

要点移入右栏，与它的来源段落顶对齐，段落前留一个 ¶ 锚点，要点里有“见 ¶”回链。让什么更可见：回看时只扫右栏就能收集全文要点，每条都能跳回证据。何时成立：宽于 640px 的舞台；窄时要点回到来源段落之后，退化为 T03-a。

T03-d 跨栏引出 graphic span · revisit

每 5 位夜间读者里，就有 1 位是第一次办证。

首次持证者占比：夜间 22%，日间 9% · 问卷与办证记录，试点期 2026-03-02 至 08-30

要点被抽成满宽色带，大字把 22% 换算成“每 5 位里 1 位”，下方小字给回原始数字、分母与时间范围。让什么更可见：一篇文章唯一的“带走句”。何时成立：全篇只用一次；换算必须保守（22% ≈ 1/5 略有取整，脚注里保留原值）。用两次以上就退化成海报。

T03-e 长数值要点 stress S2 stack · long-number

要点按首年全口径计（含一次性安保改造 ¥312,000.00），方案 A 的成本是 ¥1,284,736.50，高于年化增量 ¥1,160,000；B 仍是三个方案里唯一成本下降的一个。

S2 两个长金额放进一句要点（S2 按“首年全口径”解读，与 F0 的年化增量 ¥1,160,000 是不同口径，本次补充）。金额用 white-space: nowrap 的 .t-n 包裹，窄舞台下只在数字之间换行、不在千分位处拆开。暴露的问题：两个长数字让要点超过 50 字，“B 唯一下降”这个真正要记的判断被推到句尾。更好的写法是把金额移到支撑段落，要点只保留判断——即此处应回到 T03-a 的“证据→要点”。

T03-f 满段高亮 failed stack · dense

夜间合计到馆 12,480 人次，周均 480 人次超目标。首次持证者占 22%，满意度 4.3 / 5，81% 愿意继续，但每次到馆成本 ¥116。

失败原因：六处等权高亮，没有一处是要点；“但”后面的代价与前面的好消息同样被高亮，读者无法判断哪个更重要。高亮只剩下“这里有数字”的意思。

T04 · atom · 文本与命题

定义 · Definition

读者读到一个数字前，知道这个术语按什么口径计数，从而判断数字能不能和别处比较。

输入、适用与失败
输入
必需：术语、口径（计什么、怎么计）。可选：不计入的情形、单位、数据来源、与常识含义的差异。
适用
术语的日常含义与口径不同（“人次”不是“人”）；数字会被引用到别处。
不适合
读者已共享口径的通用词；纯名词解释（属枚举家族的术语—说明表）。
容量
单个定义 ≤ 80 字；超过就应拆成“计入／不计入”结构（T04-d）。
已见失败
定义远离首次使用处；定义里的长 token 撑破容器。

T04-a 术语—口径 baseline stack · linear

夜间到馆人次
19:00 以后闸机进入计数；同一读者多次进入分别计数。

术语一行、口径一行缩进。术语加粗，口径用正文字号。成立：独立的定义块，放在第一次出现数字之前。

T04-b 首用内联 baseline inline · linear

试点期内两馆夜间到馆人次（19:00 以后闸机进入计数，同一读者多次进入分别计数）合计 12,480，周均 480。因此它不等于夜间来过的人数。

定义放在术语第一次出现的括号里，术语用 <dfn>，括号内降一级字号和灰度。结构差异：定义不打断阅读路径，但只出现一次；之后再引用需要回看。成立：口径短于 30 字。

T04-c 边注定义 spatial main-margin · adjacent

试点期内两馆夜间到馆人次a合计 12,480，周均 480，超过每周 400 的目标。河湾 7,910，东坡 4,570。

a 夜间到馆人次：19:00 以后闸机进入计数；同一读者多次进入分别计数。

定义与使用它的句子同一高度，用字母标记配对，不用数字（避免和数据数字混淆）。让什么更可见：读者读数字的同时视线右移就能看到口径。何时成立：舞台 ≥ 640px；窄时边注落到段落下，仍紧邻。

T04-d 口径解剖 graphic juxtapose · scan

夜间到馆人次

单位：人次 · 来源：闸机计数

＋ 计入

  • 19:00 以后经闸机进入
  • 同一读者再次进入，另计一次

－ 不计入

  • 19:00 以前进入、之后仍在馆
  • 未经闸机的活动参与者

所以：它不等于“夜间读者人数”，也不能与日间“到馆人数”直接相除。

把口径拆成“计入／不计入”两栏，以＋／－符号与标题文字区分（不靠颜色），最后一行写出这个口径阻止的误读。“不计入”两条是按定义推出的边界情形（本次补充的 synthetic 细节）。让什么更可见：口径的边界。何时成立：数字会被跨部门引用、容易被当成“人数”。窄舞台两栏上下堆叠。

T04-e 长 token 口径 stress S7 stack · mixed-script

座位占用率
某时刻已被预约且签到的座位数 ÷ 该楼层可预约座位总数。取自 BookingService.getSeatOccupancy(branchId, "2026-05-14T20:30+08:00") 的返回值；例：河湾 3 层 94 / 120。

S7 的 71 字符调用放进口径。token 在 . 与 ( 后放 <wbr>、逗号后的空格是自然断点，只有单段仍放不下时才由 overflow-wrap: anywhere 硬断。初版用了 word-break: break-all，结果 1440 宽下也把 “BookingServ｜ice” 拆开，已弃用。暴露的问题：375 下 token 会被断成 3–4 段，断点落在时间戳中间时可读性差；更稳的做法是口径只写函数名，参数放到方法注（证据家族）。

T04-f 定义沉到文末 failed distant · revisit

两馆夜间到馆12合计 12,480 人次，每次到馆成本 ¥116。按到馆人数计，夜间服务覆盖了约 1.2 万名读者。

…… 另外 6 页正文 ……

12 夜间到馆：19:00 以后闸机进入计数，同一读者多次进入分别计数。

失败原因：口径沉到文末注释，正文作者自己都把“人次”读成了“人数”（“覆盖约 1.2 万名读者”是错误推论）。口径改变数字含义时，定义必须与首次使用邻接。

T05 · atom · 文本与命题

条件与限定 · Condition & qualifier

读者判断一个主张在什么条件、范围和假设下成立，以及这些条件现在是否满足。

输入、适用与失败
输入

T06-a 主张＋“例外”段 baseline stack（悬挂）· linear

T06-b 挂在被反驳的词上 spatial inline＋main-margin · adjacent

反例不针对整句，而是针对一个词“每晚”。该词加波浪下划线和 × 记号，边注用同样的 × 开头。让什么更可见：反例的精确作用点——被反驳的是量词，不是需求本身。何时成立：主张里有一个可指认的过度概括词。窄舞台下边注落到句后。
