枚举与比较

这一族帮助读者处理“多项”：按先后执行、并列浏览、查词义、在两个或多个对象之间比较、看排名、权衡得失，最后在方案中作出选择。所有比较样张都遵守同一条口径：共同字段、共同尺度、共同单位；做不到的地方直接标出，不硬凑。

原子按读者的判断划分：E01–E03 是列举，不做比较；E04–E07 是比较，比较对象的数量和形式依次变化；E08–E09 是决定。新增 E10 值状态，表示缺失、零和不适用。它原本只是 E05/E06 表格里的一个单元格问题，但数量家族的图表也会遇到，所以单独作为原子登记，便于复用和筛选。

与其它家族的边界：单个数值及其上下文属于数量家族（q-），本页只处理“多个值怎么排”。E08 取舍和文本家族的支持/反对有重叠，这里的取舍要求得失成对。E09 其实是组合：E06 对照、推荐命题和条件拼在一起。它仍作为原子登记，是因为“推荐与中立陈列分开”这个要求只有放在一起看才能检查。

E01 · atom · 枚举与比较

有序步骤 · Ordered steps

读者要知道先做什么、后做什么，哪一步要等前一步完成才能开始，每一步做到什么程度算完成。

输入、适用与失败
输入
必需：步骤序号、动作、完成条件；可选：时刻或时长、执行角色、依赖关系、例外。
适用
后一步依赖前一步的过程：闭馆清场、扩展实施。
不适合
各项之间没有先后关系（用 E02）；有分支判断的流程（用数量家族的流转与分支，或 E09-c 的门槛图）。
容量
3–9 步；超过 9 步就要分阶段。
已见失败
卡片网格按列排布，看不出顺序；去掉序号；把可并行的步骤硬排成一条线。

E02 · atom · 枚举与比较

并列列表 · Parallel list

读者要知道一组东西有哪些、有没有漏掉哪一项，不需要知道先后或主次。

输入、适用与失败
输入
必需：同类的若干项；可选：每项的一句限定（适用范围、起始时间、例外）。
适用
服务项目、覆盖范围、清单核对。
不适合
各项有主次或排名（E07）；各项需要在同一字段上比较（E05/E06）。
容量
内联写法 ≤ 6 个短项；堆叠 ≤ 12 项；再多要按某个维度分组，分组后就变成了另一种结构。
已见失败
用数字编号暗示先后或主次；把例外写进正文，而不是挂在对应的项上。

术语—说明 · Term and description

读者要查一个词在本文里指什么、怎么算，然后回到正文继续读。

输入、适用与失败
输入
必需：术语、说明；可选：单位、公式、来源或口径限制。
适用
指标定义、口径说明、词汇表。
不适合
单个定义嵌在正文里（文本家族的“定义”原子）；说明本身是比较（E04）。
容量
3–12 条；术语超过约 12 个汉字时，并排两栏会失衡。
已见失败
术语列定宽加省略号，长术语被截断；公式写进正文，读者找不到。

E04 · atom · 枚举与比较

成对比较 · Pairwise comparison

读者要判断两个对象在同一组字段上谁高谁低、差多少，这个差距算不算大。

输入、适用与失败
输入
必需：两个对象、共同字段、每个字段的单位；可选：差值或倍数、基准。
适用
夜间与日间、试点馆与候选馆、调整前与调整后。
不适合
三个或更多对象（E06）；只比一个字段（E05）。
容量
2 个对象 × 2–6 个字段。
已见失败
两个对象的字段不同、顺序不同、单位不同（E04-e）；差值方向没说明“高更好”还是“低更好”。

E10 · atom（新增）· 枚举与比较

值状态：缺失、零、不适用 · Value state

读者看到一个空位时，要能分辨三件事：量过了，是 0；本该有，但没采集；这个问题对这个对象根本不成立。

输入、适用与失败
输入
必需：状态（值 / 零 / 缺失 / 不适用）；可选：原因（未开放、未采集、未列入）。
适用
E04–E09 所有比较里的单元格；数量家族图表里的空条。
不适合
单独使用：它总是嵌在别的原子里，所以这是一个嵌入型原子。
容量
一格一个状态；原因不超过约 6 个字，更长的写进脚注。
已见失败
三种状态都显示成“—”；缺失被画成长度为 0 的条；零用灰色显示，像是没数据。

E10-a 文字状态 baseline inline · missing · zero

0
零：量过了，结果是 0。例：河湾重大安全事件 0 起（26 周）。
未采集
缺失：本应有数据，但没有收集。例：北站夜间需求。
不适用
不适用：这个问题对该对象不成立。例：东坡周日夜间到馆（周日未开放）。
