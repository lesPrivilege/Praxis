# Opus 工单：原子化编排的穷举探索

请作为 Design explorer 和 specimen maker，制作一套可打开、可比较、可召回的编排样张实验室。你有充分的 Design 判断权，可以提出分类、增加变体、使用大胆的视觉语言；目标是尽量展开内容如何被编排的可能性，给后续主代理筛选和提炼提供实物。

这不是完成一份报告，也不是套用既有页面主题。不要从几个完整页面倒推出少量组件；先找到有独立语义职责、可组合的编排单元，再探索它们的变化和组合。材料可以全部使用合成文本、数字和情境，统一标明 synthetic，不能把它们写成真实观察或客户资料。

## 探索权与判断边界

你可以自行决定视觉方向、排印、密度、留白、比例、颜色、线条、框架、非对称构图和必要的交互；允许温暖或冷调、克制或强表现，不沿用旧答卷“冷色、衬线位置、240ms、A4、单文件”等项目限定。不要把“避免模板感”误解为只能极简，也不要把所有原子都做成卡片、圆角框和同一种网格。

你可以发明新的编排模式，质疑现有分类，说明某种大胆处理何时成立。先充分展开，再标出候选，不需要替主代理提前收窄成一套统一 design system。安静的基线与富表现力的变体都要有，但两者都是待筛选样张，不能自行称为 canonical、生产可用或 Kit 已采纳。

“穷举”按可解释的覆盖矩阵推进，不是声称覆盖所有设计空间。先定义分类和变化维度，再制作代表性样张；记录未覆盖、合并、无意义或失败的组合及理由。数量由实际覆盖需要决定，不限定六页，也不靠只换色和换字体增加数量。

## 从哪些原子开始

以下只是初始种子，你可以拆分、合并和新增：

- 文本与命题：标题、引介、正文段落、lead、key point、定义、条件、限定、反例、结论、行动请求。
- 枚举与比较：有序步骤、并列列表、术语—说明、成对比较、比较行、多属性对照、排序、取舍、方案与推荐。
- 数量与关系：单个指标及上下文、数值变化、基准差异、分布、组成、区间与不确定性、时间事件、状态、流转与例外分支。
- 证据与解释：引文、证据摘录、截图及局部标注、示例、图表主体、description、annotation、caption、source、footnote、method note。
- 定位与辅助阅读：章节标识、阅读顺序、邻接注释、边注、范围说明、交叉引用、展开补充、局部与总览关系。

原子以它帮助读者完成的判断为单位。icon、divider、圆角、阴影是可用的视觉手段，不默认当作内容原子。一个“指标+基准+时间范围”的组合可能比三个孤立装饰组件更有复用意义；同时要能看出原子边界在哪里。

## 变化空间

至少考虑内容与空间两方面；可以增加你认为有价值的轴：

- 输入关系：单条/多条、顺序/并列、支持/反对、主张/证据、整体/局部、前后变化、确定/不确定。
- 空间组织：内联/堆叠/并置、主列与边注、对齐/错位、嵌入/跨栏、紧邻/远距关联、连续/分节。
- 阅读路径：线性推导、扫描查找、横向比较、逐层展开、证据邻接、局部回看。
- 内容负载：短/长、稀疏/密集、一项/多项、长中文标题、长数值、缺失值、零值、多个来源、局部例外。
- 表现强度：安静而可迁移的基线，以及有理由的编辑化、图形化、空间化变体。

同一语义原子的变体尽量共用一组 fixture，使差异可比较；不同语义无需强塞相同内容。不要机械做所有轴的笛卡尔积，要找有意义的组合，并说明哪些组合不能成立。

## 做成可看的实物

制作一个本地 HTML gallery，实际绘制原子和组合，不交付只有文字的方案。浏览者应能按语义职责找到样张，辨认同一原子的不同变体，查看必要的使用说明和压力案例。选择器、分类、对照视图及文件拆分由你设计；不要让控制面板比样张更抢眼。

在原子之外，制作少量 pattern 与完整 composition，证明原子可以组成证据段落、比较区、决定段、解释页等；明确哪些性质属于原子，哪些来自组合。完整页用于验证组合能力，不能取代原子覆盖。

可使用 HTML/CSS/SVG 与必要 JavaScript；允许自制示意图或合成截图，明确其身份。优先直接本地打开与离线阅读，不自动安装依赖，不要求访问远端才能看到主要样张。若字体或其他依赖未本地保存，明确实际退化表现，不声称完全离线。不能以图片中的文字替代本应可选择和重排的正文。

## 每条样张的薄索引

维护机器可读的 specimens.json 或等价索引，并有可阅读入口。字段可合并，避免把研究变成填表工作，但应能回答：

- 稳定 ID、名称、语义职责、层级（atom / pattern / composition）；
- 输入形状、fixture、变化维度与关联变体；
- 何时用、何时不合适、内容容量和已见失败模式；
- 对应 HTML 锚点/文件、组合关系、参考来路与本次原创部分；
- 当前状态与实际检查范围。

自创样张就注明本次原创，不虚构外部出处。借用了已消费参考时标记来源 ID 或本地路径、借用范围与改动。此索引属于本次实验，不创建全仓权威 grammar registry。

## 检查与交接

检查实际打开的宽屏和窄屏结果；至少包含 1440px 与 375px 场景。文本不意外裁切，数量有单位和可解释的编码，颜色不独自承载必要区别。交互有键盘路径和可见焦点；无 JS 时仍能读到主要样张。若用了动效，减少动效偏好下保留必要反馈。

将压力内容真正放入若干样张观察，不要只写“已考虑长文本”。按实际能力保存截图或检查记录，列出失败与未检查范围；没有浏览器就明确交接主代理验证，不能只检查源码便称视觉通过。不要求这一轮修到统一生产标准，有价值的失败样张也可以保留并说明。

最后交接：覆盖矩阵、样张清单、最有价值的结构差异、组合中暴露的问题、推荐下一轮筛选的候选，以及尚未覆盖的方向。Astra/main 后续裁决哪些可泛化，哪些保留为实验；不要自行晋升。
