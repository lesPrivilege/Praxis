## 覆盖矩阵怎样读

五个轴统一词表：输入关系、空间组织、阅读路径、内容负载、表现强度。每个原子至少有 baseline、两个结构不同的变体、一个真实压力变体，绝大多数还有一个写明原因的失败样张。表现强度分布：baseline 127，graphic 72，spatial 42，editorial 39（一个样张可计多值）。

矩阵中明显的空格：

- 文本家族几乎只有 `load:short`，长文负载只在 T09 与 C01 中检验。
- 枚举家族没有 `path:adjacent` 与 `path:revisit`；定位家族没有 `path:compare`，这两处按职责基本成立，不是遗漏。
- `load:zero` 与 `load:missing` 主要集中在枚举家族的 E10，数量家族的零值样张为 0，零与缺失的区分主要靠 E10 承担。
- composition 的 `load:long-title / long-number / mixed-script` 为 0：压力内容只在原子与 pattern 层放入过。

逐原子记录的不成立组合在入口页“未覆盖、合并与不成立的组合”一节，典型理由是：graphic 处理放不下长段落，spatial 在 375 下必然退化为堆叠，推荐不能只用 graphic 的色块表达。

## 最有价值的结构差异

这些差异改变的是读者能完成的判断，不是换色换字体。

1. **条件的作用范围可以画出来（T05-c）。** 竖括线只括住被限定的那一句（方案 A），不括方案 B；悬挂和内联都只能说“有条件”，不能说“条件限定谁”。C04 发现括线高度跟随边注而不是被限定句，三条限定时会越过邻句。
2. **反例挂在被反驳的词上（T06-b / T06-d）。** 反例反驳的是“每晚”这个量词，而不是整句；做出来后发现反例需要一个此前没有的字段“范围维度”，并要区分外因例外（空调停开）与真实弱点（周二低）。
3. **窄屏表格按属性转置，而不是按对象拆卡（E06-a vs E06-b/c）。** 按对象拆卡丢失横向比较；按属性分块、对象固定槽位保留比较；格内条形共享列尺度时，即使按对象拆开也仍可比较。
4. **同一组对象换排序依据会完全反转（E07-c）。** 按成本与按首次持证率排序，四个单元的名次完全反转，“谁最好”取决于排序依据，排序原子必须把依据写在名次旁。
5. **不确定性分成两条道（Q06-d）。** 实线框放抽样误差（有 CI），开口虚线框放自选偏差（无法量化），直接显示 95% CI 不覆盖自愿填写的偏差。
6. **比例时间轴在窄屏改为按间隔留白的竖列（Q07-b）。** 间隔有意义这一编码在 375 下保留，标签不碰撞。
7. **证据身份与距离按作用分配（V06）。** 来源紧贴数字，方法说明在结论之前，脚注在段后；失败样张 V06-e 把回收率 11% 沉到尾注，读者读完“建议扩展”才看到。
8. **证据强度拆成三维且不打分（V07）。** 覆盖、测量对象、偏差方向分开；强/中/弱用文字加实线、虚线、点线冗余编码；失败样张 V07-e 用四个勾和凭空的 92% 信心值。
9. **边注写在被注句之后的源码位置（W03-b）。** 宽屏浮到页边，窄屏无需 JS 就折回到该句下方，邻接关系在手机上仍然成立。
10. **结论与行动请求不靠颜色区分（T08-d vs T08-f）。** 句式（陈述/祈使）、“谁/何时”字段、位置、框线形状共同区分，失败对照只用颜色。

## 组合暴露的问题

这些问题只有把原子放在一起才出现，是下一轮最该处理的地方。

1. **容器查询绑定在“最近的 stage”。** 原子都写 `@container stage`；放进整页后，主栏、边栏、卡片里的原子读到的是整页宽度。五个 composition 和 pattern 页都要给每个栏位重新声明 `stage`，否则 Q01-e 的 cqi 字号放大到 80px 以上，Q01-d 在右栏排成三列。原子需要一个明确的“槽位容器”约定。
2. **边注栅格被各原子私有。** 约十个原子各带一套主栏加边注栅格（15em、15rem、16rem、14em、浮动）；C01 只能把原子拆成正文部分和边注部分分别放进页面栏位。原子也不声明自己占用哪条边距，Q09-d 与 W03-c 在宽屏争左边距，窄屏检查发现不了。
3. **外壳和原子混在一起。** 编辑化原子自带暖纸底与内边距，放在暖纸页面上变成无意义缩进；W04-c 的底色、W08-a 的竖排写在基类里；硬编码颜色不随局部 token 切换深色刊头。外壳应是独立修饰类。
4. **字号与强调体系在组合时冲突。** W01 节标题 24px 与页标题 30px 过近；T07、T08、T10 都是 20px 粗体，缺一个“主答案”层级；`--warm-accent` 与 `--signal` 同为橙红，编辑强调与例外标记难分，C02 只能把 `--signal` 收回墨色才守住“一个强调色等于推荐”。
5. **值状态需要第四态。** “停开”（本该开放而没开）不是缺失、零或不适用；E10 装不下，C03 在组合层新增 `c3-halt`，定位家族 W04-d 也提出了“范围外”。数量家族没有“不适用”类，借用 `.e-v--na` 后继承了宿主 56px 字号。
6. **原子的自足性与组合删重对立。** T06-a 为了独立成立必须重述 38/60，即使 Q03-a 刚给过；V05 与 Q10 都解释第 14 周例外，annotation 归谁未定；C05 用帧标题取代 V07 的主张行。组合层需要一张“谁负责说这句”的归属规则。
7. **投影时尺寸体系只部分 token 化。** C05 用 `--fs-*` 随帧缩放文字，但 px 写死的轨道、标签、舞台内边距和带 rem 下限的 clamp 不跟随，888px 帧宽下 5 帧溢出；Q10-a 的 SVG 文字在帧里只有 8–9px；文档尺度原子在帧里偏小，缺“展示尺度”修饰。
8. **锚点型原子不是一个盒子。** 定义、反例、未决、边注要在别的原子的句子里标记词语，`data-atom` 只能标在整行上，原子边界在视觉上说不清。
9. **需要新原子。** 乘法或面积分解（倍数 = 因子 × 因子，标出反推因子，C04 自造）、杠杆可调程度（形状加文字）、两份同构算式的双列对照（V04-a 并排时步骤无法对齐）。
