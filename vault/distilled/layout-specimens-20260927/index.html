SYNTHETIC · 实验样张 · 未经采纳

内容如何被编排：原子、变体与组合

以一组 synthetic 情境（北岸区图书馆夜间开放试点）为共同 fixture，按读者要完成的判断划分编排原子，在同一内容上比较结构、空间、阅读路径与表现强度的变化，再用 pattern 与完整页面检验它们能否组合。

未覆盖、合并与不成立的组合

跨家族缺口

  • 深色主题、打印分页、读屏器实测、200% 文字缩放和真实触屏都没有检查；键盘路径只在 C05 翻页与 W06/W08 的控件上由子代理用 headless 脚本测过。
  • 动效几乎没有探索：原子页无过渡，只有 W02-c 的滚动进度线（无过渡）与 C05 的键盘翻页；Motion 维度应另开一轮。
  • 多栏正文、命题与证据的远距连线、侧注自动避让、表格排序/筛选等交互型编排没有做。
  • 缺少的原子：乘法/面积分解（C04 自造）、杠杆可调程度、值状态第四态“停开”（E10 只有缺失/零/不适用，C03 在组合层补了 c3-halt）、边注槽位契约、展示尺度（投影）修饰。
  • fixture 缺陷已在页面上如实标出而未掩盖：东坡全部开放晚夜均约 37，与“周二 38 低于参考线、低需求集中在周二”的叙述冲突；方案 B −¥96,000 与 C −¥580,000 的推算口径未给出；方案表混用增量与总量；年龄分布无来源；值班日志 21:40 早于规程 21:50 巡查；东坡每次到馆成本并存 ¥171（计划时段）与 ¥164（扣除停开）两个口径。
  • 不成立或无意义的组合按原子记在下方；跨家族层面，expression:graphic 与 load:long（长段落）基本不成立，spatial 与 load:dense 在 375 下都退化为堆叠，所以窄屏的 spatial 取值不代表窄屏保留了空间化。
  • 一个样张可以在同一轴上取多个值；矩阵统计的是“被画过”，不是“画得好”，也不是经过筛选的覆盖。

按原子记录的不成立组合

  • T01 expression:graphic + load:long-title 大字号图形化标题放 56 字会占满一屏，标题失去扫读功能；应先拆分
  • T01 spatial:main-margin + 舞台<520px 左栏无空间，退化为眉题
  • T02 expression:graphic + relation:single 只有一个对象时路线图没有顺序可表达
  • T03 expression:graphic + 每节多次 跨栏色带用两次以上退化为海报，失去“唯一带走句”的意义
  • T04 spatial:distant + 口径改变数字含义 见 T04-f，读者先读数字后读口径
  • T05 expression:graphic(闸门) + 条件类型:范围/假设 范围和假设没有满足状态
  • T05 spatial:inline + 条件>2 从句过长，主张被淹没
  • T06 spatial:juxtapose + 反例为统计量且与主张量级悬殊 等宽并置误导权重；改用悬挂
  • T07 expression:graphic(强度刻度) + 全部强度相同 刻度无信息
  • T08 spatial:offset(日期悬挂) + multi 不同截止 会变成时间表，属数量与关系家族
  • T09 expression:editorial(首行缩进无段距) + 段间插入块级原子 缩进体系与块级插入物混用显得断裂
  • T09 multi-column + 屏幕滚动 读完一栏需回滚，本轮未做
  • T10 expression:graphic(已知/未知并置) + 未知不可测量 虚线格无法给出“如何知道”
  • E01 expression:graphic(比例轴) + 无时刻步骤 没有时刻就没有可等比的量
  • E01 spatial:juxtapose(泳道) + 单一角色 没有交接，泳道只是装饰
  • E02 spatial:inline + load:dense 句内串 12 项已不可读
  • E02 expression:graphic 并列项没有可图形化的量或关系，图形化只会添加伪结构
  • E03 expression:graphic 定义是文字判断，图形化没有可编码的关系
  • E03 spatial:inline + load:long 长说明内联会打断正文
  • E04 expression:graphic(共同尺度) + 字段单位各异 不同单位不能共享一个长度尺度，只能每行一个尺度
  • E04 relation:claim-evidence + 中立陈列需求 倍数领句天然站队
  • E05 spatial:inline + load:long-number 长数值在句内无法对齐也无法比较
  • E05 expression:graphic(点带) + 值过近 标签重叠，需分层或放弃
  • E06 expression:graphic(格内条) + 非数值列 状态、文字列无法画条
  • E06 横向滚动宽表 + 375 本族选择重排而非滚动；未使用 data-allow-scroll
  • E07 relation:before-after(换依据) + 对象集不同 连线要求两边对象一致
  • E07 expression:graphic(条) + 正负混合 需要发散轴，本页未做，E07-d 用文字
  • E08 expression:graphic(长度) + 得失单位不同 条长会暗示可比大小；E08-c 因此不用条
  • E08 条件/门槛 + 失栏 前提不是代价，应放 E09 条件位
  • E09 推荐 + 仅颜色编码 灰度与色觉障碍下丢失
  • E09 决策表列 + 部分方案缺值 使推荐看似缺乏依据，应退回可齐全的口径
  • E10 独立使用 必须嵌在比较或数量原子里
  • E10 expression:editorial 空值不应被强调成展示元素
  • Q01 expression:editorial + relation:multi 句中标值超过两个数就变成数表，失去命题
  • Q01 expression:graphic + load:missing 缺失值没有长度，刻度条只能画空轨道，退化为 Q03-e 的写法
  • Q02 expression:editorial(Q02-c) + load:zero 基数为 0 或极小时相对变化无意义或爆炸
  • Q02 spatial:juxtapose + relation:multi 多组前后并置时栏间沟无法容纳多个差值，应转表格
  • Q03 expression:graphic + 不同单位共用刻度 条长跨行不可比；只能每行自有刻度（Q03-b）或换算比例（Q03-d）
  • Q03 expression:editorial(Q03-c) + relation:multi 多对分式重复成噪音
  • Q04 expression:editorial(点阵) + load:long-number 点阵只能表达整数百分比
  • Q04 expression:spatial(累计) + 无序类别 累计只对有序类别有意义
