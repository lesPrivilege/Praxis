## 补充一手参考

以下直接读取官方或作者网站的正文，而非搜索摘要。页面没有提供本次可用的固定提交；链接指向具体章节，访问与版本边界在快照记录中单列。它们是补充参照，不冒充已读的历史研究原件，也不登记为已有来源的恢复。

### EXT-01 · Google: Abbreviations

[官方页面：When to spell out a term](https://developers.google.com/style/abbreviations)

Original-language summary: Unfamiliar abbreviations are generally expanded on first mention. Audience familiarity matters; an abbreviation in a heading can be explained in the following paragraph. Expanding the letters is not always useful by itself.

本包取用：缩写首用、标题与首段分工、受众判断。个人学习材料的具体要求来自委托需求；Google 对熟悉术语的例外不自动覆盖它。英文斜体、冠词、大小写和缩略语词表不采入中文 grammar。关联：[写作规格 §7](WRITING-SPEC.md#7-术语稳定来源语言与提炼语言分开)。

### EXT-02 · Diátaxis: Explanation

[作者页面：Writing good explanation](https://diataxis.fr/explanation/)

Original-language summary: Explanation develops understanding by connecting ideas, supplying context, considering history and alternatives, and keeping the topic meaningfully bounded. It has a different purpose from instructions and reference material.

本包取用：支持理解型材料的独立任务，及正文保留必要历史、关系与争论。没有把该方法整体写成固定文体分类或效果已证事实。关联：[写作规格 §9](WRITING-SPEC.md#9-正文保留理解所需的历史过程资料进入索引)。

### EXT-03 · Google: Headings and titles

[官方页面：Heading and title text](https://developers.google.com/style/headings)

Original-language summary: Descriptive titles support navigation. Task and conceptual sections can use different heading forms; semantic heading levels reflect structure rather than visual size.

本包取用：标题按职责写、概念与任务标题可以并存、层级服务关系。中文结构文字的既有裁决仍以 WK-02、WK-03 和 AD-27 为准，不引入英文词形限制。关联：[写作规格 §8](WRITING-SPEC.md#8-不同位置的文字分别写分别审)。

### EXT-04 · Google: Organizing large documents

[官方页面：Disclose information progressively](https://developers.google.com/tech-writing/two/large-docs)

Original-language summary: An outline groups related topics; navigation connects the current location to related and deeper material. New terms and complexity can be introduced near the point where readers need them. The guide presents tactics rather than one mandatory outline.

本包取用：渐进展开、提纲与交叉链接的成熟参照。材料中的教程练习不转为 wiki 的必经流程，第一性整体图景也是本包面向读者需求的综合要求。关联：[写作规格 §2—3](WRITING-SPEC.md#2-从问题和基本关系建立整体图景)。

## 需求输入与个人资料

本包同时依据所有者提供的私有需求归纳。只保留可公开的任务要求，不包含私聊原句、私有链接、消息标识、个人经历或身份映射。需求表示本次希望得到的结果，不是外部效果证据。

[作者资料候选](AUTHOR-PROFILE.md)来自单独审阅后提供的公开版本，本包读取该公开候选而未读取其私有证据底稿。其例子全部合成；其中的置信度属于个人表达归纳，不表示相应规则对一般作者有效。它是可选候选，正式落位和是否采用仍待裁决。

技术文档编订研究的完整正文、来源卡与原始研究材料，以及完整 Claude 会话导出，本包均未重读。RS-01 和相关 ADR 能证明它们在仓库中的登记或既有裁决，不能替代原件证据。若后续裁决依赖其中某项事实，应按该项主张回查原件并记录范围；不宣称所有历史材料已经消费完毕。
