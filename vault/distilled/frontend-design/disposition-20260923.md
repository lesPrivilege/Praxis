# 本次素材裁取与覆盖

本目按用户要求独立保存通用前端设计材料。Luna定向登记CW、SE、career的来源和消费记录，Astra连接实际素材与新任务。已有快照直接关联，新原件保留hash、mtime和消费去向；不更改源仓库。

## 当前采纳与舍弃

| 来源 | 当前采用 | 当前舍弃或延后 |
|---|---|---|
| CW Pages pipeline | 来源、筛选、工作集、执行与回写的关系表达 | 内部术语、产品数字和统一编译器已经实现的暗示 |
| CW状态与差异图 | 候选/运行记录/正式记录分离，删除/新增符号、宽窄双版 | 原样例ID、品牌色、真实Accept按钮 |
| CW图式编排/校验 | title/desc、焦点、精确值、无脚本退化、hash与来源身份 | 把历史回执当新页面通过；把旧dist当当前HEAD重建 |
| career章节与纲要HTML | 章节导航、卡片层级、标题串读、自然打印续页 | 业务文案、合成合同数字、固定八/九页比例与amber |
| career规则控制台 | 规则/版本/修改/决定分层，用于静态比较 | 整套控制台、实时状态和生产能力暗示 |
| CW/SE外部参考与review | 保留“引用→裁取→落点→验证”的可追溯记录 | 未复核外部主张不晋升；来源指令不自动执行 |

五页答卷只采用当前需要的结构。纲要卡收窄为标题与一句判断，来源中的多字段卡片、保护说明与元数据布局不照搬。仅浅色冷色系是当前答卷的风格，不改变通用资料的原始颜色。必要位图由Codex准备，当前没有必须补充的概念图。

## 覆盖边界

CW Pages的定向索引覆盖8组图式/实现线索，4份SVG/编排原件保存；其共享CSS、其他SVG、registry、构建运行链、fixture与完整产品媒体未随最小快照复制。career保存6份通用或明确标记为合成的HTML，未读取复制个人简历、投递和内部机密目录；外部链接未逐一镜像。

CW与SE的消费记录及外部参考范围分别见各自intake、provenance catalog和主题索引。目录或文档声称某规则“已采纳”，仍需区分作者记录、实际代码落点和本轮验证。本轮未运行来源构建、浏览器、打印、图像生成、外部API或业务测试。

本任务的实现方已有rendered工作产物。召回只增加文档与目录README，不修改或验收该实现。全仓静态检查与新快照完整性结果记录于[召回验收](../../../docs/verification/ai-visual-recall-20260923.md)。
