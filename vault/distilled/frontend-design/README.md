# Frontend design distillations

本目录保存从只读 Courtwork 记录消费出的前端设计摘要。每份摘要必须把来源、采纳/拒绝、实现坐标和验证状态分开；没有实现或验证证据的内容保持候选、partial 或未覆盖。

- [CW consumption](cw-consumption.md)：CW 通用前端设计素材的消费链，供 CW/SE 前端绘制时查阅。

本目录不复制 Courtwork 应用源码、客户材料或截图，也不把源仓库的 AGENTS/Skill 当作本仓库指令。通用视觉索引 `cw-pages-reference-index.md` 已存在，本批只补充消费链，不重复其 Pages 图式快照。

[真实编排锚点与消费验收](composition-anchors.md)：两张已查看的Pages历史截图，记录可见机制如何进入新页面。

[解释、结构化与可视化上游参考](explanation-visualization-index.md)：结构重组讨论、三份已固定版本的上游原文、采纳边界及当前答卷18个节点的消费位置。
