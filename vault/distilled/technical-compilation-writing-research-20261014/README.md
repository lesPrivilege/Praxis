# 技术文档与教材编订研究

本目录研究社区与供应商公开的技术文档写作方法、Agent Skills 及成书实践，供 SaaS 工程教材试用。所有建议均为候选；不改变 Kit、现行写作 skill 或 SaaS 交付分支。

研究重点是来源与版本、术语与翻译、章节协作、算例与教学审阅、图文关系、多格式构建和修订维护；不收录文学模仿或通用“去 AI 味”提示词。取用既有术语和成熟实践，不为工作步骤另造框架名称。

## 阅读入口

完整交付将由研究正文、来源卡、实践比较、Praxis 覆盖分析、最小候选约定与 SaaS 试用计划组成。研究中的外部仓库只作静态材料，不安装、不执行其 skill 或构建脚本。

基线、处理范围、验证与提交记录见 [研究记录](CHANGELOG.md)。
