# 技术文档与教材编订研究

本目录研究社区与供应商公开的大语言模型（large language model，LLM）技术文档技能及成书实践，供软件即服务（Software as a Service，SaaS）工程教材试用。所有建议均为候选；不改变 Kit、现行写作 skill 或 SaaS 交付分支。

研究重点是来源与版本、术语与翻译、章节协作、算例与教学审阅、图文关系、多格式构建和修订维护；不收录文学模仿或通用“去 AI 味”提示词。取用既有术语和成熟实践，不为工作步骤另造框架名称。

## 阅读入口

**主要判断：先完善已有材料的章际接口、证据与例题版本关联、术语首用和分层审阅，再把已解决的材料交给 Claude 自由编订；目前没有理由替换现有 Kit 或安装一套通用写作技能包。** 成熟做法来自文档工程、教学设计与技术出版；供应商公开技能提供了可用的操作入口，但不构成独立效果证明。

最具体的配置发现是：AI Infra 的历史第 4 章回执与当前稿 hash 不同，部分输出说明也落后于工作流；AI Agent 的多语言计数检查与图注转换有实际实现，但不等于翻译和教学审阅。两例都支持把“协议、实现、配置调用、实际回执”分别记录。

外部仓库只作静态材料，不安装、不执行其 skill 或构建脚本。来源原语言与固定版本留在原站点，本目录保存原语言原创摘要、定位和校验值；不分发全文快照。三个动态网页没有固定提交或内容快照，依赖边界在来源卡中说明。
