# Docs as Code

来源：`TW-WTD` · Eric Holscher & the Write the Docs community · 原语言：English。

## Source-language summary

Docs as Code treats documentation as collaborative, versioned work using issue tracking, plain-text markup, review and automated checks. It gives writers and developers a shared workflow. The page supplies a practice definition and further reading, not a measured guarantee that any particular toolchain improves documentation.

## 中文消费
