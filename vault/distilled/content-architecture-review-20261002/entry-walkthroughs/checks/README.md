# 走读的检查

| 文件 | 内容 |
|---|---|
| [routing.json](routing.json) | 每次运行从工具日志里取出的：读过的文件、做过的搜索、是否读了维护文档、是否进了 `vault`、有没有写文件、token 数 |
| [contentcheck.py](contentcheck.py) | 按冻结协议里“守住”的字串核对每份报告的“产出”一节 |
| [content-check.json](content-check.json) | 上面脚本的结果 |

字串核对只管能逐字比的那部分。十四份里有两处不符：

- `N3-after`：`2026-09-07` 和 `2026-01-05` 没有出现，产出写的是 `2026-9-7`、`2026-1-5`。
- `N1-after2`：“本次迭代”没有出现，产出写的是“本迭代周期内”，事实还在，字面不同。

N1 和 N3 的报告在答案旁边解释了另一种写法，脚本只取答案本身：N3 取代码块，N1 取含“导出功能”的那一行。其余各项（没有承诺交付、假说没有写成原因、未决项没有写成已约定等）不能逐字比，由主会话逐项看，结果在 [走读记录](../README.md#守住了什么)。
