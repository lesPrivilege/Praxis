首轮记法里撤回的三处：

- “历史台账实际是 H01–H18”不是包的错。包内写的就是采纳 18 条；写成 H01–H20 的是主会话给代理的任务书。

## 边界

- 重访读的是文字。本仓库只看过 H01 页内的一张海报；包内自述看过图的七个来源都没有复核图像。
- 没有保存任何网页正文或素材；离线可读的只有摘要、来源卡和包的快照。
- 八个条目来自一次研究的检索起点，偏重西方与互联网视觉文化，不是设计史分类。
- A01 是一件样张、一种内容；三条观察都还是场景内观察。
- 没有做读者测试、读屏、键盘、打印或跨系统字体检查。

## 何时重访

真实任务用到某个条目，或在问题地图某一行找不到足够指引；uxdesign.cc 或 sony.com 变得可读；要把原作图像当视觉参照；包出新版；或 Kit 入口再出现“没找到、读了大量无关材料”的反例。
