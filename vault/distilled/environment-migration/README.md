# 环境迁移研究

本目录保存设备与账号迁移的候选操作指南，状态为研究登记，尚未采纳为 Kit 规范，也没有执行设备清理或账号操作。

[迁移指南](migration-guide.md)区分正常换机、凭据疑似泄漏，以及个人设备、组织托管设备；用于准备恢复入口、资料保留、新端验证、旧端撤销和移交清单。

依据是 2026-09-30 在线核查的 15 条官方来源，逐 URL 身份见 [来源 catalog](../../provenance/anthropic-migration-20260930/catalog.json)，覆盖与缺口见 [intake](../../intake/anthropic-migration-evidence-20260930.json)。本地只保存证据摘录及其 hash，未保存远端网页原件或网页依赖。

指南是本仓库对已核查材料的操作顺序整理。具体账号、设备、租户与权限尚未检查；再次迁移、产品入口变化或组织策略变化时重访来源，实际操作由设备所有者或组织管理员授权并验收。
