# 主题提炼目录

这里保存企业工作、Kit 架构与文档实践的研究提炼；各批次记录证据、候选和当前裁决入口。

## 证据标记

早期对话提炼区分以下来源角色：

1. 用户已经明确的意图；
2. 历史 assistant 提出的候选解读或建议；
3. 仍需核实的事实和需要裁决的问题；
4. 可追溯到 turn/item UUID 的来源。

早期对话占位引用缺口见 [材料登记](../../intake/materials.json)。后续研究的核查日期与主张范围按对应批次记录。
