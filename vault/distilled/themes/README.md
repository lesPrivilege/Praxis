# 主题提炼目录

这里按业务目标、验证闭环、产品 grammar、企业拓扑、Kit/demo 架构和技术栈边界组织对话内容。文件之间允许交叉引用，但不把一次客户特例自动提升为平台事实。

## 证据标记

每份主题文件都按以下顺序写：

1. 用户已经明确的意图；
2. 历史 assistant 提出的候选解读或建议；
3. 仍需核实的事实和需要裁决的问题；
4. 可追溯到 turn/item UUID 的来源。

外部网站、GitHub repo、产品版本、客户系统现状等均保留为“待核实”。本次不重新浏览外部源；占位引用的缺口见 [`../../intake/materials.json`](../../intake/materials.json)。
