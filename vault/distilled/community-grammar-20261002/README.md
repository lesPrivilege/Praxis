## 候选卡

研究包要求最多三个优先候选、两个暂缓，每个能指出来源、反例、本地落点和没有验证的地方。

| 卡 | 机制 | 结果 |
|---|---|---|
| [M1](candidates/m1-partial-success-reconciliation.md) | 部分成功之后先逐项对账 | 备用素材。没有写成规则：对照到顶 |
| [M2](candidates/m2-single-falsifiable-hypothesis.md) | 一次只验一条可证伪的假设 | 备用素材。Kit 没有调试分支，挂 G1 |
| [M3](candidates/m3-control-and-holdout.md) | 对照、留出、代价 | 备用素材；文档结构契约的验收把它列为默认做法 |
| [D1](candidates/d1-terminal-states.md) | 分支怎样结束要带回来 | 备用素材。暂缓写成交接项 |
| [D2](candidates/d2-coverage-of-checks.md) | 检查通过只覆盖实际看过的范围 | 备用素材。来源没有读 |

用户在施工中补充说明：这一轮不创建 skill，只是从社区的成熟实践里取工作的开展方式，放在 Kit 里备用。所以五条的泛化说法收在 Kit 的 [工作开展方式 · 备用素材](../../../kit/environment/working-methods.md)一页，取用优先级 normal，不是规则，不默认加载；这里的五张卡是它的来路，记来源、反例、与本地条目的关系和没有验证的地方。研究包“怎样读这些样本”的四层拆法也收在那一页。

## 对照走读

研究包建议比较“现有流程”和“只加候选短语法”。主会话另加了不读仓库的对照，并留了一个陌生领域的任务最后才跑。八次运行，见 [对照走读](control-walkthroughs/README.md)。

结果改变了裁决。原打算在共同工作语法的不变量里加一行“部分成功”。不读仓库的对照在批处理和合同替换两个任务上把冻结的各项全做到了，这一行拿不出可归给它的作用，没有写成规则，只在备用素材页留了泛化的说法并标明这个结果。读仓库的那次反而暴露了路由问题：它把“写出恢复步骤”当成写作任务，读了 8 个成文分支的文件，没有到达已有的“结果未知”一行，还在报告里说仓库没有讲恢复。入口加一行之后，同一任务读 5 个文件，到达了工作契约和共同工作语法，并逐条引了其中的原句。

## 多模型分工的登记

研究包拆解了用户给它的一条分工 tip。原始 tip 和它提到的“Lexicon”里的原话没有随文件提供，下面只是研究包的转述，记为 2026-10-02 的配置快照，没有在本仓库验证。

| 角色 | 研究包转述的配置 | 本地对应 |
|---|---|---|
| 日常处理与执行 | Sol | 没有这个名字。本仓库由主会话执行 |
| 探索 | Luna | [Kit 使用约定](../../../kit/Agent.md)：Luna 是首选 explorer |
| 复核 | Astra，在几个固定时点；固定三次专家调用 | Kit 使用约定：Astra 或主会话裁决 |
| 便宜的有界判断 | Jev，允许返回“不确定” | [Jev 实践研究](../jev-practices/README.md)讲的是局部语义判断在工作流里的位置 |

研究包认为该留的是角色、交接证据和升级条件，不该留的是模型名、effort、半秒延迟和固定三次复核。它给的升级条件是：不可逆的承诺、反复失败却没有新增信息、证据冲突、高影响的交付。本地的说法是主会话“只在证据不足、相互矛盾或影响重大裁决时回查原件”，[使用与额度登记](../../../kit/environment/agent-usage.md)列了要投影给人的语义变化。两边基本同义，“反复失败却没有新增信息”本地没有，与 M2 的停止条件是同一条。

根 `AGENTS.md` 的分工是用户指定的，没有动。本会话里 Luna 不可用，探索由 Sonnet 只读代理承担，裁决在主会话。

研究包还提到“后续作为 mod 引入，需要 RSI 和兼容性”。它没有确认 mod 指哪个产品，本页也不确认。它建议兼容性只验四条窄通路：能否被发现并正确触发，引用的资源在不在，工具与权限条件成不成立，产物和失败状态能否交接。这与 [消费登记](../../../kit/environment/expert-contract.md)的“兼容范围、升级重验与回退”对应，记为候选，没有新增。它给 RSI 的最小闭环是“真实失败、候选机制、对照、接纳或撤回及原因”，本轮照这个顺序走了一遍，只是起点是一份研究而不是一次真实失败。

## 边界

- 45 个链接读了 8 个。Trail of Bits、SWE-agent、DOCX、BMAD、Fabric、OpenAI 的样本和三篇论文都只有研究包的转述。

- 多模型分工只有转述。
- M2、D1、D2 没有任何实测。

## 何时重访

换了执行模型或 harness；出现用到某个候选的真实任务；某次汇总漏报了失败的分支；有一件真的文档交付；用户给出多模型分工的原始配置；或上游样本有影响结论的改动。
