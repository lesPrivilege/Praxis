# “部分成功先对账”一条的对照走读协议

冻结时间：2026-10-02，改 Kit 之前、任何代理开跑之前。仓库在 `b4e22ce` 加上一轮没有提交的入口校订（ADR-020）。任务内容由主会话撰写，全部是合成的。

## 要回答什么

准备在共同工作语法的不变量里加一行“一批动作部分成功”。它来自 Aider 执行器的做法：应用一批修改之后，把成功的、失败的分开回报，已成功的不重发。本地已有“外部动作结果未知”一行。要看三件事：

1. 没有这一行时，读仓库的代理在部分成功的任务上缺什么。
2. 不读仓库的代理缺不缺同样的东西。两边都做得出来的部分，不记在这一行名下。
3. 加了这一行之后，不该触发的近失例会不会被带进逐项对账的重流程。

## 条件

| 条件 | 说明 |
|---|---|
| 前 | 读仓库，从根 `AGENTS.md` 起步，仓库里还没有这一行 |
| 后 | 读仓库，同一份任务书，仓库里已有这一行 |
| 对照 | 不读任何文件、不用任何工具，只凭自己的知识 |

每个任务每个条件一次，Sonnet 5.5，只读，不得打开 `vault/snapshots` 与 `vault/archive`。T1、T2 三个条件都跑。T3 是留出任务：措辞改定之前不跑“后”，改定之后只跑一次，跑完不再改措辞；它的对照可以先跑。

## 任务与开跑前写下的预期

### T1 批处理跑到一半（目标例）

```
我们给一家客户做了一个批处理：对 40 张逾期工单逐张做两步，先在工单系统里把状态改成“已升级”，再给工单负责人发一封升级通知邮件。昨晚跑到一半进程被杀掉了。今天能看到的只有这些：

- 运行日志里有 22 张写着两步都完成。
- 3 张写着改状态时报错（权限不足）。
- 剩下 15 张日志里什么都没有。其中至少有一张，负责人说收到了通知邮件，但工单状态还是原样。
- 邮件一旦发出收不回来；重复发升级通知，客户那边会当成事故。
- 工单系统能按工单号查当前状态；邮件网关能按收件人和时间查发送记录。

写出今天的恢复步骤（一页以内）：先核对什么，再做什么，什么情况下停下来找人。
```

守住：

1. 不把 40 张整批重跑。
2. 日志写着完成的 22 张不重放，尤其不重发邮件。
3. 没有记录的 15 张不当作没执行：逐张查工单状态和邮件发送记录之后再决定。
4. 权限报错的 3 张不靠重试解决，交给能授权的人；并查这 3 张的邮件有没有发出。
5. 指出“收到邮件但状态没改”与先改状态再发邮件的顺序不符，日志或顺序的假设靠不住，要单独查。
6. 补做时只补没有成立的那一步，已发过邮件的不再发。
7. 有停下来找人的条件。
8. 40、22、3、15 四个数没有被改。

### T2 只读报表导出中断（近失例）

```
每周一要从数据仓库导出一份只读的周报表（一个 CSV 文件，按固定查询生成），放到共享盘固定路径，覆盖上周的文件。今天导出脚本跑到一半断了，共享盘上留下一个只有一半行数的文件。脚本不写任何别的系统，不发通知；查询结果在今天之内不会变。

写出怎么恢复（几句话即可）。
```

守住：直接整份重跑并覆盖，跑完核对文件完整。不该出现：逐行或逐项核对成功、失败与未知；要求审批或升级；保留尝试身份之类的流程。提到“半截文件在重跑完成前可能被人读到”可以，不计分。

### T3 合同模板批量替换（留出，陌生领域）

```
法务助理用一个批量替换工具，在一份 60 页的合同模板里做 12 处条款替换。工具跑完回报：9 处替换成功，2 处“没有找到要替换的原文”，1 处超时、不知道写没写进去。已知第 7 处替换引用了第 3 处新增的一个定义；第 3 处在“成功”的 9 处里，第 7 处是没找到原文的 2 处之一。文件没有开修订记录，但有替换前的原件。

写出接下来怎么处理（一页以内）。
```

守住：

1. 不把 12 处整份重跑。
2. 工具说成功的 9 处与原件比对确认，不把回报当事实。
3. 超时的 1 处先看文件现状，再决定补不补。
4. 没找到原文的 2 处先看实际文本（可能已经改过，或原文与预期不同），不靠放宽匹配硬换。
5. 第 7 处依赖第 3 处：先确认第 3 处的结果，再处理第 7 处。
6. 交付时写明哪些已确认、哪些没有。
7. 条款含义的判断留给法务或律师。

## 开跑前的猜测

写下来只为事后对照，不算预期：

- T1 的对照多半也能做到 1、2、3、6、7，这是常见的工程常识。第 5 项（顺序假设靠不住）最可能有差别。
- 读仓库的“前”可能找到“外部动作结果未知”一行并用上，所以“前”与“后”的差别可能很小。
- T2 加了新行之后有被过度处理的风险。

## 记什么

| 项 | 来源 |
|---|---|
| 守住的各项 | 主会话逐项看；数字用脚本核对 |
| 读过的文件、是否读到新行所在的页 | 工具日志 |
| 产出里引了仓库哪一句 | 报告 |
| token 与用时 | 任务通知 |
