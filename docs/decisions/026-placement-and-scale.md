# ADR-026：排列与刻度进入 Design Foundations

日期：2026-10-04。状态：accepted（Design 知识的落位；实现留在 demo）。用户裁决；Claude Opus 5.5 主会话编订，三个 Claude Sonnet 只读子代理清点与对照，一个 Sonnet 子代理独立复查，四个 Sonnet 子代理冷读与对照。Luna 在本会话不可用。

## 问题

[ADR-025](025-relation-marks-and-anchors.md)那一轮列出过第三条可以泛化的语法，当时叫“轨与挂接行”，用户要求继续做。重读第一批四个图件之后，原来的说法需要更正：四个件并不都是“一条竖轨加挂接的行”，它们共有的是让位置说了话，却没有写明说的是什么。版本图把三条各排各的版本线并排，同一高度的两个版本会被读成同时；这句读法当时只写在源码注释里。

仓库别处的情况相同。子代理列出五十四种沿一条线排开的构造，写明位置含义的大约一半。原子编排实验早已把“等距排布暗示等间隔”记为已见失败，也写过“共享尺度是组合性质，需组合层声明”，这两句一直留在 Vault 的样张记录里。

## 决定

1. Design / Foundations 新增 [排列与刻度](../../dsh-praxis/kit/design/foundations/placement.md)，与 [成立程度与归属的标记](../../dsh-praxis/kit/design/foundations/standing.md)、[精确指向](../../dsh-praxis/kit/design/foundations/anchoring.md)并列，体例相同：问题、不随排法改变的约束、一套默认、三级做法、最容易犯的错。不给间距和尺寸。
2. 不规定“时间轴怎样画”。规定的是：位置回答了哪几个问题（谁先谁后、隔了多久、属于谁、是不是同一个）要写成一句读法放进图里，读者会顺手读出而图不表示的也要说一句；没有量就不按比例画；并排的线要么共用一条标尺，要么写明各排各的。
3. 每一项自己带着位置词，线、间距和缩进只是重复。这是第一级做法，任何材料都做得到；一条线和几条线并排是后两级，不新增信息。
4. 实现留在 `projects/editable-native-svg/svg-01-relations`，版本 0.3.0：新增 `rel-rail`（清单、先后、时间三种读法，可以带上下级或并排的栏）和 `rel-pair`（前后对照与选取）；`rel-tracks` 在图脚补上读法。样板页加第三节。它们是候选实现，不是 Kit 的共享组件。
5. 第一批工单里没有画的 R10 和只画了一半的 R18 由 `rel-pair` 画出。R16、R19、R33 登记在第二批工单名下，这一轮只是因为同一种排法顺带画出了它们的一部分，登记为 `partial`；第二批接手时自行决定沿用、修改还是重画。

## 与既有决定的关系

沿用 ADR-018 和 ADR-025 的层次：泛化判断在 Kit，生成器、样板和输入是它的取用。不改 ADR-002：晋升的是知识说明，不是运行组件。不改 ADR-017：[按属性维持比较](../../dsh-praxis/kit/design/references/curated/comparison-continuity.md)照旧管窄屏下怎样保住比较，新页只在第 10 条写了宽窄不改变先后、时刻和对应。

[图形编码](../../dsh-praxis/kit/design/composition/encoding.md)的“长度有尺度”后面加了半句和一个链接。[成立程度与归属的标记](../../dsh-praxis/kit/design/foundations/standing.md)的“归属优先用位置”后面补了“位置说明归谁，不说明谁有权限”。[精确指向](../../dsh-praxis/kit/design/foundations/anchoring.md)的状态一节原先写着时间范围和字段集合还没有画法，现在改为指向新页。问题地图的 G01、G10 两行各加了一个链接。

## 没有采纳的

- 把“固定部分实心、可变部分斜纹”定为区间时长的画法。它在两次样张里独立出现过，仍只是观察。
- 标尺的断轴、“现在”的记号、横排。没有真实任务需要，生成器也没有实现。
- 把 `rel-tracks` 改写到新的生成器上。两者只共用一条通线的画法和读法的词表，版本线的绑定行是它自己的结构。
- Vega-Lite 的尺度类型名或 OWL-Time 的词表。只对照了分法，见 [提炼页](../../vault/distilled/placement-grammar-20261004/README.md)。

## 验证与限制

自动检查、浏览器实测、独立复查、冷读与对照的范围和结果见 [验收回执](../verification/placement-grammar-20261004.md)。全部是合成内容，出自同一名制作者，没有读者或专业人员看过。

重访：真实任务里默认排法行不通；出现时长是区间、需要断轴或需要“现在”的任务；第二批工单对 R16、R19、R33 另有判断；冷读或真实使用出现“读了这一页仍然排错”的反例。
