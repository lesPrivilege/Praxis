# ADR-003 · Reporting as a separate kit entry

状态：accepted。编订：Astra。日期：2026-09-18。

依据：用户追加“登记汇报设计 Kit”及Courtwork/career-kit/Downloads材料，要求别篇裁出、单独一目、不再依赖外部。

决定：kit/reporting为独立消费入口，vault/distilled/reporting为充分提炼，vault/snapshots/local保留必要原件与HTML依赖。原路径仅溯源；正文链接本repo副本。与enterprise共享登记/状态/证据规范，不强制统一输出文体。

限制：源材料含不可取得资产或引用占位时，显式登记缺口。离线提炼可用不等于原始HTML完全离线；不得用无依据的重建掩盖缺失。
