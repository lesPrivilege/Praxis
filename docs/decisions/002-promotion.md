# ADR-002 · Promotion needs independent evidence

状态：accepted。编订：Astra。日期：2026-09-18。

冲突：Enterprise原对话9a81d625要求第三个独立场景晋升；末轮1c0c2346允许第二个场景后形成candidate并经contract/story/fixture晋升。

裁决：第一次scenario-local；第二个独立场景进入candidate；第三个独立场景仍需要、稳定契约与fixture/验证齐备后可申请shared primitive，Astra通过ADR裁决。三个不是自动门槛通行证；同客户的换皮demo不算独立场景。

治理层的证据命名与目录约定不受此运行组件门槛限制。紧急例外需单独ADR，记录被跳过证据和撤回条件。
