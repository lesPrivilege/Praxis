# ADR-004 · Work system as a third entry

状态：accepted。编订：Astra。日期：2026-09-18。

依据：用户明确要求“工作系统工具链整理”同样入账。该完整对话含5轮，范围超出预览里的3轮。

决定：kit/work-system单列第三目，连接会议/项目状态、人的review和软件控制面；vault保存提炼和来源。设备、订阅和工具属于reference，实际启用需具体场景、可用控制面与授权。

不在本次修改用户全局workspace、不执行watch folder、不发送外部消息、不购买订阅。后续可从已登记的手动loop实测反馈修订对象和review契约。
