# ADR-008 · 材料路由与驻场组织接口

状态：accepted（工作契约）；具体文体与效果验证 deferred。裁决：Astra，2026-09-19。

来源：[建立材料分类体系](../../vault/distilled/reporting/material-classification.md)，2 轮/4 消息。用户要求即时消费；历史 assistant 的建议不等于已验证行业事实。

采纳到已有 Reporting brief：受众、期待、行动、阶段、证据、分歧六项最小契约，先工作目的后呈现形式；八类目的仅作可扩展路由词表。采用不同证据姿态时仍保持同一事实基础，逐步锁定共识。

采纳到 Work System：明确 sponsor 授权和一线合作条件；区分演示、采用、净减负与经营改善；记录价值与资产两份账；在约定检查点对缺失组织条件收敛升级。净减负包含 AI 引入的额外人工成本。

本次扩展现有知识与治理契约，没有晋升共享实现；ADR-002 的独立场景验证门槛不变。不建八套空目录、不固定所有行业模板、不承诺裁员或 ROI、不将组织工程必然主导所有项目作为事实。后续用真实材料、反馈与验证结果修订分类轴和工作约束。
