# ADR-033：互著别裁与内容的持续维护

日期：2026-10-08。状态：accepted（依用户明确的长期治理要求）。主代理编订，Luna 只读核对既有条款与缺口。
编号说明：起草时编为 ADR-029；并入 main 时该号已由 [书目摘要与可选语法参考](029-design-writing-reference-encyclopedia.md)使用，改编 033，日期与决定不变。


## 缘由

入口审查发现：上层仍写“尚未提炼”，下层已有候选笔记；部分项目保留了制作经验，相关分支却没有入口。用户要求目录和主要文档逐层提供信息，新增或清理内容时保持无关分支独立，并用互著别裁保留内容的发现路径。

## 决定

在 [文档结构契约](../architecture/documentation.md#互著与别裁)中明确：多个入口指向同一正文；按独立用途提炼并保留来源关系；分别列出可选参考与必要依赖。[修订流程](../governance/evolution.md#修订流程)补充新增、迁移、合并、移交和清退时的入口与去向处理。

沿用现有目录归属、来源 ID 和状态词表。登记仍在原台账维护；项目实现与运行依赖留在项目内，必要前提在使用处列明。

本决定兼容 ADR-011、ADR-015、ADR-017 和 ADR-022。新内容按上述规则维护，既有内容在修订时核对。历史证据与替代路径的规则在上述两处维护。

## 验证与边界

已对照参考生命周期，保留取用优先级、证据状态和采纳状态的区分。新增参考、合并重复正文、撤回且无替代三种情形的条文走读，均能确定维护位置、入口和历史去向。本次未执行实际迁移、删除或对照实验；引用关系与去向仍需人工检查。

仓库校验结果见 [CHANGELOG](../../CHANGELOG.md)。后续出现入口失效、无关分支被迫同步修改，或清退后无法追溯时，按既有修订流程复核。
