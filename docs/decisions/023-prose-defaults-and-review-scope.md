# ADR-023：成文默认与审阅范围的窄修订

日期：2026-10-03。状态：accepted（本轮授权的成文与入口修订）；Write 的纯文本职责收缩待迁移裁决。主代理编订，Luna（gpt-6-luna）只读探索。

## 问题与依据

当前委托要求薄默认、渐进消费，个人偏好不普适化，不用禁词表、固定短句或结尾制造统一口吻。召回只提供带角色和时间的摘要，没有取得原消息 ID 或原文；本决定不将其当作逐字引用。

ADR-019 已给八条原理补了例外，但审阅方法仍要求一问一句、名词短语及正文没有阅读指引，交付又同时要求“只交成文”和修改表。入口与执行要求不一致。对照、外部核查和片段检查见 [回执](../verification/writing-review-20261003.md)。

## 决定

- Shared 四条语义底线保留；信息作用按读者理解与任务完成判断，必要导航、重复、情境和警示不因没有新事实而删除。
- Prose 八条保留当前维护位置，改为条件明确的编辑判断。技术报告的平实书面语是任务语体默认；语言搭配与术语约定按目标读者取用。句式、叙事次序与结尾不固定，改变实质约束的取舍才附理由。
- 审阅核对准确性、信息作用、术语、范围、必要复杂度与连贯。修改记录按任务和实质改动提供；格式检查维持原有保护范围，语义判断不机械化。
- writing skill 保留薄入口和中文成段文本的范围，简单改一句话与日常回答不加载。已给出的口吻可决定本次基调，具体个人用字不默认复刻。
- 外部指南低权重、按需读取；入口只提示足以选路的段落、列表和指代判断。ASD-STE100 访问受限，没有采纳具体规则或标准合规声明。
- Reporting 的 brief 前提与其 README 对齐；Publish 只补当前职责决定的链接。

## 与既有决定的关系

修订 ADR-019 第 4 项“八条原文不改”的维护状态及第 5 条原理的分类；保留四条底线、格式检查和任务取用方向。ADR-013 答卷体例仍只用于相应文体，改为按第一人称和命名的实际作用审阅。

召回摘要提出 Write 仅纯文本，与 ADR-016/019 的 Publish、Motion、Shared 落位有冲突。本轮列出迁移所需裁决，未移动目录、转交规则所有权或新建 Present、Core、Language、Profiles。当前路由与正式落位继续可用，不能声称纯文本收缩已经实施。

## 验证与重访

仓库验证、skill 结构与链接检查、少量现有片段审阅见回执。它们不证明自动发现效果或真实读者理解改善。职责落点明确、原文裁决可核对或真实任务出现新的误用时重访。
