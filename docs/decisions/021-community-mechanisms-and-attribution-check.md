# ADR-021：社区实践里的工作方式作为备用素材，以及“规则起了作用”的检查

日期：2026-10-02。状态：accepted（Kit 的一页备用素材、一行入口路由、验收的一条默认做法）。用户当日交来研究包并说“可以串行施工”，保留 Opus 的裁决权；施工中补充说明：这一轮不创建 skill，只是从社区的成熟实践里取工作的开展方式，放在 Kit 里备用。Opus 5.5 主会话回读来源、对照本地、裁决并编订，Sonnet 5.5 只读代理做带对照组的走读。Luna 在本会话不可用。改动没有提交。

## 问题

研究包从十个社区 skill 与 prompt 样本里抽出五类机制，建议先消费三个：Aider 的局部恢复、superpowers 的单一假设、Anthropic skill-creator 的基线与轨迹分析。它要求每次处理一个机制，默认合并或交叉引用到已有条目，状态标“未实测”。

要裁决四件事：这些机制以什么身份进 Kit；哪一条够格写成规则；研究包自己提出的“先对照再接纳”要不要先用在这些机制身上；多模型分工的配置怎样登记。

## 决定

1. 十个样本都不安装、不导入、不保存原文，不做成 skill。研究包和 45 个外部链接作为参考入账，主会话按固定提交回读了其中 8 个。
2. 五条机制的泛化说法收进 Kit 的一页 [工作开展方式 · 备用素材](../../kit/environment/working-methods.md)，取用优先级 normal，不默认加载，碰到对应情形才取。同一页收了研究包“从外面拿一条做法之前先拆四层”的读法。每条的来源、反例、与本地条目的关系留在 Vault 的候选卡里。
3. 五条里没有一条写成规则。按“先对照再接纳”先验了最有把握的一条“部分成功先逐项对账”：不读仓库的执行者在两个任务上把该做的全做到了，它在这类执行者身上拿不出可归给规则的作用。备用素材页如实标了这个结果。
4. “对照、留出、代价”在 [文档结构契约](../architecture/documentation.md#验收)的验收里列为默认做法：说一条规则或入口起了作用之前这样查，做不到时记“未对照”。它是默认，不是硬规则。本地依据是当日三轮走读各自缺的那一块，和本轮它改变了第 3 条的裁决。
5. 对照走读暴露了一个路由问题：恢复类任务被当成写作任务，到不了已有的“外部动作结果未知”一行。[Kit 任务入口](../../kit/README.md)的企业工作表加一行，把“动作失败、中断或结果不明”指向工作契约和共同工作语法。不变量的正文不动。
6. 多模型分工登记为 2026-10-02 的配置快照，只有研究包的转述，没有在本仓库验证，留在 Vault。角色、交接证据和升级条件与本地已有的分工基本同义；根 `AGENTS.md` 的分工是用户指定的，不动。
7. 兼容性的四条窄通路（能否被发现、资源是否可达、工具与权限条件、产物能否交接）记为候选，与 [消费登记](../../kit/environment/expert-contract.md)的“兼容范围、升级重验与回退”对应，不新增。

## 没有采纳的

| 研究包的内容 | 处置 |
|---|---|
| 把机制写成既有领域条目里的候选交叉引用 | 改为集中在一页备用素材，由相关条目指过去。分散到五六个页面，每处一句，读者看不出它们是没有实测的素材 |
| 三种条件的评测：现有流程、只加短语法、必要时原包 | 做了前两种，另加不读仓库的对照。原包没有装 |
| 安全差分审阅的方法 | 不收。没有对应任务，研究包自己也说领域知识不能稀释成口号 |
| 完成、预算耗尽、执行失败三种终态写进交接项 | 只作备用素材。本地没有自动汇总多分支的环节 |
| 模型名、effort、延迟、固定三次复核 | 不进 Kit，只在提炼页留带日期的转述 |

## 与既有决定的关系

延续 ADR-018 的做法：泛化的判断留在 Kit，原子（这里是候选卡）作为来路和取用方式留在 Vault。延续 ADR-017：备用素材是 normal 参考，没有申请 preferred。延续 ADR-020：入口表又加一行，目录不动；在 Environment 下新增一页，没有新建分支。第 4 条细化 ADR-011 的“用合成任务走读”。不改 ADR-002：进入 Kit 的是知识说明，不是共享实现。

## 验证与限制

八次走读，协议和预期在改 Kit 之前冻结，首轮之后写了一份补记。结果见 [对照走读](../../vault/distilled/community-grammar-20261002/control-walkthroughs/README.md)与 [回执](../verification/community-grammar-20261002.md)。每个任务每个条件一次，一种模型，任务是合成的，评阅者是裁决的人。

对照到顶只说明这一种执行模型在这三个任务上不需要那一条，不说明更弱的执行者或真实的长任务也不需要。备用素材页和入口里指向它的两句是走读之后写的，没有走读经过。五条里四条没有任何实测，一条的来源没有读。

重访：某一条被真实任务用到；换了执行模型或 harness；某次汇总漏报了失败的分支；有一件真的文档交付；或用户给出多模型分工的原始配置。

来路见 [对照与裁决](../../vault/distilled/community-grammar-20261002/README.md)。
