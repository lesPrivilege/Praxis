# ADR-009：以工作为入口的知识架构

状态：accepted（2026-09-19）

## 决定

保留 Enterprise、Reporting、Work System 和共享 Environment；增加工作全景、共同工作语法、现场闭环与研究问题清单，让使用者从任务进入并按需调用知识。知识覆盖可以宽，实施范围仍须有界。

## 保留与不采纳

保留现有入账、来源、快照、晋升和双账本规则；不增加顶层目录、runtime、厂商百科或第二套机器总账，不把九问扩成统一状态机，不把外部参照宣称为合规认证。

## 维护

每条长期知识有唯一维护位置、适用边界、依据、正反例和重访条件。任务驱动和材料驱动都可提出修订；知识说明、治理采纳、使用验证和共享实现分别处理。破坏性变化须说明消费者、迁移与重验；错误主张从当前消费页撤回。
