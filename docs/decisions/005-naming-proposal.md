# ADR-005 · Praxis naming

状态：accepted。编订：Astra。日期：2026-09-18。用户提供远端 https://github.com/lesPrivilege/Praxis.git，采纳展示名与repo名 Praxis。

上下文：用户提出Praxis/Apparatus/Fieldcraft等长期名字，希望涵盖个人驻场工作方式、办公控制面、Agent hands、workspace schema与review grammar。

原建议为展示名Praxis、repo名praxis-kit；最终跟随用户建立的repo名Praxis。Enterprise作为业务应用域，Reporting作为汇报设计域，Work System作为个人工作系统域。Field/Workplace/Workspace/Tools/Loops/Review作为Work System内部分类，不替代已有三个消费入口。

Apparatus可保留为未来工具基础设施子域候选，当前无需增加命名层级。

已连接用户提供的origin。当前路径仍为enterprise-kit，未执行目录重命名或Codex project修改；首次远端检查没有已有refs。本轮材料整合和验证完成后衔接初始版本。

展示名与入口说明已更新；保留来源历史标题和稳定ID；相对链接应继续可用，并重新运行仓库验证。
