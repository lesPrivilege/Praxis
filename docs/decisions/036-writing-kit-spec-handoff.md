# ADR-036：Writing Kit 修订交接的裁决

日期：2026-10-17。状态：accepted（用户授权主会话裁决）。主会话（Claude Opus 5.5）独自裁决并编订，没有分派代理；Luna、Astra 在本环境不可用。

## 问题与依据

另一会话把一份 Writing Kit 修订规格交到分支 `cloud/writing-kit-spec-handoff-20261016`，已并入 main，入口是 [Writing Kit 修订交接](../../vault/distilled/writing-kit-spec-handoff-20261016/README.md)。它逐项对照现行 Kit，指出四处待裁决：机制讲解的整体图景与渐进展开；缩写首用及原语言来源与中文提炼的边界；共享验收页固定的故事线顺序；个人语体怎样按需取用。

交接的基线是 `c4f77e4`，早于 [ADR-035](035-local-answers-and-link-relations.md)。ADR-035 已经给讲解页的结论层加了验收（只读这一层也能说出对象、核心关系、主要分支和改变判断的条件），并要求交叉链接写明关系。第一项的大部分因此已在 Kit 里，本次只补剩下的部分。

用户另交一份个人写作研究的压缩包，含私聊链接、消息 ID 和原句。仓库公开，用户裁定不入库；作者语体只用交接包里已脱敏的公开候选。

## 决定

- **整体图景从问题讲起。** [讲解页的编排](../../kit/write/publish/explainer.md)补一段：结论层从对象要解决的问题讲起，交代分工与连接，不只排组件名；几章共用的机制只在一处讲，其余用写明关系的链接指过去，不把跨章依赖写成从属。可选参考，与该页同强度。
- **缩写首用。** [成文原理](../../kit/write/prose/grammar.md)第 6 条补写：缩写首次实质使用时给全称并交代含义，展开字母不等于解释；标题里首次出现的在首段展开；可直接进入的页面各展开一次；目标读者普遍熟悉的缩写不展开。中文语言约定，强度不变。
- **来源语言与中文提炼。** [多语言与本地化边界](../../kit/write/prose/multilingual.md)加第 5 项：原件、引文、代码、标识符和来源标题保留原语言，中文提炼另写；来源之间的术语边界不同就分别交代，不在翻译时统一成新名称。Prose 入口的路由行同步。
- **验收不定次序。** [内容与媒介验收](../../kit/write/shared/verification.md)把“标题与故事线 → … → 文字去套话”的固定顺序换成五个检查面，从风险最大的一面开始；非叙事、非决策材料不要求故事线或行动请求。按输出检查的表和导出、交互、实速观看的要求不变。
- **正文里的历史不是过程材料。** [证据与来源](../../kit/write/shared/evidence.md)补一句：对象自身的历史、设计缘由和来源之间的实质分歧是正文内容。防止按 ADR-034 误删。
- **改正时不补假设。** [审阅方法](../../kit/write/prose/review.md)第 7 步与验收补写：改正一处错误后，检查改后的文本有没有补进来源没有给出的假设；偏差表加“字面量都在，条件丢了”“改正时补进假设”两行，取交接包的 24 小时保留期例子。
- **作者语体单页，默认不启用。** 公开候选改写为 [作者语体](../../kit/write/prose/author-profile.md)，只在要求用所有者本人口吻代拟时取用；成文原理“个人语体”一节加一句指针。不建 profiles 目录或配置层，与 ADR-019 不冲突。

## 没有进入的

- 文字角色的按位置路由。成文原理第 5 条、展项与说明、微文案和口播体例已分管，没有观察到发现性断点。
- 读者页按“个人学习者”另写。讲解页已按知识状态定读者（ADR-031），不再加情境画像。
- 交接包的合成审阅样例 A、C—F。各自对应的规则已在 Kit，例子留在交接包供取用。
- 新 linter、四层升为全局模板、Google 缩写指南的斜体与大小写规则、Diátaxis 的整套分类。

## 与既有决定的关系

补足 ADR-031、035 的讲解页分层，扩展 ADR-027、034 的审阅与过程分离，不改变强度。兼容扩展：已交付的成文不追改。没有做真实写作试用，也没有对照；下一项本来要做的机制讲解或长文改写是第一次消费。缩写展开在熟悉的读者那里显得啰嗦、整体图景让短讲解变长，或作者语体启用后事实与观点发生变化时，重访本决定。
