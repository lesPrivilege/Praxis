# ADR-013：能力测试的回答体例与证据分层

日期：2026-09-23。状态：accepted（写作与知识治理）；运行方案、业务效果与页面制作 deferred。裁决：Astra/main；登记与外部探索：Luna Max worker（gpt-5.6-luna）。

## 问题与依据

本批 [AI 能力测试](../../vault/distilled/ai-capability-assessment/README.md) 同时涉及上下文、成本、操作权限、概率决策和知识演化。原 Chat、附件和另一模型的 review 含有有价值的判断，也混有未恢复引用、易变能力和未实测推论。评审者不应先理解本仓库专用术语才能理解答案。

## 采纳

在 [回答体例](../../kit/reporting/assessment-answer-profile.md) 单点维护：判断先行；机制有边界；反例与验收支持判断；个人案例区分文档、实现和实测；概念用自然语言展开，不硬翻译、不加面向读者的叙事；来源、技术版本、核查状态和实践快照集中在index，正文只保留实质判断与成立条件。

本套题按 [回答母稿](../../vault/distilled/ai-capability-assessment/answer-draft.md) 编订，并作以下裁决：

| 问题 | 裁决 | 理由与边界 |
|---|---|---|
| 新增工具一定重算前缀 | 拒绝绝对化 | 分清目录、加载位置、服务状态与调用授权；成本由实际usage验证 |
| 高工作量、统一等待数字或固定价格 | 仅条件化使用 | 按可验证性和错误代价路由；等待和价值需要目标任务数据 |
| 云端/本地决定全部安全边界 | 拒绝 | 按实际权限、副作用与授权；未知外部结果先核对 |
| schema正确意味着无幻觉；均值低于2即放行 | 拒绝 | 类型、校准、业务正确性和动作稳定性独立验收；用完整分布挑战均值规则 |
| 律师交付等于规则生效；德国一例成立即可跨国晋升 | 拒绝 | D1/D2独立审议；规则身份、客户scope、法域及active状态均需检查 |
| RSI研究作为成熟法律治理保证 | 拒绝 | 只借鉴候选、独立验证、选择和回滚方法，研究不替代法律真值 |
| 三层HTML入口＋各题不同工件 | 接受为后续交付方向 | 先文字母稿；仅Q4优先交互；后续Claude工单承担呈现 |

## 暂不采纳

不把某一模型名称、价格倍率、缓存例外、SDK字段或法律公式固定为 Kit 通则。尚未独立核验的原 Chat/Claude review 内容留研究缺口；附带引用占位不可因找到相似网页就写成恢复原引文。尚未取得的实测、合同条款、国内网络数据、完整三国法律适用结论不得进入事实层。

本批不新增运行组件，不声称完成客户隔离、权限引擎、校准服务或真实副作用测试。按 ADR-002，这些实现仍需独立场景和契约证据；本次通用写作约定属于知识治理采纳。

## 结果与修订条件

资料留 vault，采纳的写作约定进 kit，具体五题解法与证据版本仍可更新。上游原生能力变化时可删除多余补丁，保留历史采用依据。用户后续明确正文不含阅读指引、旁白、保护性措辞和实践快照；该要求优先于历史Chat中的写作建议。最终提交答卷前复核影响主结论的易变来源；开始视觉制作时再执行渲染、离线与打印验收。
