# ADR-001 · Knowledge and contracts first

状态：accepted。编订：Astra。日期：2026-09-18。

依据：用户本次要求先架构、目录、README与材料入账；Enterprise原对话区分Build Surface/Product Grammar/Reference Index。

决定：当前仅建设知识与契约repo；不启动应用、不安装参考栈。vault为研究材料单一归档位置，kit为采纳后消费入口，docs保存裁决。

后果：目录与组件名称不能解释成已实现能力；正式demo需另有scenario和运行验证。CW只作为可读研究材料，未读取的治理不可声称已继承。
