# ADR-029 · 书目摘要与可选语法参考

状态：accepted（内容归属、体例与维护机制）；新增语法条目是 normal / reference，未晋升为普遍规范或实现组件。

## 问题与决定

设计与写作已有稳定分支，也有比较、注释、证据和中文成文规则；主要缺口是细部判断没有充分展开，以及来源之间的独特方法不易从任务入口发现。沿用现有树，在相关任务下补充可独立使用的参考，提供两个互通的视角：

- Vault 的来源卡解释作者的术语、论述结构、具体贡献、证据范围与局限，按 URL 保留身份。
- Kit 的问题条目解释何时选用、何时不选、变量与代价，并用原创正反例连接来源。选用仍由任务决定。

来源摘要、可选语法、已采纳指导与实现成熟度分别维护。外部方法相互冲突时保留各自前提；不把英文品牌写作、中文语体、技术标准、个别视觉作品或商业素材混成统一规则。

当前正文只放任务、判断、证据边界与稳定回查路径。版本、取得/复核时间、上游提交、使用轨迹、批次与修订故事放独立 CHANGELOG 或验收记录。不可变历史原件不改写，正文去除历史叙事后的旧状态由 Git 基线与既有回执保留。

## 发现与维护

来源作者、任务、媒介、操作、行业语境、技术栈与风格是可选分面，交叉指向同一张卡。证据、权利、采纳与实现状态独立；字段允许未标注、未知、不适用与多值，推断不能冒充来源明示。保留历史 registry ID，以 alias 解析来源自有 ID，不为统一命名迁移全库。

只有具体发现失败或反复语义歧义证明目录不足时才改结构。合并真正同义的条目，保留旧 ID/路径的 redirect；前提不同或互相冲突的条目继续并存。消费日志是可选的轻量反馈，不要求每项小任务记录，不以固定次数自动晋升。

## 影响与验证

修订现有 [文档体例](../architecture/documentation.md)、[入账](../governance/intake.md)、[参考生命周期](../governance/reference-lifecycle.md)与[增量机制](../governance/evolution.md)，没有新建第二套维护规范。普通使用者仍从 [Kit](../../kit/README.md)进入，不预读治理。

本决定承接 ADR-015、ADR-017、ADR-018、ADR-022 的分层与单点维护；替代其中要求在普通卡片内保留验收日期或连续消费日志的做法，不改变历史验收结论。分工、时间、基线、范围、独立任务与实际检查见 [变更和验收记录](../verification/design-writing-encyclopedia-20261011/README.md)。
