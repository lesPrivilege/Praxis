# ADR-023：按产物的组成部分取用 Write 与 Design

日期：2026-10-03。状态：accepted（入口措辞与 skill 触发条件）。用户要求修订入口，让 agent 能自己发现并取用 Write 和 Design 的参考；Opus 5.5 主会话找原因、改入口，两个 Sonnet 5.5 只读代理做改前改后的对照走读。Luna 在本会话不可用。改动没有提交。

## 问题

2026-10-03 主会话按一份设计交接做 [Palantir 首次设计打样](../../demos/palantir-discovery/README.md)，一页中文交互网页。它从 Kit 任务入口进了 Design，页面文字没有经过 Write / Prose 的成文原理和审阅方法，Design 的参考卡也一张没读。用户读页面时觉得文案别扭，追问 Write 是否完成消费。

沿主会话实际的阅读路径找到四个原因：

1. [Kit 任务入口](../../kit/README.md)按请求的叫法分到一支。“设计打样”落在 Design 那一行，入口没有说一件产物可能要过几支。
2. [Design 入口](../../kit/design/README.md)写着“图表和界面任务可以直接从这里开始，不必先过 Write”，没有把页面上写给读者的文字排除在外。
3. 项目 skill `writing` 只在用户明确要求撰写时触发，网页里的文字不在触发范围内。
4. 唯一写着“撰写对外中文成文时从 Prose 读规则”的一句在 [Kit 使用指引](../../kit/Agent.md)第 5 步。按 [ADR-019](019-expression-owners-and-entry-paths.md)，做任务时不预读这一页。

Design 参考卡的情形相同：窄屏比较、注释邻接等触发条件写在 [参考路由](../../kit/design/references/README.md)和 Publish 入口里，从 Design 入口进来的人看不到。

## 决定

1. Kit 任务入口加一段：按产物的组成部分取用，不按请求的叫法。写给读者的成句文字，包括正文、图注、页面说明、界面标签、按钮和状态提示，按 Prose 写、按审阅方法查；阅读顺序和展项过 Publish；视觉、交互和运动过 Design。交互网页和带图的报告通常三支都用到。
2. Design 入口的“不必先过 Write”改为“不必先走 Write 的成文流程”，并写明产物上写给读者的文字仍按 Prose 写和审。同一页加一张“先读哪张参考”的表，列出五种情形：窄屏比较、局部注释、风格名、界面控件与状态、关系图与页面节奏。
3. [媒介验收](../../kit/write/shared/verification.md)的审阅顺序后加一句交付前的分工核对：文字、编排、视觉三部分各自经过了维护它的分支，没有经过的回去补，或写明不需要的理由。
4. [成文原理](../../kit/write/prose/grammar.md)第 5 条的结构位置加上图例、界面按钮和状态提示。
5. `writing` skill 的触发条件加一种情形：任务产物里有写给读者的中文文字时加载，只用于这部分文字。

根 `AGENTS.md` 和 `kit/Agent.md` 没有改。前者是用户指定的分工，后者是维护路径。

## 对照走读

改动前写下预期，再派两个 Sonnet 5.5 只读代理。两边拿同一份交接和同一段任务说明，只是仓库不同：一份是 `b76ece4` 的导出，另一份是同一导出加上面五处改动。代理只报告实际打开的文件和打算取用的文件。

| | 改前 | 改后 |
|---|---|---|
| 成文原理 | 打开 | 打开 |
| 审阅方法 | 只看到名字，没有打开 | 打开 |
| 展项与说明 | 只看到名字，没有打开 | 打开 |
| Design 参考 | 两张优先卡只看到名字，没有打开；界面参考、编排参考没有提到 | 两张优先卡、界面参考 U01–U09、编排参考 C01–C25 都打开 |
| 打开的仓库文件 | 18 个 | 25 个 |

改前的代理也读到了成文原理，原因可能是任务说明的第三问点名了“页面上的中文文字”，这对它是一种提示。主会话在真实任务里没有这个提示，也就没有读到。所以这次对照能支持的只是：改后的入口让 Design 参考和审阅方法从名字变成了被打开的文件。它不能证明改动改善了写出来的文字。每边只走了一次，没有留出任务。代价是多读了 7 个文件。`writing` skill 的新触发条件没有测：代理看不到 skill 列表。

## 与 ADR-024 的关系

同一天另一条分支 `codex/writing-review-20261003`（`7488f02`）按 [ADR-024](024-prose-defaults-and-review-scope.md)收窄了成文默认和审阅范围，也改了 `writing` skill 和成文原理第 5 条。两处在整合时逐段合成：skill 的描述采用 ADR-024 的写法和排除范围，再加上本决定的产物文字；第 5 条采用 ADR-024 的“按用途选名词短语或完整陈述”，结构位置的列举加上图例、按钮和状态提示。其余规则以 ADR-024 为准。

## 没有做的

- 没有加自动检查。分工核对靠交付前的那一句。
- 没有让代理真的写出页面再比较文字质量。
- 根 `AGENTS.md` 的任务路径一句没有改，因为 Kit 任务入口是它指向的第一站。

## 什么情况下重访

又有一件产物的文字或参考在交付时被发现漏了分支；改后入口让小任务读得过多，比如改一句话也去读三支；或者 skill 的新触发条件在日常对话里被误加载。
