# ADR-035：每节先给局部答案；链接写明关系

日期：2026-10-15。状态：accepted（用户裁决）。主会话（Claude Opus 5.5）提炼并编订；SaaS 书的试用由六名 Opus 编辑按文件分工完成，主会话复核。

## 问题与依据

用户交来一份《知识组织与解释性写作规范》（[快照](../../vault/snapshots/local/knowledge-organization-spec-20261015/knowledge-organization-spec.md)），评语是：“gpt 文笔不足采，但或许有些结构方面的理念可以进入本轮 artifact 或 distill 进入 kit。”主会话按它的“只读标题与各节首段”检查抽看 SaaS 书四页：章首大多成立；节首不一定先给答案，有的直接是表格，有的是一句免责；方法第 4 章的开头列了几个问题，没有交代几种方法各管什么。书中不少交叉链接只写“见 V04”。取舍全文见 [提炼记录](../../vault/distilled/technical-compilation-writing-research-20261014/knowledge-organization-spec-20261015.md)。

## 决定

- **局部答案。** [讲解页的编排](../../dsh-praxis/kit/publish/html/explainer.md)“章”一层补写：章下的每节同样先说这一节支持的判断，再给表格、列表或推演。“结论”一层补写验收：只读这一层，也能说出对象、核心关系、主要分支和改变判断的条件。强度：可选参考，与该页相同。
- **两种反模式。** [审阅方法](../../dsh-praxis/kit/writing/review.md)的问题类别加“目录冒充概览”“摘要逐级稀释”，偏差表各加一行；前者的检查是只读标题与各节首段，看能否拼出概览。
- **链接写明关系。** [内容编排](../../dsh-praxis/kit/publish/html/composition.md)“从原稿到页面”补一句：交叉链接旁写明与此处的关系（需先理解、此处的特例、同一问题换了条件），单独的“另见”不说明为什么要去。

## 没有进入的

练习导向的“先作答，再对照”与学习测试，和用户“wiki 而非教辅”的裁定相反；四种深度的固定分层、评分表与模板，Kit 已有分层，评分表没有使用证据；分类、论证与源流分开，对思想史材料有用，工程教材暂无需要。原件的文字不取：它的自我限定与来路说明正是 [ADR-034](034-state-limits-once-and-keep-process-out.md) 删去的写法。

## 与既有决定的关系

细化 ADR-031 的讲解页分层，扩展 ADR-027 与 ADR-034 的审阅问题类别，不改变强度。使用证据是一部教材的一轮编订，没有对照组和真人读者；另一类材料上局部答案显得重复时重访。
