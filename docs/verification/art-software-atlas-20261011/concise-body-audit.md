# 挂载正文审校

## 依据与范围

按用户的渐进阅读要求，审校本批 9 个 Kit 页面。读取项目 Writing skill、中文成文原理、证据契约、审阅方法和文档结构契约；遵循「每个成分承重」「证据强度不变」「说完即止」。仓库提到的 ASD-STE100 是尚未核实全文的受控英文外部参考，本批不自行扩写其规则，也不声称符合该标准。

正文保留概念与原语境、关键区别、可调关系、实现取舍、例子和反例。只保留会影响选用的局部条件，如屏幕示意与现场感知、模型假说与历史制作、开放演奏与未说明事项的区别。

## 调整与归属

| 页面组 | 正文调整 | 完整信息的现有位置 |
|---|---|---|
| 材料 / 空间 | 合并重复的等价性警告、访问失败和研究过程；保留对象差异、建构条件与实例 | material / spatial 的来源卡、catalog 与 CHANGELOG |
| 编辑 / 时间 / 规则 | 缩短重复来源状态与运行清单；保留 Isotype 协作、计量关系、JLReq 限制、Brown 条件、规则与随机区别 | editorial / temporal 的逐源卡与回执 |
| 范围选择 | 从正文移出浏览器/远端访问叙述；用状态例子解释 null、合法空集和反向区间 | brush-probe.md、brush-results.json 与来源卡 |
| agent 资源 | 用资源职责、实现表和两项构造例组织正文；移出重复账号/运行验收说明 | ecosystem 来源卡与 entities/index；具体复制或写入前仍保留必要条件 |
| 操作入口 / 来源接力 | 去掉重复的注册状态和创意权限声明；保留任务入口与下一产物 | atlas 索引、来源书目和交付记录 |

没有为单句另建档案，没有删除来源卡或重写旧快照。所有旧的逐源卡链接和 12 个叶子锚点保留。新 facet 说明在研究索引目录，维护与验证活动在本目录，不回灌到各条目的开场。

## 不可损失项复核

- 原物名称、对象号、作者/协作者、原术语与有争议的历史解释保留。
- 未看图的作品没有变成视觉观察；两幅 JLReq 图与原创 D3 探针的检查身份不变。
- Brown 的直接演出条件与现代事件表的区分保留。独立审阅发现一次把「未说明」改成「开放」的回归，已改回未知，并限定只有明确交给演奏者的部分才开放。
- source URL、ID、逐项主张和卡片正文未改；所有关系与已有 facet 值保留。
- 各深条目仍有操作、实现选择、构造例/具体对象与失效方式；缩短文字不作为设计效果改善的证据。

字符数只作篇幅记录，不是文风合格的机械门槛；逐页读者作用和证据身份由人工复核。统计与链接/锚点检查随 [补正验证](facet-validation.json)保存。
