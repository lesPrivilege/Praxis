# 发现与消费 · 薄记录

## 2026-10-11 · 新上下文试用

三个 agent 均以 `fork_turns=none` 启动，只给正常任务、工作目录和遵循 AGENTS 的要求；未给新卡片名称或定位。试用产物是设计决策 memo，非用户实验。没有无 Kit 对照，不能归因有效性或节省注意力；以下只记录实际找到、取舍和输出变化。

| 任务 | 实际路线与消费 | 产物中的改变 | 失败/代价与跟进 |
|---|---|---|---|
| 纺织展网页要有交错手工秩序，数百件还需比较 | Kit → Design → References → 新操作入口 → 材料条目；读 ASA-M-01–03、既有比较卡、ASA-G-EXTENT | 提出连续索引和分区接续两种现代假设；把目录筛选与小集合比较分开；拒绝挪用另一传统当“手工感” | 18 个文件；读入同文件伊斯兰分支但明确拒绝。路由现加经纬锚点与停止说明；没有改变分类或拆页 |
| 品牌规则与组件怎样让 coding agent 找到；Open Design 名称不确定 | Kit → Design → References → systems → 新入口 → agent 资源条目及九张新卡、D01 | 区分两候选项目与五种资源角色；建议先本地包，再决定 registry / MCP；保留未测试权限/效果边界 | 19 个文件；systems 对具体项目身份绕路，补上精确入口；memo 一处称核心候选“likely”，应改为“文档较充分的研究候选”，不能推定用户所指 |
| 科学展触屏要像呼吸与有停顿的乐段，又能随时比较（留出任务） | Kit → Design → Interaction/Motion → 既有运动语法 → 范围受控关键词搜索 → score 条目、ASA-T-10/09、反馈 | 提出可暂停事件谱与固定比较台；只有时序承担意义才加引导段；声音和动画可独立放弃 | 读取约 18 步，部分为片段；初始 find 越界到系统目录报权限错误，未读额外内容，记录为执行失败。声音入口仍依赖搜索，未把此结果说成无摩擦发现 |

公开产物的概括：纺织试用拒绝把离散经纬结构泛化为所有藏品；生态试用拒绝从文件名推断执行权限；留出试用拒绝从“呼吸”形容词推断数据变化或声音映射。这些是三次可见决策，不证明实际设计效果、社群认同或运行能力。

维护走读另外计：根代理执行源身份/双向链接/分面/类型验证，并查看两个 JLReq 源图与两张原创合成输出；这不冒充新的消费 agent。详细文件读序由 [试用回执](discovery-trials.md)保留。后续实际项目需用自己的数据、读者和设备检验，保留采用/调整/拒绝决定。
