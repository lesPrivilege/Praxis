## 内置浏览器门槛

用户明确要求内置浏览器。CUA运行环境已恢复；访问本地file://答卷被Browser Use URL安全策略拒绝。按策略停止该动作，不用外部Chrome、原始CDP、间接执行或其他表面绕过。等待允许访问的预览入口。

先前真实外部Chrome的键盘导航和窗口截图只作辅助记录，不作为最终内置浏览器交互通过证据。被权限框遮挡、地址输入受IME影响、错误页面或误捕其他应用的截图已拒绝或删除。可见标题修订不是完整UI验收。

采纳用户对“字体层级不能代替论证层级”的诊断。将5个总问题、18个子问题及即时答案落实到母稿与生成页面，推导、支持与动作条件记录在[问题—答案树](../../../vault/distilled/ai-capability-assessment/argument-tree.md)。Q2计时改为统一请求起点，初始目标单表；Q3参数错误不获得无条件重试许可；Q5记录图明确支持生效判断。Question→Answer→Why→Evidence→Rule作为核对框架，不固定为五个可见栏目。
