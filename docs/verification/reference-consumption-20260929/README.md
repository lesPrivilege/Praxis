# 无材料提示的自然发现与消费证据

这些产物只验证Praxis的目录与文档安排能否让fresh agent自然找到、判断和取用既有素材，及反馈能否回到唯一维护位置；不是产品交付、作品库或新Kit规范。

- `opening-comparison/`：同题复用观察。初始agent借助了既有同题验收记录；源卡机制误读由main指出后修正。不能把修正版全部记作无提示成功。
- `survey-explainer/`：不同题材的发现观察。任务未点名材料，agent找到Q06-d、V06及W03并取用；对另一张不适用卡的过度归因经main纠正。
- `device-comparison/`：文档反馈后新的独立上下文，只生成小型布局样例与消费trace，验证明确写回参考卡的区别能否被正常发现并使用；不再制作HTML。

完整任务设置、初始入口hash、人工提示范围和结果见 [收尾机器回执](../visual-grammar-20260928-result.json) 与 [说明](../visual-grammar-20260928.md)。这些是有界样本，不证明任何模型、任务都必然正确取用，更不把视觉精美当作结构验收。

测试工件最初在独占临时demo目录生成；收尾归到本目录保存。导航trace保留实际发生的读取顺序，产物的保留位置另行登记。来源材料留原位置，未复制整库。
