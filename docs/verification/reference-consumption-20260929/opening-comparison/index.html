核心判断

C 的“7 天”不能脱离周末志愿者条件来读。

条件成立时，C 才能算作每天有人开门。

为什么：“7 天”只说明计划覆盖的天数，不等于每一天都已有开门人。C 把周末交给志愿者；只要周末志愿者缺席，周六或周日就会没有人开门，原来的“每天”判断随之失效。

  • A直接成立：7 天且没有附加条件。
  • B直接不成立：5 天少于七天。
  • C先查条件：周末志愿者到位才成立。

02 · Synthetic fixture

把 C 的条件代入一周

两个 fixture 使用同一套方案和金额，只改变一个事实：周末有没有志愿者。这样可以看到条件如何改变结论。

周末有志愿者

失败 fixture · weekend volunteers = false

反例：周末没有志愿者

周六、周日没有志愿者，C 的计划条件没有满足。成本仍写作 1500，但不能把这周算成七天有人开门。

缺口就在“每天”这个词里：

  1. 周一有人
  2. 周二有人
  3. 周三有人
  4. 周四有人
  5. 周五有人
  6. 周六关闭
  7. 周日关闭

结果：C 不满足“每天有人开门”；这是条件失败造成的反例。
