# 便携设备比较布局样例

读者需按同一属性比较三台设备，宽屏用“属性为行、设备为列”的短表，列序固定甲、乙、丙，数值和单位同格对齐。375px 不横向滚动：每个属性成为小组，先写属性名，再按“甲 / 乙 / 丙”三行写值；组间留白，滚动仍可对照。首屏直接给表，结论不替读者排序。

宽屏强调横向同属性，窄屏强调纵向同属性，标签和单位保持一致。
