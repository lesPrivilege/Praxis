# Design / Write 参考编订验收

这是维护记录，不是做 Design 或 Write 任务的必读材料。当前正文仍从 [Design](../../../dsh-praxis/kit/design/README.md) 或 [Write](../../../dsh-praxis/kit/README.md)进入；按作者、书目与主题找来源，从 [书目入口](../../../vault/provenance/design-writing-encyclopedia/README.md)进入。

- [变更记录](CHANGELOG.md)：基线、所有权、分工、来源与正文修订、整合和交付状态。
- [正文历史定位](body-history.md)：移出活跃正文的日期与消费叙事到既有证据的定位；历史原件不改。
- [独立任务消费记录](consumption.md)：任务、真实查找路线、取用裁决与发现性缺口。
- [校验与编订复核](verification.md)：实际运行的检查、修复和范围。

走读只说明对应合成任务的发现与判断表现，没有受众效果、交互实现或无障碍合规的普遍结论。
