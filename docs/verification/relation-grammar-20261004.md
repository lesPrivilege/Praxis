## 冷读与对照

两个任务，各用一份没有用来调过样板的合成内容。每个任务跑两份：一份从根 `AGENTS.md` 进仓库、自己找指引；一份不读仓库，只看任务。四个都是 Claude Sonnet 子代理，互不相见。任务书没有点页面名字，只要求报告打开过的文件和每条做法的出处。截图在 [evidence](../../demos/editable-native-svg/grammar-specimens/evidence/README.md)。

| 任务 | 读了 Kit 的一份 | 对照 |
|---|---|---|
| 一：把六条采购记录做成一页，让人看出哪些定了、没定、被否、等人决定 | 经 Design README 的“先读”表找到两页。“出自”和“成立程度”分成两栏；左边线只回答生效没有；蓝色只在“等人拿主意”一处；图例由数据生成；依据写不出身份的标“未定位” | 四种状态四种颜色，各带一个符号和词；虚线同时表示“无人批准”和“没有书面依据”，图例里也这样写；没有“谁说的”一栏 |
| 二：说明三条说法各靠哪份文件的哪一版、哪一处，看出有没有靠旧版本的 | 找到两页。出处分成对象、版本、位置三栏，缺版本的写“无版本号”，口头确认标“未定位”；每条说法画在它所指的版本下面；把“由课件间接靠旧版本”标为推断 | 同样把出处分成文件、版本、位置三栏，缺的写“无”；同样指出只有 A 靠旧版本；卡片更短，结论更靠前 |

能说的只有这些。任务一里两份的差别与页面的规则对得上，但每边只有一份，不能说差别来自页面。任务二里对照组自己就写出了三栏，页面带来的是次要的区别；对照的那一页读起来反而更快。两份读了 Kit 的产出都比对照长，这是代价。

冷读指出、已经补进页面的缺口：指向经过第三份文件接力时怎么写；有位置没有版本、有版本没有位置各叫什么；按“已定、未定”分组之后，组内不同的事又并成一种画法（两份任务一的产出都有这个倾向）。指出而没有处理的：页面没有给整页的字体和配色；Kit 没有检查产出页面的工具；“过期”还没有对应的取值。

## 没有做的

- 没有读者或专业人员看过样板和两页条目，“提高”的部分只有制作者自己的判断。
- 第二轮复查之后的修改没有再复查。
- 冷读只有两个任务、每边一份，产出没有在浏览器里交互检查，子代理自己也没有渲染过。
- 编辑器往返、读屏、Safari 与 Firefox、A4 打印仍然没有做，与第一批相同。
- “有没有这个值”一类的值状态、时间范围和字段集合的指向没有处理。
- 两份清点报告的全文没有入库。
