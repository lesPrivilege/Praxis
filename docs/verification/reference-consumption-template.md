# 参考消费的薄记录模板

需要反馈发现断点、误用或实际增量时使用；不是每项任务必填的流程。将填好的记录放在消费者自己的变更或验收记录中，普通来源卡和挂载 grammar 只链接它。维护规则见 [参考生命周期](../governance/reference-lifecycle.md)。

| 项目 | 记录 |
|---|---|
| 任务与产物 | 正常任务提示或简述；产物路径 |
| 参考 ID | 实际发现与消费的稳定 ID；必要时附发现路径 |
| 取舍 | adopt / adapt / reject（采用 / 改写 / 拒绝）及理由 |
| 判断或输出变化 | 哪项判断、结构或内容因参考而变化；没有变化也如实记录 |
| 遗漏或过度读取 | 预期未找到的资料、无关读取、误用或证据缺口；没有则省略 |
| 缺口跟进 | 修入口、补摘要或证据、修 grammar、复核或暂不处理及理由 |

需要复现时，在这份独立记录中附执行时间、Kit commit 或版本、实际执行角色及验证范围。不要把这些历史信息回填普通卡片。区分维护走读与新 agent 上下文中的实际任务试用；独立发现试用不给出卡片名或路径提示。记录一次消费只能支持这次观察；效果归因、实现行为与跨任务泛化各需相应证据。
