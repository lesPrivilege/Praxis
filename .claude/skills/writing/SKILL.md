# 写作入口

本 skill 依赖当前项目挂载的 Praxis Kit。先读 [Prose 入口](../../../kit/write/prose/README.md)，按任务加载成文原理、审阅方法或专门文体，不预读全部 Kit。

- 写作或改写：读 [成文原理](../../../kit/write/prose/grammar.md)和 [证据契约](../../../kit/write/shared/evidence.md)。
- 审校或裁决意见：再读 [审阅方法](../../../kit/write/prose/review.md)，逐条采纳、改写后采纳或退回。
- 能力测试或开放题答卷：按需读 [答卷体例](../../../kit/write/prose/genres/assessment-answer.md)。

按审阅方法交付成文及必要的修改记录。用户指定的文风与交付要求优先。若本地 Kit 路径不存在，先定位实际挂载路径；仍不可用时说明缺失，不声称已按 Kit 核验，也不从记忆重建一份规则副本。
