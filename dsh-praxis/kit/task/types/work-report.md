# 工作报告

推进中的工作向相关人交代状态：现场试点、交付进展、移交前后。对应 [材料目的与组织动作](../brief.md)里“推进工作”一行。

| 项 | 内容 |
|---|---|
| 读者 | 要据此决定资源、排期或接收的人：sponsor、业务 owner、接收方 |
| 结果 | 读者知道现在在哪、变了什么、卡在哪、谁负责什么、下一步是什么，以及要他批准、选择或执行什么 |
| 默认流水线 | html（网页或打印成 PDF） |
| Writing | [底线](../../writing/evidence.md)、[读者与任务](../../writing/organization/audience.md)、[论证与证据链](../../writing/organization/argument.md) |
| Design | [成立程度与归属的标记](../../design/foundations/standing.md)：已定、未定、被否和等人拿主意的事项放在一起时；[排列与刻度](../../design/foundations/placement.md)：版本、事件和阶段排成一条线时 |
| Publish | html：[内容编排](../../publish/html/composition.md)、[展项与说明](../../publish/html/exhibits.md) |
| 素材 | 本期的事实来源：会议记录、提交、验收回执、指标口径；上一期报告 |

## 验收

- 状态、变更、阻塞、owner、下一步五项都有，缺的写明原因。
- 事实、假设和已验证结果分开标出；与上一期口径不同的地方写明。
- Ask 写在读者第一眼能看到的位置；不需要对方做什么时也写明。
- 处在 [现场闭环](../field-loop.md)哪一段、下一决定由谁做，写得出来。
