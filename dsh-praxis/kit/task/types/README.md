# 任务类型

一种任务类型写明读者、要促成的结果、默认流水线、要读的 Writing 与 Design 单元、素材从哪里取和验收；字段见 [task-type 草案](../../../schemas/task-type.schema.json)。没有匹配的类型时按 [brief](../brief.md)现写。

| 类型 | 什么时候用 | 默认流水线 |
|---|---|---|
| [技术说明](technical-explainer.md) | 向不读原件的人讲清一个系统、项目或机制 | html，可另出 video |
| [工作报告](work-report.md) | 推进中的工作：当前状态、变更、阻塞、责任与下一步 | html |

一件任务兼有两类时，按读者读完主要要做的事选一类，另一类的要求写进本次 brief。方案比较、操作指南等类型在第一次真实任务时写，不预建空页。类型页里列出的单元按表照读；所依据的做法各有来路（见各页），类型页本身还没有在真实任务里取用过。
