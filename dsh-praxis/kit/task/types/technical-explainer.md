# 技术说明

向不读原件的读者讲清一个系统、项目或机制。读者懂这个领域，但不会去读源码、文档和配置。

| 项 | 内容 |
|---|---|
| 结果 | 读完能说出对象、核心关系、主要分支和改变判断的条件，并据此判断是否采用或怎样接入 |
| 默认流水线 | html；要在会上讲或做成片时另出 video，共用事实底稿 |
| Writing | [底线](../../writing/evidence.md)、[机制讲解](../../writing/organization/mechanism.md)、[论证与证据链](../../writing/organization/argument.md)；video 另加 [口播旁白](../../writing/genres/narration.md) |
| Design | [构成关系](../../design/foundations/relations.md)、[精确指向](../../design/foundations/anchoring.md)；html 页面要折叠、分页或站内跳转时另加 [导航与渐进披露](../../design/interaction/navigation.md)，video 另加 [运动判断](../../design/motion/grammar.md) |
| Publish | html：[讲解页的编排](../../publish/html/explainer.md)、[展项与说明](../../publish/html/exhibits.md)；video：[叙事与分镜交接](../../publish/video/narrative.md) |
| 素材 | 被讲解对象的来源条目与摘录，固定在一个版本；画面可用的图片与截图 |

## 验收

- 只读结论层也能说出对象、核心关系、主要分支和改变判断的条件。
- 每个局部答得出机制讲解的四问，答不出的写“未核实”。
- 每条事实说法能回到事实底稿里的来源与版本。
- 所走流水线的检查通过。
