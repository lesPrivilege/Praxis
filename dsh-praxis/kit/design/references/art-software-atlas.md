# 从艺术与设计实践发现软件操作

需要跳出惯用组件或风格名时，从一句意图选路，比较可调操作、实现选择与反例。原生应用、终端、游戏、空间界面及跨平台反馈问题，先查 [软件交互范围](../../../../vault/provenance/art-software-atlas/software-scope.md)。

| 当前意图 | 先读 | 可以形成的最小产物 |
|---|---|---|
| “想有织物或手工感，但不想只贴纹理” | [材料构造](../composition/material-relations.md#asa-g-andean-woven-garments) | 把交错、重复与材料约束分开的试件 |
| “信息要像一张能读懂的图，换语言也成立” | [编辑转译](../composition/editorial-translations.md) | 计量单位、文字方向、阅读顺序的对照 |
| “空间安静、有光和深度，仍看得清内容” | [空间与材料](../composition/spatial-materials.md) | 光源、视点、表面与信息层的变量表 |
| “有节奏、停顿或声音，观众还能控制” | [乐谱与时间](../motion/score-and-time.md) | 事件、时长、触发与观众控制的时间契约 |
| “重复中要有变化，能解释为什么这样变” | [规则系统](../motion/rule-systems.md) | 规则、参数、随机种子与拒绝条件 |
| “框选一些对象，又不丢掉全局” | [范围选择](../interaction/extent-selection.md) | 范围、选集、可见集与替代输入状态表 |
| “不知道名称，想从实验和作品找到方向” | [来源接力](discovery-relay.md) | 集合 → 单件 → 原意 → 两种机制及反例 |
| “设计系统怎样供 agent 使用；Open Design 是哪一个” | [设计资源生态](agent-design-resources.md) | 候选身份、资源分类、接口与权限边界 |
