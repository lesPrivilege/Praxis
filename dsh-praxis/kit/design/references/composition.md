# 内容与数据可视化编排参考

组织内容、关系、数据图和页面节奏时，从既有图形、导航、动效与版式样本中借机制，配色、字体和动效参数留在各自项目。

返回 [Design 参考路由](README.md)。

关系图与数据图借的是线型、箭头与状态的语法，直接标值、区分缺失与零值、按数据语义选图式，以及下一层增加信息而不重复的分层；先辨认问题、机制、数据和交付，再选表达，图注说明主张。单个图形快照不是通用 renderer，一条数据约定也不能泛化为所有数量图必须零起点或用同一种 chart。

导航与披露可取原生 `details` 目录、无 JS 基本可读、窄屏章节纵向排列、条目数与当前所在的位置提示，以及展开控件的语义、键盘和焦点路径；小节少时不强加吸附侧栏。反例是窄屏隐藏章节导航却没有替代，或标签栏由 JS 生成、横向滚动成为唯一路径。用户触发的非必要动效要有关闭路径；文字放大、重排和调整文字间距时不以固定高度裁切。

动效先判断该不该动、为何动，再定属性与曲线；排印借具名字号档位、基线表格和数字右对齐，不用嵌套框或装饰渐变补层级。一次性页面里的单个反馈机制（如阅读进度线）可以单独借走，该页的配色、字体和滚动动效留在它自己的 profile。模板化大标题、紫蓝渐变、玻璃拟态和渐变光晕作为反模式识别。

## 维护

项目使用这些参考后，在自己的 index 写下来源版本、调整理由、验证和重访条件。
