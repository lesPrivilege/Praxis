# 精确指向

证据、条件、审核或注释要挂在别的东西上时，写清它指向哪个对象、哪一版、哪一处，并让这个指向在内容重排和版本更新之后仍然找得到。

例如一条证据支持哪项主张，一个条件限定哪几个字，一次审核依据哪一版规则，一条注释解释哪个数。内容上的要求在 [共同工作语法](../../../../kit/grammar/work.md)：证据“定位到版本与片段”，批准“绑定对象、版本、动作和范围”。

## 一条指向的四个部分

| 部分 | 含义 | 例 |
|---|---|---|
| 指向者 | 发出指向的一方 | 一条证据、一个条件、一条注释、一次审核 |
| 对象 | 被指的东西 | 借阅规则；调阅单 D-12；第二项主张 |
| 版本 | 对象的版本 | v3 |
| 范围 | 版本里的位置 | 第 8 条；“两个工作日”这几个字；相邻的两项主张 |

范围有粗细：整个对象，一个版本，版本里的一个位置（条、节、字段、行），原文里的几个字，相邻的几项。能细到哪里就写到哪里，写不到的那一层照实空着，并写明缺的是哪一层：有位置没有版本的写“缺版本”，有版本没有位置的写“只到版本”，连对象都说不出的写“未定位”。口头说法属于最后一种。

W3C 的 Web Annotation 模型用的是同一种分法：target 是被指的资源，State 说明是哪个版本，Selector 说明是哪一段，与这里的“对象、版本、范围”一一对应。

## 换什么写法都要守住的

1. 对象、版本、范围分开写。缺版本的指向不能写成“已核对”。
2. 写不出身份、只有一句话的依据，标明“未定位”。它可以留在图上，但读者要看得出它回查不到。
3. 位置相邻是呈现方式，不是指向本身。注释挨着某句话，是因为它指向那句话；内容重排之后，指向还在，相邻可以重新安排。只靠相邻、没有写下指向的，重排一次就丢了。
4. 指向落不到任何已知的对象或版本时，拒绝画，或者明说它指向图外。不悄悄接到最近的一个上。
5. 限定原文里的几个字时，这几个字要能在原文里唯一找到。找不到或不止一处，拒绝，不退成限定整句。
6. 对象出了新版本，旧指向不跟着走。绑定在 v1 上的阅读记录仍然绑定 v1；要它指向 v2，得有人重新读过。
7. 整体适用的说明不硬绑到某一个词上，单独放。
8. 指向可以接力，每一段各写各的。“培训覆盖了离心机安全”指向签到表，培训的课件又是按手册 v4 编的；这是两条指向，不合并成“培训依据手册 v4”。由接力推出来的结论是推断，照推断标。

## 默认写法

给读者看的写成“对象 版本 位置”，例如“借阅规则 v3 第 8 条”；给程序用的写成 `id@version#locator`，例如 `rule-loan@3#第 8 条`。两种是同一个指向的两个面，由同一份输入生成，不各写各的。为了让后一种写法拆得开，id 里不用 `@`、`#` 和空白；版本是一个数或以数字开头的版本号，“最新版”这类说法不算版本。

图里的默认：

- 限定一项或相邻几项时，括线量的是被限定的内容，引线从括线接到限定语。括线不去量限定语自己。
- 限定几个字时，那几个字在原文里加下划线，并在限定语的标题里把它们引出来。
- 判断绑定版本时，判断画在它所绑的那个版本下面。
- 几张图连在一起、一处写到的“对象 版本”正好画在另一张里时，两处之间连一条比内容浅的线，主干走在内容之外。连线只是文字指向的重复，去掉它，指向仍然完整。

括线画在哪一侧、引线的折法、下划线还是底色，都是风格取舍。

## 三级做法

1. 只用文字。每句话后面跟一个指向，写成“对象 版本 位置”；回查不到的写“未定位”。
2. 一张图。括线、下划线和引线把指向重复成画法。
3. 几张图连成一张。同一个对象在各处用同一个名字，版本和位置用同一种写法，读者可以用眼睛对上；画得出来时再连线。

[样板](../../../../demos/editable-native-svg/grammar-specimens/index.html)用同一份内容把三级各做了一遍，第三级里“审核通过”连到规则 v2，别处都指着 v3，审核依据的是旧版这件事不用另写一句。

## 正例与最容易犯的错

正例：“审核通过。依据：借阅规则 v2 第 8 条。”规则到了 v3，这条指向落在旧版本上，需要重新审核一望即知。

反例一：“审核通过。依据：借阅规则。”规则更新之后这句话读起来照样成立，过期无从发现。

反例二：括线围住了条件那一块，被限定的是哪一句只靠标签“A 的条件”说明。条件一长，括线跨到旁边的句子上，读者以为两句都受限定。原子编排实验的 T05-c 就是这样失败的。

反例三：材料出了新版本，界面把“已阅读”的标记和旧说明一起挪到了新版本上。没有人读过新版本，记录却说读过。

反例四：一条说明适用于整张表，却画成指向表里某一个数。

## 最小产物与何时停

最小产物是第一级：每句话后面一个写清楚的指向。只有一个对象、一个版本、没有人会弄混的时候，到此为止。

需要退回内容的情形：写指向时发现说不出是哪个版本、哪一处。这是来源没有核对到位，不是画法的问题。

需要升级的情形：同一句话上叠了三层以上的限定范围，或者被别处指到的对象太多、连线互相交叉。先拆内容，或者只保留文字指向。
