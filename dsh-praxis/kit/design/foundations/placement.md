# 排列与刻度

把几项内容沿一条线排开时读本页：步骤、版本、事件、层级、前后对照、分栏的清单。它回答两件事：位置在说什么；并排的几条线能不能互相比。产物是每一项自己带着的位置词，以及在需要时与它对应的排法和一句写在图里的读法。

本页给问题、约束和一套默认，不给间距和尺寸。数量怎样映射成长度见 [图形编码](../composition/encoding.md)，窄屏下怎样保住几个对象之间的比较见 [按属性维持比较](../references/curated/comparison-continuity.md)，一句话指向谁见 [精确指向](anchoring.md)。这里只管内容排成一条线之后，位置本身被读成什么。

## 位置回答的四个问题

读者不等说明就会从位置读出东西。五个步骤等距排开，会被读成五段一样长的时间；两条线并排，同一高度的两点会被读成同时。动手之前先分清位置要回答哪几个问题，其余的要明说不表示。

| 问题 | 位置上的做法 | 常见的回答 |
|---|---|---|
| 谁先谁后 | 沿线的次序 | 第几步；在某一版之后；次序没有含义 |
| 隔了多久、差多少 | 沿线的距离 | 四十分钟；两个工作日；不知道 |
| 属于谁 | 缩进，或者分栏 | 隶属于某个部门；包含在某一类里；归某个角色 |
| 是不是同一个 | 同一行，或者同一高度 | 同一个字段的两个值；同一时刻的两件事 |

一条线可以只回答第一个问题，也可以同时回答前两个。只回答第一个时，距离不表示什么，这一点要写出来。

## 换什么排法都要守住的

1. 每一项自己带着位置词：第几、什么时刻、上级是谁、对应哪一项。线、间距和缩进只是这些词的重复；内容改排成表格或正文，位置不丢。图里已经由读法交代的位置（例如缩进表示隶属），不必在每一行重复上级的名字，等效文字里要有。
2. 位置回答了哪几个问题，写成一句读法放进图里。读者会顺手读出、图却不表示的，也写一句“不表示”。读法由生成这张图的同一份输入得出，只写图里出现的情形。
3. 距离要表示长短，先得有量：同一种单位，确切的起止。只知道先后，时长是约数，一项按分钟、另一项按工作日，或者有一项未知时，不按比例画；改成只表示先后，把知道的时间写成字。
4. 按比例画时写明每格多长、按哪个时区。时刻、区间、截止是三种东西，形状分开，各自写成词；区间不画成点。两个时刻之间量出来的间隔不是一段持续的事，用离开标尺的括线或者直接写数，不画成区间。
5. 不知道结束的区间只画起点，写明“结束时间未知”。不替它补一个长度，也不把它延到“现在”。压缩或截掉的一段要画出来并写明。
6. 并排的几条线，要么共用一条标尺，要么写明各排各的、互相不可比。共用之后，同一高度才表示同一时刻或同一个量。几件图拼在一起时，是否共用由拼的那一层声明，各件不自己假定。
7. 同一行表示同一项时，每一格都有字。没有对应内容的格子写明是原先没有、已经不在，还是没有选入；空着会被读成“没有”或“一样”。没有变的、没有选入的行照样留着。
8. 两份内容要按行对照，先得是同一个对象、同一种口径。单位不同的先换成同一种，并把换算写在那一格里；换不了的，和对象不同的一样，不排成前后变化。
9. 缩进表示哪种关系要写出来：隶属、包含，还是汇报。一项有两个上级就不是一棵树，不硬排成缩进。位置可以说明一项归谁，不能凭位置推出谁有权限。
10. 窄屏可以把几栏并成一条线，栏名改写进每一行。先后、时刻和对应关系不随宽度改变。

## 默认排法

画关系、版本、事件和对照时，没有别的理由就用这一套。

| 位置回答的 | 排法 | 图里的读法 |
|---|---|---|
| 只有先后 | 一条通线，每项前面写序号，间距跟着文字走 | 自上而下是先后次序；间距不表示时长 |
| 先后加时长 | 一条标尺，刻度写时刻。时刻画成点，区间画成贴着标尺的条，截止画成横过标尺的短线 | 每格多长，时刻按哪个时区 |
| 属于谁 | 每深一层缩进一格，从上级引一条线到下级 | 缩进表示哪种关系；同级之间的次序没有含义 |
| 是不是同一项 | 一行一项，栏名写在栏顶 | 同一行的几栏说的是同一项；行的次序没有含义 |
| 几条线的先后 | 每栏一条轨，共用一条标尺 | 各栏共用这一条标尺 |
| 几条线各排各的 | 每条线自己一根通线 | 不同的线之间，位置不表示谁先谁后 |

通线只在位置表示先后或时间时画。次序没有含义的清单不画通线，画了会被读成步骤。

按比例排时，文字常常比刻度密。默认让文字上下让开，用引线接回它在标尺上的位置；标尺上的记号保持比例，不为了排字去挪。

线画成竖的还是横的、刻度用点还是短线、每格多宽，都是风格取舍，由项目决定。

## 三级做法

先做到第一级，后两级才有东西可画。

1. 只用文字。每一项后面写它的位置词：第几、什么时刻、属于谁、对应哪一项。表格、清单、正文都做得到，也是图的等效文字。
2. 一条线。把位置词画成位置，附一句读法。
3. 几条线并排。共用一条标尺并写明，跨线的先后才读得出来；不共用就写明各排各的。

[样板](../../../../demos/editable-native-svg/grammar-specimens/index.html)用同一份合成内容把三级各做了一遍。第三级里，审核、规则生效和调阅单的改动分在三栏、共用一条标尺，读者看得出审核在新规则生效之前，改动在它之后；各排各的版本图回答不了这个问题。

## 正例与最容易犯的错

正例：“审核通过，09:40”“规则 v3 生效，10:15”各在自己的栏里，两栏共用一条每格一小时的标尺，图脚写着“各栏共用这一条标尺，标尺上同一高度是同一时刻”。

反例一：五个步骤等距排开，没有说明。第三步可能要几周，第四步只要几分钟，读者把它们读成一样长。改法是写明间距不表示时长，把知道的用时写在那一步旁边。

反例二：两条各排各的版本线并排，刻度落在同一高度。读者把调阅单 v2 和规则 v3 读成同时。改法是写明不同的线之间位置不表示先后；确实要比先后，就给出时刻，换成共用的标尺。

反例三：三步的用时分别是“约十分钟”“一到三个工作日”和未知，画成按比例的三段。未知被赋了一个长度，分钟和工作日上了同一条尺。

反例四：前后对照只列变了的字段。读者分不清其余字段是没有变，还是没有查。

反例五：还没有结束的区间画到“现在”为止。图一旦存下来，“现在”就成了一个没有人记录过的结束时刻。

## 最小产物与何时停

最小产物是第一级的位置词。内容只有三四项、先后一目了然时，到此为止；一份编号列表就够了，不必画线。

需要退回内容的情形：写位置词时说不出谁先谁后，或者说不出一个时刻是按哪个时区写的。这是内容没有核对到位，不靠排法补。

需要换一种形式的情形：行数多到读者要筛选和排序，用表格；一项有几个上级，用关系图；要比的是数量而不是时间，回到 [图形编码](../composition/encoding.md)，零点、分母和缺失值另有要求。

与已有页面的关系：[图形编码](../composition/encoding.md)写了“长度有尺度”和“数量比较需要共同尺度”，本页把这两句用到时间和并排的线上，并补上“没有量就不按比例画”。[成立程度与归属的标记](standing.md)说归属优先用位置，本页第 9 条补了另一半：位置说明归谁，不说明谁有权限。[精确指向](anchoring.md)留下的两个缺口，时间范围和字段集合，现在各有一种画法：沿标尺的区间，和对照表里的选取。

使用证据限于合成内容上的两个生成器、一个组合和一页样板，出自同一名制作者；两个任务各有一次冷读和一份不读仓库的对照，各只有一份，不足以说差别来自本页。时长是区间时的画法、标尺的断轴、“现在”的记号和横排还没有规则。被真实任务挑战、或默认排法在另一类图上行不通时，修订本页。仓库里既有排法的清点见 [提炼页](../../../../vault/distilled/placement-grammar-20261004/README.md)，冷读、对照与未做项见 [验收回执](../../../../docs/verification/placement-grammar-20261004.md)。
