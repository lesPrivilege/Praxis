# 界面运动的编排、连续性与减少动态

语法 ID：`DWG-M-CHOREOGRAPHY` · 取用：可选普通参考（`normal` / `reference`）。

本页把 [运动判断](grammar.md) 扩展到状态连续、可中断操作和减少动态替代；只针对界面运动，不处理视频叙事。Apple HIG 可提供平台参考，但具体时长、曲线和动效 API 仍由目标环境决定。

## 先确定运动在说什么

写明运动表达的是状态变化、空间变化、层级/归属变化、直接操纵，还是纯装饰。标出起点、终点、同时更新的状态和替代反馈。未承载语义的运动按装饰性处理；对频繁操作，重复等候的动画尤其容易干扰。

运动不能成为业务时钟。动画未结束时界面仍可响应下一步操作；新的命令可替换、反向或取消当前运动，不留下与真实对象状态不一致的中间帧。不能因为 transition 尚未收尾就拒绝点击、冻结焦点或推迟保存。

## 运动的状态轨迹

为关键变化说明：

- 输入：用户动作、键盘/触控/指针方式、当前用户偏好。
- 状态：起始事实、允许的中间视觉态、最终事实、错误与取消态。
- 映射：运动对象、方向/幅度、遮挡范围、静态状态提示。
- 打断：连续输入、反向操作、取消、离开视图、系统减少动态偏好。

位移可帮助辨认元素从哪里来、归属何处；没有有用空间关系时，长距离滑动可能只是让用户等待。列表排序要区分元素重排与新增/删除；真实计数即时更新，不能让补间帧被误认为数据值。

## 减少动态的有意义替代

先依目标平台检测系统偏好，再按内容逐项审查。持续自动移动可暂停；纯装饰动画可移除；位置关系可以用轻微不位移的高亮、边框或标签提示；层级转换可以瞬时切换并更新标题/面包屑。Apple 对其生态建议减少对某些运动敏感的表现，同时提醒不要把所有动画无差别取消，以免丢失可理解性。替代方案须在实际设备、常用路径和系统偏好开启时走读。[Apple HIG Motion（S10）](../../../../vault/provenance/design-grammar-atlas-20261002/cards/s10-apple-hig-motion.md) Apple SF Symbols 的图标动画概览见 [DWI-008](../../../../vault/provenance/design-writing-encyclopedia/interaction/cards/apple-sf-symbols-overview.md)，但产品页介绍不代替播放检查与许可核对。

W3C WCAG 2.2 的 2.3.3 Animation from Interactions 位于 AAA；2.2.2 Pause, Stop, Hide 为 A，覆盖符合其范围的自动移动/闪烁内容。先核对每条标准的触发条件与例外，并声明产品选择的合规目标；不要把网页规范推成任意原生应用都适用的事实。[WCAG 2.2 正式标准](https://www.w3.org/TR/WCAG22/)

## worked example：抽屉切换到详情页

桌面上，侧边抽屉从列表侧进入，表示其属于当前列表；用户在过渡中按 Escape，抽屉关闭、焦点返回触发按钮。连续点击不同条目时，只保留最新选中对象，关闭前一条目的运动，不让旧内容盖住新内容。系统启用减少动态后，抽屉直接呈现，标题和焦点状态仍标明当前对象；错误提示与加载状态仍显示。动画用来理解层级归属，并不延迟对象切换。

## 反例

大幅缩放与旋转依序播放，即使用户已启用减少动态也照常；新内容在动画结束前不可操作，按 Escape 也不停止；最终页面没有标题、选中状态或焦点位置。装饰效果既延迟操作，也承担了唯一的层级线索。

## 运行前审查

按一项高频变化做可见行为走读：快速重复触发、反向、键盘触发、取消、系统偏好开/关、窄屏、加载失败。记录真实运行的环境和未覆盖项。仅读 HIG/规范或查看组件源码不能证明页面的运行行为。

`prompt-motion.com` 是动态作品与提示词条目聚合页的线索，能够帮助找到想研究的作品/提示词。其首页、作者提示词或静态条目不能单独验证输出视频、运动质量或控制实际效果；要把它作为动态参考，需明确取得并实际观看具体成品，记录作品 URL、来源归属、所见时间和限制。它尚无运动行为验证证据。
