承载稳定语义的运动

十种运动，各表达一种变化。每种都写成时间 t 的函数：给一个时刻，得到那一刻的画面。网页用它播放，视频用它逐帧渲染，两边是同一个函数。

本页的样张都由下面列出的函数逐帧画出，拖动 t 可以停在任意一刻。普通网页不必逐帧画，“网页里的实现”一栏给的是等价的 CSS 写法，components.html 里的控件用的就是那种写法。含义与约束见 README。

1

移动

同一个东西从 A 到了 B。读者要能一直认出它是同一个。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
时长：界面 200–300 毫秒，视频 0.4–0.8 秒。曲线：先加速后减速。距离远时加时长，不加速度感。
t 的函数
move: (t, { a, b, d = 0.6 }, r) => {
  const k = clamp01(t / d);
  return { x: r ? (k < 1 ? a : b) : lerp(a, b, easeInOut(k)), arrived: k >= 1 };
}
网页里的实现
transform: translate(…);
transition: transform var(--t-move) var(--ease-in-out);
减弱动效时
不补间，直接出现在 B；A 到 B 之间留一条带箭头的细线，说明它是从哪里来的。
不该用的情形
前后不是同一个东西时不用（那是一个退出、一个出现）。位置没有含义、只是重新排版时也不用。
2

流向

东西此刻正沿这条线朝一个方向持续流动。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
速度 24–60 单位/秒，匀速。小箭头的间距固定。线保持实线：虚线留给“尚未成立”。
t 的函数
flow: (t, { len, v = 36, gap = 40 }, r) => {
  const shift = r ? gap / 2 : (v * t) % gap;
  const xs = [];
  for (let x = shift; x < len; x += gap) xs.push(x);
  return { xs };
}
网页里的实现
@keyframes flow { to { transform: translateX(40px); } }
.arrows { animation: flow 1.1s linear infinite; }
减弱动效时
小箭头停在线上不动。方向仍然看得出，只是不再表示“正在流”，由旁边的词说明。
不该用的情形
只是有依赖关系、此刻没有东西在流时不用。速度不表示流量，除非流量是量出来的并且写明。
3

出现与退出

一个对象加入了，或者离开了。别的对象不动。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
时长 150–250 毫秒，视频可到 0.4 秒。出现时上移 8 个单位并淡入；退出只淡出，不位移。
t 的函数
appear: (t, { at = 0, out = Infinity, d = 0.2 }, r) => {
  const i = r ? (t >= at ? 1 : 0) : easeOut(clamp01((t - at) / d));
  const o = r ? (t >= out ? 1 : 0) : easeOut(clamp01((t - out) / d));
  return { opacity: i * (1 - o), dy: (1 - i) * 8, present: t >= at && t < out + (r ? 0 : d) };
}
网页里的实现
.enter { animation: in var(--t-state) var(--ease-out); }
@keyframes in { from { opacity: 0; transform: translateY(8px); } }
减弱动效时
直接出现或消失，旁边的词同时更新（“3 个工具”变“4 个工具”）。
不该用的情形
同一个对象换状态时不用。被拒绝的和已过期的不退出，它们留在图上。
4

状态切换

同一个对象从一种状态变成另一种。位置和名字不变，变的只有状态。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
时长 150–250 毫秒。旧记号先淡出，新记号再淡入，两者不同时可见；状态词在中点替换。
t 的函数
swap: (t, { at = 0, d = 0.2 }, r) => {
  const k = r ? (t >= at ? 1 : 0) : clamp01((t - at) / d);
  return { from: clamp01(1 - k * 2), to: clamp01(k * 2 - 1), word: k < 0.5 ? 0 : 1 };
}
网页里的实现
.state { transition: opacity calc(var(--t-state) / 2) linear; }
/* 脚本在真实状态变了之后才换记号和词 */
减弱动效时
记号和词同时直接替换。词是反馈本身，不需要别的替代。
不该用的情形
不在两种状态之间补出“中间状态”的样子。状态变化以真实结果为准，动画播完不等于事情做完。
5

标出当前

读者或叙述此刻在哪里。一张图里只有一个“当前”。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
标记移动 200–300 毫秒；每处停多久由那里的文字量决定（至少 2 秒，或字数 ÷ 9）。
t 的函数
current: (t, { n, stay = 1.2, d = 0.24 }, r) => {
  const i = Math.min(n - 1, Math.floor(t / stay));
  const k = r || i === 0 ? 1 : easeInOut(clamp01((t - i * stay) / d));
  return { index: i, pos: i === 0 ? 0 : lerp(i - 1, i, k) };
}
网页里的实现
.marker { transition: transform var(--t-move) var(--ease-in-out); }
[aria-current="step"] { font-weight: 600; }
减弱动效时
标记直接出现在新位置，不滑动。当前项的名字照样加粗。
不该用的情形
同一张图里已经用强调色标“等人决定”时，不再用它标“当前”。不同时标出两个当前。
6

等待

停在这里，等人或等外部结果。不知道还要多久。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
一次明暗 1.4–2 秒，最暗不低于 45%。位置不动，不旋转，不画进度。
t 的函数
wait: (t, { p = 1.6, low = 0.45 }, r) => ({
  opacity: r ? 1 : lerp(low, 1, 0.5 + 0.5 * Math.cos((2 * Math.PI * t) / p)),
})
网页里的实现
@keyframes wait { 50% { opacity: .45; } }
.waiting { animation: wait var(--t-pulse) ease-in-out infinite; }
减弱动效时
记号静止，旁边的词写“等待中”。词已经说明了状态。
不该用的情形
有已知时限时改用计时。系统其实在工作时用“进行中”。结果未知不是等待，用它自己的记号。
7

循环一轮

同一组步骤又走了一遍。读者要知道这是第几轮，以及什么时候停。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
一轮 1.5–3 秒，匀速。轮数写成字。视频里最多演两轮，之后用轮数代替。
t 的函数
loop: (t, { n, d = 2.4, max = Infinity }, r) => {
  const turns = Math.min(t / d, max);
  const round = Math.min(Math.floor(turns) + 1, max);
  const k = turns >= max ? 0 : turns % 1;
  return { round, pos: r ? Math.floor(k * n) : k * n, done: turns >= max };
}
网页里的实现
offset-path: path("…");
animation: lap 2.4s linear infinite; /* 轮数由脚本按真实轮次更新 */
减弱动效时
标记在几个步骤之间逐个跳，不沿路径滑；轮数照常更新。
不该用的情形
不知道停止条件时不让它无休止地转。只走一遍的流程不画成环。
8

入队与出队

东西在排队：从一头进，从另一头被取走；放不下的被丢弃，但看得出它来过。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
每个动作 300–500 毫秒，动作之间留停顿。进和出走同一个方向。
t 的函数
queue: (t, { d = 0.5, gap = 0.5 }, r) => {
  const step = d + gap, phase = Math.min(2, Math.floor(t / step));
  const raw = clamp01((t - phase * step) / d);
  return { phase, k: r ? (raw > 0 ? 1 : 0) : easeInOut(raw) };
}
网页里的实现
.item { transition: transform var(--t-move) var(--ease-in-out); }
/* 脚本改的是队列数据，位置由数据算出 */
减弱动效时
每个动作直接到位，不滑动。被丢弃的那一项照样留在队列下方，带着叉和“已丢弃”。
不该用的情形
顺序没有意义的一堆东西不画成队列。被丢弃的不让它凭空消失。
9

收拢与展开

多项压成了一项，或者一项展开成多项。读者要知道压之前有几项。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
时长 300–500 毫秒。各项向同一处靠拢并淡出，代表它们的那一项随后出现，项数写成字。倒放即展开。
t 的函数
fold: (t, { at = 0, d = 0.4 }, r) => {
  const raw = clamp01((t - at) / d);
  const k = r ? (raw > 0 ? 1 : 0) : easeInOut(raw);
  return { k, items: 1 - clamp01(k * 1.6), summary: clamp01(k * 2.5 - 1.5) };
}
网页里的实现
.item { transition: transform var(--t-move) var(--ease-in-out), opacity var(--t-state) linear; }
减弱动效时
直接替换，并写明“由 4 条压成”。项数是必须保留的反馈。
不该用的情形
压缩有损失时不让它看起来像无损：写明压掉了什么。几项之间没有归并关系时不用。
10

计时

时间在走，离一个已知的时限还有多远。

合成例子 · 可以播放，也可以拖到任意一刻定格 · 五个时刻的定格
0.00 秒
可调的参数
匀速，不缓动。视频里画面的 1 秒等于讲的 1 秒；要压缩时间就写明比例。
t 的函数
timer: (t, { limit }, r) => {
  const e = Math.min(t, limit);
  return { seconds: Math.floor(e), ratio: (r ? Math.floor(e) : e) / limit, over: t >= limit };
}
网页里的实现
/* 每帧按真实经过的时间设宽度，不用固定时长的 transition */
bar.style.width = elapsed / limit * 100 + "%";
减弱动效时
读数和量条每秒跳一次。计时照常，读数是文字。
不该用的情形
只用于真实的计时。不知道要等多久时不用，否则就是一条假进度。
11

画面位置与驻留

视频没有滚动和点选，读者靠固定的位置找东西。这一节是工单清单之外补的：同一类文字在每个画面里待在同一个位置，每块文字停够读完的时间。

示意 · 16 : 9 画面里的五个位置，比例是这一版的画法
位置放什么约束
章节位现在讲到哪一章整章不动；换章时换字，不做转场特效
舞台对象、关系、运动同一个对象在相邻的镜头里造型不变，位置不变或用“移动”交代
图例位这个画面实际用到的画法画法出现时图例同时出现；画面里没有的画法不列
字幕位旁白的文字，或无声片的讲解句一次一句，最多两行；不遮舞台
来源位例子是合成的还是实测的，数据出自哪里内容的来路变了就换，不省略“合成”二字
驻留的函数
hold = (chars, rate = 9) => Math.max(2, chars / rate)   // 秒
一块新出现的文字至少停这么久。12 个字停 2 秒，27 个字停 3 秒，45 个字停 5 秒。每秒 9 字是本仓库一条无声知识片用过的读速，属于项目参数；有旁白时以旁白的时长为准，取两者里长的。
同时出现的量
运动进行时不换字幕，字幕换的时候舞台不动。读者一次只跟一处变化。
网页里的对应
网页的读者自己控制时间，所以不需要驻留；位置的约定仍然适用：图例紧挨着图，来路写在图题或标签里。
不该用的情形
画面比例不是 16 : 9，或一个画面只放一句话时，位置按那个项目重新定。这里的五个位置是参考，不是模板。

本页是单个离线文件。脚本关闭或打印时，每种运动显示五个时刻的定格，由同一个函数在生成页面时算出。
