承载稳定语义的控件

每个控件承载一种含义，下面各给一个最小实例和它的状态矩阵。实例里说的“一次请求怎样走完”是合成的，不描述任何真实产品。

含义与约束见 README 的 grammar 部分，色值、字号和时长在 tokens.css，记号在 glyphs.svg，运动在 motion.html。本页的强调色只表示“当前选中”；第 12 节单独一张图，那里的强调色表示“等人决定”。键盘焦点一律用墨色外框，不占强调色。

1

步进器

有先后的几步，一次只看一步。读者知道现在是第几步、一共几步，可以前进、后退，也可以让它自己走。

合成例子 · 一次请求的五步
  1. 用户提问问题从浏览器发出，带着这一轮对话的编号。
  2. 网关接收网关核对身份，把请求排进队列。
  3. agent 规划agent 读入问题和记忆，决定先调用哪个工具。
  4. 等人确认要写文件的那一步停下来，等人点头。
  5. 交付结果写成 artifact，连同来源一起交回。

状态矩阵

正常下一步三个按钮加一句“第 2 步，共 5 步”。计数是文字，不画进度条。
悬停下一步底色变淡灰蓝。
键盘焦点下一步墨色外框。Tab 依次到三个按钮，Enter 或空格触发；换步之后焦点留在原按钮上。
选中暂停播放中，按钮文字换成“暂停”。每步停 2.4 秒，走到最后一步自己停下；按任何一个按钮都会打断播放。
禁用上一步第一步没有“上一步”，最后一步没有“下一步”。虚线边框加灰字，不只靠颜色。
无脚本五步排成一张编号列表，按钮不出现。
打印与无脚本相同：五步全部印出。
2

轨道

一排站点和一个移动的标记，回答“从哪里到哪里”。标记经过的站是实心，没到的是空心。

合成例子 · 请求此刻在哪一站，点站名可以移过去

已过当前未到

状态矩阵

正常站名是文字，站点是圆点；已过实心、未到空心，去色后仍分得开。
悬停站名下出现淡灰蓝底色。
键盘焦点每个站是一个按钮，Tab 到达，Enter 移过去；墨色外框。
选中标记移到这一站，站名加粗，下方的文字写出“当前在第几站”。标记移动 240 毫秒，中途再点会从当前位置转向。
禁用本例没有不可到达的站。需要时该站用虚线圆点，并在站名后写明原因。
无脚本站点和站名照常排列，没有标记，全部按“未到”画。
打印印出当时的已过与未到，标记不印，“当前”由下方的文字说明。
窄屏520 px 以下改成竖排，站的顺序不变，标记沿竖线移动。
3

分段单选

几个互斥的预设，任何时候恰好选中一个。选项少而且名字短时用；多于五个或名字长时改用列表。

合成例子 · agent 遇到要写文件的步骤时怎样处理
写文件前的处理方式
每次都问每一次写文件都停下来等人确认。最稳，也最慢。
只问一次第一次写文件时问，这一轮对话里之后不再问。
不问直接写。只适合放在沙箱里跑。

状态矩阵

正常只问一次一个框里并排几段，段与段之间一条细线。
悬停只问一次底色变淡灰蓝。
键盘焦点只问一次整组是一个停靠点，左右方向键换选项，墨色内框。
选中每次都问深底白字加粗，去色后是全组最深的一段。对应的说明立即换成这一项。
禁用按目录灰字加删除线，名字后面写明原因；方向键跳过它。
无脚本照常可用：单选框和说明的切换都不依赖脚本。
打印选中的一段照样印出深底，三项说明全部印出。

可点选的节点与说明面板

选中图里的一个对象，在旁边看它的说明。说明不放在悬停提示里。

合成例子 · 四个对象
网关所有请求的唯一入口。它核对身份、限制频率，再把请求交给 agent。
agent读入问题、记忆和可用的工具，一轮一轮地决定下一步做什么。
工具agent 能调用的一个动作，例如读文件或查询。每个工具有自己的权限。
数据库保存对话和 checkpoint。agent 重启之后从这里接着做。
当前选中

状态矩阵

正常agent记号加名字，墨色边框。记号只是名字的重复。
悬停agent底色变淡灰蓝。悬停不显示任何别处看不到的内容。
键盘焦点agent每个节点是一个按钮，Tab 到达，Enter 或空格选中；墨色外框。
选中agent边框加粗并换成强调色，名字加粗；面板换成这个对象的说明，读屏会念出来。
禁用agent没有说明的对象用虚线边框和灰字，不能选中。
无脚本四个对象的说明依次全部列出，节点不可点。
打印与无脚本相同：四段说明全部印出。
窄屏520 px 以下节点竖排，连线跟着转成竖线，顺序不变。
5

展开与收起

细节层。标题说清里面是什么，读者不展开也知道自己略过了什么；可以一次全部展开。

合成例子 · 三条细节
队列满了怎么办
新的请求收到“稍后再试”，已经排上的不受影响。
checkpoint 多久存一次
每完成一次工具调用存一次，所以最多重做一步。
记忆和对话有什么不同
对话只属于这一轮，记忆跨越多轮，并且可以被人改写。

状态矩阵

正常队列满了怎么办收起时只有标题，前面一个加号。
悬停队列满了怎么办标题行底色变淡灰蓝。
键盘焦点队列满了怎么办标题行是停靠点，Enter 或空格开合；墨色外框。
选中队列满了怎么办展开后加号变减号，内容出现在标题正下方。“全部展开”按下后文字换成“全部收起”。
禁用不设禁用。没有细节的条目不做成可展开的样子。
无脚本每条仍可单独开合，“全部展开”按钮不出现。
打印全部展开后印出。
6

标签

紧挨着一项内容，用一个词说明它的状态或来路。标签不可操作。

合成例子 · 四个配置项和一条说法
  • 记录每次工具调用默认开
  • 自动压缩长对话默认关
  • 接入聊天渠道可选
  • “压缩后回答质量不变”未核实转述
  • 本页的全部例子合成

状态矩阵

正常默认开记号加一个词。不默认生效的两种（默认关、可选）用虚线边框，与关系线的虚线同一个意思。
悬停、焦点、选中、禁用都没有。标签不可操作，不进入 Tab 顺序，也不做成按钮的样子。
无脚本没有区别。
打印没有区别；去色后靠词、记号和边框的虚实区分。

“转述”“合成”这类来路标签只有文字，没有记号：“是谁说的”不占画法。

按属性对照

少量对象在共同属性上比较。读者的问题是“同一个属性下谁不一样”，所以窄屏按属性分块，对象的位置和顺序不变。

合成例子 · 三种存放方式，四个属性
属性记忆checkpointartifact
保存多久记忆跨越多轮对话checkpoint这一轮对话之内artifact直到被删除
谁能改写记忆人和 agentcheckpoint只有系统artifact人
条数上限记忆200 条checkpoint缺失artifact不适用
回滚后记忆保留checkpoint退回到所选的一份artifact保留

状态矩阵

正常一行一个属性，一列一个对象。没有值的格子写明是哪一种没有：“缺失”是应该有而没查到，“不适用”是这个属性对它没有意义。
悬停、焦点、选中、禁用都没有。这是一张静态的表。
窄屏560 px 以下每个属性成一块，块里三个对象仍按“记忆、checkpoint、artifact”的顺序各占一行，对象名每行都写。
无脚本没有区别，重排只靠样式。
打印按宽屏的表印出。

时间线

有先后的几个节点。位置只表示先后，间距不表示相隔多久；要表示时长就得换成有刻度的图。

合成例子 · 一个功能的四个节点
  1. 3 月提出只在内部试用
  2. 5 月默认关文档里写明怎样打开
  3. 8 月默认开旧配置继续有效
  4. 未定移除旧配置尚未发生
已经发生尚未发生

状态矩阵

正常已经发生的节点实心，线是实线；还没发生的节点空心，通向它的线是虚线，并且写着“尚未发生”。
悬停、焦点、选中、禁用都没有。节点需要点开看说明时，改用第 4 节的节点与说明面板。
窄屏560 px 以下改成竖排，从上到下是从早到晚。
无脚本没有区别。
打印按宽屏横排印出。

阅读进度线

页面顶上的一条细线，表示读到了哪里。它画的是真实的滚动位置，本页顶上那条就是实例。

状态矩阵

正常
3 px 高的墨色线，长度等于已经滚过的比例。不用强调色，它不是读者要处理的事。
悬停、焦点、选中、禁用都没有。它不可操作，不接收点击，对读屏隐藏：滚动条已经提供了同样的信息。
减弱动效没有区别。线的长度直接跟随滚动，本来就没有补间。
无脚本不出现。
打印不印。

试算

读者改一个输入，按写明的规则算出结果。规则和结果一起给出，读者可以自己验算。

合成例子 · 规则和数字都是为演示编的

规则：每条消息按 400 token 计，窗口上限 8,000 token。占用超过上限时，最早的消息被压缩。

0上限 8,00016,000
按规则算出的三个例子
消息条数占用结果
124,800未超过上限
208,000正好到上限
3012,000超过 4,000，最早的 10 条被压缩

状态矩阵

正常滑杆、当前取值、一句结果和一条有刻度的量条。量条从 0 开始，上限画成一条竖线，并标着数值。
悬停滑块沿用浏览器的悬停样式。
键盘焦点滑杆是停靠点，左右方向键每次加减 1，Home 和 End 到两端；墨色外框。
选中没有“选中”。每次改动结果立即更新，数字不做滚动动画：中间值不是数据。
禁用输入由别处决定时，滑杆禁用并写明由谁决定；结果照常显示。
无脚本滑杆不出现，改为规则加三个算好的例子。
打印印出规则、当时的结果和三个算好的例子。
11

计时条

真实在走的时间。只在确实有一个钟在走、并且有一个已知的时限时用；不知道还要多久的等待不用它。

合成例子 · 时限 20 秒是为演示定的，计时是真的
0 秒未开始
0时限 20 秒

计时需要脚本。时限是 20 秒，到时显示“已到时限”。

状态矩阵

正常读数、状态词和量条。状态词有四个：未开始、计时中、已停止、已到时限。
悬停、焦点两个按钮与第 1 节的按钮相同。
选中计时中，“开始”换成“停止”。量条按真实经过的时间加长；到时限后停在满格，状态词换成“已到时限”，不自动重来。
禁用读数为 0 时“归零”禁用。
减弱动效量条和读数每秒跳一次，不连续加长。计时本身照常。
无脚本只有一句话：时限多少，到时会怎样。
打印印出当时的读数和状态词。

关系、范围与图例

线、端点和边界各回答一个问题，图例由画图的同一份输入得出。这一节的强调色表示“等人决定”。

合成例子 · 六条关系；每条下面的词是它的等效文字
  • 人 · 批准记录合同第 3 版已经成立 · 已确认
  • 机器 · 条款摘要合同第 3 版已经成立 · 未确认
  • 机器 · 修改建议合同第 3 版尚未成立 · 未确认
  • 机器 · 删除建议合同第 3 版已拒绝，没有生效
  • 法务意见合同第 3 版这一项还不存在
  • 人 · 是否放行合同第 3 版等人决定

图例只列上面实际出现的画法。输入里少一种，图例就少一行。

没有脚本时不画线，每条关系靠下面的词说明，内容不少。

边界是一条闭合的线，虚实与关系线同义。边界的名字写在边界里面的左上角；边界不靠底色区分，所以可以套两层而不成为嵌套的卡片。

状态矩阵

正常每条关系一行：左边是说话的一方，右边是它指向的对象，下面两个词是它的状态。画法只是这两个词的重复。
悬停、焦点、选中、禁用都没有。这是静态的图。
输入不全状态没写或写了不认识的词时拒绝画，并说明是哪一条，不当成“已经成立”。
无脚本只剩文字：两端的名字和状态词。
打印照屏幕印出；强调色去色后，“等人决定”靠词辨认。
