# Interaction · 对象、状态与操作

决定小产品、工作台、控件和交互材料里，对象、状态与操作怎样表达、反馈和保持可达。

- 分清按钮、链接、切换、图标与可访问名称：读 [控件与图标语义](controls.md)。
- 切换页面仍保留对象与输入、选择折叠/标签/弹窗，或给拖动提供替代：读 [导航与渐进披露](navigation.md)。
- 请求中、超时、失败和成功怎样反馈：读 [操作反馈](feedback.md)；具体提示文字见 [微文案](../../writing/genres/microcopy.md)。
- 在图形里选择连续范围，同时保留上下文：读 [范围选择](extent-selection.md)，先分清范围、选集与可见集。
- 状态、身份与权限边界：读 [状态与可达性](states.md)。
- 运动可中断、反向、连续触发或减弱：读 [界面运动编排](../motion/choreography.md)。
- 讲解页里的步进器、轨道、展开收起等控件要一版现成画法：看 [记号、控件与运动](../marks/README.md)，语义仍以上面各条为准。

新增方法是可选参考，来源文档、示例和运行检查分别说明；不因控件名称相同就推断平台行为相同。

候选企业组件及其状态矩阵由 [UI](../../../../kit/ui/README.md)维护，未有实现证据的组件仍为候选。具体参考沿 [界面索引](../references/interface.md)回查，不从一个token或像素值推断整项验收完成。
