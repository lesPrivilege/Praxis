# Publish / html · 空间编排

决定网页、报告、Slides 与 PDF 的阅读单元、分页、密度、证据位置和可收起的内容；把一份内容改成另一种篇幅时同样适用。

输入是已确定的读者、主张、证据和文字，输出是阅读顺序清楚、展项职责完整的材料。编排决定改变了意思时，回到维护那条规则的分支。

取用或公开证据前，读 [共享证据契约](../../writing/evidence.md)，确认来源身份与披露范围。要删减、概括或重排原稿时，同一页的“投影、改编与新增”说明要交什么。

- 要决定页面与章节如何承载论证：读 [内容编排](composition.md)。
- 要放入图表、引文、截图或证据：读 [展项与说明](exhibits.md)。
- 要选择具体图形、尺度、字体或表现方式：进入 [Design / Composition](../../design/composition/README.md)。
- 窄屏比较或局部注释有困难时，先比对 [按属性维持比较](../../design/references/curated/comparison-continuity.md)与 [注释保持邻接](../../design/references/curated/note-adjacency.md)；样张数字和代码不直接继承。
- 要向不读原件的读者讲清一个系统、项目或机制的各个局部：内容组织读 Writing 的 [机制讲解](../../writing/organization/mechanism.md)，页面分层与可见性取用 [讲解页的编排](explainer.md)，任务类型列出它时照读，只按 brief 做时可选。
- 需要检验真实输出：用 [共享验收](../verification.md)。

本分支定义内容职责，不固定主题和 renderer。需要比较原子化编排，读 [实验样张](../../../../vault/distilled/layout-specimens-20260927/README.md)和 [局部筛选](../../../../vault/distilled/layout-specimens-20260927/review.md)；可直接取样、改编并比较失败对照，无需先获main批准；审阅范围按记录消费，尚未形成已采纳组件库。
