# 叙事与分镜交接

文稿改编、动态说明和视听材料的分镜交接：先有主张与证据，再确定哪些关系必须通过时间表达，每段时间解决一个认知任务。

只把段落依次淡入不算完成改编。

## 每段时间解决一个认知任务

每个 beat 写清读者此刻要理解什么、需要看见的证据、屏幕文字、可选声音以及进入下一段的条件。镜头数量、驻留秒数和声音样式由内容决定。把表格压成短暂画面可能丢失可比性，此时重构对比或保留可暂停、可查阅的配套材料。

可用最小分镜表组织交接：

| 字段 | 要说明什么 |
|---|---|
| 主张/关系 | 本段使哪项判断或变化可理解 |
| 输入与来源 | 对应原稿位置、数据口径、合成或实测身份 |
| 画面与文字 | 必须同时可见和可以依次出现的信息 |
| 时间 | 驻留、顺序及与前后段的语义衔接 |
| 声音/字幕 | 是否必要，与画面分工，静音或无法听见时的可理解路径 |
| 检查 | 实际速度下是否读得完，转场是否暗示了不存在的因果 |

只有声音承担的信息需要可达的文字替代；只是装饰的声音不承担事实证明。时间线调整后核对字幕、语义状态和声音同步。静帧联络表用于检查构图，不能代替完整观看。

## 旁白与屏幕文字的审阅

旁白是成文，屏幕上的文字大多是结构位置。两者分开撰写，也分开审阅；事实核对另做，不能代替它们。

- **旁白**按 [口播旁白体例](../../writing/genres/narration.md)撰写，写完按 [成文审阅](../../writing/review.md)单独过一遍；对外发布时可以再交 [独立冷读](../../writing/review.md#成文的独立冷读)。口播用口语，目标仍是接近人类作者说出来的话。
- **屏幕上的结构文字**包括章名、小节标题、图表标题与类目、节点、图注和状态标签。它们按 [成文原理](../../writing/principles.md)第 5 条单独撰写，不从旁白里截句子；文字多，或由几个人、几个代理分头写成时，再按 [结构文字的独立审阅](../../writing/review.md#结构文字的独立审阅)交给没有参与撰写的审阅者。夹在事实或画面审阅里的一项检查代替不了这一遍。逐字跟着旁白出现的字不在其内。
- **文字清单**：做独立审阅时，审阅者要拿到画面上实际出现的全部文字。从源码或成片抽一份清单，带上出现的时间和位置；只看分镜稿会漏掉施工时加进去的标签。
- **任务书**：屏幕文字交给别人或别的代理写时，把第 5 条和本节写进任务书。主笔读过的规则，到不了没读过它的撰写者手里。

## 多平台封面与交付表述

视频交付默认附 4:3 与 3:4 两种封面，按各自画幅原生绘制，交付可编辑源件和预览图。标题、图形与留白分别编排，检查文字可读、边缘安全区与主题一致。把横版机械裁成竖版而截断标题或丢失关系，是需要重绘的反例。

封面为多平台发布预留，与成片画幅独立；横屏视频保持自己的尺寸和时间线。指定平台模板时按其要求调整并记明取舍。制作状态与泛泛保护性措辞留过程文档，成片和封面由内容承担；会影响理解的具体条件、来源和示例身份仍准确交代。

此默认来自 2026-10-12 用户对 [AgentScope 知识片](../../../../projects/agentscope-enterprise-film/README.md)的交付要求，适用于后续新视频，不追补历史成片。双画幅已原生绘制并检查；多平台发布效果尚未验证。

## 完成与回流

逐段映射回原稿，核对未遗漏的限定、单位与来源，再按 [媒介验收](../verification.md)检查实际输出。未做观众测试时只报告制作和观看范围，不称叙事效果已验证。

本契约消费 [Write–Design 边界](../../../../vault/distilled/write-design-grammar/write-design-boundary.md)与既有 [动态简报](../../../../vault/distilled/ai-capability-assessment/motion/README.md)的交接对象。镜头、字体运动与缓动的选择由 [Design / Motion](../../design/motion/README.md)维护，renderer API 留在具体项目。
