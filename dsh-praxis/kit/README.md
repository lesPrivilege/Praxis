# dsh-praxis Kit · 按任务进入

先选 [Task](task/README.md)：这次为谁做什么，走哪条流水线，读哪些方法；Writing 与 Design 常驻，Publish 在选定流水线后读。

四层都在这里维护。每页挂载的来源记在控制面的名册里，随 `praxis_resolve` 返回的 materials 或控制面中该页的条目给出。分工见 [分层体例](../layers.md)。各页示例里的产品、数据、人物与阈值均为构造。

| 层 | 入口 | 读取方式 |
|---|---|---|
| Task | [这次做什么](task/README.md) | 每次任务选一个类型或现写 brief |
| Writing | [成文、内容组织与语言](writing/README.md) | 常驻：入口与底线每次都在 |
| Publish | [按媒介编排与制作](publish/README.md)：html、video | Task 选定流水线后读 |
| Design | [视觉与媒介表达](design/README.md) | 常驻：入口与判断契约每次都在 |
