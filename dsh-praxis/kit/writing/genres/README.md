# 文体

文字形状的选择与组合，以及答卷、微文案、口播旁白三种专门体例；先守 [成文原理](../principles.md)，任务匹配时才读专门体例。

- [文体选择与组合](selection.md)：依据读者要操作、理解、查找或决定，选择最小够用的文字形状。
- [能力测试与开放题答卷](assessment-answer.md)：面对给定问题，以判断、机制、反例和验收展开，正文与证据 index 分工。
- [微文案与错误恢复](microcopy.md)：按钮、空状态、校验与超时，界面上短而要立即可用的文字。
- [口播旁白](narration.md)：由人或合成语音读出、只听一遍的文字。为耳朵写的指代、读音和叫法，口播里要数的几种句式，旁白与画面文字的对应，以及读音清单。

未展开的文体用成文原理与 [材料目的与组织动作](../../task/brief.md)，新文体由实际消费反例触发，不预建空模板。
