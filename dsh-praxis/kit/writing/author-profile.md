# 作者语体：仓库所有者

配置项，默认关闭。以下任一情形打开：

- 任务里要求用仓库所有者本人的口吻代拟中文讨论、思考或工作说明
- 项目的 AGENTS.md 写有一行 `作者语体：开`，该项目的中文成文都取用本页

其他写作任务不加载，也不把这里的偏好推给别的作者。它只管句法、判断怎样呈现和语域；事实、证据、结构和交付仍按 [成文原理](principles.md)与 [证据与来源](evidence.md)，冲突时按 [Write 入口](README.md#规则有三种强度)的次序，作者偏好排在任务要求和语言约定之后。要一句回复就写一句；要完整推导，就不因简洁删去成立条件。轻度编辑已有原稿时，保留原稿有效的结构，不为贴合本页重写。

## 表达偏好

| 偏好 | 把握与语境 | 起草与修订时 |
|---|---|---|
| 按语域定长短 | 高；分析、日常问答、工作反馈 | 分析可以长段推演；日常可以只问一个具体问题；工作反馈交代对象、阻力、期望和范围，篇幅随实际复杂度 |
| 从具体对象进入 | 高；分析性讨论 | 从眼前的情形和它的成立条件出发，追问资源、时间、使用方式或组织约束，再落到判断与取舍；结论可以在推演末尾，不另造宏大开场 |
| 让步与转折改变推论 | 高；需要辨析的段落 | 先承认成立的部分，再说它推不出什么、哪些问题仍未解决；连接词承担推理，不制造装饰性的对立 |
| 限定而不磨平 | 高；分析与评论 | 对象、阶段、条件和不确定性照写；有依据的明确判断也照写，不把立场磨成两面兼顾，也不把局部判断扩成普遍断言 |
| 长句里的推进 | 高；分析 | 一句可以容纳几层因果、递进和自我修正；沿逻辑转向处分句，删空转的复述，不把每个从句拆成等长短句，也不堆口语接头 |
| 判断者在场 | 高；私人讨论与工作说明 | 第一人称连接判断与选择；简短的疑问、欣赏或不耐烦可以直说，不升格成宣言；正式场合按关系和受众另行校准 |
| 中文句法承载英文概念 | 高；熟悉技术概念的读者 | context、agent、runtime、review 这类词按概念需要保留，中文动词配英文对象；读者陌生时解释或改写，不按比例掺英文 |
| 跨域搭配 | 中；确有机制对应时 | 工程词可以描述生活或组织里的约束，前提是关系因此更准确；不用抽象名词代替具体问题 |
| 少量书面色彩 | 中；适合的论说场合 | 现代中文为底，语义合适处可以有书面词或偶发的典故；不设必用词、词频或通篇古雅 |

“高”“中”是对个人表达归纳的把握，不是规则效果的证明。

## 不迁移的

- 某次讨论里的立场、经历和承诺。新稿的事实和观点来自当前任务。
- 输入噪声：异常拼写、未完的句子、口述转写的重复。整理时修标点和已确认的错字，含义不清的词不凭空补义，条件链和概念区别不整理掉。
- 固定的长句、连接词、分段数、英文比例或罕见词配额。

## 合成示例

**分析段保留条件链。**“检索变快，确实能减少找资料的时间，但如果旧稿没有注明版本，使用者仍然要逐份核对，最后省下的时间未必很多。那么这次值得先做的，可能是把版本和来源整理清楚，再决定要不要加新的检索功能。”压成“提升检索效率。完善资料治理。打造可靠的知识系统。”丢的不是字数，是版本条件和取舍的依据。

**日常问答保留窄问题。**“这把伞收起来有多长？能放进通勤包的话，我就不选更大的了。”不补一段“兼顾便携与防护”的概述。

**工作反馈交代可执行范围。**“现在每次导出都要重新选日期和字段，连续做几份报表时会反复打断。能否保留上一次的设置，再把重置做成单独的入口？其他要重复填同样条件的地方，也可以一起查。”说清摩擦、期望和相邻范围，不把一处问题升格成架构改造。

**英文只在概念需要时出现。**“这个 fallback 能处理短暂超时，但缓存过期以后，它仍然要访问原服务。要覆盖长时间断网，数据保存和恢复就得另行考虑。”面向一般读者时，fallback 改成“备用处理方式”。

## 写完后核对

- 条件、因果和取舍还在，还是只剩流畅的结论？
- 长短来自当前场合，还是来自固定的长句或短句？
- 英文、书面词和陌生搭配确实帮助辨别关系吗？
- 有没有加进本人没有表达过的观点、经历或承诺？
- 关掉本页之后，同一任务的事实和观点是否不变？

## 来路与证据边界

取用：可选普通参考（`normal` / `reference`），按上面的配置项开关。偏好归纳自所有者的一批对话原文，私有证据底稿不在本仓库；示例为构造。尚无启用、关闭与换受众的对照试用。候选全文与交接见 [Writing Kit 修订交接](../../../vault/distilled/writing-kit-spec-handoff-20261016/AUTHOR-PROFILE.md)，裁决见 [ADR-036](../../../docs/decisions/036-writing-kit-spec-handoff.md)。
