# Praxis

Praxis 积累设计与写作的判断和方法，加一份来源名册和你自撰的 stream；工作流把它们带到具体场景。方法分四层，每层是一组短页：

| 层 | 位置 | 决定什么 |
|---|---|---|
| Design | 核 | 关系用什么视觉、交互或运动表现 |
| Writing | 核 | 内容怎样论证和组织，用什么文体、哪门语言 |
| Task | 工作流 | 这件工作为谁、要促成什么，走哪条流水线，读哪些页 |
| Publish | 工作流 | 内容怎样按媒介制作：html 页面或视频 |

来源是网页上的参考：标准规范、成熟实践、组件库、案例库、文章。名册只记链接、概要和摘录，不存原件；来源编目按 Kit 区域与形态排列，每条有一句说明，写明什么时候打开、取什么，挂到具体页上时还可以写这一页特有的用法。本地产物不是来源，分三类记在产物里：交付、管线（再做同类交付的方法）与范例（为示范某种做法预先做的样张）；写明服务哪些页的管线与范例、以及接受过的交付，在网页素材之后给到任务。过程记录不登记。

## agent 怎样用

插件给 agent 会话注册 11 个工具，并在系统提示里加一段简短入口。做一件任务时，agent：

1. 用任务类型和流水线调用 `praxis_resolve`，只用 `praxis_unit` 读它列出的页；Writing 与 Design 的入口页常驻，其余按需读。
2. 从素材里挑：这些页上的每个来源列一次，前十二条带摘录，其余给出说明供判断，要哪条用 `praxis_source` 取全。需要核对或借鉴时，按链接与摘录定位回原件读；`praxis_catalog` 按区域与形态翻来源编目，`praxis_search`、`praxis_source` 查名册，搜索连挂载页上写的说明和摘录一起查。
3. 遇到值得留下的参考，用 `praxis_capture` 成批登记网页来源，写明为哪件任务收录、形态与说明，需要时再用 `praxis_curate` 挂到页上。
4. 用 `praxis_projects` 查交付目录属于哪个项目，没有就用 `praxis_project` 登记；产物放在项目约定的位置。
5. 交付前用 `praxis_consume` 记下读过的页和来源，每个来源可以写一句这次用它做什么，并把交付的文件登记为产物；改过再交付就是新版本。运行记下这次会话，读到的原件正文可以回到会话记录里找。

`praxis_resolve` 与 `praxis_consume` 在会话里显示为卡片：展开看列出的页和素材，或打开交付的文件；卡片上的 **Open in Praxis** 打开 Praxis 页的对应位置。

维护名册、预设与产物的其余工具在控制面、命令行与 MCP。

## Praxis 页

左侧栏的 **Praxis** 就是控制面，只输入 `/praxis` 也打开它；后面带文字时，在会话界面列出任务类型和待处理事项，不发给模型。会话里的 `praxis_resolve`、`praxis_consume` 卡片链到这一页的对应位置。

页面的层级和 agent 取用的路径一致：入口 → 层 → 区域 → 单元 → 挂在单元上的来源 → 来源条目 → 原件。每一级只给说明和计数，往下一级才展开。五个标签：

- **Kit**：首页是核（Design、Writing）、Stream、下游工作流（Task、Publish）、Kit 之外的挂载和来源包。单元页给说明、全文（按需展开）、下级和挂在这页的来源；来源可以开关 **Use in tasks**（关掉后任务拿不到它）、收藏、对照原件检查、给这页上的挂载说明记 review、从这页移除（可恢复）。单元有修订时标出理由，可以撤回。
- **Sources**：分两处，各自记着滚动位置。**Catalog** 按 Kit 的层与区域摆成货架：每个区域摆出最新的三条，点 **Show all** 看其余，按形态分组。搜索或点标签时，所有匹配的都摆出来，筛选旁写着匹配几条，一条都没有时给 **Clear filters**。**Review** 按 To review、Needs work、Reviewed、All 筛选。一行只在读取程度不寻常时才写出来，部分读过是常态，不写。网格里的卡片先给一段摘录（带原件里的位置）作预览，下面是标题、形态与站点、何时用；标签、状态、日期和购物车放在底部。点标签在当前目录里筛选。搜索查标签、Kit 页上写的说明和摘录；搜的词出现在摘录里时，这一行列出那段摘录，卡片也拿它作预览。

  详情按同一套栏目、按判断要用的顺序展开，没有内容的栏目照样留着：何时打开、取什么；原件里的位置；读了什么，连同读取深度和上游检查（原件打不开时在页首直说）；边界与何时重访；然后问这条说明准不准。再往下是它挂在哪些 Kit 页上（点开就到那一页），以及它的活动：为什么收、哪些运行读过它、各用它做什么、交付了哪些文件（点开就到产物）。回到目录时筛选、搜索和展开的货架都保留，刚看过的那条有标记；在 Review 里记下判断后，那条离开队列，焦点给下一条。右上角直达原件：说明只用来判断开不开，要用就读原件。点 **Accurate** 记下，记的是你看到的那一版：读的时候 agent 改了说明，Praxis 不记这次判断，先换上新说明再让你判断。点 **Needs work** 写一句哪里不对，交给 Praxis 读原件重写。记下之后，**Next source** 打开下一条。
- **Task**：选任务类型、流水线、预设和 stream，看到 agent 会读的单元、挂在这些单元上的每个来源（各列一次）、范例与管线和验收项。下面是每条流水线的预设，预设是设置，在这里直接改。
- **Artifacts**：按项目分组的本地产物。打开一件看它服务的页、各个版本（每版的运行、用了哪些单元与来源、出自哪条管线），在 Finder 中显示或用默认应用打开，并记录对当前版本的 review。
- **Log**：需要处理的事（通常为空，有事时标签上显示数字）、运行和维护记录。没编目的来源、集合上游新增的成员可以直接交给 Praxis 处理；不收录、淘汰要写一句理由。

每个标签记着自己的位置、筛选和滚动：切到别的标签再回来，还停在原处；再点一次当前标签，回到它的第一层。来源在打开它的地方之上展开，页首的路径是它上面的各级，例如从 Kit 页打开时是 Kit / Design / Interaction / 那一页。点路径中的一级或按 Esc 回去，滚动位置照旧，焦点回到刚才那一项；在 Kit 页或产物页上按 Esc 回到上一级。← → 在打开它的那份列表里前后翻：来源目录、Review 队列、Kit 页上挂的来源、任务的素材、产物某一版用过的来源，或购物车。

**输入框**在每个标签底部。贴一个或几个链接，Praxis 在后台开一个 agent 会话：读原件，写清它是什么、什么时候该推荐用，按编目规则登记，并挂到它确实服务的页上，之后的任务经 `praxis_resolve` 就能拿到它。也可以贴一段别处的对话：agent 把它当二手材料，把其中提到的项目和说法逐个回原件核对，只收站得住的，最后交代哪些说法没站住。要改已有来源，也在这里说。记录没有手改的入口，和 Claude 的 memory 一样：人说，agent 改。输入框上方显示进度，完成后列出收了哪几条，点标题打开那一条，点 **Session** 看它读了什么。

**购物车**收集要用的来源：每条来源一行（或卡片、详情页）上的 **Add to cart**。选好后，购物车出现在输入框上方：**Open in chat** 开一个新会话，把这些来源的链接、何时用和 Praxis ID 填进输入框，在那里开工；**Copy** 复制同一段文字，交给别的 agent，装了 Praxis MCP 的 agent 可以凭 ID 用 `praxis_source` 查读取范围和摘录定位。购物车只存在这台机器的浏览器里。

来源条目自成一体：说明、概要、摘录、边界、何时重访，以及挂载页从它取什么，都不提本地项目，也不引别的来源，任何任务拿到都能照着用。某个项目怎样用了它，是它的活动：收录记录与运行记录，运行记录写着每次用它做什么。

来源没有写取用说明、没人 review 过，是默认状态：有人需要时再把来源摘要改写成说明。

## 修订 Kit

人或 agent 对一页的修订存在用户数据里，立即对所有入口生效，包里的原页不动。包升级后原页变了，这条修订列进待处理事项，由人或 agent 合并或撤回；撤回时修订全文留在历史里。

## 其他 agent

同一组工具也经 MCP（`adapters/mcp.js`，stdio）和命令行（`adapters/cli.js`）提供，Claude Code、Codex 等 agent 读写同一份 Kit 与名册。MCP 另有 resources（入口、每一页、来源与产物）和 prompts（每个任务类型一条）。

## 安装与数据

```bash
dsh plugin --profile desktop add link:/path/to/dsh-praxis
```

装完重启 DeepSeek Harness。数据根依次取：`config.data`、环境变量 `PRAXIS_DATA`、包旁的 `data/` 目录、`$DSH_HOME/dsh-praxis`（未设 `DSH_HOME` 时为 `~/.dsh/dsh-praxis`）。MCP 与命令行按同一顺序解析，默认共用一份数据。`config.prompt: false` 关掉系统提示里的入口段。完整说明见 [安装与运行](../INSTALL.md)。
