# Praxis

Praxis 是写作、编排、设计和报告的工作方法整合包，分四层，每层是一组短页：

| 层 | 决定什么 |
|---|---|
| Task | 这件工作为谁、要促成什么，走哪条流水线，读哪些页 |
| Writing | 内容怎样论证和组织，用什么文体、哪门语言 |
| Design | 关系用什么视觉、交互或运动表现 |
| Publish | 内容怎样按媒介制作：html 页面或视频 |

来源挂在页上：参考、范例、外部文档。每条挂载有一句说明，写明什么时候用。

## agent 怎样用

插件注册 `praxis_*` 工具，并在系统提示词里加一段简短入口。做一件任务时，agent 用任务类型和流水线调用 `praxis_resolve`，只用 `praxis_unit` 读它列出的页，交付前用 `praxis_consume` 记下用了什么，并把交付的文件登记为产物；改过再交付就是新版本。Writing 与 Design 的入口页常驻，其余按需读。

## 侧栏面板

在右侧栏的引导页打开 **Praxis**。

- **目录**：先是四层，再是各层的领域，再是页。每一级只给说明和计数；页打开后是来源卡片，可以启用或停用、收藏、对照上游检查（链接是否还在、内容是否变了）、改写说明、记录 review、删除（可恢复）。**登记来源**收录新的参考。
- **任务**：选任务类型和流水线，看到 agent 会读的页、可用的来源和验收项。
- **产物**：交付过的文件，按项目分组；项目头部写着它把底稿、中间产物、最终产物放在哪里，以及最终产物路径里还有哪些文件没登记。打开一件看它的各个版本、每版依据的单元与来源、针对各版的 review；可以预览、在 Finder 中显示、用默认应用打开，或把它直接拖出去。
- **预设**：每条流水线的默认配置，例如视频的 TTS 音色与画幅、html 的明暗。只记密钥所在的环境变量名，不记密钥。
- **记录**：顶部是需要处理的事（review 结论为待改、来源在上次 review 后变了、交付后所用的页、来源或预设又改过、产物文件找不到、最新版待改或不在约定位置、项目的最终产物没登记、新登记的来源还没挂上），下面是运行记录和维护记录。通常为空，有事时标签上显示数字。

来源没有写取用说明、没人 review 过，是默认状态：有人需要时再把来源摘要改写成说明。

## 其他 agent

同一组工具也经 MCP（`adapters/mcp.js`，stdio）和命令行（`adapters/cli.js`）提供，Claude Code、Codex 等 agent 读写的是同一个 Kit。

## 安装

```bash
dsh plugin --profile desktop add link:/path/to/dsh-praxis
```

装完重启 DeepSeek Harness。插件按包的位置找仓库；包被复制到别处时设置 `config.root`。`config.prompt: false` 关掉系统提示词里的入口段。
