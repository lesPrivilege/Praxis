# Streams · 自撰

一条 stream 是一页自撰：一个持续探索的方向，写自己的主张、还没定的问题和取用的 Kit 单元；它用到的来源挂在这一页上，一个来源可以同时挂在 Kit 页和几条 stream 上。

| 怎样用 | 做法 |
|---|---|
| 消费 | `praxis_resolve` 带 `stream`，得到这一页、它取用的单元和挂在它上面的素材；可与任务类型同用 |
| 新建 | 在本目录写一个 kebab-case 文件名的 Markdown：`# 标题`，下一段是 description，正文用反引号写出取用的 `kit/….md` |
| 挂来源 | `praxis_curate`，binding 写 `<来源 ID>@<这一页的路径>` |
| 修订 | 直接改文件，修改走 Git；不经覆盖层 |

正文以用户说过的话为准。Agent 提出、用户没确认的说法单列，不写进主张。成熟到能跨任务复用的部分，别裁进 Kit 单元或范例，这一页留链接。
