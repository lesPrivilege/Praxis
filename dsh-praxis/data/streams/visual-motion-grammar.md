# 视觉与运动语法

给界面、插画或 film 找视觉方向时打开；取“成熟语法加少量陌生化”这条主张、未决问题和取用的 Kit 单元。

状态：探索中，权重高，不预设终点；可以分化为文章、Kit 单元或 film 专章，也可以一直开着。

## 主张

1. 彩色粒子、点阵、光影、割线、纵深、blur glass 放在一起，常常是设计感的来源。
2. 这样的方式可以轻易收获设计感和高级感，之后只需要一点陌生化。
3. 陌生化不限于球体：任何几何形状、构图上优美的线条都是它的来源。
4. 周边的动效、色彩运用、运镜、构图、纵深结合在一起，对 film 同样有帮助。
5. 再收录不同的插画风格、色彩搭配、笔触质感，也只是陌生化的来源，不诞生新的体例。
6. 可以有限收敛地别篇裁出单独的经典做法，比如类 Anthropic 的插画风格；这不造成路径依赖。
7. 模型能够自然 one shot 之后，这条 stream 也不过时，它是扫盲和陌生化的来源。

## 还没定的

- 同一母题复用到什么程度会从语法变成模板。两张 ElevenLabs 海报是现成的对照：蓝色球面局部与橙红完整球体，构图和材质几乎相同。
- 第一件别裁选什么、落在 Design 的哪一页；类 Anthropic 插画还没有写。
- Design/Motion 与 Publish/video 要不要共用一页镜头语法。现在运动判断和视频制作分在两层，运镜没有固定的家。

## 候选

原 Chat 的助手提出，用户没有逐条确认，只作试用的线索：

- 六类原语：色场、粒子与点阵、线与切割、玻璃与光学、光影、纵深与构图。
- 尺度分工：宏观定构图，中观定材质与空间，微观定精致程度；低频色场与高频细节的反差。
- 陌生化的维度：形态、材质、空间、语义、构图，以及前后两帧之间的关系。
