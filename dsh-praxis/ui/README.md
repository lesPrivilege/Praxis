# 控制面

单个离线 HTML：[index.html](index.html)，无外部依赖。配色、圆角、发丝线和控件形状取 DeepSeek Harness 客户端的 design-platform 别名 token。嵌在 DSH 侧栏里时跟随 DSH 的明暗与界面语言（`<html lang>`），单独打开时跟随系统，右上角可切换中英文。界面文字有中英两套；Kit 正文、来源标题、说明与摘要保留原语言。由 [http.js](../adapters/http.js)提供，DSH 插件挂在 DSH 已认证的 `/api/praxis`（页面）、`/api/praxis.call`（调用）与 `/api/praxis.file`（产物文件），单独运行用 `node dsh-praxis/adapters/cli.js serve`。

| 页 | 做什么 |
|---|---|
| 目录 | 渐进披露：首页依次是核（Design、Writing）、Stream、下游工作流（Task、Publish）的卡片，“Kit 之外的挂载”和来源包列表（名称、格式、文件、条目数、用途，只读）；点开 stream 看它的说明、来源卡片和正文，点开层看领域，点开领域看单元，每一级只给 description 与计数，正文按需展开。单元页列出来源卡片：启用、收藏、检查来源（链接是否还在、内容是否变了）、删除（可恢复），改说明、取用题解、优先级与 tag，记录 review，查看来源条目；只有待改或来源已变时才出现提示。单元在用户数据里有修订时标“已修订”，写明理由与依据，可撤回修订。来源条目显示记录本身：形态与编目 description（及对它的 review）、链接、概要、读取范围、边界、何时重访、带定位的摘录、Kit 分类、所属集合；任何来源都可编目（改形态、Kit 分类与 description）与记录 review，自有来源另可编辑、写理由淘汰，集合另列成员账目：上游列出的全部成员链接，按已登记、不收录、未处理筛选，未处理的可登记或写理由不收录，已登记的点开即是它的条目；上游已下线的成员写理由淘汰；来源包里的条目只读，标明来自哪个来源包。Kit 之外的挂载按路径逐级展开。首页“登记来源”登记网页来源（URL、形态与说明必填，可选 Kit 分类、集合的成员链接模式、所属集合），单元页“来源”把已登记的来源挂上来 |
| 来源 | 来源编目：网页来源按 Kit 的层与区域分组，区域里再按形态（标准规范、成熟实践、组件库、案例库、单个案例、Skill、工具、文章、研究）分组；每条给标题、description、证据状态、所挂页数、信号与原件链接。区域默认只给各形态的条数，点开才列条目；可按形态筛选、按关键词找。点开一条即来源条目，在原处编目、review、编辑 |
| 任务 | 选任务类型、流水线与预设，可再指定一条 stream，列出要读的单元（附理由）、可取用的素材（网页来源）、服务这些单元的范例与管线、预设的值与验收 |
| 产物 | 本地产物分三类：交付、管线（再做同类交付的方法）、范例（为示范某种做法预先做的样张），最近变动在前，可按名称、说明或路径找，按种类筛选；有未登记改动、找不到文件或待改时标出。详情列“服务的页”：它在哪些 Kit 页上作为范例、何时对照，点开即到该页。详情：预览、在 Finder 中显示、打开（嵌在 DSH 里时交给 DSH；单独运行时只有预览），版本时间线（每版的运行、所用单元与来源、派生自、产出它的管线、依据是否已变；最近一次 review 标在它针对的版本上），对当前版本记录 review，改名称与说明、移除。列表行和详情顶部可直接拖出文件 |
| 预设 | 按流水线维护默认配置：video 的 TTS provider、音色、语言、语速、画幅、风格、方向；html 的模板、明暗、打印与离线要求；每条流水线可设一个默认 |
| 记录 | 顶部“需要处理”，通常为空：待改或来源已变的挂载、交付后所用单元、来源或预设又改过的运行、编目放不下的自有来源（没有形态，或既无 Kit 分类也未挂到页面）、review 待改或来源变了而挂载上看不到的编目条目、集合上游新增的链接（登记或不收录）与已下线的成员（淘汰）、与包里更新后的原页冲突的单元修订（打开或撤回）、找不到文件或最新版待改的产物；有事时标签上显示数字。下面是运行记录和维护记录 |

未写说明、未 review 是默认状态，不算缺口，不计数：来源摘要在有人需要时才改写成取用说明。

页面上的每个操作都调用 agent 用的同一个工具；修改带 revision，被别人先改了会提示并载入最新版本。
