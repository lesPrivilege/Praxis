# 控制面

单个离线 HTML：[index.html](index.html)，无外部依赖。配色、圆角、发丝线和控件形状取 DeepSeek Harness 客户端的 design-platform 别名 token。嵌在 DSH 侧栏里时跟随 DSH 的明暗与界面语言（`<html lang>`），单独打开时跟随系统，右上角可切换中英文。界面文字有中英两套；Kit 正文、来源标题、说明与摘要保留原语言。由 [http.js](../adapters/http.js)提供，DSH 插件挂在 DSH 已认证的 `/api/praxis`（页面）、`/api/praxis.call`（调用）与 `/api/praxis.file`（产物文件），单独运行用 `node dsh-praxis/adapters/cli.js serve`。

| 页 | 做什么 |
|---|---|
| 目录 | 渐进披露：首页是四层卡片（一句话说明 Kit 是整合包）和“Kit 之外的挂载”；点开层看领域，点开领域看单元，每一级只给 description 与计数，正文按需展开。单元页列出来源卡片：启用、收藏、检查来源（链接是否还在、内容是否变了）、删除（可恢复），改说明、取用题解、优先级与 tag，记录 review，查看来源条目；只有待改或来源已变时才出现提示。Kit 之外的挂载按路径逐级展开。首页“登记来源”登记新来源，单元页“来源”把已登记的来源挂上来 |
| 任务 | 选任务类型、流水线与预设，列出要读的单元（附理由）、可取用的素材、预设的值与验收 |
| 产物 | 交付过的文件，最近变动在前，可按名称、说明或路径筛选；有未登记改动、找不到文件或待改时标出。详情：预览、在 Finder 中显示、打开（嵌在 DSH 里时交给 DSH；单独运行时只有预览），版本时间线（每版的运行、所用单元与来源、派生自、依据是否已变、该版的 review），对当前版本记录 review，改名称与说明、移除。列表行和详情顶部可直接拖出文件 |
| 预设 | 按流水线维护默认配置：video 的 TTS provider、音色、语言、语速、画幅、风格、方向；html 的模板、明暗、打印与离线要求；每条流水线可设一个默认 |
| 记录 | 顶部“需要处理”，通常为空：待改或来源已变的挂载、交付后所用单元、来源或预设又改过的运行、新登记还没挂上的来源、找不到文件或最新版待改的产物；有事时标签上显示数字。下面是运行记录和维护记录 |

未写说明、未 review 是默认状态，不算缺口，不计数：来源摘要在有人需要时才改写成取用说明。

页面上的每个操作都调用 agent 用的同一个工具；修改带 revision，被别人先改了会提示并载入最新版本。
