# 付款复核台 · 后端

[场景契约](../../scenarios/payment-review.md)的实现，挂在 [内核](../README.md)上，接口在 `/api/payment`。

| 文件 | 职责 |
|---|---|
| `store.ts` | 内存状态的形状：事项、材料及其各个版本、预制的机器提议、人的记录；fixture 的自洽检查 |
| `domain.ts` | 三条检查规则、视图和三个动作；不涉及 HTTP |
| `scenario.ts` | 路由、列表查询的校验、一位按脚本并发提交的同事 |
| `payment.test.ts` | 19 项 |

检查结果不存储：每次读取时对材料的当前版本重新算，所以材料一变结果就变。事项是“待补件”还是“可提交”也由检查结果当场得出，存下来的只有“尚未提交、待复核、已决定”这三个由人的记录决定的阶段。

金额只在同一币种内比较，全程是最小货币单位的整数；这里没有任何换算。
