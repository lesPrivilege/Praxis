# 实现 ADR · 本 demo 的技术栈

状态：只对本目录有效。没有经过 Kit 的裁决，不进 `docs/decisions` 的编号，也不改变 Kit 里技术栈“候选、未裁决”的状态。编订：Opus 5.5 主会话。日期：2026-10-04。依据：用户同日转来的收尾建议，其中第 2 条建议写一份简短、限定于 demo 的记录。

具体版本见 [实现说明的版本表](demo.md#版本)，每一项没有采用的做法见 [同页的取舍表](demo.md#选了什么没选什么)。这里只记决定、换掉它们要动哪里，和还没有验证的能力。

## 决定

| 层 | 采用 | 理由 |
|---|---|---|
| 契约 | OpenAPI 3.1：一份公共片段，每个场景一份并引用它；由 openapi-typescript 生成类型，前后端共用 | 契约先于代码。两轮里有两处前后端不一致是类型检查和契约测试当场拦下的（第一轮 F01、F02） |
| 假后端 | 独立的 HTTP 进程，只用 Node 自带的 `node:http`，直接运行 TypeScript，没有框架和运行时依赖 | 进程有状态，能真实地断开连接、延迟、跑后台作业、让另一个人并发修改；前端和它之间只隔一个地址 |
| 界面 | React 加 Vite 的单页应用；直接组合 Ant Design，没有在它上面再包一层 | Kit 的候选方向；两个场景之前不建组件库 |
| 服务端状态与地址 | TanStack Query 管读取与失效；react-router 管地址里的状态、离开前的拦截和滚动位置；openapi-fetch 作客户端 | 查询、选中的对象和依据引用都放在地址里，刷新和返回不丢 |
| 测试 | `node:test` 经 HTTP 断言后端行为；ajv 按契约校验每一个响应 | 测试走的是和前端同一个接口，换一个地址就能对另一个后端跑 |

## 替换边界

| 要换的 | 要动的 | 不用动的 | 这个说法的依据 |
|---|---|---|---|
| 后端 | 启动前端时把 `API_TARGET` 指向新服务 | 前端全部代码 | 只有结构上的依据，没有第二个后端跑过。新后端要实现契约的全部，包括尝试编号、尝试回查、随对象返回的可做动作和下一步 |
| 身份 | `web/api/persona.ts`、`web/workbench/PersonaProvider.tsx`、内核里读请求头的那一段 | 页面 | 演示身份是一个请求头，接真实认证时这三处重做 |
| 组件库 | 引用它的 24 个文件：`web/workbench` 的 9 个组件、两个场景的 12 个页面文件、`main.tsx`、`Workbenches.tsx`、`theme.ts` | `web/api`、各场景的 `routes.ts`、`labels.ts`、`money.ts`，契约，后端 | 换组件库等于重写界面层。没有包一层是有意的：一层只有一个实现的抽象挡不住什么 |
| 服务端状态库 | 两个场景的 `api.ts`、`web/api/attempt.ts`、`Loaded`、`PersonaProvider`，以及直接用了它的三个事项工作台页面 | 付款复核台的页面只经 hooks 取数 | 事项工作台的三个页面是第一轮留下的，没有收回接口模块 |
| 路由库 | 引用它的 17 个文件：`main.tsx`、两棵路由树、两个场景的多数页面、`ActionPanel`（离开前的拦截）、`AppShell`、`CommandPalette` | `web/api`、`routes.ts` 里地址与查询的互转 | 地址即状态是结构性的选择，换库的面很大 |
| 类型生成器 | `package.json` 里的 `contract` 一条脚本 | 其余全部 | 只消费生成的类型，没有生成的客户端、handler 或假数据 |
| 运行方式 | 改成先编译再运行不需要改代码 | | 后端只用可擦除的类型语法，`tsconfig` 里强制 |

假后端独有、真实后端不必实现的：`/__fake/reset`、fixture 里的 `behaviors`（延迟、失败、响应丢失、同事并发提交）。

## 没有验证的能力

- 生产构建（`vite build`）没有运行过。
- 可替换性没有试过：没有第二个后端，没有真实认证，没有持久化。尝试记录在进程内存里，重启即失，幂等的保证止于这个进程的一次运行。
- 前端组件测试用什么跑还没有选。现在只有纯函数的测试；动作面板和尝试状态机两个场景都靠，没有测试。
- Storybook、Playwright 和截图基线都没有装。
- Ant Design 6 在读屏和真实文字缩放下的表现没有检查；只在应用内置的 Chromium 里看过。
- Node 只实测了 25.9.0。README 写的“24 以上”是按类型剥离的可用版本推的，没有在 24 上跑过。
- TypeScript 停在 5.9.3：openapi-typescript 7 要求 `typescript@^5`。升级要等它，或换类型生成器。
- 数据量：列表最多十几行，没有试过虚拟滚动和大分页。界面只有中文。

## 何时重访

接一个真实后端时；出现第三个场景时；要做视觉回归或逐状态审阅时；Kit 对技术栈作出裁决时，这份记录让位于那份裁决。
