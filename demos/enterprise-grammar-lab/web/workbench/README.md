# 工作面

这里的组件不出现事项、风险、付款等业务词，不调用任何场景的 hooks，只依赖 [work.yaml](../../contracts/work.yaml)里的公共类型。业务词由调用方以标签表传入，数据由调用方作为属性传入。两个场景都在用。

| 组件 | 回答的问题 | 事项工作台 | 付款复核台 |
|---|---|---|---|
| `AppShell` | 在哪个环境、以谁的身份、在哪里 | 用 | 用 |
| `PersonaProvider` | 先选定演示身份，再放行其余请求 | 用 | 用 |
| `ObjectHeader` | 这是哪个对象的第几版，页面上这份是什么时候取的 | 用 | 用 |
| `Loaded` | 面板拿到数据之前的状态：读取中、失败、无权、空；刷新失败时保留旧内容 | 用 | 用 |
| `ActionPanel` | 现在能做什么，以及做它的表单：表单绑定读过的版本，对象变了先核对；换动作清空；取消丢弃；离开前拦一下 | 用 | 用 |
| `ActionBar` | 后端说现在能做什么；不能做的写出规则和例外找谁 | 经 ActionPanel | 经 ActionPanel |
| `RuleViolations` | 一条不允许的理由：说明、规则与版本、例外归属 | 用 | 经 ActionPanel |
| `AttemptNotice` | 一次尝试的结果：等待确认、已生效、被拒、版本冲突、结果未知 | 用 | 经 ActionPanel |
| `AuditTimeline` | 谁在何时对哪个对象的哪一版做了什么，检查了哪些规则，属于哪次尝试 | 用 | 用 |
| `CommandPalette` | 按编号或名称跳到对象或视图 | 用 | 用 |

按 [晋升规则](../../../../docs/decisions/002-promotion.md)，这些组件现在有两个独立场景在用，是候选，不是已晋升的 Kit 组件。[Kit 的候选清单](../../../../kit/ui/README.md)里的名字和这里对不上，差异见 [施工发现](../../evals/README.md)。

没有进这里的：列表页的筛选与分页、依据抽屉、检查结果列表、金额。前者两个场景各写了一遍，是下一批候选；后三者只有一个场景用。
