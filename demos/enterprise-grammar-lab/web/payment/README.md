# 付款复核台

[场景契约](../../scenarios/payment-review.md)的界面。接口模块、用词、地址和页面都在这个目录里。

| 文件 | 页面或部件 |
|---|---|
| `api.ts` | 这个场景的请求客户端、读取 hooks 和三个动作，按 [payment.openapi.yaml](../../contracts/payment.openapi.yaml)生成的类型 |
| `labels.ts`、`routes.ts`、`money.ts` | 用词；地址规则；金额的显示与录入 |
| `PaymentApp` | 路由树和外壳 |
| `CaseListPage` | 复核事项列表：按状态、复核员、期限和金额范围查询，查询在地址里 |
| `CasePage` | 事项页：复核、材料、记录三个投影 |
| `CaseActions` | 提交复核、接受、退回的字段；提交前列出结论、所依据材料的版本和接收人 |
| `EvidenceDrawer` | 按“材料、版本、位置”打开一处依据 |

复核页把三种来路的话分在三处：左边是规则检查（带规则编号和版本，不能改）；右边依次是机器提议（竖线标出，写明机器生成、基于哪一版材料）和人的判断（提交、退回、接受的记录）。

金额录入按币种的最小单位换算，用的是数字串而不是浮点数。按金额筛选要先选币种；换币种时已填的范围清掉。

地址即状态：`/reviews/PR-4101?file=F-2103&fv=1&at=amount` 直接打开发票第 1 版的金额栏。
