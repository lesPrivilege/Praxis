# 接口层的公共部分

这里没有任何请求地址，也不引用任何场景的契约，只用 [work.yaml](../../contracts/work.yaml)生成的公共类型。每个场景在自己的 `api.ts` 里建客户端、写读取 hooks 和动作，再用这里的部件。

- `core.ts`：请求的两种失败。后端明确拒绝时是 `ApiError`（带契约里的 `Problem`）；没有得到契约定义的答复时是 `TransportError`，包括断线、超时和网关错误。
- `attempt.ts`：一次动作尝试从提交到结果确定的状态机。提交时生成尝试编号；`TransportError` 和 5xx 都不算失败，进入“结果未知”，先向后端回查这次尝试，后端说没收到才允许用同一编号重发。怎样发送、怎样回查由场景传入。提交进行中和结果未知时，关标签页或刷新会先请求浏览器确认，因为尝试编号只在这个页面里。
- `persona.ts`：演示身份。每个场景各存各的，互不影响。

动作生效或被拒之后，所有查询作废重取：一次动作可能改动页面上任何对象，被拒也可能说明页面内容已经落后。读取失败不自动重试，由面板显示错误和重试按钮。
