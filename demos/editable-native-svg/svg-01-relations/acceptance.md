## 独立复查

Sonnet 子代理只读代码和产物，自己构造输入运行生成器，报告了 15 项经运行确认的问题和 4 项读代码得出的问题。主会话逐项核对后全部采纳，修改如下，B02、B03、A11b、X01、P07、P08 是为此新增的检查。

| 复查发现 | 处理 |
|---|---|
| 绑定的第二个依据处一律画实线，被拒绝或未成立的看起来像已成立 | 接线随状态用虚线，文字写出状态 |
| 已作出的决定也用了蓝色，与“蓝色只留给等人决定的那一处”不符 | 只有待定用蓝色 |
| 片段括线量的是整行，分不清限定的是哪一处下划线 | 限定语标题引出片段原文，如“条件 · 限于‘两个工作日’” |
| 未知的 `state` 被画成已成立 | 拒用 |
| `no_default` 的理由和整张图共用的依据只在等效文字里 | 画进图的下方；`no_default` 与默认分支并存时拒用 |
| 汇合的输入可以带“默认” | 拒用 |
| F02 的非法事件序列被照常折叠，或直接报错 | 拒用，代码为 `illegal-event` 或 `conflict` |
| 空片段变成整项主张；只含换行的片段算出 NaN | 拒用 |
| 只限定片段的证据被当成整项主张有了证据 | 仍标“证据 · 尚无” |
| `container: null` 与不写容器被当成两个范围 | 视为同一处，拒用 |
| 关系、对象、限定语的 ID 互相重名时文字键和外框互相覆盖 | 底层统一检查，拒用 |
| 没有 `title` 时输出 `undefined`；ID 含空白；U+FFFF 使 XML 不合法 | 分别拒用、拒用、去掉 |
| 一个成员接六条跨界关系时接点排到框外 | 每个成员最多四条，超出拒用 |
| 行首禁则带字后可能超宽 | 带下来的字放不下时单独成行 |
| 图例把虚线只说成“尚未成立” | 改为“尚未成立、尚未核对或没有生效” |
| “每项至多 5 条限定”没有对应输入 | 增加五条来源的压力输入，表述改为实际测到的范围 |
| A07 只查属性不查位置；P06 不查片段行；A11 只测了一个生成器 | 新增 P07、P08、A11b |

修改之后没有再做第二轮独立复查。

## 剩余的问题

- R09 的状态转移图、R10、R18 的字段映射没有画，理由和去向见 [作品 README](README.md#任务与取舍)。
- `rel-qualify` 的宽版里，主张列按最宽的一项收窄，较短的主张离括线仍有一段距离。
- `rel-scope` 的跨界关系用编号对应图下的说明行，读者要在图和说明之间对照一次；关系多于三四条时会吃力。
- `rel-tracks` 的版本按先后等距排列，不能表达时长，这一点只写在生成器注释和预览页的“不适用”里，图上没有标。
- F01 的 `proposal` 没有 `basis` 字段，适配时按最新材料版本绑定；材料再多一个版本时，这个假设会和它的文字“复核 v2”不一致。
