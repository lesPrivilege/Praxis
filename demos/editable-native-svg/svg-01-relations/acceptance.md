2026-10-04，Praxis `9514ce4` 之上的分支 `claude/editable-native-svg-01-20261004`（已并入本地 main），fixture 修订 `20261004-r1`，资产版本 `0.1.0`。制作与自动检查由 Claude Opus 5.5（`claude-opus-5-5`）完成；独立复查由一个只读的 Claude Sonnet 子代理完成，它没有看到制作方的结论。环境：macOS，Node v25.9.0，Chrome 154 无界面模式，xmllint。没有安装任何依赖。

## 独立复查

Sonnet 子代理只读代码和产物，自己构造输入运行生成器，报告了 15 项经运行确认的问题和 4 项读代码得出的问题。主会话逐项核对后全部采纳，修改如下，B02、B03、A11b、X01、P07、P08 是为此新增的检查。

| 复查发现 | 处理 |
|---|---|
| 绑定的第二个依据处一律画实线，被拒绝或未成立的看起来像已成立 | 接线随状态用虚线，文字写出状态 |
| 已作出的决定也用了蓝色，与“蓝色只留给等人决定的那一处”不符 | 只有待定用蓝色 |
| 片段括线量的是整行，分不清限定的是哪一处下划线 | 限定语标题引出片段原文，如“条件 · 限于‘两个工作日’” |
| 未知的 `state` 被画成已成立 | 拒用 |
| `no_default` 的理由和整张图共用的依据只在等效文字里 | 画进图的下方；`no_default` 与默认分支并存时拒用 |
| 汇合的输入可以带“默认” | 拒用 |
| F02 的非法事件序列被照常折叠，或直接报错 | 拒用，代码为 `illegal-event` 或 `conflict` |
| 空片段变成整项主张；只含换行的片段算出 NaN | 拒用 |
| 只限定片段的证据被当成整项主张有了证据 | 仍标“证据 · 尚无” |
| `container: null` 与不写容器被当成两个范围 | 视为同一处，拒用 |
| 关系、对象、限定语的 ID 互相重名时文字键和外框互相覆盖 | 底层统一检查，拒用 |
| 没有 `title` 时输出 `undefined`；ID 含空白；U+FFFF 使 XML 不合法 | 分别拒用、拒用、去掉 |
| 一个成员接六条跨界关系时接点排到框外 | 每个成员最多四条，超出拒用 |
| 行首禁则带字后可能超宽 | 带下来的字放不下时单独成行 |
| 图例把虚线只说成“尚未成立” | 改为“尚未成立、尚未核对或没有生效” |
| “每项至多 5 条限定”没有对应输入 | 增加五条来源的压力输入，表述改为实际测到的范围 |
| A07 只查属性不查位置；P06 不查片段行；A11 只测了一个生成器 | 新增 P07、P08、A11b |

修改之后没有再做第二轮独立复查。

### 0.3.0 的独立复查

一个只读的 Claude Sonnet 子代理拿到源码、输入、检查脚本和 Kit 页面，自己运行生成器，不看本回执。它报了 13 组问题，运行确认的 11 组。处置如下。

| 复查发现 | 处置 |
|---|---|
| 三栏的时间图里，栏名长到折行时压住第一行文字和标尺的起点 | 标尺从最高的栏名下面开始；加了一份折行栏名的压力图进浏览器段 |
| 首尾相接的两个区间画在同一个小栏里，并成一条；很短的区间以开始时刻为中心画成 3 高，起点提前 | 首尾相接的分到两个小栏；条一律从开始时刻画起，短到看不见的留最小高度并在读法里说明；条加纸色描边，挨着的两条分得开 |
| `2026-04-31`、`T24:00` 被接受并悄悄挪到别的日子；`scale.offset` 写 `+99:99` 也被接受 | 逐个字段核对，不存在的日期、钟点、偏移一律拒用 |
| 写了秒的时刻，文字只到分；时长四舍五入；图里从不写日期和年份 | 有一行写了秒，所有时刻都写到秒；时长不舍入；读法里写标尺从哪年哪月哪日哪一刻起 |
| `rel-pair`：版本不是数时“选取之后才有”的判断失效；选取依据比源还新、后一份比前一份旧也照画；同一个对象两边名字不同；只差空格算“已改”；`pending: "false"` 当成待定；指向写错字段时图和摘要不一致；全选、空选时摘要自相矛盾 | 逐项拒用或改正，各有断言 |
| 组合图里，指向某个对象的依据会被连到同名的字段上；时间图里的依据拉过来的横线穿过标尺，像一个刻度；组合图没有说明各件之间位置表示什么 | 行和字段不参与指向的匹配；时间图里的依据只留作文字，等效文字里说明它画在哪一件里；组合图图脚加一句 |
| 输入里的 `data` 键不转义，能注入属性，还能盖掉生成器自己写的属性 | 只接受 `data-*` 形式的键，否则拒用；生成器的属性在前，输入的不能覆盖 |
| 并排的栏里行自己的正文和依据被悄悄丢掉；没有栏却写了 `cells` 或 `lane`；正文写成对象或数字 | 写了却画不出来的字段一律拒用 |
| 一串大写的 W、M 实际比估算的宽，溢出预留宽度 | 估宽调大；加了三张全是宽字母的图进浏览器段 |
| 名叫 `__proto__` 的行没有位置；带 U+FFFF 的两个 id 写成同一个属性值；`null` 输入抛出类型错误 | 分别改正、拒用、拒用 |
| 只有一条版本线时仍写“不同的线之间”；没有任何下级时仍写“缩进表示”；“各栏共用这一条标尺”而图上每栏各有一条轨 | 读法按图里实际的情形分别写；改为“各栏的轨按同一条标尺排” |
| 检查偏松：读法只比开头十二个字；P09 放过 3 高以内的区间、不查引线的横向落点；P10 认不出挂错上级；窄版对照表没有浏览器检查 | 逐项收紧，各加一张对照图 |

没有处理的两项：一个时刻落在一个区间里面时，它的引线从区间的条后面穿过去；单位写在值的文字里（“60 分钟”对“1 小时”）时只能当文字比较，要让生成器把关须把单位写进 `unit`。修改之后没有再做第二轮独立复查。

## 没有运行的

- 编辑器往返（A12）：没有在任何图形编辑器里保存再打开，不声称支持哪个编辑器。
- 读屏与键盘（A10）：每张图有 `title`、`desc` 和预览页里的等效文字列表，没有用读屏软件实测；图本身不可交互，没有键盘路径要测。
- Motion（A13）：0.3.0 有了时间图，但只有静态的；F04 的播放帧率和时长没有取用，暂停、seek 和静态终态的对照没有做。
- 量与口径（A06）、组合与职责（A09）：属于 SVG-02 和 SVG-03。
- Safari、Firefox 和非 macOS 平台：没有测。文字估宽依赖字体，换平台后应重跑浏览器段。
- Flash 或其他 Agent 的陌生消费、真实读者的理解效果：没有做，本批不预设效果。
- 双向文字、深色背景、A4 纸张：没有测。

## 剩余的问题

- R09 的状态转移图没有画；R10、R18 在 0.3.0 画出；R16、R19、R33 只画了一部分，归属仍在 SVG-02。理由和去向见 [作品 README](README.md#任务与取舍)。
- `rel-qualify` 的宽版里，主张列按最宽的一项收窄，较短的主张离括线仍有一段距离。
- `rel-scope` 的跨界关系用编号对应图下的说明行，读者要在图和说明之间对照一次；关系多于三四条时会吃力。
- `rel-tracks` 的版本按先后等距排列，不能表达时长。0.3.0 起这句读法写在图脚；要比较不同对象的先后，用 `rel-rail` 的时间标尺。
- `rel-fan` 的分支上下次序有没有含义，图里仍然没有写。
- 时间图一律竖排，没有断轴，没有“现在”的记号；时长本身是区间（“一到三个工作日”）时不能画。
- F01 的 `proposal` 没有 `basis` 字段，适配时按最新材料版本绑定；材料再多一个版本时，这个假设会和它的文字“复核 v2”不一致。
