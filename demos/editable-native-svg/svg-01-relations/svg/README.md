# 生成的 SVG

本目录由 `node src/build.mjs` 生成，不要手改；要改图，改输入后重建。文件名是 `输入 ID--w宽度.svg`，每份输入有宽、窄两个版本：窄版 288，宽版 672（`rel-scope` 为 480）。

每个文件是独立的静态 SVG：带 `xmlns` 和 `viewBox`，文字是 `<text>` 与 `<tspan>`，不含脚本、样式表、外部引用或字体文件，字体取系统字体。根节点的 `id` 就是这个实例的作用域，其余 ID 都以它为前缀。

[manifest.json](manifest.json) 记录每个文件的尺寸、各对象的外框（`boxes`）、各文字标签的位置与排版时留的宽度（`labels`）、括线范围（`brackets`）以及等效文字，另有被拒用输入的代码和理由。
