# 需求覆盖与组合判断

本轮枚举 44 项表达需求：22 项独立关系候选、14 项组合、8 项暂不独立抽取。数字表示研究范围，不是资产数量或效果。独立原子能在另一内容与另一容器中修改同一关系；组合需要共享尺度、版本、规则或阅读顺序；没有独立表达职责或更适合宿主原生内容的部分暂不抽取。绘制可合并候选，一个需求不强制对应一个文件。

[机器登记](catalog.json)是字段源；下表为本轮可读投影。输入、编辑维度、压力边界、拒用条件和逐项依据在 JSON，`artifact_entry` / `preview_entry` 全为空，不能据此宣称已有 SVG。研究依据 L/S 的解释在 [研究页](../../vault/distilled/editable-native-svg-20261004/README.md)。

## 从任务系统得到覆盖

| 真正要完成的任务 | 重点需求 | 必须保持的组合关系 |
|---|---|---|
| 解释、请求或记录决定 | R01–R08、R17、R26 | 主张、条件、证据与人判断分开；箭头不偷换为因果或授权 |
| 定义实现、解释运行和交接 | R02/R03/R05/R09、R23–R25 | 条件决定合法路径；责任、接收依据、事件与权威状态各自保留 |
| 证明有效、比较方案与复盘 | R10–R16/R21/R22、R28–R30/R34–R36 | 同口径、共同尺度、缺失与未知、前后差异及方法说明不能随组装丢失 |
| 寻找层级或空间位置 | R04/R05/R19/R20、R31/R32 | 拓扑、度量、范围、参照和标签分别表达，不能让空间暗示未定义权限 |
| 说明时间、版本与证据适用性 | R08/R16–R18、R25/R27/R33 | 事件时间、持续区间、播放时间、事项版本、材料版本和阅读依据独立 |
| 跨屏幕、注释、静态与动态改编 | 全体所用关系，尤其 R06/R07/R14/R17/R21 | 文字与几何可分别改；来源与必要限定在判断前可见；降级仍能完成任务 |

关系、流程、状态、数量、比较、层级、空间、注释、证据、时间已作为交叉搜索空间覆盖，未固化为最终分类或十套目录。来源不是关键词清单：工作语法与 Reporting 提供实际任务，既有实验提供成功与失败压力，外部资料仅支持图形机制与接口边界。

## 组合不是拼贴

- R24 把候选、条件、依据、版本与决定合成闸门；同一节点身份贯穿，拒绝留在历史但不改变当前状态。
- R27 用 R08/R10/R17/R26 显示独立版本。材料 v2 到达而事项 v8 不变时，基于材料 v1 的阅读说明仍指向 v1；新材料不得继承“已阅读”或旧说明。
- R28/R29/R34 共享尺度、单位、分母与缺失语义；图例和说明可合并，不能丢掉各对象不同的口径或方法。
- R31/R32 共用身份与空间参照；跨图连接由组合层解释，避免每个原子用自己的全局坐标。
- R33 的区间与 R09 的状态按真实语义关联；进度动画不能决定完成状态。R36 只有在流量与收支定义成立时采用，普通流程无需画成 Sankey。

`compose_with` 表示值得试的相邻关系，不是已经兼容或必须一起读。端口、bounds、注释槽位、标题/来源/方法由谁输出须在实际作品写清。共存先检验 ID/CSS 和语义不变量，再看图判断阅读关系；不能据零溢出宣称解释成立。

## 覆盖边界与停止条件

本轮到达可以给 Opus 开第一批工单的程度。没有穷举所有图型、行业符号、地理数据、编辑器插件或视觉语言；也没有查遍 280 个旧变体。新增资产的理由是解决具体未覆盖判断、编辑失败或组合冲突，不能以补齐分类格子为由继续堆件。

压力参数、可访问性和 Motion 接口见 [合同](delivery-contract.md)，反例与正常/失败输入见 [验收](acceptance.md) / [fixtures](fixtures.json)。未知容量、许可未核、未运行 Flash 和受众效果仍保持未知。
