# 两条关系语法的样板

2026-10-04，图件版本 `0.2.0`。这一页用同一份合成内容（一张破损古籍的调阅单）演示 Kit 里的两页判断怎样落到材料上：[成立程度与归属的标记](../../../kit/design/foundations/standing.md)和 [精确指向](../../../kit/design/foundations/anchoring.md)。每条语法做三级：只用文字，一张图，几张图连成一张；另各附一个反例。

| 当前需要 | 入口 |
|---|---|
| 看样板 | [index.html](index.html)，可直接用 `file://` 打开，不需要 JS 和网络 |
| 改内容 | 改 [sheet-rare-book.json](../svg-01-relations/inputs/sheet-rare-book.json)，先在 `svg-01-relations` 里运行 `node src/build.mjs`，再在本目录运行 `node build.mjs` |
| 取用单张图 | [svg/](svg/README.md) |
| 读生成器 | [svg-01-relations/src](../svg-01-relations/src/README.md) |

## 这一页想让人带走什么

第一级是普及的部分：每句话后面写清“谁说的、成立到哪一步”和“对象 版本 位置”，表格和正文都做得到，不需要任何图件。后两级是提高的部分：同样的信息由线型、端点、括线和连线重复一遍，读者更快看见，但不多出一句新内容。页面上的两张第一级表格与下面的图由同一份输入生成，可以逐行对上。

第三级的组合图是本页最想给人看的一张。“审核通过”这条证据连到规则 v2，分支的依据和新证据连到 v3；审核依据的是旧版规则这件事，没有哪一句话专门去说，是指向自己显出来的。

## 取舍

- 配色和线型沿用第一批：浅冷色，正文墨色，一种蓝只标等人决定的那一处。跨件的连线用最浅的一档灰，主干走在内容左侧的留白里，因为它只是文字指向的重复，不该和各件自己的线争。
- 反例“一条虚线回答三个问题”是照着第一批真实出过的毛病画的，不是凭空设想。
- 默认画法那张表写明了它只是这一族关系图的默认。
- 页面文字按 [Write / Prose](../../../kit/write/prose/README.md)写：先说做法，再给图；表头和小标题用名词短语。

## 范围与限制

内容是合成的，不是真实馆务。样板、生成器和两页 Kit 条目出自同一名制作者，没有读者或专业人员看过。验收范围见 [验收回执](../../../docs/verification/relation-grammar-20261004.md)。本目录的图由 `svg-01-relations` 的生成器画，几何和安全检查在那边的 `node src/check.mjs` 里做，组合图那份输入也在检查之内；本页自己的两张单件图和反例图只看过渲染结果。
