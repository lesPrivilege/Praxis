# 工单 · 承载稳定语义的记号、控件与运动

状态：2026-10-12 写成，待用户交给独立的 ClaudeDesign。全文自足，可以整段粘贴；能读到本仓库时再看第 8 节列的路径。成果回交后是候选，经用户 review 再登记进 Kit 的 Design 分支。

## 1 目的

以后做讲解页、报告和知识片的人或 agent，需要一套可以直接取用的小件：一看就知道“这是数据库”“这一步在等人”“这条关系还没生效”“东西从这里流到那里”。这些含义在不同主题之间不变，适合画一次、反复用。

服务两种编排：HTML（可交互、可打印）和 video（逐帧渲染的画面）。同一个含义在两边用同一个造型和同一种运动。

要的是一套稳定的 grammar，外加一版参考画法。grammar 是每一项的含义、它和别的项怎样区分、哪些约束换了造型也不变；画法是这一版的造型、色值和时长。两者分开写。以后的任务可以直接取用这一版，可以只取其中几项，也可以按同一套 grammar 重新画；这套东西不限制下一次开工的选择。

## 2 要交的四组

清单是起点。可以增、删、合并，说明理由；没有稳定含义的不画，不为凑数。

### A 记号

每个记号对应一个词。

| 类 | 建议的词 |
|---|---|
| 对象 | 人、浏览器、终端、聊天渠道、定时器、webhook、网关、服务、agent、subagent、模型、工具、skill（说明文件）、中间件（层）、队列、数据库、文件、目录、记忆、checkpoint（快照）、artifact（交付文件）、沙箱（隔离环境）、容器、外部服务、密钥、锁 |
| 状态 | 默认开、默认关、可选、已完成、进行中、等人决定、已拒绝、已过期、出错、警告、结果未知、未核实 |
| 流程 | 分支、合并、循环、重试、排队、上限、压缩、外置、注入、流式、广播、回滚 |

### B 关系画法

线和端点的一套可复用定义：实线与虚线，实心、空心、叉、无端点四种端点，箭头，以及由同一份输入生成图例的约定。

### C 控件（HTML）

| 控件 | 承载的含义 |
|---|---|
| 步进器 | 上一步、下一步、播放与暂停、当前第几步 |
| 轨道 | 一排站点和一个移动的标记，表示“从哪里到哪里” |
| 分段单选 | 几个互斥的预设 |
| 可点选的节点与说明面板 | 选中一个对象，看它的说明 |
| 展开与收起 | 细节层；可以一次全部展开 |
| 标签 | 默认开、默认关、可选、未核实 |
| 按属性对照 | 少量对象在共同属性上比较；窄屏按属性分块，对象的位置和顺序不变 |
| 时间线 | 有先后的几个节点；窄屏改成竖排 |
| 阅读进度线 | 读到页面的哪里 |
| 试算 | 滑杆输入加按规则算出的结果 |
| 计时条 | 真实在走的计时 |

每个控件给出状态矩阵：正常、悬停、键盘焦点、选中、禁用，以及没有脚本时和打印时的样子。

### D 运动语义（HTML 与 video 共用）

| 运动 | 表达的变化 |
|---|---|
| 移动 | 一个东西从 A 到 B |
| 流向 | 沿一条线持续流动的方向 |
| 出现与退出 | 对象加入或离开 |
| 状态切换 | 同一对象从一种状态变成另一种 |
| 标出当前 | 读者或叙述此刻所在的位置 |
| 等待 | 停在这里，等人或等外部结果 |
| 循环一轮 | 同一组步骤再走一遍 |
| 入队与出队 | 排队、被取走、被丢弃 |
| 收拢与展开 | 多项压成一项，或一项展开成多项 |
| 计时 | 时间在走；只用于真实的计时 |

每种运动写明：含义；可调的参数（时长范围、曲线）；HTML 里怎样实现；写成“时间 t 的函数”的形式，供逐帧渲染在任意一帧定格；减弱动效时用什么替代，替代要保留反馈；什么情形不该用。

## 3 必须守住的语义

造型怎样变，这几条不变。

1. 记号是一个词的重复。它旁边总有文字；去掉记号，内容不变。
2. 一种画法只回答一个问题。默认的分配：线型回答“生效了吗”（实线是已经成立，虚线是尚未成立或没有生效）；端点回答“确认了吗”（实心已确认，空心未确认，叉是已拒绝，没有端点是这一项还不存在）；强调色只用在“等人决定”的那一处；“是谁说的”用文字或位置，不占画法。
3. 供读者点选或步进的图里，强调色可以改作“当前选中”，写进图例；它和“等人决定”不出现在同一张图里。
4. 颜色不单独承担区别。去色、文字放大到 200%、调整间距之后，区别仍然看得出。
5. 被拒绝的和已过期的仍然留在图上，看得出它存在过，也看得出它没有生效。
6. 没有真实进度时不画百分比和预计完成时间。“结果未知”是一种独立的状态，不等于失败，也不等于进行中。
7. 必要的信息不能只在悬停时出现。焦点和操作结果看得见。
8. 运动只用来表达状态切换、空间位置、关系变化或叙事时间。它和真实状态同步，可以被打断；两个数值之间的补间是过渡，不是数据。
9. 图例只列这张图里实际出现的画法。

## 4 形式约束

- 原生 SVG：`<symbol>` 加基本图形和路径，颜色用 `currentColor`。不用位图、外链字体、外链脚本；不依赖滤镜。文字不转曲。
- 每个 `symbol` 带 `<title>`，`id` 用 `g-` 加英文语义名。
- 能整段内联进一个离线的单文件 HTML。
- 记号建议用 24 × 24 的网格、1.5 的描边、圆头端点；要改就统一改，并写明。
- 色板是浅色、冷调：干净的白、淡灰蓝、石板色的墨，一种清楚的蓝作强调。不用暖色，不用装饰性渐变，不用嵌套的卡片。具体色值由你定，以 CSS 自定义属性给出。
- 层级靠字号和字重，不靠颜色和框。
- 375 px 宽不出现横向滚动；A4 打印可读；遵守 `prefers-reduced-motion`。

## 5 由你决定的

造型、比例、色值、曲线、时长、组件的具体实现，都由你决定。清单的取舍也由你决定。某一条约束在你的方案里行不通时，写明哪一条、为什么、你怎样处理，不要悄悄绕过。

## 6 交付物

| 文件 | 内容 |
|---|---|
| `glyphs.svg` | 全部记号和关系画法的定义；文件自身打开就是一张带文字标签的总览 |
| `components.html` | 单文件、离线；每个控件一个最小实例和它的状态矩阵 |
| `motion.html` | 单文件、离线；每种运动一个可以播放、可以定格的样张，附 t 的函数 |
| `tokens.css` | 色值、字号、间距、时长的自定义属性 |
| `README.md` | 分两部分。grammar：每一项的含义，与相邻项的区分，什么时候用、什么时候不用，一个正例和一个最容易误用的反例，换了造型也不变的约束。这一版的画法：造型的取舍、可以调的变量，以及重新绘制时至少要保住什么 |
| `checks.md` | 去色、375 px、键盘、减弱动效、无脚本、打印，各自的实际结果；没有做的写“未做” |

样张里的内容用合成的例子，并标明是合成的。

## 7 不做的

- 不安装依赖，不引入框架或现成的图标库，不照搬现成图标集的造型。
- 不发明业务含义，不替某个具体产品画标识。
- 不做深色主题。
- 不把一次样张里的色值或时长写成所有项目的规定；不要求消费者整套采用，也不把某个主题的内容画进记号。
