从题型选择解法

先描述“哪些事实看起来冲突”，再选择方法。下表用常见机制连接案例；题型分组是本书的教学归纳。算法沿用 lookup、Top-K、window、graph、scheduling 等熟悉名称，provider 术语保持原样，技术方案和行业制度的范围在各例说明。

对象、权限、页面与工作完成的关系可先读 企业机制。其中 前端工作面解释表格、表单、详情、工作台、看板、批量动作与设置各自需要的后端契约；工作上下文与工具把这些契约接到 agent 的执行与回写。

题型与方案

识题线索 解法家族 演算入口 下一步查证与反例
一件事显示完成，另一方仍说没完成 分离承诺、执行、接收、资金对象；用明确 guard 连接 H01、V20、V01 列出每个完成状态的确认者及证据，尝试只完成一个子对象
多张单据金额相等，仍无法对账 按来源行、币种、版本匹配；保存差额和调整链 H02、H03、X02 查来源身份和抵销范围，用总额相等但行归属错的输入
数量拆分、部分交付或退回 数量守恒、累计占用、独立实物与资金账 V04、V05、V14 查不可逆交接点，改变一个取消/退货回执的到达次序
输入更正，旧批准或报告是否还能用 冻结输入版本；沿证据依赖求影响集合，再由责任人重判 H07、H09、V03、V09、V15 查签署范围和修订效力，保留旧版批准而替换输入
成员关系结束，权限或费用仍残留 人、成员关系、访问权和结算义务分别建模 H04、V17、X01 查各系统停用与保留规则，用成功停用但账单未结的例子
工作结束，责任尚未被接收 执行证据、恢复探测、接收决定分开；按范围聚合 H05、H06、V16、V20 查谁可以接收及等待原因，取消一个 booking 后再判总完成
同一事件跨日期或迟到后改变结果 半开区间、事件时间窗口、固定口径与修订链 H01、V06、V11、V12、V22 查时区、计费基数和生效日；分别移动发生时间与收到时间
先后顺序可行，资源仍冲突 先求依赖，再加技能、容量、地点和时窗约束 H03、V19、V20、V21 查硬约束；构造两项同时争用一名技师的方案
授权存在，动作仍可能越界 授权绑定范围、动作、输入版本和有效期；效果逐项确认 H08、V02、V18 查撤回与认领边界，给旧版本发送一个迟到动作
配方或设计正确，产物仍不能放行 基线、实际谱系、质量证据与专业决定分开 V07、V08、V10 查实际批次/设备资格，插入一个失效测量或旧解锁命令
估计、预留与实际支付混在一起 按责任维度保存可修订估计、占用与现金效果 V13、V19、V01 查额度或责任规则，保留未知支付占用再重算
请求超时，是否能安全再做一次 持久化操作身份；核对外部结果；明确补偿与人工接管 H01、V12、V18、X01 查 provider 身份与查询能力，让回执在重试后到达

算法索引

每种算法先说明输入、单位、规模和要保持的不变量；复杂度与服务延迟分别验证。案例采用的家族全部列在 机器目录。

家族 何时选择及取舍 方法章与行业演算
lookup / 查找 稳定键找对象；hash 平均 O(1) 或树索引 O(log n) 的前提不同，先保证身份完整 查找与索引；H02、H04、X01
sorting / Top-K 按可解释分数选少量优先项；顺序不能代替授权或运输可行性 顺序与区间；H06、H08、V14
windows / 窗口 累计区间或事件时间；先定义半开边界、迟到和修订 窗口与累计；H01、V06、V11、V22
graph paths / 图路径 来源追溯和影响集合；方向、权限与环决定结果 图与连通；H07、V03、V15、V18
dependencies / scheduling DAG 求先后与关键路径；资源约束须另外加入 依赖与队列；H03、H09、V09、V20
optimization / 优化 在硬约束内比较成本、时间或利用率；启发式不保证全局最优 约束与选择；V04、V19、V20、V21
caches / 缓存 复用读取与计算；键、失效、版本和当前权限一起设计 复用与失效；H07、X01、V16
approximate / 近似 允许量化误差的估计；阈值附近需要精确复核，不能直接授予放行权 近似与检索；V03

先读 技术栈与研究，把一次动作的责任分清，再从数据与恢复条件反推技术栈。下表是案例设计候选，既不描述 provider 内部实现，也不要求 Claude 使用指定框架。

系统需要 候选构件与选择理由 前提与替代 案例入口
版本、数量、金额与唯一操作一起提交 关系数据库、约束、事务、操作账本 先界定本地原子边界；外部效果另用核对与补偿 H01、H02、V04、V19
承受回执重复、迟到与进程恢复 durable outbox/inbox、队列或可恢复 worker 小规模可先用数据库任务表；每项外部效果仍需独立身份 H08、H09、V18、X01
保存文件/测量证据与引用版本 对象存储、内容摘要、关系元数据 hash 判断内容身份，不能替代来源实例、权限、签署或保留义务 H09、V02、V03、V18
查来源和变更影响 邻接关系表、递归查询或图计算 有实际多跳规模再考虑图引擎；先固定边类型与方向 H07、V07、V15
时间容量与资源冲突 区间类型、约束/锁、调度器或求解器 SQLite 合成检查不等于生产隔离；小时容量也不能代替地点时窗 V06、V16、V20、V21
展示状态且承受投影滞后 API + 查询投影 + UI 等待/冲突/重试状态 服务端复核当前权限与版本；界面禁用只是反馈 H06、H09、X01
AI 提供候选或检索结果 检索、模型适配、引用与评估记录 固定分母、留出集、拒绝条件和人工接管；模型输出不自动成为执行授权 H08、V01、V02、X01
