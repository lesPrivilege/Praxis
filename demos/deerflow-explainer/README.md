# DeerFlow 怎样工作 · 交互讲解页

状态：2026-10-12 第一版，可打开、可打印；用户当天目验通过，没有做受众测试。做法已提炼进 Kit，见 [ADR-031](../../docs/decisions/031-stable-terms-and-explainer-page.md)。作品是 [index.html](index.html)，单文件，直接用浏览器打开，不需要服务、安装或网络。执行者：Opus 5.5 主会话负责范围、编排、撰写、制作和裁决；六个 Sonnet 只读代理分区读源码并各写一份底稿；一个 Opus 只读代理做了文字的独立审阅。Luna 在本会话不可用，没有工作记在 Luna 名下。

## 解决什么

读者有工程背景但不再读源码，需要讲清 DeerFlow 的每个局部“为什么需要、怎样工作、默认是什么、何时不适用”，颗粒度以经得起追问为准，不到类名和行号。

## 选定的形式

连续的长页，不做 16:9 幻灯片。读者会按自己的问题跳读和回查，需要可滚动的正文、可展开的细节层和可点选的图；固定画幅会把每个局部压成等大的一页。各章的主图是独立、可步进的图件，将来要成片时可按 [分镜交接](../../kit/write/motion/narrative.md)另做。

| 层 | 内容 | 做法 |
|---|---|---|
| 结论 | 一句话与七条支撑判断 | 页首；每条指向展开它的章 |
| 章 | 十一章实现讲解，每章先给一句话答案 | 主图在前，正文随后；影响判断的默认值和边界留在正文里 |
| 细节 | 33 处折叠的机制说明 | 原生 `details`；侧栏可一键全部展开，打印时自动展开 |
| 回查 | 十二条常见追问、来源与核实范围 | 追问各指回对应章；未核实项和文档与源码的出入单列 |

交互图件八个：系统全景点选、消息行程步进、循环六个位置点选与播放、四种模式与三个开关、skill 三阶段、委派试算、沙箱对照表、记忆队列计时模拟。试算和模拟按源码里的规则与默认值实现；闸门判定表是构造的例子，页面上已标明。

## Kit 消费记录

| 分支 | 取用 | 调整 |
|---|---|---|
| Write / Prose | 成文原理八条；审阅次序；结构文字的独立审阅与独立冷读合并为一轮 | 按用户 2026-10-12 的意见，agent 领域的术语用英文原词（agent、subagent、skill、run、thread、artifact、checkpoint、harness、guardrail），沙箱、中间件、网关等已通行的中文保留；页首交代一次含义。这一条随后进了成文原理第 6 条 |
| Write / Publish | 展项职责（标题、引介、主体、图注、来源）；条件不藏进折叠区 | 来源集中在末章和底稿，正文不逐句挂路径 |
| Write / Shared | 证据底线；改编与新增的标注 | 构造例子和未复现的数字就地标明 |
| Design | 空间编排；状态与可达性；运动判断；[成立程度标记](../../kit/design/foundations/standing.md)；C08、C13–C16、C20、U04–U06；[按属性维持比较](../../kit/design/references/curated/comparison-continuity.md) | 强调色用于“当前选中”，只在澄清时间线上用于“等用户回答”；这与“强调色只留给等人决定”的默认不同，原因是讲解页的主要状态是读者的当前位置。实线框表示默认启动，虚线框表示按配置启动，图例随图 |

审阅裁决：独立审阅给出 40 条意见和一份同概念异名清单。意见表逐条裁决，绝大多数采纳，其中几条改写后采纳（如澄清一节的标题、批处理不自动触发一句）；时间线节点“闸门”保留，因为全篇一致。异名清单里统一了提问与澄清、扩展包、运营者几组；多副本、多实例、多进程没有合并，它们指的是不同的东西。没有留逐条的裁决表。

## 验收

| 项 | 结果 |
|---|---|
| 结构 | 标签闭合、锚点、按钮与面板一一对应：脚本检查通过 |
| 交互 | 八个图件在浏览器里逐个触发并核对结果；控制台无报错 |
| 宽窄 | 1320 px 看图；375 px 无横向溢出（表格在自己的容器里横向滚动） |
| 无脚本 | 面板、步骤说明和模式对照表全部可见 |
| 打印 | A4 共 35 页，细节层自动展开，无空页；没有逐页细读 |
| 文字 | 一轮独立审阅并裁决；术语替换后没有再审 |
| 未做 | 键盘与读屏的完整走查、200% 缩放、真实读者试读、事实的二次抽查（只在主会话核对了配置模板的若干默认值和 IM 的交互方式） |
