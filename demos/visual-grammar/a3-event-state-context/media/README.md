# 成品与字幕

[three-existences.mp4](three-existences.mp4) 为 84 秒 H.264 MP4，1920×1080、30 fps、无音轨、2520 帧。实际输出在独立工作树生成，成片不入 Git；`npm run render` 可重建。[captions.srt](captions.srt) 与 [storyboard.json](storyboard.json) 从同一 model 生成；视频已烧录中文屏幕字幕。

源码包/完整交付包与 Library 独立视频是本轮 deliverable。若只拿源码且未渲染，播放器会明确说明视频未找到，不能据此声称已有成片。
