## 项目体例的局部结论

本次支持「以 demo 项目为消费与复核入口」：README 是当前入口，brief/输入基线、消费摘要、源码、media、evidence 和 rounds 能连回同一对象；Vault 只沿来源链接展开。把 demos 仅当 output 会使可编辑实现、输入与回执分离，本次没有采用。

该项目没有需要重复复制的 reference；原件和外部研究仍在 Vault，Kit 保留可复用契约，本轮不晋升 grammar/recipe/tools。旧材料不迁移、不删除，历史 owner 不改。后续可逐个真实项目补短消费摘要与当前入口；只有出现真实查找断点再搬动文件，先重建链接与许可边界。不能以这一项目证明所有旧轮次都适用，也不把父建议写成全仓强制规范。
