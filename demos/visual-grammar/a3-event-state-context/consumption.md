# 本次消费摘要

从 AGENTS 的「用 Kit 完成一件任务」进入 Kit README，按双媒介任务读取 Write/Motion、Write/Publish 与 Design 的 Composition、Interaction、Motion。先在 demos 工场找到现成题材，再沿 VG-01 的加工 fixture 与 Core Model 定义核对输入。规范没有批量预载给 worker；本轮没有 worker。

| 取用 | 为什么读 | 实际改变 | 结果 / 边界 |
|---|---|---|---|
| Write / Motion / narrative | 将机制变成时间推导 | 每个 beat 一项认知任务，画面与字幕按同一时间模型生成 | 84 秒；1 倍速播放与抽帧验证，原生连续观看仍待屏幕通道恢复 |
| Shared / evidence 与 verification | 转媒介不升级证据身份 | 固定候选契约/合成标签、改编说明、来源与未验项 | 不冒充业务录屏或 Kit 因果证明 |
| Design / encoding | 箭头、颜色与对象应一致 | 事件青绿、状态蓝、上下文金色；同时用文字/ID/线型；过期时切断投影箭头 | 原版本输入可追溯；去色后仍有标签，不宣称 WCAG 全量合规 |
| Design / interaction / states | 重复操作与不可用状态 | 独立时刻、禁用的实验入口、空投影/重放反馈、键盘原生按钮和滑块 | Chromium 实际程序测试通过；真实读屏未验 |
| REF-COMP-001 / 按属性维持比较 | 手机仍需比较同一字段的状态与上下文 | 两列保留、按属性分块，逐字段同时看两值；日志独立堆叠 | 两对象、四状态字段，ctx-B 加一关联证据行；375/390截图目检，没有复制原子样张代码或数据 |
| Prose / grammar 与 review | 说明和字幕保留条件、语体统一 | 先用中文说明关系，再给数学记号；整体版本条件不藏起来 | 不是固定句长或删所有导航；导航与来源依任务保留 |
| VG-01 / fixture、说明 + Core Model | 有明确正常与失败基线 | 匿名化公司；保留事件/值/版本；重做折叠与投影视觉推导 | 改编，非只换皮；旧图形代码、片段和音频均未复用 |
| Remotion 官方 render / interpolate / license | 现有来源卡明确要求选型时重访 | 使用既有 4.0.529 本机依赖，frame/fps驱动；单独确认评估用途许可范围 | 实际渲染成功；无新增依赖、TTS、密钥或付费操作；复用包/字体/浏览器未完整快照 |
| animate 会话技能 | 限制 HTML 控件与叙事运动 | 控件仅短颜色反馈，默认不自动播放；影片运动只表示派生/注意变化 | 未采用春天物理、复杂摄像机、拖拽或营销动效 |

读取视觉语言参考后发现没有与数学机制推导直接匹配的条目，未硬套 Swiss、Bauhaus 等风格名；回到可检验的图形关系。读到宽窄比较参考已够施工，未进入原子样张或 raw Vault。原旧工场面向 Opus 的 prompt 视为历史数据，未加载唤醒 prompt，也未改用强模型设计。

模型自行补全的范围：技术工程、符号、三列布局、尺寸/字阶/颜色、84 秒时长、字幕措辞、控件和测试脚本。Kit 没有提供 Remotion renderer；这些留在项目中，不伪称已有通用工具。不用 Kit 对照、双盲或消融；只能说真实任务发现并采用了上述规则，不能因果证明规则带来增益。

为局部目录编排另按维护路读 Agent、architecture、intake、documentation 与 demo 蓝图；没有发生本轮 Kit 规范补丁。详见 [实际消费与工具轨迹](evidence/consumption-trace.json)。这份 trace 是从本轮可见工具调用整理的简短决策账，不是私有思维链或完整宿主会话导出。
