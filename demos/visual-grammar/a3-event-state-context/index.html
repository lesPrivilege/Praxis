折叠与投影，各守一条边界

折叠：依次读日志，按本例的生效规则更新状态。候选先等待；批准才生效；拒绝保留在历史。版本只在生效变化时增加。

投影：从一个明确版本的状态和相关证据，选择本次任务需要的材料。未选入的字段仍留在状态里。

适用性：本例按整体版本判断上下文是否过期。即使 ctx-A 没选付款，v2 与 v3 不同，决定入口仍暂停。这不是接受授权，也不是所有系统的通用规则。
