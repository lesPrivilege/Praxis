# 出处与取舍

片中每一条事实对应的来源、定位和核对方式。访问日期均为 2026-10-04。“主会话亲核”指写稿的会话自己打开原件读到了这句话或这个数；“代理核查”指只由研究代理读过，细节在对应的笔记里。

## 研究里有、片中没用或改掉的

| 原先的说法 | 处理 | 原因 |
|---|---|---|
| 她是哈佛 MBA 最早的八位女生之一 | 不用 | 哈佛自己的记录是那八位 1963 年入学、1965 年毕业，与她 1963 年毕业对不上 |
| 她上学前在克利夫兰一家铁路公司做秘书 | 不用 | 只有二手报道，雇主对不上 |
| 她被派去帮欧洲顾问用英语写报告 | 改成“在巴黎和杜塞尔多夫见到同样的毛病” | 一手材料没有“用英语”这层意思 |
| 击中机翼的泡沫是 1920 立方英寸 | 改成幻灯片上的原话 | 1920 是泡沫坡道的体积；委员会说当时估计相差 640 倍，事后分析约 400 倍 |
| BLUF 是陆军条例里的术语 | 改成引条例原句 | 2020 年版正文里没有这个缩写 |
| 贝索斯 2004 年邮件“禁用 PPT、六页备忘录” | 不用 | 只有 2015 年媒体转述，原文写的是四页 |
| “Governing thought” 是明托的术语 | 不用，片中只说“塔尖” | 没能在她的网站或可核对的引文里找到 |
| 先说结论已被实验证明更有效 | 不说，改成 c3.5 的如实交代 | 找到的实验没有这样的结果 |
| 明托本人讨论过坏消息或敌意读者的例外 | 不归到她名下 | 没有在可读到的材料里找到 |

## 没有核到原件的地方

- 明托的书本身没有读到合法的全文；书中的措辞和页码都经由二手笔记。片中凡涉及书的内容都按转述处理。
- Miller、Cowan、Li 等、Pöttker、陆军条例由研究代理读过，主会话没有重读。
- 明托的出生年、现况、第一版出版年在来源之间对不上，片中都不提。
