    02

    下一步的四个分支

    补证后的提醒试验、人工整理、写明缺项和暂缓各有前提。前提有材料提示时，可以准备对应的一步；前提不满足或仍然未知时，下一步是补证。暂缓和不做是可以说明理由的业务选择，不等于研究失败。

    分支判读结果

    项目设计 判读规则：准备一步所需的前提全部“有材料提示”时，可以准备；任何一项“不满足”，这一步暂不可行；有一项仍“未知”，记为证据不足。以“或”连接的前提，一项有提示即可。规则和分支措辞都是本项目的操作化，不是作者原文。

    03

    决定者与 agent 的分工

    人确认待作的决定、受影响的人、允许接触的资料和负责裁决的人。agent 在获准材料内整理、比对并标出缺口；它的产物既不能代替人的授权，也不能代替证据。

    人

    • 提供或确认可以改变的决定，以及受影响的人
    • 划定允许接触的资料，指定负责裁决的人
    • 确认范围与专业边界后，再进行获准的研究
    • 作出业务决定，包括不做这个功能

    agent

    • 在获准材料内提出最少的研究未知，匹配方法，标出当前方法答不了的问题
    • 整理来源定位、遗漏和互相冲突的陈述
    • 可以建议不做功能
    • 不假装访谈过人，不补造观察，不自行发送邀请或催单

    私密原件留在获准范围之内；通用表达不携带真实身份或原文。

    04

    问题与方法的匹配

    取证方法随问题而定。等待发生在哪个动作之前，由获准的案例回放区分；发生比例需要有分母和时间窗口的记录；受访者对未来是否使用的表态，不能当作预测。

    合成 错误推理示例 X1

    访谈 5 人→ 4 人说愿意用→ 80% 的订单可自动化

    表态不是采用“愿意用”是受访者的陈述，不是实际使用。
    受访者不是订单总体5 名受访者的回答既没有订单分母，也没有时间窗口。
    意愿不是可自动化边界技术与组织上能否自动化，需要另行判断。
    研究未知相配的取证方式不能单独回答的材料
    等待发生的环节在获准的最近案例中，请实际经办人回放状态变化、依赖与已有提醒发生比例数据
    各类等待的发生比例有分母和时间窗口的记录、计数或对照少量回放或访谈
    提醒对等待的影响定好可比基线、成本与停止条件后的小范围试验意愿表态
    容量、总体发生率、因果收益与问题相配的方法，由相应研究或业务专家判断访谈已完成这一事实

    回放提问示例：“请带我看最近一次未按预期推进的订单，从上一个动作开始，之后发生了什么？”现场提问是取证手段，不能替代研究未知；待检验的解释也不写成诱导式选项。

    05

    方法卡：从功能诉求到待作决定

    收到功能诉求后，先确定要作的决定。每项研究未知都写明它会改变哪个决定、什么材料能支持判断。最小产物是一页业务负责人和研究者都能复核的研究计划，或一份有依据的补证、改方法或停止建议。

    项目设计 下表的字段、状态与催单案例是本项目的操作化，不是作者原文的 schema。方法仍是项目候选，未经真实任务使用。

    记录项要回答什么不合格的替代
    本次决定谁在什么边界内决定启动、改变、暂缓或停止什么只写“了解用户”
    研究未知哪些解释尚待区分，什么新信息会改变选择只问“大家是否喜欢 AI”
    已有材料来源、范围、时间、许可与缺项把方案说明当用户证据
    取证方式哪种观察、回放、访谈、日志或试验能区分解释先定访谈人数，再找理由
    现场提问/动作怎样取得具体经历或获准的工作过程把内部抽象研究问句直接念给人
    证据与推断分开保存观察、当事人陈述和研究者推断，并附定位将 agent 补全的原因写成访谈原话
    下一决定谁接收，材料还不能证明什么，怎样补证或停止因访谈完成就宣告应上线

    这些关系可以反复调整，保留原问题和改动理由。不同解释可以并存，也不要求所有工作遵循同一条线性流程。记录是否完整，与决定和方法是否匹配，分开判断；填满表格不能证明研究计划成立。
