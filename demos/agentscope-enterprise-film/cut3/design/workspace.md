# 工作区与恢复 · 设计卡

两场分别讲 Python Agent Service 的工作区分配与 Java Harness 的恢复能力。独立后端与身份，跨场不把目录、Session 或调用混成一个运行系统。无声；工作区 206 秒、Java 恢复 96 秒。

## 工作区的主角与空间

主角是一份持续存在的 `contract-v3.pdf`，坐落在 W-A 的目录中。左边是会话入口，路径汇合与分叉直接回答“谁看到同一个目录”。PA1 与 PA2 从 Agent A 的同一括线下出发，汇入 W-A；PB1 属于 Agent B，路径落入另一个 W-B。它们不搬运文件。

新分配策略在下方另画 `per_session` / `per_user` 配置对照。新会话编号 PA3、PA4、PA5、PB2 与上方已绑定的 PA1、PA2、PB1 不同。per_session 的路径分别进入两个独立空目录；per_user 的两个 Agent 汇入同一新目录。旧 contract 不出 W-A，也不在对照图重复出现。

后段把配置对照降为背景，从 Session 顶部/底部另接独立 MCP 侧支；原 Session→W-A 文件线始终直达目录，不穿 MCP 盒。Agent 级 Skills 用另一条跨会话括线。原 W-A 外显露 Local 主机边界；无内层“沙箱”盾牌或隔离框。底部用后端选择分叉展示 Docker 挂载、E2B 元数据重连与 K8s Pod/PVC，并在各自位置标明单机/跨节点能力。工作区绑定与闲置回收条件贴近其对应对象。

### 三帧

1. **12 秒 / 变化前**：PA1 的单一路径通向 W-A；目录内有一份 contract。文件是真正主角，说明不占等大面板。
2. **69 秒 / 变化中**：PA2 汇入原 W-A，PB1 分叉到 W-B；一份文件与两条汇入线已能解释默认粒度。
3. **187 秒 / 变化后**：同一目录仍在原位置；主机边界、后端连接和绑定标签已展开。文件共享、资源分区、执行位置三种关系有不同画法。

### 时序与运动

0–24 认目录、文件与 PA1；24–46 PA2 连线延伸到相同目录；46–70 B 会话与独立目录显露；70–94 per_session 的新入口分叉；94–120 per_user 的新入口汇合；120–147 资源端口与技能括线；147–173 Local 主机边界及其他后端配置；173–206 工作区绑定、TTL 与分布式条件。线的路径生长用于解释连接，目录和文件不做飞行副本；采用共享 power3.inOut，所有状态由场内 t 纯函数决定。

### 否决

- 改 isolation 后旧文件飞进新目录，或复制到对照图。
- 用同一个大框同时表示共享目录、MCP 连接和 Skills；同目录被误读为同资源分区。
- Local 周围出现安全盾牌或沙箱边界；所有后端都标成跨节点可达。
- TTL 被表述成文件过期/固定任务时限；workspace_id 只画成每次请求重新计算。
- 说明框比目录和路径更醒目，去掉文字便无法看出共享关系。

## Java 恢复的主角与空间

动作轴从提交、工具派发、外部执行、提交结果到页面观察。同一 J-T1 沿执行轨向右移动，原 turn J-TURN1 固定；checkpoint 与 committed log 位于对应动作下方，外部系统的回执在上方单独一轨。观察连接与执行轴分离，浏览器断连只截断观察线。

### 三帧

1. **12 秒 / 变化前**：同一动作轴上，观察页通过 committed log 的竖直连接显示进度。J-T1 已发出。
2. **42 秒 / 变化中**：进程在外部执行与本地结果提交之间停下。蓝色已执行轨停在外部执行位置，不越过进程断点；断点下面写“本地结果未提交”，上方外部系统保留结果；未知状态留在这段空隙，而非把整条任务打叉。
3. **82 秒 / 变化后**：查询按 J-T1 找到原回执，reconcile 保存已核实结果后，蓝色轨才延伸到“提交工具结果”；观察连接从标题外侧绕接页面。仍是 J-TURN1，显式 resume 后为新 run。原调用不再次穿过派发口。

### 时序与运动

0–18 建立任务/执行/观察三者位置；18–34 浏览器观察线断开再接至已提交日志，执行轴继续；34–53 进程停在派发后、提交工具结果前，暴露未知区；53–71 查询外部原回执，回执返回核对位；71–84 reconcile 写入保存事实，J-T1 留在完成端；84–96 显式 resume，turn 不变/run 更新，条件贴在 checkpoint 边。

### 否决

- 刷新页面让调用再次从提交口出发；读取 log 变成再次 inference。
- checkpoint 与线程、网络请求或工具进度混画。
- 外部结果未知直接显示失败/成功；核对回执时产生新的调用身份。
- “已恢复”掩盖恢复还要求相同工具、凭据与工作文件，以及 writer lease 已释放/过期。
