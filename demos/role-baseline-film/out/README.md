# 成品

| 文件 | 内容 |
|---|---|
| `补充说明.txt` | 《岗位职责与薪酬方案补充说明》全文，可以独立转交；视频放不下的条件和测算口径都在这里 |
| `补充说明.docx`、`补充说明.pdf` | 由 `build/doc.py` 从 txt 编出的 Word 与 PDF：只排标题、段落和一张表，不加视觉效果 |
| `role-baseline.mp4` | 视频，1920×1080、30 帧、H.264 + AAC；生成物，不入库 |
| `captions.vtt` | 字幕，与念白逐字一致；画面底部也有同样的字幕条 |
| [narration.md](narration.md) | 念白文稿，由合成脚本从 `../narration.json` 导出 |
| [screen-text.md](screen-text.md) | 画面上出现过的全部文字，从渲染后的舞台抽出 |
| `timeline.json`、`voice-report.json`、`mix-report.json`、`check-report.json` | 时间线、配音测量值、响度、成片检查结果 |
