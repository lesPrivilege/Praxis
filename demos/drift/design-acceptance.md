## 一项 grammar 增补

变化页的当前值与基线值分别带上自身的完整采集时间，明细栏也保持这层对应。时间取各自观测的 `observed_at`，不以扫描开始时间代替；精度到秒，按当前浏览器时区显示。真实记录缺时间时显示“采集时间未提供”，无法解析时显示“时间未知”，演示缺时间时显示“演示样本”。比较规则与原始记录保持不变。

使用现有读数槽位和次要文字层级，新增 `.reading-time`。宽屏仍为当前／基线相邻两列；窄屏仍按观测项组织两份值及其时间。

## 独立检查发现与修复

| 发现 | 证据 | 修复 |
|---|---|---|
| 来源链接点击框偏小 | 在 390 与 1440 宽度，两条来源链接高度均为 15px | 保留字号和颜色，链接最小高度 24px，并保留长地址换行 |
| 窄屏空值单元格从辅助树消失 | 不支持的系统 DNS 行在 390 宽度只有 3 个非忽略单元格；宽屏为 4 个 | 将 `display:none` 改为仅视觉裁剪，保留空单元格辅助语义 |
| 加大文字间距后观测项按钮缩至 23.5px | 行高覆盖为 1.5 后出现，整行点选仍有效 | 为观测项按钮明确保留 24px 最小高度 |
| 宽屏折叠标题在文字间距压力下缩至 22px | 1181／1440 下的采集披露、数据源对照及方法说明标题 | 明确保留 24px 最小高度，另做键盘开合和尺寸窄检查 |
| 原明细截图位于淡入中间帧 | 正文处于 160ms 淡入过程 | 新截图等待有限动画结束；无限采集中提示单独排除，不通过关闭正常动画取得稳态图 |

点击框测量和辅助树结构检查各自说明一个具体结果，不等于完整 WCAG 或 VoiceOver 验收。

## 流程审阅

1. **观测概览**：首屏读数提前，来源、状态和时间相邻；已隐藏与未知有独立表达。
2. **观测明细**：整行可点选，观测项名保留键盘入口；显隐作用于整页，方法说明按需展开，窄屏返回原行。
3. **观测基线与变化**：参照由独立操作设置；宽窄屏都按属性维持两份读数的对应，新增时间随各自值呈现。
4. **观测来源**：读取方法、字段范围、测量限制和来源地址分列；链接点击区域已修正。精准跳转到所选来源卡另列后续。
5. **观测记录与恢复**：历史身份明确；保留裁剪、独立基线、会话恢复和迟到响应的既有行为回归。

## 验证与证据边界

独立复跑后端 29 项测试、1440×1000 与 390×844 浏览器回归均通过；浏览器外部请求与非预期错误为 0。测试使用合成探针及隔离目录，本轮没有访问使用者在 8765 端口的实例或默认私有记录。

新增时间语义、显隐、宽窄邻接、点击尺寸及辅助树复验通过，稳态截图经过独立查看。证据与可复跑脚本保存在[独立验收目录](evidence/acceptance-20261005/README.md)。

五宽×五视图×显隐×正常／加大间距共 100 组检查，无页面水平溢出或实际文字裁剪，最小字号 12px；该轮保留源码前后相等的哈希。它同时发现宽屏折叠标题在压力条件下仍为 22px，随后补上最小高度，并只复验受影响的 1181／1440 两宽、三种标题、键盘开合和溢出，均通过。两份报告分别保留，未将后续窄检查写成再次运行完整 100 组。最终 JavaScript 语法、差异及仓库一致性检查通过。
