# Drift · 本机环境观测

Drift 以只读采集呈现本机环境、后端请求结果与固定基线的变化。真实采集由本地 Python 服务执行；打开页面只恢复已有记录，点击“开始采集”才发起探测。演示样本保留在独立模式，不产生采集或历史记录。

## 启动与使用

在仓库根目录运行：

```sh
python3 demos/drift/backend.py
```

打开 [本地看板](http://127.0.0.1:8765/)。后端使用 Python 标准库，无需安装依赖，只绑定 `127.0.0.1`。可用 `--port` 指定端口、`--data-dir` 指定仓库外的专用私有数据目录；停止服务按 `Ctrl+C`。

1. 点击“开始采集”，查看逐项进度。一次扫描结束后，失败、未知与不支持的项分别保留；“结束”不表示全部成功。
2. 选择观测项查看来源、时间、耗时与边界。公网 IP、DNS 地址和其他敏感值默认隐藏，可在本页显示；窄屏选行后进入明细，“返回观测列表”回到该行。
3. 在基线页将已完成记录明确设为参照。重新采集创建新记录，不改写基线；只有同一来源、同一方法且完整成功取得的值才比较，未知不计为相同或变化。
4. 在历史页查看先前结果；“用当前记录替换基线”是独立操作。切换“演示样本”可查看构造例子。

## 采集范围与隐私

| 观测 | 实际范围与限制 |
|---|---|
| 本机环境 | OS 家族、版本、架构、时区、语言、后端可读取的代理配置存在性；不导出代理 URL、凭据或其他环境变量。未发现配置不证明 VPN/PAC 未启用 |
| DNS 配置 | macOS 固定 `scutil --dns`，仅取 nameserver 地址；其他 OS 不支持。配置不证明某次请求使用的 resolver |
| 浏览器自报 | 当前页面的时区、语言和 online；不证明外网可达，不是浏览器指纹 |
| ipify / GeoJS | 两个固定 HTTPS 端点分别观测请求出口。ipify 仅 IP；GeoJS 提供 IP/ASN/国家，缺项、私用或保留 ASN 保持未知。逐源保留分歧，不选赢家或合成评分 |
| 固定目标 DNS | 解析 `example.com`、`www.cloudflare.com` 的地址；不检测 DNS resolver 的公网出口 |
| 固定目标 TLS | 向上述目标发起校验证书的 HTTPS HEAD，尝试取该请求的 TLS 版本、cipher、transport peer。遵循系统/环境代理，peer 可能是代理；取不到时不补造结果 |

后端请求与握手不代表浏览器或其他应用的出口，也不提供 JA3、账号风控或地区可用性判断。外部服务会看到发起请求的出口 IP；探针不额外上传本机设置、账号或凭据，不承诺第三方不追踪。

真实记录保存在仓库外的 `~/.local/share/drift/state.json`，目录权限 `700`、文件 `600`。历史保留最近 30 次，固定基线单独保留；重启可恢复，页面自身不使用 localStorage 或浏览器数据库保存真实值。代理 URL、提供方完整回包、headers、trace、城市与坐标不进入保存记录。HTTP 日志不输出观察值或原始异常。默认存储与 `--data-dir` 都拒绝当前仓库内路径。

单次只运行一轮扫描；每个探针以独立子进程施加最多 8 秒截止时间，整轮最多 65 秒，HTTP 响应最多 16 KiB，输入 JSON 最多 8 KiB。超时保留未知，重试另建扫描。服务校验 Host / Origin / CSRF，不开放 CORS；静态文件仅允许 HTML、CSS、JS，不能读取源码、README、目录或任意路径。实际账号操作、系统配置修改、迁移自动化与风险分数均未实现。
