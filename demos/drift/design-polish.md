### 删去与合并

下列内容删去或合并，原因是重复或没有承担信息。需要恢复时从 `git diff` 取回。

- 侧栏的工作区标签（“Local workspace／本机观测空间”与头像字母）、“工作台”小标题和一句标语。模式由顶栏的数据模式选择器和面包屑表达。
- 页头英文眉题、标题后的装饰句点、范围说明右侧的 `LOCAL WORKSPACE`、基线卡的 `REFERENCE OBSERVATION` 和三处装饰图标。
- 来源页与记录页的“阅读提示”栏。两页没有可选中的观测项，明细栏隐藏，内容占满宽度；原提示与页面说明重复。
- 模式徽标在与选择器同义时隐藏，只在“尚未采集”时出现。
- 来源卡原先把字段范围放在标签里、方法与限制是两段无标签的文字，现在是“读取方法／字段范围／测量限制／来源地址”四行。只有 HTTPS 数据源带标签；原先“目标 DNS 解析”“目标 HTTPS / TLS”被标成本机来源，与实际不符，已去掉。

### 文案

导航用两字短名：概览、基线、变化、来源、记录；页面标题用全称：观测概览、观测基线、观测变化、观测来源、观测记录，与交接的视图表一致。概览页原标题“环境观测”改为“观测概览”，`verify.py` 的两处断言随之更新。

查看历史记录时，概况标题原先仍写“本次观测”，现在只有最新一次或进行中的采集写“本次观测”，其余写“历史观测”；当前记录是基线时加“固定基线”标签。页内跳转的箭头统一为“→”，“↗”只留给新窗口打开的来源地址。

独立审阅的裁决见[结构文字审阅](#结构文字审阅)。

## 状态

每种状态有自己的形状和文字，颜色只是重复这层区分。标记在 `.status` 上，由 `phaseKind`、`resultKind` 给出类名。

| 状态 | 标记 | 类名 |
|---|---|---|
| 已观测／相同 | 实心圆点 | `ok`／`same` |
| 等待采集 | 点线空心圆 | `pending` |
| 采集中 | 正文色实心圆点，缓慢明暗 | `running` |
| 未知／不可比 | 实线空心圆 | `unknown`／`unavailable` |
| 不支持 | 短横 | `unsupported` |
| 失败 | 红色菱形，文字同色 | `error` |
| 有变化 | 琥珀色三角，文字同色加粗 | `changed` |

读数里由 Drift 给出的词（已隐藏、未知、未检出配置、部分结果）用界面字体和次要色，实测值用等宽字，两者一眼可分。

界面状态与交接的行为契约逐项对应：连接中、未连接、空历史、无基线、采集中、部分结果、采集失败、会话失效后重新连接、记录已不可用、演示模式。各状态的截图由下节的脚本取得。

## 动效

每段运动对应一次实际的状态变化，减少运动偏好下全部关闭，状态文字本身仍是反馈。

| 运动 | 参数 | 对应的变化 |
|---|---|---|
| 按钮、选择器、折叠标题的底色与字色 | 120 ms ease | 悬停与按下 |
| 明细栏内容淡入 | 160 ms ease-out，不透明度 0.35 → 1 | 读者换选了一行；轮询重绘不触发 |
| 行底色淡出 | 700 ms ease-out，`--arrive-bg` → 行原色 | 同一条记录里这一项的状态或读数刚变。时长短于 850 ms 的轮询间隔，下一次重绘前已经结束 |
| “采集中”标记明暗 | 1200 ms ease-in-out，循环 | 这一项正在采集。重绘时用 `--pulse-offset` 接上原相位，不会每次轮询重头开始 |
| 进度条填充 | 240 ms ease | 采集器报告的已完成任务数变了。进度是 `done / total` 的真实计数，没有估计值 |

视图切换、筛选和显隐没有过渡。

## 没有验证的

- 浏览器原生缩放没有测。720 CSS px 的视口只能说明 1440 px 窗口放大到 200% 时版式会怎样重排，没有经过浏览器的缩放界面，也没有在真实屏幕上看过放大后的文字。
- 读屏没有测。表格在窄屏改成块状排列，行与单元格补了显式的 ARIA 角色，这一点只核对了标记，没有用 VoiceOver 听过。
- 只在 Chromium 上看过。Safari、Firefox 和其他系统没有测；`:has()`（窄屏下隐藏空读数行）在不支持的浏览器里会多显示一行“—”。
- 没有人用过这一版。截图是制作者自己看图的依据；审阅由模型完成。
- 真实采集没有重跑。polish 期间没有向外部数据源发请求，也没有打开使用者的私有记录。已经在运行的后端不需要重启就会提供新的前端文件，但页面要刷新。
- 进度条的填充过渡和“采集中”的明暗只在合成探针下看过单帧，没有按真实采集的速度看完整过程。

## 留给验收的决定

1. 侧栏标语和工作区标签删去了，是否保留由 Astra 或使用者决定。
2. “本地采集器”与“本机服务端”的定名。
3. 交接里列出的 `--quiet`、`--amber-bg`、`--green` 已删；后续字段若需要“正常”色，再按用途加回。
4. 后续字段接入时，读数走 `readingHTML` 的字段表 `fieldLabels`，状态走 `phaseKind`，不需要新增组件。
