# 对两份独立审校的处理

两份审校由没有参与制作的代理完成：[事实审校](review-facts.md)（35 条）和[画面审片](review-visual.md)（31 条）。下面按原编号记录主会话的裁决。编号没有出现的，属于“已知、暂不改”，列在各节末尾。

## 事实审校

| 编号 | 问题 | 处理 |
|---|---|---|
| 1 | “事实一条没少，换掉的只有顺序”与画面不符（有六张卡被剔除，备忘录也没有收全） | 旁白和屏幕文字改为“证据还是那些证据，换掉的是顺序” |
| 2 | 旁白说试点“从 48% 升到 85%”，画面是对照组比较 | 旁白改为“配了辅导的 40 家，启用率是 85%，没配的只有 48%”，备忘录同步 |
| 3、8、9 | 61%/93%、72%、48%、82% 不能同时成立；诊断解释不了单季下跌；“走掉的是……”只靠面板里的一个数 | 案例数字重排：往年到期客户首月启用 94%（续约 91%），这一批 66%（续约 82%），流失客户里 74% 未启用。旁白补了一句“这一批到期的客户，当初用起来的比往年少得多”，并把“四分之三”说出口 |
| 4 | “委员会把事故主要归于组织和管理”说过头 | 改为“组织文化对这次事故的责任，不亚于那块泡沫”，屏幕与出处表同步 |
| 5 | 旁白把 1920 说成“这次脱落的泡沫坡道”的体积 | 改为转述幻灯片：“写的是：坡道体积 1920……” |
| 6 | 标题中译替原文选了一种读法 | 改为直译“隔热瓦击穿方面偏于保守”，标注“直译” |
| 7 | “降价留不住这些客户”超出了证据 | 判断改为“价格解释不了谁走谁留”，全片同步 |
| 10 | 归纳组被称为“同类的判断” | 改为“几条理由并排” |
| 11 | “明托的办法从最底下开始”——书里先讲的是自上而下的做法 | 旁白加了条件：“手里只有材料、还没有答案的时候”；第四章同步为“没有答案的时候，塔要从底下的证据往上搭” |
| 12、19 | “走到同一个顺序上”“同一种读者”没有出处 | 改为“写法里有同一条：要点在前”“三种写法各有来历；相同的一点是，读的人时间少，要点要先到”；屏幕文字同步 |
| 13 | “这个顺序为什么管用”预设了结论；把“主题”等同于“结论” | 章名改为“凭什么先说结论”；新增一句旁白：“不过，开头那个实验给的是主题，不是结论。” |
| 15 | 片尾的塔把 Bransford & Johnson 挂在 Kieras 的结论下面 | 那一格的判断改为“先读到的，定下后面怎么读” |
| 14 | 片尾塔尖去掉了“多半” | 塔尖补上“多半”。片名保留原样，片名不是论断 |
| 16 | “各地的办公室都来借她”去掉了原话里的保留 | 改为“后来，各地的办公室差不多都借过她” |
| 17 | 把 “main point” 说成“结论” | 改为“要点” |
| 18 | “有实验发现……更容易接受”丢了语言和文体 | 改为“荷兰有实验发现，拒绝信先讲理由再给结论，读的人觉得更好懂，也更愿意接受” |
| 20 | “母语各不相同”和 EN/FR/DE 标签没有出处 | 旁白改为“国家不同，毛病相同。那它多半不是语言的毛病”；标签改成国别 UK/FR/DE |
| 21 | “去图书馆……最后自己画出了一个形状”颠倒了原页的先后 | 改为“最后把改报告时反复见到的那个形状想明白了” |
| 22 | “在客户报告中撞见了同一件事” | 改为“在一份份报告里看到了相近的事” |
| 24 | 哈佛授 MBA 给女性一句没有归属 | 改为“还是没几年的事”，与哈佛自己的记录一致 |
| 25 | “这个缩写是明托起的”没有归属 | 改为“按明托自己的说法” |

暂不改：23（第四章的回路用了案例里的变量，属于本片自己的论证，出处表已注明）；26（Lévi-Strauss 的名字）；27–35（标为“成立但脆弱”的各条，保留现状，出处表里有说明）。

## 画面审片

| 编号 | 问题 | 处理 |
|---|---|---|
| H1 | 第二章的证据卡片在约 140 秒里字号远低于下限 | 全景里卡片改为“一张纸条一道横杠”，不再摆读不清的字；卡片本身加宽、字号加大，供分组和近看时读 |
| H2 | 一张卡片的文字被裁切 | 缩短文字，卡片加宽 |
| H3 | 开场骨架的长条碰到右侧文字 | 骨架缩小并左移 |
| H4 | 两处文字贴近右边缘 | 标签移到塔尖右侧；规则说明的取景放宽 |
| M1、M2 | 开场有两段几乎空着的画面 | 实验图表提前入场；时间轴上的年份放大 |
| M3、M4 | 计数被卡片盖住；两处暗场空档 | 计数加底衬并置于最上层；第一批材料提前落下；报告页提前出现 |
| M5、M6 | 两处孤字换行 | 标签不换行；判断框加宽 |
| M7 | 面板上的数字比旁白早出现 | 数值随各自的条形在旁白说到时出现 |
| M8 | 一句关键说明太小太淡 | 放大、加深 |
| M15 | 片尾的塔静止过久 | 缩短 1 秒 |

暂不改：M9–M14 与各条低优先级意见（构图偏重一侧、个别小字、过场的灰帧、章节标的残留、各章顶部部件不统一）。这些不影响理解，留给下一轮。M10 所指的字号实测为 42px，审片是在缩小的联络表上估的。
